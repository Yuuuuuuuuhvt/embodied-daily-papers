### 第二模块：核心架构解释

Lift3D-VLA 的整体架构分为数据预处理、自监督预训练（Stage 1）和监督微调（Stage 2）三个核心流程。

**1. 3D 编码与 2D 模型提升 (2D Model-Lifting)**
模型接收 RGB 图像和 3D 点云。点云通过 Farthest Point Sampling (FPS) 和 KNN 聚类提取局部特征，生成 3D Token。为了复用 2D 视觉编码器（SigLIP + DINOv2），模型利用相机外参将 3D 坐标投影到与相机视角对齐的虚拟平面上，直接提取对应的预训练 2D 位置编码（PE），并与 3D Token 结合输入视觉编码器。

**2. 阶段一：几何中心掩码自编码器 (GC-MAE)**
这是一个纯几何自监督阶段。输入点云被高比例 Mask，视觉编码器仅处理可见 Token。解码器包含两个分支：
- 静态分支：重建当前帧被 Mask 的点云坐标（计算 Chamfer Distance）。
- 动态分支：预测当前可见 Token 在下一帧（未来）的几何位置，强制模型学习物理动态。

**3. 阶段二：层级时序动作建模 (Layer-wise Temporal Action Modeling)**
在监督微调阶段，冻结视觉编码器，微调 LLM（LLaMA2）和动作投影 MLP。模型不依赖 LLM 的最后一层输出所有动作，而是从 LLM 的中深层（如第 20, 24, 28, 32 层）分别提取隐藏状态，每一层负责预测动作块（Action Chunk）中的一个特定时间步。这种设计利用了 Transformer 深层天然关注浅层特征的特性，保证了动作的时序连贯性。

```python
        self.llm = llm # e.g., LLaMA2-7B (32 layers)

        self.static_decoder = TransformerDecoder()
        self.dynamic_decoder = TransformerDecoder()

        self.action_layers = [20, 24, 28, 32] 
        self.action_mlps = nn.ModuleList([nn.Linear(llm.hidden_size, action_dim) for _ in range(num_action_steps)])

        pred_masked_points = self.static_decoder(encoded_features, mask_tokens)
        loss_static = chamfer_distance(pred_masked_points, gt_masked_points_t)

        pred_future_points = self.dynamic_decoder(encoded_features)
        loss_dynamic = chamfer_distance(pred_future_points, gt_visible_points_t_plus_1)
        
        return loss_static + lambda_weight * loss_dynamic

    def forward_stage2_action(self, rgb, point_cloud, language_instruction):
        # 1. Multimodal Encoding
        visual_features = self.vision_encoder(rgb, point_cloud)
        prompt_tokens = self.llm.tokenizer(language_instruction)
        
        # 2. LLM Forward Pass (extracting intermediate hidden states)
        hidden_states = self.llm(visual_features, prompt_tokens, output_hidden_states=True)
        
        # 3. Layer-wise Action Decoding
        action_chunk = []
        for i, layer_idx in enumerate(self.action_layers):
            # Extract hidden state from the specific layer
            layer_hidden = hidden_states[layer_idx]
            # Predict action step t+i
            action_step = self.action_mlps[i](layer_hidden)
            action_chunk.append(action_step)
```

### 第二模块：核心架构解释

SIEVE 的整体流程分为三个明确的阶段：基元发现（Primitive Discovery）、结构曝光度预算分配（Structural Exposure Allocation）和学习友好型轨迹选择（Learning-Friendly Trajectory Selection）。

1. **基元发现：** 利用物理先验（夹爪的开/闭状态翻转）作为自然边界，将长轨迹切分为多个短片段。使用预训练的 V-JEPA2 提取片段的起始、中间、结束帧特征并拼接，通过 PCA 降维后，使用 Mini-Batch K-Means 聚类，得到全局可复用的“基元词表”。
2. **结构曝光度预算分配：** 将每条轨迹映射为基元序列（即组合模式）和基元间的过渡接口。构建一个贪心分配算法，目标函数包含基元曝光度和过渡曝光度，并引入对数项以实现边际效益递减。该算法迭代地将数据预算分配给能带来最大结构多样性增益的组合模式桶（Pattern Bucket）。
3. **学习友好型轨迹选择：** 在获得每个组合模式桶的预算配额后，计算桶内所有轨迹在特征空间中的余弦相似度。选取与其他轨迹相似度总和最高的轨迹作为中心点（Medoid），并优先保留距离该中心点最近的轨迹，从而剔除同一模式下的边缘、异常或高噪声演示。

```python
# SIEVE 核心逻辑伪代码
import numpy as np
from sklearn.cluster import MiniBatchKMeans
from sklearn.decomposition import PCA

def sieve_data_selection(trajectories, budget_size, K_clusters):
    # Stage 1: Primitive Discovery
    all_segments = []
    for traj in trajectories:
        # Segment by end-effector state flips (e.g., grasp/release)
        segments = segment_by_gripper_flips(traj)
        traj.segments = segments
        all_segments.extend(segments)
    
    # Extract features using V-JEPA2 and apply PCA
    segment_features = extract_vjepa2_features(all_segments)
    reduced_features = PCA(n_components=256).fit_transform(segment_features)
    
    # Cluster to find primitives
    kmeans = MiniBatchKMeans(n_clusters=K_clusters).fit(reduced_features)
    
    # Map trajectories to composition patterns (primitive sequences)
    pattern_buckets = {}
    for traj in trajectories:
        traj.primitive_seq = kmeans.predict(traj.get_reduced_features())
        pattern = tuple(traj.primitive_seq)
        if pattern not in pattern_buckets:
            pattern_buckets[pattern] = []
        pattern_buckets[pattern].append(traj)
        
    # Stage 2: Structural Exposure Allocation (Greedy)
    allocation = {pattern: 0 for pattern in pattern_buckets.keys()}
    current_budget = 0
    
    while current_budget < budget_size:
        best_pattern = None
        max_marginal_gain = -float('inf')
        
        # Evaluate marginal gain for adding one trajectory to each pattern
        for pattern in pattern_buckets.keys():
            if allocation[pattern] < len(pattern_buckets[pattern]):
                gain = compute_marginal_gain(pattern, allocation) # Logarithmic utility
                if gain > max_marginal_gain:
                    max_marginal_gain = gain
                    best_pattern = pattern
                    
        allocation[best_pattern] += 1
        current_budget += 1
        
    # Stage 3: Learning-Friendly Trajectory Selection
    selected_dataset = []
    for pattern, count in allocation.items():
        if count == 0:
            continue
        bucket_trajs = pattern_buckets[pattern]
        
        # Compute pairwise cosine similarity within the bucket
        sim_matrix = compute_cosine_similarity_matrix(bucket_trajs)
        
        # Find the medoid (trajectory with highest sum of similarities to others)
        medoid_idx = np.argmax(np.sum(sim_matrix, axis=1))
        
        # Sort trajectories by distance to medoid and select top 'count'
        distances_to_medoid = 1 - sim_matrix[medoid_idx]
        closest_indices = np.argsort(distances_to_medoid)[:count]
        
        selected_dataset.extend([bucket_trajs[i] for i in closest_indices])
        
    return selected_dataset
```

### 第二模块：核心架构解释

Lift3D-VLA 的整体架构分为数据预处理、自监督预训练（Stage 1）和监督微调（Stage 2）三个核心流程。

**1. 3D 编码与 2D 模型提升 (2D Model-Lifting)**
模型接收 RGB 图像和 3D 点云。点云通过 Farthest Point Sampling (FPS) 和 KNN 聚类提取局部特征，生成 3D Token。为了复用 2D 视觉编码器（SigLIP + DINOv2），模型利用相机外参将 3D 坐标投影到与相机视角对齐的虚拟平面上，直接提取对应的预训练 2D 位置编码（PE），并与 3D Token 结合输入视觉编码器。

**2. 阶段一：几何中心掩码自编码器 (GC-MAE)**
这是一个纯几何自监督阶段。输入点云被高比例 Mask，视觉编码器仅处理可见 Token。解码器包含两个分支：
- 静态分支：重建当前帧被 Mask 的点云坐标（计算 Chamfer Distance）。
- 动态分支：预测当前可见 Token 在下一帧（未来）的几何位置，强制模型学习物理动态。

**3. 阶段二：层级时序动作建模 (Layer-wise Temporal Action Modeling)**
在监督微调阶段，冻结视觉编码器，微调 LLM（LLaMA2）和动作投影 MLP。模型不依赖 LLM 的最后一层输出所有动作，而是从 LLM 的中深层（如第 20, 24, 28, 32 层）分别提取隐藏状态，每一层负责预测动作块（Action Chunk）中的一个特定时间步。这种设计利用了 Transformer 深层天然关注浅层特征的特性，保证了动作的时序连贯性。

```python
        return loss_static + lambda_weight * loss_dynamic

    def forward_stage2_action(self, rgb, point_cloud, language_instruction):

        visual_features = self.vision_encoder(rgb, point_cloud)
        prompt_tokens = self.llm.tokenizer(language_instruction)

        hidden_states = self.llm(visual_features, prompt_tokens, output_hidden_states=True)

        action_chunk = []
        for i, layer_idx in enumerate(self.action_layers):

            layer_hidden = hidden_states[layer_idx]
            # Predict action step t+i
            action_step = self.action_mlps[i](layer_hidden)
            action_chunk.append(action_step)
```

### 第二模块：核心架构解释

SIEVE 的整体流程分为三个明确的阶段：基元发现（Primitive Discovery）、结构曝光度预算分配（Structural Exposure Allocation）和学习友好型轨迹选择（Learning-Friendly Trajectory Selection）。

1. **基元发现：** 利用物理先验（夹爪的开/闭状态翻转）作为自然边界，将长轨迹切分为多个短片段。使用预训练的 V-JEPA2 提取片段的起始、中间、结束帧特征并拼接，通过 PCA 降维后，使用 Mini-Batch K-Means 聚类，得到全局可复用的“基元词表”。
2. **结构曝光度预算分配：** 将每条轨迹映射为基元序列（即组合模式）和基元间的过渡接口。构建一个贪心分配算法，目标函数包含基元曝光度和过渡曝光度，并引入对数项以实现边际效益递减。该算法迭代地将数据预算分配给能带来最大结构多样性增益的组合模式桶（Pattern Bucket）。
3. **学习友好型轨迹选择：** 在获得每个组合模式桶的预算配额后，计算桶内所有轨迹在特征空间中的余弦相似度。选取与其他轨迹相似度总和最高的轨迹作为中心点（Medoid），并优先保留距离该中心点最近的轨迹，从而剔除同一模式下的边缘、异常或高噪声演示。

```python
# SIEVE 核心逻辑伪代码
import numpy as np
from sklearn.cluster import MiniBatchKMeans
from sklearn.decomposition import PCA

def sieve_data_selection(trajectories, budget_size, K_clusters):
    # Stage 1: Primitive Discovery
    all_segments = []
    for traj in trajectories:
        # Segment by end-effector state flips (e.g., grasp/release)
        segments = segment_by_gripper_flips(traj)
        traj.segments = segments
        all_segments.extend(segments)
    
    # Extract features using V-JEPA2 and apply PCA
    segment_features = extract_vjepa2_features(all_segments)
    reduced_features = PCA(n_components=256).fit_transform(segment_features)
    
    # Cluster to find primitives
    kmeans = MiniBatchKMeans(n_clusters=K_clusters).fit(reduced_features)
    
    # Map trajectories to composition patterns (primitive sequences)
    pattern_buckets = {}
    for traj in trajectories:
        traj.primitive_seq = kmeans.predict(traj.get_reduced_features())
        pattern = tuple(traj.primitive_seq)
        if pattern not in pattern_buckets:
            pattern_buckets[pattern] = []
        pattern_buckets[pattern].append(traj)
        
    # Stage 2: Structural Exposure Allocation (Greedy)
    allocation = {pattern: 0 for pattern in pattern_buckets.keys()}
    current_budget = 0
    
    while current_budget < budget_size:
        best_pattern = None
        max_marginal_gain = -float('inf')
        
        # Evaluate marginal gain for adding one trajectory to each pattern
        for pattern in pattern_buckets.keys():
            if allocation[pattern] < len(pattern_buckets[pattern]):
                gain = compute_marginal_gain(pattern, allocation) # Logarithmic utility
                if gain > max_marginal_gain:
                    max_marginal_gain = gain
                    best_pattern = pattern
                    
        allocation[best_pattern] += 1
        current_budget += 1
        
    # Stage 3: Learning-Friendly Trajectory Selection
    selected_dataset = []
    for pattern, count in allocation.items():
        if count == 0:
            continue
        bucket_trajs = pattern_buckets[pattern]
        
        # Compute pairwise cosine similarity within the bucket
        sim_matrix = compute_cosine_similarity_matrix(bucket_trajs)
        
        # Find the medoid (trajectory with highest sum of similarities to others)
        medoid_idx = np.argmax(np.sum(sim_matrix, axis=1))
        
        # Sort trajectories by distance to medoid and select top 'count'
        distances_to_medoid = 1 - sim_matrix[medoid_idx]
```

模型将 20 种不同机器人的异构控制信号映射到一个 55 维的规范化向量中（涵盖双臂、夹爪、灵巧手、腰部、头部和移动底盘）。对于特定机器人缺失的自由度，直接采用 Padding 处理。实验表明，采用相对关节位置（relQpos）配合 MeanStd 归一化能够最大化保留长尾修正动作的动态范围。

**2. 无辅助损失的稀疏 MoE 架构 (Sparse MoE Architecture)**
为了在不增加推理计算量的前提下吸收 6 万小时的异构数据，模型在 Action Expert 的 Transformer 块中引入了稀疏 MoE 层。该层包含 1 个共享专家（提取通用物理先验）和多个路由专家（处理具身特异性）。模型摒弃了传统的 Softmax 路由与辅助负载均衡损失，转而采用基于 Sigmoid 的独立亲和度计算，并通过动态调整偏差（Bias）来实现负载均衡，避免了辅助损失对动作回归主任务的干扰。

**3. 时空感知的双查询蒸馏 (Dual-Query Distillation)**
为了让模型具备预测未来的 World Model 能力，模型在视觉和文本 Token 后附加了两个可学习的 Query：$Q_t$（关注当前）和 $Q_{t+T}$（关注未来）。这两个 Query 的输出特征被用于向两个冻结的教师模型进行蒸馏：
- **几何监督**：向 LingBot-Depth 蒸馏，预测当前与未来的深度特征。
- **时序监督**：向因果视频模型 DINO-Video 蒸馏，预测当前与未来的运动感知视频特征。

**核心逻辑伪代码**：

```python
def forward_lingbot_vla(vision_tokens, text_tokens, action_labels, current_frame, future_frame):
    # 1. 附加双查询 Queries (Q_t: 当前状态, Q_t_plus_T: 未来状态)
    queries = [Q_t, Q_t_plus_T] 
    hidden_states = concat([vision_tokens, text_tokens, queries])
    
    # 2. 通过带有无辅助损失 MoE 的 VLA Transformer
    for layer in transformer_layers:
        attn_out = layer.attention(hidden_states)
        
        # 计算无偏路由亲和度 (Sigmoid 替代 Softmax)
        router_logits = layer.router(attn_out)
        affinities = sigmoid(router_logits)
        
        # 负载均衡：加上动态 bias 进行 Top-K 选择
        biased_affinities = affinities + layer.bias
        topk_indices = topk(biased_affinities, K)
        
        # 聚合 Shared Expert 与 Routed Experts
        moE_out = layer.shared_expert(attn_out)
        for k in topk_indices:
            weight = affinities[k] / sum(affinities[topk_indices])
            moE_out += weight * layer.routed_experts[k](attn_out)
            
        # 根据专家负载情况动态更新 bias (EMA 方式)
        layer.update_bias(topk_indices)
        hidden_states = attn_out + moE_out
        
    # 3. 动作预测与主损失计算
    action_preds = action_head(hidden_states)
    action_loss = L2_loss(action_preds, action_labels) # 实验证明 L2 优于 L1
    
    # 4. 双查询蒸馏 (Dual-Query Distillation)
    out_Q_t, out_Q_t_plus_T = extract_query_states(hidden_states)
    
    with torch.no_grad(): # 冻结的教师模型
        depth_t, depth_t_plus_T = LingBot_Depth(current_frame, future_frame)
        video_t, video_t_plus_T = DINO_Video(current_frame, future_frame)
        
    # 几何蒸馏损失 (L1) + 时序动力学蒸馏损失 (MSE)
    loss_depth = L1_loss(proj_depth(out_Q_t), depth_t) + L1_loss(proj_depth(out_Q_t_plus_T), depth_t_plus_T)
    loss_video = MSE_loss(proj_video(out_Q_t), video_t) + MSE_loss(proj_video(out_Q_t_plus_T), video_t_plus_T)
                 
    total_loss = action_loss + lambda_1 * loss_depth + lambda_2 * loss_video
    return total_loss
```

### 第二模块：核心架构解释

OTQL 的整体架构分为两个并行的更新流：价值评估（Critic）与策略演化（Flow Policy）。其核心流程如下：

1.  **数据收集与初始化：** 使用次优的预训练基础策略（Base Policy）在环境中收集少量交互数据，存入回放缓冲区（Replay Buffer）。
2.  **Critic 网络更新：** 从缓冲区采样状态-动作对，使用时序差分（TD）学习更新 Q 网络。由于流模型通常输出动作块（Action Chunks），这里的奖励是动作块内的折扣奖励总和。
3.  **优势加权（Advantage Weighting）：** 对于采样到的动作，利用更新后的 Q 网络计算优势函数（Advantage）。将优势函数作为负能量，通过指数映射转化为权重，高优势动作获得高权重。
4.  **条件最优传输流匹配（wCOT-CFM）：** 
    *   将状态条件（Condition）与噪声/动作拼接，构建增广代价矩阵。
    *   利用上一步算出的权重，对目标动作分布进行重采样/加权。
    *   求解 Minibatch 熵正则化最优传输问题，找到噪声与高优动作之间的最优匹配（Coupling）。
    *   使用该匹配对流模型进行回归训练，迫使其学习直线轨迹。
5.  **推理阶段（带拒绝采样）：** 仅需 2-3 步 Euler 积分生成少量候选动作，利用 Q 网络挑选价值最高的一个执行。

**核心逻辑伪代码 (Python 风格):**

```python
def OTQL_step(buffer, policy_flow, critic_q, target_critic_q, lambda_temp, alpha):
    # 1. 采样 Mini-batch
    states, actions, rewards, next_states = buffer.sample(batch_size)
    
    # 2. 更新 Critic (TD Learning)
    noise = sample_gaussian(batch_size)
    next_actions = policy_flow.euler_integrate(next_states, noise, steps=3)
    target_q = rewards + gamma * target_critic_q(next_states, next_actions)
    current_q = critic_q(states, actions)
    critic_loss = MSE(current_q, target_q)
    update_network(critic_q, critic_loss)
    
    # 3. 计算优势函数与权重 (Advantage Weighting)
    # 实际实现中会生成多个候选动作计算期望 V 值
    v_values = compute_v_value(critic_q, states, policy_flow) 
    advantages = critic_q(states, actions) - v_values
    
    # 限制权重上限以防止有效 Batch Size 崩溃
    weights = torch.clamp(torch.exp(lambda_temp * advantages), max=w_max)
    normalized_weights = weights / weights.sum()
    
    # 4. 构建增广向量并求解最优传输 (wCOT)
    # 将状态条件 alpha * states 拼接到噪声和动作上
    noise_samples = sample_gaussian(batch_size)
    augmented_noise = concat(noise_samples, alpha * states)
    augmented_actions = concat(actions, alpha * states)
    
    # 求解带权重的 Minibatch OT 耦合矩阵
    # source_weights 均匀分布, target_weights 为 normalized_weights
    ot_coupling_matrix = solve_entropic_ot(
        source=augmented_noise, 
        target=augmented_actions, 
        target_weights=normalized_weights
    )
    
    # 5. 根据 OT 耦合矩阵采样匹配对，更新 Flow Policy
    matched_noise, matched_actions = sample_from_coupling(ot_coupling_matrix)
    
    # Flow Matching 损失：迫使向量场拟合直线 (matched_actions - matched_noise)
    t = sample_uniform(0, 1)
    x_t = t * matched_actions + (1 - t) * matched_noise
    predicted_vector_field = policy_flow(t, x_t, condition=states)
    target_vector_field = matched_actions - matched_noise
    
    policy_loss = MSE(predicted_vector_field, target_vector_field)
    update_network(policy_flow, policy_loss)
```

### 第二模块：核心架构解释

MECo-WAM 的架构设计本质是一个非对称的流匹配（Flow Matching）训练框架。其核心流程如下：

1.  **特征初始化：** 视频帧通过 VAE 编码，动作数据通过 MLP 编码，当前与未来帧通过冻结的 VGGT 编码器提取干净的 4D 几何目标特征。
2.  **多专家去噪（训练阶段）：** 模型包含三个并行的 Transformer 专家：视频专家、动作专家和 4D 几何专家。它们共同接收加噪的未来状态，并预测去噪结果。
3.  **衰减掩码注意力（Decayed Read-Mask）：** 在 Transformer 的混合注意力层中，应用一个动态掩码。训练初期，视频和动作的 Query 被允许关注当前帧的 4D 几何 Key；随着训练步数增加，这种允许的概率线性衰减至零。
4.  **动作感知几何蒸馏：** 4D 专家的输出不仅要逼近 VGGT 的特征，还要计算空间关系矩阵和时间演变差异。计算损失时，利用视频 Token 与动作 Token 的注意力权重，赋予与当前动作强相关的视觉区域更高的损失权重。
5.  **纯净推理（部署阶段）：** 移除 4D 专家、VGGT 编码器和所有几何损失计算，仅保留视频和动作专家进行标准的自回归/扩散解码。

**核心伪代码实现逻辑：**

```python
import torch
import torch.nn.functional as F

def meco_wam_training_step(video_tokens, action_tokens, rgb_frames, step, max_decay_steps):
    # 1. 提取冻结的几何目标 (VGGT)
    with torch.no_grad():
        clean_geo_targets = frozen_vggt_encoder(rgb_frames) 
        curr_geo_token = clean_geo_targets[:, 0]
    
    # 2. 构建流匹配的加噪输入
    noisy_video = add_flow_noise(video_tokens)
    noisy_action = add_flow_noise(action_tokens)
    noisy_geo = add_flow_noise(clean_geo_targets)
    
    # 3. 计算衰减概率并生成动态掩码
    decay_prob = max(0.0, 1.0 - (step / max_decay_steps))
    read_geo_active = torch.rand(1).item() < decay_prob
    
    attention_mask = build_base_causal_mask()
    if read_geo_active:
        # 允许 video 和 action 关注 curr_geo_token
        attention_mask = enable_geo_read_edges(attention_mask)
    else:
        # 隔离 4D 分支
        attention_mask = disable_geo_read_edges(attention_mask)
        
    # 4. 多专家 Transformer 前向传播
    # 内部使用 attention_mask 控制信息流
    pred_video, pred_action, pred_geo = multi_expert_transformer(
        noisy_video, noisy_action, noisy_geo, curr_geo_token, attention_mask
    )
    
    # 5. 计算基础流匹配损失
    loss_video = flow_matching_loss(pred_video, video_tokens)
    loss_action = flow_matching_loss(pred_action, action_tokens)
    
    # 6. 动作感知时空几何蒸馏损失
    # 计算视频 token 与动作 token 的相关性权重
    action_aware_weights = compute_action_relevance(pred_video, pred_action)
    
    # 空间关系匹配损失 (加权)
    loss_geo_spatial = compute_relational_loss(pred_geo, clean_geo_targets, action_aware_weights)
    # 时间演变匹配损失 (加权)
    loss_geo_temporal = compute_temporal_change_loss(pred_geo, clean_geo_targets, action_aware_weights)
    
    loss_4d = alpha * loss_geo_spatial + beta * loss_geo_temporal
    
    # 7. 总损失
    total_loss = loss_video + loss_action + loss_4d
    return total_loss

def meco_wam_inference(obs_tokens, instruction):
    # 部署时完全没有 4D 专家和 VGGT
    # 仅使用视频和动作专家进行去噪生成
    pred_action = base_wam_denoise_loop(obs_tokens, instruction, experts=['video', 'action'])
    return pred_action
```

### 第二模块：核心架构解释

Image2Sim 的整体架构分为两个核心阶段：**神经模拟器构建（环境生成）** 与 **自动化数据引擎（轨迹与指令生成）**。

1.  **场景编码与 3D 高斯构建 (Scene Encoding):** 输入位姿 RGB-D 图像，通过双流编码器（DINOv3 提取语义，Detail Encoder 提取几何）提取特征。通过特征上采样器融合后，直接前馈预测出 3D 特征高斯（包含位置、缩放、旋转、不透明度、RGB 和语义特征）。
2.  **投影与单步像素流渲染 (Projection & Pixel Flow Rendering):** 给定目标相机位姿，将 3D 高斯溅射（Splatting）到 2D 空间，得到带有空洞和噪声的投影图（RGB、深度、Alpha、特征）。以此为条件，结合噪声，输入到一个带有 Transformer 瓶颈层和 Alpha 门控跳跃连接（Alpha-Gated Skip Connections）的 U-Net 中。利用连续时间 MeanFlow 匹配，单步生成高保真全景 RGB-D 图像。
3.  **运动模拟与轨迹生成 (Motion Simulation):** 将 3D 高斯场景体素化，结合语义和几何约束（如高度、连通性）构建可通行体素图。使用 NavFn 规划器生成避障路径，并通过纯追踪控制器（Pure-Pursuit）生成平滑的运动学轨迹。
4.  **多模态指令标注 (Instruction Annotation):** 沿轨迹渲染全景观察序列，根据里程计进行语义分块。将“图像-动作”交错序列输入给大型视觉语言模型（Qwen3-VL），生成对齐的自然语言导航指令。

```python
class Image2Sim:
    def __init__(self):
        self.gaussian_encoder = FeedForward3DGS()
        self.pixel_flow_renderer = OneStepPixelFlow()
        self.motion_planner = NavFnPlanner()
        self.vlm_annotator = Qwen3VL()

    def build_scene(self, posed_rgbd_sequence):
        """阶段一：前馈构建 3D 场景底座"""
        # 提取语义与几何特征并预测 3D 高斯属性
        gaussian_scene = self.gaussian_encoder(posed_rgbd_sequence)
        
        # 构建物理碰撞与导航图
        voxel_grid = voxelize(gaussian_scene)
        nav_graph = build_connectivity_graph(voxel_grid)
        return gaussian_scene, nav_graph

    def render_novel_view(self, gaussian_scene, target_pose):
        """阶段二：几何感知的单步生成式渲染"""
        # 1. 物理锚定：将 3D 高斯溅射到目标视角，得到带有置信度(Alpha)的投影
        projected_maps = splatting(gaussian_scene, target_pose) 
        alpha_map = projected_maps['alpha']
        
        # 2. 噪声混合：高置信度区域保留投影，低置信度区域注入大噪声
        noise = sample_gaussian_noise()
        z_src = alpha_map * projected_maps + (1 - alpha_map) * noise
        
        # 3. 单步流渲染：利用 Alpha 门控跳跃连接，补全未观测区域
        high_fidelity_rgbd = self.pixel_flow_renderer(z_src, projected_maps, alpha_map)
        return high_fidelity_rgbd

    def generate_training_data(self, gaussian_scene, nav_graph):
        """阶段三：自动化数据引擎"""
        # 采样长尾目标并规划无碰撞物理轨迹
        start_pose, target_obj = sample_endpoints(nav_graph)
        trajectory = self.motion_planner.plan(start_pose, target_obj, nav_graph)
        
        # 沿轨迹渲染视觉观察
        observations = [self.render_novel_view(gaussian_scene, pose) for pose in trajectory]
        
        # VLM 生成对齐的自然语言指令
        instruction = self.vlm_annotator.generate(observations, trajectory)
        
        return observations, trajectory, instruction
```

### 第二模块：核心架构解释

Point as Skeleton 框架的运行流程分为离线资产构建与在线闭环仿真两个阶段：

1. 离线资产构建：从记录的驾驶日志中提取点云和图像，将其解耦为全局静态背景点云和基于轨迹 ID 的规范化前景实例点云。
2. 闭环仿真交互：在每个仿真时间步，端到端自动驾驶（E2E-AD）规划器输出动作，交通仿真器据此更新自车和其他交通参与者的状态（3D 边界框）。
3. 点云骨架投影：根据更新后的 3D 边界框状态，将前景实例放置回背景中，并投影到当前相机视角，生成彩色图（提供外观线索）和模板深度图（提供几何线索）。
4. Reset-and-Roll 自回归生成：维护一个包含历史帧和当前帧的滚动窗口。在扩散去噪过程中，引入预测的未来布局以增强动态线索；但在进入下一个仿真步前，重置并丢弃受未来条件影响的隐变量，仅保留基于当前确认状态的隐变量。
5. 图像合成与反馈：生成器结合历史帧、当前布局、彩色图和深度图条件，合成当前步的相机观测图像，并将其反馈给规划器用于下一步决策。

```python
    # 1. 骨架投影：生成当前视角的物理锚点
    color_map, depth_map = project_skeleton(point_skeleton, current_layout)
    conditions = concat(current_layout, color_map, depth_map)
    
    # 2. 初始化当前帧隐变量并构建滚动窗口
    current_latent = sample_noise()
    window_latents = append(history_latents, current_latent)
    
    # 3. Reset-and-Roll 扩散去噪
    for t in reversed(range(num_timesteps)):
        # 在第一步去噪后，缓存仅见过当前确认状态的隐变量
        if t == num_timesteps - 1:
            cached_latent = window_latents[-1].clone()
            
        # 引入预测的未来布局以增强动态线索 (Lookahead)
        lookahead_conditions = get_lookahead_conds(forecast_layouts)
        all_conditions = concat(conditions, lookahead_conditions)
        
        # 执行滚动去噪
        window_latents = denoise_step(window_latents, all_conditions, t)
        
    # 4. 提取生成的当前帧图像
    generated_frame = decode(window_latents[-1])
    
    # 5. 重置：丢弃受未来影响的隐变量，返回干净的缓存隐变量用于下一步
    next_history_latents = append(history_latents[1:], cached_latent)
    
    return generated_frame, next_history_latents
```

### 第二模块：核心架构解释

ActionCache 的核心架构分为特征构建、缓存检索、动作生成与缓存管理四个标准流程。其本质是在不改变预训练 VLA 任何权重的前提下，在 VLM 骨干网络与动作头之间插入一个基于键值对（Key-Value）的显存模块。

1. **检索键构建 (Key Construction):** 截取 VLM 骨干网络前向传播产生的输出特征嵌入（Output Embeddings）。为了降低高维特征带来的内存与检索开销，使用一个预先生成的、固定的稀疏三值随机矩阵（Sparse Ternary Random Matrix）将高维特征投影为低维向量，作为当前状态的检索键。
2. **缓存查找 (Cache Lookup):** 计算当前检索键与缓存池中所有历史键的余弦相似度。提取 Top-1 相似度并与预设的命中阈值（Hit Threshold）进行比较。
3. **分支生成 (Branched Generation):** 
    *   **命中 (Hit):** 若相似度大于阈值，提取对应的历史中间动作块（Action Chunk），将其作为初始状态，仅执行极少步数（甚至零步）的流匹配去噪。
    *   **未命中 (Miss):** 若相似度低于阈值，触发回退机制（Fallback），从纯高斯噪声开始执行完整的流匹配多步去噪过程，保证模型在未知场景下的鲁棒性。
4. **缓存填充与更新 (Cache Population and Management):** 在未命中且最终任务执行成功的轨迹中，提取特定去噪步数的中间动作及其对应的检索键存入缓存。当缓存达到容量上限时，采用 LFU（最近最少使用）策略驱逐旧数据，以保留跨任务复用率最高的基础动作。

**核心逻辑伪代码 (Python 风格):**

```python
import numpy as np
import torch

class ActionCache:
    def __init__(self, vlm_dim, key_dim, cache_size, hit_threshold, nfe_hit, nfe_full):
        # 初始化稀疏三值随机投影矩阵 R
        self.R = self._generate_sparse_ternary_matrix(key_dim, vlm_dim)
        self.cache_keys = []
        self.cache_actions = []
        self.hit_threshold = hit_threshold
        self.nfe_hit = nfe_hit
        self.nfe_full = nfe_full
        self.pending_buffer = []

    def _generate_sparse_ternary_matrix(self, d, D, p=0.01):
        # 生成包含 {-1, 0, 1} 的稀疏矩阵用于降维
        R = np.zeros((d, D))
        # 按照概率 p 随机填充 1 和 -1 (省略具体实现细节)
        return torch.tensor(R, dtype=torch.float32)

    def compute_key(self, vlm_output_embeddings):
        # 降维投影: k_t = R * h_t
        return torch.matmul(self.R, vlm_output_embeddings.flatten())

    def retrieve(self, current_key):
        if not self.cache_keys:
            return None, 0.0
        
        # 计算余弦相似度
        keys_tensor = torch.stack(self.cache_keys)
        similarities = torch.nn.functional.cosine_similarity(current_key.unsqueeze(0), keys_tensor)
        max_sim, max_idx = torch.max(similarities, dim=0)
        
        if max_sim >= self.hit_threshold:
            return self.cache_actions[max_idx], max_sim
        return None, max_sim

    def forward_action_head(self, vlm_output_embeddings, action_head_model):
        current_key = self.compute_key(vlm_output_embeddings)
        cached_action, sim = self.retrieve(current_key)
        
        if cached_action is not None:
            # Cache Hit: 使用缓存动作进行少步数热启动
            initial_action = cached_action
            nfe = self.nfe_hit
        else:
            # Cache Miss: 从纯噪声开始全步数生成
            initial_action = torch.randn(action_shape)
            nfe = self.nfe_full
            
        # 执行流匹配去噪过程
        final_action, intermediate_action = action_head_model.denoise(
            initial_state=initial_action, 
            steps=nfe, 
            condition=vlm_output_embeddings
        )
        
        # 若未命中，将中间动作存入待定缓冲区
        if cached_action is None:
            self.pending_buffer.append((current_key, intermediate_action))
            
        return final_action

    def commit_episode(self, success):
        # 仅在回合成功时将 pending_buffer 写入主缓存，并执行 LFU 替换逻辑
        if success:
            self._update_main_cache(self.pending_buffer)
        self.pending_buffer.clear()
```

```python
class AlayaWorldModel:
    def __init__(self, encoder, autoregressive_core, decoder):
        self.encoder = encoder                  # 视觉编码器 (如 VQ-VAE)
        self.core = autoregressive_core         # 核心自回归网络 (如 Transformer)
        self.decoder = decoder                  # 视觉解码器
        self.kv_cache = None                    # 用于推理加速的缓存

    def reset_world(self, initial_frame):
        # 初始化世界状态
        self.kv_cache = self.core.init_cache()
        latent_state = self.encoder.encode(initial_frame)
        return latent_state

    def step(self, current_latent, user_action):
        # 核心机制：基于当前状态和动作，自回归预测下一帧状态
        # user_action 包含复杂指令：移动、施法、攻击等
        action_embedding = self.encode_action(user_action)
        
        # 结合 KV Cache 实现低延迟推理
        next_latent, self.kv_cache = self.core.forward(
            current_latent, 
            action_embedding, 
            self.kv_cache
        )
        
        # 解码为视觉观测帧
        next_frame = self.decoder.decode(next_latent)
        return next_latent, next_frame

# 实时交互循环 (部署端)

while True:

    render_to_screen(frame)                     # 渲染可玩世界
```

本文的系统架构将机器人控制解耦为两个独立但协同的层级：**智能体层（Agent Layer）**与**具身执行层（Embodiment Layer）**。

```python
# Part 1: Visual Defense - Attention Area Mixing (AAM++)
def apply_aam_plus_plus(image, ground_truth, model, threshold_HAA, threshold_LAA):
    # 1. Generate attention map from the model
    attention_map = model.get_attention_map(image)
    
    # 2. Apply Gaussian blur for generalization
    blurred_map = gaussian_blur(attention_map, sigma=1.0)
    
    # 3. Extract High and Low Attention Areas
    mask_HAA = blurred_map > threshold_HAA
    mask_LAA = blurred_map <= threshold_LAA
    
    # 4. Find mismatches with Ground Truth (GT)
    mismatched_regions = []
    for region in get_connected_components(mask_HAA):
        if overlap(region, ground_truth) < acceptable_threshold:
            mismatched_regions.append(get_bounding_box(region))
            
    for region in get_connected_components(mask_LAA):
        if overlap(region, ground_truth) > acceptable_threshold: # Should have attended but didn't
            mismatched_regions.append(get_bounding_box(region))
            
    # 5. Mix mismatched regions into new training images
    augmented_image = mix_regions_into_image(image, mismatched_regions)
    return augmented_image

# Part 2: Textual Defense - Prompt Adversarial Tuning (PAT++)
def train_pat_plus_plus(advlm_model, benign_data, hard_data, alpha=0.6):
    # Initialize learnable defense prompt tokens
    defense_prompt = initialize_learnable_tokens(length=N)
    optimizer = Adam([defense_prompt], lr=1e-3)
    
    for epoch in epochs:
        # Loss for benign examples: maintain normal response
        img_bgn, text_bgn, gt_response_bgn = sample(benign_data)
        full_prompt_bgn = concat(defense_prompt, text_bgn)
        loss_bgn = -log_likelihood(advlm_model(img_bgn, full_prompt_bgn), gt_response_bgn)
        
        # Loss for hard examples: force attention to illusion factors
        img_hard, text_hard = sample(hard_data)
        full_prompt_hard = concat(defense_prompt, text_hard)
        target_goal = "I will focus on the factors affecting the road" # Malicious target
        loss_hard = -log_likelihood(advlm_model(img_hard, full_prompt_hard), target_goal)
        
        # Combined optimization objective
        total_loss = alpha * loss_bgn + (1 - alpha) * loss_hard
        
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
    return defense_prompt
```

### 第二模块：核心架构解释

GEM-Occ 框架将局部证据学习与流式地图构建解耦，其核心流程分为四个阶段：

**1. 局部证据提取 (Local Evidence Extraction)**
输入单帧透视或全景 RGB 图像，通过局部编码器预测深度/点云几何、图像特征、语义逻辑和置信度。

**2. 证据转换 (Evidence Adaptation)**
将像素级预测反投影至世界坐标系。不直接体素化，而是实例化为各向异性的语义高斯图元（占据证据），其协方差沿视线方向对齐以建模深度不确定性。同时，沿视线记录首次命中表面前的射线段，作为自由空间证据。

**3. 因果记忆融合 (Causal Memory Fusion)**
在局部缓存、房间子图和建筑级图中，通过马哈拉诺比斯距离匹配新输入的证据与现有高斯记忆。匹配成功则进行置信度加权更新（中心、协方差、语义）；同时，利用自由空间射线对穿透的高斯图元进行对数赔率（log-odds）惩罚，抑制错误漂浮物。

**4. 占据查询 (Occupancy Query)**
在任意 3D 坐标，通过聚合邻域高斯图元的响应值，计算最终的占据概率与语义分布。

**核心逻辑伪代码 (Python-style)**：

```python
def update_memory(memory, observation, pose):
    # 1. 提取局部几何与语义特征
    depth, semantics, confidence = local_encoder(observation)
    
    # 2. 转换为瞬态证据 (世界坐标系)
    gaussian_evidence = create_gaussian_primitives(depth, semantics, confidence, pose)
    free_space_rays = extract_free_space_rays(depth, pose)
    
    # 3. 占据证据的因果融合
    for g_in in gaussian_evidence:
        match = find_closest_mahalanobis(memory.gaussians, g_in)
        if match:
            # 基于置信度的加权更新
            match.weight += g_in.confidence
            match.center = weighted_merge(match.center, g_in.center)
            match.covariance = moment_consistent_merge(match.cov, g_in.cov)
            match.log_odds += g_in.confidence * DELTA_OCC
        else:
            # 无匹配则插入新图元
            memory.gaussians.append(g_in)
            
    # 4. 自由空间射线惩罚 (可见性感知)
    for ray in free_space_rays:
        intersected_gaussians = find_intersections(memory.gaussians, ray)
        for g_mem in intersected_gaussians:
            # 仅对位于观测到的自由空间内的高斯图元降低占据概率
            g_mem.log_odds -= ray.overlap_weight * DELTA_FREE
            
    # 5. 记忆维护 (控制显存爆炸)
    memory.prune_low_confidence_and_high_uncertainty()
    memory.merge_spatially_overlapping()
    
    return memory
```

问题：自动驾驶车辆（AVs）面临人为破坏导致的摄像头遮挡攻击（VOAs），这会严重影响基于摄像头的感知系统。虽然现有的检测框架可以识别被破坏的图像，但在物理遮挡发生后，如何有效恢复摄像头数据流的实用性以维持下游任务，仍是一个未被充分探索的领域。

### 第一模块：一分钟核心速写

**1. 论文领域：** World Model 增强的具身感知前端（自动驾驶视觉恢复）

**2. TL;DR:** 
REVIVE 提出了一种基于多阶段分类与类型感知路由的图像修复框架，以解决自动驾驶车辆摄像头遭受物理破坏（遮挡攻击，VOAs）导致感知失效的问题，在 BDD100K 数据集及 YOLOv8 目标检测基准上实现了感知召回率的显著恢复与安全兜底。

**3. 研究动机:** 
现存的图像修复方案通常将所有遮挡视为同类问题，盲目应用单一的生成式或经典修复算法。这种做法在自动驾驶场景中存在致命痛点：一是生成模型容易产生看似合理但缺乏物理事实的“幻觉”，危及下游目标检测；二是计算延迟极高，无法满足实时性要求。本文的切入点极为巧妙：放弃“一招鲜”的修复执念，转而采用**类型感知路由（Type-aware Routing）**与**质量门控（Quality Gate）**机制，将轻量级算法用于简单遮挡，将高延迟的生成模型（如 Stable Diffusion）降级为异步分支，并严格拦截任何会降低下游检测性能的修复图像。

**4. 关键数据:**
*   **最具证明效力的数据:** 在对齐参考条件下，直接像素替换（Direct Pixel Replacement）将 YOLOv8l 的召回率从受损状态的 0.588 恢复至 0.967，F1 分数达到 0.970。这证明了在极短时间窗口内（参考帧未发生空间偏移），基于历史真实观测的硬替换是恢复感知最有效的方法。
*   **存疑/暴露局限性的数据:** Stable Diffusion 分支的召回率仅为 0.339（甚至低于未修复时的 0.588），且单帧处理延迟高达 8610ms。这直接暴露了当前基于扩散模型的 World Model 在具身智能实时感知中的致命缺陷：视觉上的高保真度（SSIM 0.731）掩盖了语义事实的丢失，幻觉不仅无助于目标检测，反而会破坏残存的有效特征。

### 第二模块：核心架构解释

REVIVE 框架是一个严格的串行流水线，包含四个核心阶段与一个最终的质量门控模块。其底层逻辑是“先诊断，后分流，再质检”。

1.  **二分类检测 (Binary Detection):** 使用轻量级 CNN 快速判断当前帧是否受到物理破坏。若无破坏，直接放行至下游感知栈，保证零延迟开销。
2.  **多类别模式识别 (Multi-class Classification):** 若检测到破坏，进一步将其分类为 5 种空间拓扑模式（随机、中心向外、自上而下、自下而上、定向）。
3.  **条件分割 (Conditional Segmentation):** 将上一步的类别标签作为条件向量注入 EfficientNet-U-Net，精准输出被遮挡区域的二值掩码。
4.  **类型感知恢复 (Type-aware Recovery):** 
    *   随机散点遮挡 -> 统计参数中值滤波（极低延迟）。
    *   结构化大面积遮挡 -> BLIP 引导的 Stable Diffusion（异步执行，高延迟）。
    *   存在对齐的干净参考帧 -> 直接像素替换（最优解）。
5.  **质量门控 (Quality Gate):** 将修复后的图像送入目标检测器，对比其与未修复图像的检测结果。仅当修复图像没有抑制原有检测（召回率不降）、没有引入大量假阳性，且结构相似度达标时，才将其输出给自动驾驶系统；否则触发降级警告。

**核心逻辑伪代码 (Python 风格):**

```python
def revive_pipeline(current_frame, reference_frame=None):
    # Stage 1: Binary Vandalism Detection
    is_vandalized = binary_classifier.predict(current_frame)
    if not is_vandalized:
        return current_frame, "CLEAN"
        
    # Stage 2: Multi-class VOA Identification
    voa_type = multiclass_classifier.predict(current_frame)
    
    # Stage 3: VOA Segmentation Localization
    mask = unet_segmentation.predict(current_frame, condition=voa_type)
    
    # Stage 4: Type-aware Image Recovery
    recovered_frame = None
    if is_aligned(current_frame, reference_frame):
        # Upper-bound recovery if temporal alignment holds
        recovered_frame = direct_pixel_replacement(current_frame, reference_frame, mask)
    elif voa_type == "RANDOM":
        # Fast statistical filtering for noise-like occlusions
        recovered_frame = adaptive_median_filter(current_frame, mask)
    elif voa_type in ["CENTER_OUT", "TOP_BOTTOM", "BOTTOM_TOP", "TARGETED"]:
        # Asynchronous generative recovery for structured occlusions
        # Note: In real deployment, this runs off the critical path due to ~8.6s latency
        prompt = blip_scene_analysis(current_frame)
        recovered_frame = stable_diffusion_inpaint(current_frame, mask, prompt)
        
    # Stage 5: Quality Gate Evaluation
    if quality_gate_passed(current_frame, recovered_frame):
        return recovered_frame, "RECOVERED"
    else:
        # Fallback: Do not output hallucinated/degraded frames
        return current_frame, "DEGRADED_WARNING"

def quality_gate_passed(original, recovered):
    orig_detections = yolov8.detect(original)
    recov_detections = yolov8.detect(recovered)
    
    recall_maintained = calculate_recall(recov_detections) >= calculate_recall(orig_detections)
    no_excessive_fp = calculate_fp(recov_detections) <= threshold
    ssim_ok = calculate_ssim(original, recovered) >= 0.5
    
    return recall_maintained and no_excessive_fp and ssim_ok
```

### 第三模块：核心学术问答

Q1: 这篇论文试图解决什么核心问题？

A1: 自动驾驶车辆的摄像头在物理世界中极易遭到恶意破坏或环境遮挡（如喷漆、贴纸、泥浆），导致视觉感知系统失效。现有研究多集中于检测这些攻击，而缺乏一种能在严格的实时性约束下，安全、有效地恢复图像语义并支撑下游目标检测任务的系统性框架。

Q2: 作者提出的核心解决方案（创新点）是什么？

A2: 核心创新点是摒弃了单一的图像修复范式，提出了“类型感知路由”与“质量门控”相结合的机制。系统根据遮挡的物理形态（散点或结构化）动态选择修复算法，并在输出前强制进行目标检测级别的逻辑校验。这确保了高延迟的生成模型不会阻塞实时感知，且幻觉生成的错误像素不会污染自动驾驶的决策流。

Q3: 实验设计的关键支撑（或巧妙之处/数据集特点）是什么？

A3: 实验设计的巧妙之处在于其评估指标的降维打击：作者没有停留在传统的图像质量评估（SSIM/PSNR），而是将 YOLOv8 的目标检测召回率（Recall）和 mAP 作为最终的验收标准。数据集方面，作者在 BDD100K 真实驾驶场景上程序化生成了 5 种特定拓扑结构的遮挡掩码，构建了 5000 张图像的训练集和 500 对严格跟踪的测试集，从而能够精确量化“修复前”、“修复后”与“绝对干净”三种状态下的感知差异。

Q4: 这篇论文最显著的贡献点（Top 3）是什么？

A4:
1. 构建了首个端到端的自动驾驶物理遮挡分类与类型感知恢复框架（REVIVE）。
2. 揭示了生成式修复（如 Stable Diffusion）在具身感知中的致命缺陷：视觉逼真度与目标级语义正确性存在严重脱节，且延迟无法满足实时要求。
3. 引入了基于下游任务表现的质量门控机制，从工程落地的角度提供了一个“最坏情况下不低于未修复状态”的安全兜底保证。

Q5: 这项工作在哪些相关研究的基础上做了推进？（列举1-2个最核心的前置工作即可）

A5:
1. 物理对抗攻击与防御研究：如 ShapeShifter (Chen et al., 2018) 和物理遮挡攻击 (Petit et al., 2015)，本文将防御推进到了图像级别的语义恢复。
2. 图像修复与扩散模型：如 LaMa (Suvorov et al., 2022) 和基于 Stable Diffusion 的 Inpainting，本文测试了这些前沿 CV 模型在严苛的自动驾驶闭环中的实际可用性。

Q6: 客观评价：这篇论文的局限性、漏洞或"未讲明的故事"是什么？对后续科研有何启发？

A6: 论文最大的逻辑漏洞在于其性能上限（直接像素替换）建立在一个极度理想化的假设之上：存在一个空间完全对齐的干净参考帧。在自动驾驶的强自车运动（Ego-motion）下，前一帧与当前帧的像素对齐几乎是不可能的，作者自己的位移敏感性测试（偏移 20 像素召回率暴跌）也证明了这一点。此外，测试数据依赖合成掩码，无法完全模拟真实世界中半透明污渍或复杂光影折射的物理特性。对后续科研的启发是：在具身智能中，单视角的时序像素替换是死胡同，未来的 World Model 必须走向多模态/多视角（如利用侧边摄像头或 LiDAR 投影）的交叉参考修复；同时，必须开发无需 Ground Truth 即可运行的无参考质量门控算法（如基于多传感器一致性校验）。
