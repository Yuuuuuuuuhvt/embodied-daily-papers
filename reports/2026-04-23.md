### 第二模块：核心架构解释

ORS 框架的运行流程完全解耦，分为三个独立且递进的阶段。其核心思想是将复杂的积分计算转化为对流匹配模型速度场（Velocity Field）的均方误差计算。

**阶段一：学习占用测度（Occupancy Measure）**
作者使用流匹配（Flow Matching）模型来拟合离线数据集中的占用测度 $d^{\pi_D}(s^+ | s, a)$。该模型学习一个速度场，将标准高斯噪声映射为智能体在执行动作 $a$ 后可能访问的未来状态 $s^+$ 的分布。为了处理轨迹的拼接，这里采用了类似时序差分（TD）的自举（Bootstrapping）损失函数。

**阶段二：提取占用塑造奖励（Occupancy Reward Shaping）**
这是本文最核心的数学转换。计算未来状态分布到目标状态 $g$ 的平方 Wasserstein-2 距离通常需要求解复杂的常微分方程（ODE）。作者在数学上证明了，该距离可以被流匹配模型预测的速度场与目标速度场之间的均方误差（MSE）所上限约束。因此，可以直接训练一个神经网络 $\psi$ 来回归这个误差，作为密集的标量奖励 $r^W(s, a, g)$。

**阶段三：离线策略训练（Policy Training）**
将阶段二学到的密集奖励函数 $r^W$ 替换掉原环境中无用的稀疏奖励，直接插入到任何标准的离线目标条件强化学习算法（如 GCIQL）中进行 Actor-Critic 训练。

```python
def train_occupancy_model(dataset, v_theta, v_theta_target, optimizer):
    s, a, s_next, a_next = dataset.sample_transitions()
    
    # 采样时间 t 和高斯噪声 x_0
    t = uniform(0, 1)
    x_0 = normal(0, I)
    
    # 1. 拟合单步转移 (Next state)
    x_1_next = s_next
    x_t_next = (1 - t) * x_0 + t * x_1_next
    loss_next = MSE(v_theta(t, s, a, x_t_next), (x_1_next - x_0))
    
    # 2. 拟合未来状态 (Future states, bootstrapping)
    x_1_future = sample_from_target_occupancy(v_theta_target, s_next, a_next)
    x_t_future = (1 - t) * x_0 + t * x_1_future
    loss_future = MSE(v_theta(t, s, a, x_t_future), stop_gradient(v_theta_target(t, s_next, a_next, x_t_future)))
    
    # 组合损失并更新
    loss_flow = (1 - gamma) * loss_next + gamma * loss_future
    optimizer.step(loss_flow)

# 阶段 2: 训练奖励函数 (Reward Network r_psi)
def train_reward_function(dataset, v_theta, r_psi, optimizer):
    s, a, g = dataset.sample_state_action_goal()
    
    # 采样时间 t 和高斯噪声 x_0
    t = uniform(0, 1)
    x_0 = normal(0, I)
    
    # 目标状态作为 x_1
    x_1_goal = g
    x_t_goal = (1 - t) * x_0 + t * x_1_goal
    
    # 计算速度场误差作为 Wasserstein 距离的替代
    velocity_error = MSE(v_theta(t, s, a, x_t_goal), (x_1_goal - x_0))
    
    # 训练 r_psi 逼近负的速度场误差
    loss_rew = MSE(r_psi(s, a, g), -velocity_error)
    optimizer.step(loss_rew)

# 阶段 3: 策略训练 (以 GCIQL 为例)
def train_policy(dataset, r_psi, q_network, v_network, policy, optimizers):
    s, a, s_next, g = dataset.sample_transitions_with_goal()
    
    # 使用 ORS 提供的密集奖励替换稀疏奖励
    shaped_reward = r_psi(s, a, g)
    
    # 标准的 GCIQL 更新逻辑
    v_target = expectile_regression(q_network(s, a, g), v_network(s, g))
    q_target = shaped_reward + gamma * v_network(s_next, g)
    
    update_q_and_v_networks(q_target, v_target, optimizers)
    update_policy_via_advantage_weighted_regression(policy, optimizers)
```

DeVI 的核心架构分为三个连续的阶段：场景初始化与视频生成、混合模仿目标提取、以及基于强化学习的物理策略训练。

```python
            sim_obj_2d = project_to_2d(next_state.object_3d, env.camera_matrix)
            r_object = exp(-mse(sim_obj_2d, object_2d_tracks[t]))
            
            # Contact Reward
            r_contact = calculate_contact_reward(next_state.contact_forces, contact_labels[t])
            
            total_reward = r_human * r_object * r_contact
            
            optimizer.store_transition(state, action, total_reward, next_state)
            state = next_state
            
        optimizer.update_policy()
        
    return policy
```

### 第二模块：核心架构解释

ORS 框架的运行流程完全解耦，分为三个独立且递进的阶段。其核心思想是将复杂的积分计算转化为对流匹配模型速度场（Velocity Field）的均方误差计算。

**阶段一：学习占用测度（Occupancy Measure）**
作者使用流匹配（Flow Matching）模型来拟合离线数据集中的占用测度 $d^{\pi_D}(s^+ | s, a)$。该模型学习一个速度场，将标准高斯噪声映射为智能体在执行动作 $a$ 后可能访问的未来状态 $s^+$ 的分布。为了处理轨迹的拼接，这里采用了类似时序差分（TD）的自举（Bootstrapping）损失函数。

**阶段二：提取占用塑造奖励（Occupancy Reward Shaping）**
这是本文最核心的数学转换。计算未来状态分布到目标状态 $g$ 的平方 Wasserstein-2 距离通常需要求解复杂的常微分方程（ODE）。作者在数学上证明了，该距离可以被流匹配模型预测的速度场与目标速度场之间的均方误差（MSE）所上限约束。因此，可以直接训练一个神经网络 $\psi$ 来回归这个误差，作为密集的标量奖励 $r^W(s, a, g)$。

**阶段三：离线策略训练（Policy Training）**
将阶段二学到的密集奖励函数 $r^W$ 替换掉原环境中无用的稀疏奖励，直接插入到任何标准的离线目标条件强化学习算法（如 GCIQL）中进行 Actor-Critic 训练。

**核心伪代码实现逻辑：**

```python
# 阶段 1: 训练基于流匹配的占用测度模型 (Velocity Field v_theta)
def train_occupancy_model(dataset, v_theta, v_theta_target, optimizer):
    s, a, s_next, a_next = dataset.sample_transitions()
    
    # 采样时间 t 和高斯噪声 x_0
    t = uniform(0, 1)
    x_0 = normal(0, I)
    
    # 1. 拟合单步转移 (Next state)
    x_1_next = s_next
    x_t_next = (1 - t) * x_0 + t * x_1_next
    loss_next = MSE(v_theta(t, s, a, x_t_next), (x_1_next - x_0))
    
    # 2. 拟合未来状态 (Future states, bootstrapping)
    x_1_future = sample_from_target_occupancy(v_theta_target, s_next, a_next)
    x_t_future = (1 - t) * x_0 + t * x_1_future
    loss_future = MSE(v_theta(t, s, a, x_t_future), stop_gradient(v_theta_target(t, s_next, a_next, x_t_future)))
    
    # 组合损失并更新
    loss_flow = (1 - gamma) * loss_next + gamma * loss_future
    optimizer.step(loss_flow)

# 阶段 2: 训练奖励函数 (Reward Network r_psi)
def train_reward_function(dataset, v_theta, r_psi, optimizer):
    s, a, g = dataset.sample_state_action_goal()
    
    # 采样时间 t 和高斯噪声 x_0
    t = uniform(0, 1)
    x_0 = normal(0, I)
    
    # 目标状态作为 x_1
    x_1_goal = g
    x_t_goal = (1 - t) * x_0 + t * x_1_goal
    
    # 计算速度场误差作为 Wasserstein 距离的替代
    velocity_error = MSE(v_theta(t, s, a, x_t_goal), (x_1_goal - x_0))
    
    # 训练 r_psi 逼近负的速度场误差
    loss_rew = MSE(r_psi(s, a, g), -velocity_error)
    optimizer.step(loss_rew)

# 阶段 3: 策略训练 (以 GCIQL 为例)
def train_policy(dataset, r_psi, q_network, v_network, policy, optimizers):
    s, a, s_next, g = dataset.sample_transitions_with_goal()
    
    # 使用 ORS 提供的密集奖励替换稀疏奖励
    shaped_reward = r_psi(s, a, g)
    
    # 标准的 GCIQL 更新逻辑
    v_target = expectile_regression(q_network(s, a, g), v_network(s, g))
    q_target = shaped_reward + gamma * v_network(s_next, g)
    
    update_q_and_v_networks(q_target, v_target, optimizers)
    update_policy_via_advantage_weighted_regression(policy, optimizers)
```

### 第二模块：核心架构解释

本文的核心架构建立在统计校准与强化学习的理论桥接之上。其整体流程可拆解为以下四个逻辑步骤：

1. **问题建模（Episodic Sequential Tasks）**：在回合制任务中，VLA 模型在每个时间步 $t$ 预测一个任务成功的置信度 $c_t$，但真实的二元结果 $Y \in \{0, 1\}$ 只有在回合结束（时间步 $T$）时才能观测到。
2. **序列 Brier 分数（Sequential Brier Score）**：将传统的 Brier 分数扩展到时间序列维度，目标是最小化整个轨迹上预测置信度与最终真实结果之间的均方误差 $\mathbb{E}[\sum (c_t - Y)^2]$。
3. **价值函数等价性（Value Function Equivalence）**：作者通过数学推导证明，能够最小化上述序列 Brier 分数的最优置信度 $c_t^*$，精确等于给定当前状态和动作下最终成功的期望 $\mathbb{E}[Y | s_t, a_t]$。在强化学习语境下，这正是以最终结果为奖励的动作价值函数 $Q^\pi(s_t, a_t)$。
4. **时序差分校准（TD Calibration）**：既然最优置信度就是价值函数，模型便无需等待回合结束获取真实 $Y$（蒙特卡洛方法），而是可以直接利用时序差分（TD）学习，通过相邻时间步的置信度自举（Bootstrap）来动态更新和校准网络。

**核心伪代码（Python 风格）：**

```python
# 核心逻辑：利用 TD 学习对 VLA 的置信度（价值）网络进行序列校准
def td_calibration_update(vla_policy, confidence_network, replay_buffer, optimizer, gamma=1.0):
    # 从经验回放池采样一个 batch 的转移数据 (s_t, a_t, r_t, s_{t+1}, done)
    # 对于二元结果任务，r_t 在非终止状态为 0，终止状态为 1(成功) 或 0(失败)
    batch = replay_buffer.sample()
    
    for state, action, reward, next_state, done in batch:
        # 1. 计算当前状态-动作的预测置信度 (即 Q 值)
        current_confidence = confidence_network(state, action)
        
        # 2. 计算 TD 目标 (TD Target)
        if done:
            # 终止状态，目标即为真实的二元结果 (0 或 1)
            td_target = reward
        else:
            # 非终止状态，利用 VLA 策略采样下一步动作，并自举估计下一步的置信度
            next_action = vla_policy.predict_action(next_state)
            next_confidence = confidence_network(next_state, next_action)
            # 核心等价关系：利用下一步的置信度作为当前的校准目标
            td_target = reward + gamma * next_confidence.detach()
            
        # 3. 计算损失 (等价于最小化序列 Brier 分数)
        loss = mse_loss(current_confidence, td_target)
        
        # 4. 反向传播更新置信度网络 (完成一步校准)
        loss.backward()
        optimizer.step()
        
    return confidence_network
```

### 第二模块：核心架构解释

Cortex 2.0 的核心架构实现了一个完整的“观测-想象-评估-执行”闭环。其工作流程可以拆解为以下四个关键步骤：

1. **视觉编码 (Observation Encoding)**：系统首先接收来自机器人摄像头的当前视觉观测，并通过视觉编码器将其压缩为一个低维的视觉潜在状态（Visual Latent State）。
2. **潜在空间推演 (World Model Rollout)**：利用训练好的世界模型（World Model），以当前潜在状态为起点，结合不同的候选动作序列，在潜在空间中自回归地“想象”出多条未来的状态-动作轨迹。
3. **轨迹评分 (Trajectory Scoring)**：将生成的每一条候选轨迹输入到一个价值评分器（Value Scorer）中。评分器根据任务目标，评估该轨迹最终成功的概率以及执行的效率，并输出一个标量分数。
4. **最优执行 (Action Execution)**：系统对比所有候选轨迹的分数，锁定得分最高的那条“最优未来”，并提取该轨迹的第一步动作发送给机器人底层控制器执行。

**核心伪代码实现逻辑**：

```python
class Cortex2:
    def __init__(self, encoder, world_model, value_scorer, action_generator):
        self.encoder = encoder                  # 视觉特征编码器
        self.world_model = world_model          # 世界模型 (预测潜在空间中的下一个状态)
        self.value_scorer = value_scorer        # 价值评分器 (评估轨迹成功率与效率)
        self.action_generator = action_generator# 动作采样器

    def plan_and_act(self, current_obs, task_goal, num_candidates=10, horizon=5):
        # 1. 视觉编码：将当前物理世界的观测映射到潜在空间
        z_current = self.encoder.encode(current_obs)
        
        candidate_trajectories = []
        
        # 2. 潜在空间推演：并行生成多条未来候选轨迹
        for _ in range(num_candidates):
            z_t = z_current
            trajectory = []
            
            for t in range(horizon):
                # 采样一个候选动作
                action = self.action_generator.sample(z_t, task_goal)
                # 世界模型预测执行该动作后的下一个潜在状态
                z_next = self.world_model.step(z_t, action)
                
                trajectory.append((z_t, action))
                z_t = z_next
                
            candidate_trajectories.append(trajectory)
            
        # 3. 轨迹评分：寻找最优未来
        best_score = -float('inf')
        best_action = None
        
        for traj in candidate_trajectories:
            # 评估整条轨迹的预期成功率和效率
            score = self.value_scorer.evaluate(traj, task_goal)
            
            if score > best_score:
                best_score = score
                # 4. 最优执行：仅提取最高分轨迹的当前第一步动作
                best_action = traj[0][1] 
                
        return best_action
```

```python
import torch
import torch.nn as nn

class ProximityEstimator(nn.Module):
    def __init__(self, hidden_size):
        super().__init__()
        # 轻量级线性分类器
        self.classifier = nn.Linear(hidden_size, 1)
        self.sigmoid = nn.Sigmoid()
        
    def forward(self, features):
        return self.sigmoid(self.classifier(features))

def build_midtrain_dataset(vlm_model, vlm_data_loader, vla_data_loader, top_k):
    # 1. 冻结 VLM 提取特征
    vlm_model.eval()
    vlm_features = extract_features(vlm_model, vlm_data_loader) # 负样本
    vla_features = extract_features(vlm_model, vla_data_loader) # 正样本
    
    # 2. 训练邻近度评估器
    estimator = ProximityEstimator(hidden_size=vlm_model.config.hidden_size)
    optimizer = torch.optim.Adam(estimator.parameters(), lr=1e-3)
    criterion = nn.BCELoss()
    
    for _ in range(training_steps):
        # 采样并计算 Loss
        pos_feat = sample(vla_features, batch_size)
        neg_feat = sample(vlm_features, batch_size)
        
        pos_pred = estimator(pos_feat)
        neg_pred = estimator(neg_feat)
        
        loss = criterion(pos_pred, torch.ones_like(pos_pred)) + \
               criterion(neg_pred, torch.zeros_like(neg_pred))
               
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
    # 3. 对海量 VLM 候选数据进行打分
    scores = []
    for batch in vlm_data_loader:
        feat = extract_features(vlm_model, batch)
        score = estimator(feat)
        scores.append((batch, score))
        
    # 4. 筛选 Top-K 样本
    scores.sort(key=lambda x: x[1], reverse=True)
    midtrain_dataset = [item[0] for item in scores[:top_k]]
    
    return midtrain_dataset

def train_vla_pipeline(vlm_model, midtrain_dataset, vla_dataset):
    # 阶段一：VLM 中期训练 (Mid-training)
    vlm_model.train()
    midtrain_optimizer = torch.optim.AdamW(vlm_model.parameters(), lr=5e-5)
    train_model(vlm_model, midtrain_dataset, midtrain_optimizer)
```

### 第二模块：核心架构解释

X-Cache 的核心逻辑在于将计算资源的分配与时间序列上的信息变化率解耦。其架构流程可拆解为以下三个关键机制：

1. **跨块残差缓存 (Cross-Chunk Residual Caching)**：模型在处理连续的视频/状态生成块（Chunks）时，不再丢弃上一 Chunk 的中间计算结果，而是为每个 Transformer Block 维护一个持久化的残差缓存。
2. **双指标门控机制 (Dual-Metric Gating Mechanism)**：在处理当前 Chunk 的某个 Block 时，提取当前输入的“结构与动作感知指纹（structure- and action-aware fingerprint）”。通过计算当前指纹与缓存指纹的差异，独立决定该 Block 是执行完整的注意力/前馈计算，还是直接加上缓存的残差。
3. **KV 缓存污染阻断 (KV Cache Contamination Cut-off)**：自回归模型依赖 KV Cache 生成长序列，如果将带有近似误差的特征写入 KV Cache，误差将永久污染后续生成。X-Cache 识别出负责写入持久化 KV Cache 的特定前向传播（KV update chunks），在这些 Chunk 上强制关闭缓存复用，执行 100% 的全量计算，确保写入的 Keys 和 Values 是绝对干净（Clean）的。

**核心逻辑伪代码（Python 风格）：**

```python
def x_cache_inference(chunks, is_kv_update_chunk_list, threshold):
    """
    chunks: 随时间推移的连续生成块序列
    is_kv_update_chunk_list: 布尔列表，标记当前 chunk 是否用于更新持久化 KV Cache
    """
    residual_cache = {}    # 跨 Chunk 持久化存储 Block 残差
    fingerprint_cache = {} # 跨 Chunk 持久化存储 Block 输入指纹
    
    for chunk_idx, chunk in enumerate(chunks):
        is_kv_update = is_kv_update_chunk_list[chunk_idx]
        hidden_states = chunk.initial_states
        
        for block_idx, block in enumerate(transformer_blocks):
            # 机制 3: 强制全量计算 KV 更新块，阻断误差传播
            if is_kv_update:
                residual = block.compute(hidden_states)
                hidden_states = hidden_states + residual
                # 更新干净的缓存
                residual_cache[block_idx] = residual
                fingerprint_cache[block_idx] = compute_fingerprint(hidden_states, chunk.action)
                continue
                
            # 计算当前 Block 输入的结构与动作感知指纹
            current_fingerprint = compute_fingerprint(hidden_states, chunk.action)
            
            # 机制 2: 双指标门控机制决定是否复用
            if block_idx in residual_cache:
                diff = compare_fingerprints(current_fingerprint, fingerprint_cache[block_idx])
                
                if diff < threshold:
                    # 机制 1: 差异极小，跳过计算，直接复用跨块残差
                    residual = residual_cache[block_idx]
                else:
                    # 差异较大，重新计算并更新缓存
                    residual = block.compute(hidden_states)
                    residual_cache[block_idx] = residual
                    fingerprint_cache[block_idx] = current_fingerprint
            else:
                # 初始 Chunk，全量计算
                residual = block.compute(hidden_states)
                residual_cache[block_idx] = residual
                fingerprint_cache[block_idx] = current_fingerprint
                
            # 应用残差进入下一层
            hidden_states = hidden_states + residual
            
        yield hidden_states
```

### 第二模块：核心架构解释

JoyAI-RA 的核心架构分为数据对齐、模型前向传播与多阶段训练三个核心流程：

**1. 统一动作空间 (Unified Action Space)**
为了让 VLA 模型能同时消化人类视频、仿真数据和真实机器人数据，作者将所有末端执行器（End-Effector）的位姿统一转换到**相机坐标系**下（3D平移 + 3D轴角旋转）。同时，定义了一个超长的固定维度动作向量，涵盖所有可能出现的执行器（左右臂、左右灵巧手等）。对于特定机器人没有的自由度，在计算损失时直接进行 Mask（掩码）处理。

**2. 模型架构 (Model Architecture)**
*   **VLM 骨干:** 接收多视角图像和语言指令，输出包含空间信息的视觉-语言多模态特征表示（以及高维度的子任务文本描述）。
*   **感知-动作专家 (Perception-Action Expert):** 这是一个基于 Perceiver 架构的条件速度场预测器（Conditional Velocity Field Predictor）。它接收 VLM 的特征、当前本体感受状态、时间步 $\tau$ 以及加噪的动作序列，通过流匹配（Flow-matching）机制预测动作的去噪速度（Velocity），从而生成平滑的连续动作块（Action Chunks）。

**3. 多阶段预训练流程 (Multi-stage Training Recipe)**
*   **Stage 1: VLM 共预训练:** 混合通用 VQA、具身 VQA 和离散动作数据，训练模型的视觉理解和空间推理能力（自回归损失）。
*   **Stage 2: VLA 共预训练:** 引入仿真轨迹、真实机器人数据和重定向的人类视频。冻结部分视觉能力，重点通过流匹配损失训练动作专家生成连续动作。
*   **Stage 3: 目标机器人后训练:** 丢弃自回归目标，仅使用目标机器人的数据，端到端微调模型以适应特定的物理部署环境。

核心机制: 让一个大模型（领导者）先预测主臂的完整轨迹，然后将该轨迹作为已知条件输入给第二个大模型（跟随者），让其预测副臂的配合轨迹。

### 第二模块：核心架构解释

BiCICLe 框架摒弃了端到端输出 14 维双臂动作的单体模型思路，将其拆解为两个 7 维单臂动作的序列化预测过程，并辅以推理期优化策略。

**1. 观察与动作的文本化表征 (Serialization)**
系统首先将视觉输入转化为纯文本。通过多视角 RGB-D 相机提取目标物体的 3D 点云，计算质心，并将其映射到 100x100x100 的离散体素网格中。动作空间同样被离散化为 7 维向量（3维体素坐标 + 3维欧拉角分箱 + 1维夹爪开闭状态）。

**2. 阶段一：领导者预测 (Leader Prediction)**
指定一只机械臂为领导者（通常为执行主要操作的臂，如右手）。系统将少样本演示（Demonstrations）中领导者臂的动作序列与当前环境的文本化观察拼接成 Prompt，输入给第一个 LLM 代理。该代理仅负责输出领导者臂的完整未来轨迹。

**3. 阶段二：跟随者预测 (Follower Prediction)**
将阶段一中领导者预测出的完整轨迹，作为额外的环境状态（`leader_arm`）注入到当前观察字典中。第二个 LLM 代理（跟随者）在接收到包含领导者意图的 Prompt 后，生成与之在时空上严格协同的副臂轨迹。

**4. 推理期优化 (Inference-time Refinement)**
- **Arms' Debate (双臂辩论)**: 进行第二轮反向条件预测。领导者根据跟随者的初版轨迹重新规划，跟随者再根据领导者的新轨迹进行微调，解决初始预测中领导者缺乏副臂信息的非对称性缺陷。
- **Best-of-N (多选一裁判)**: 利用 LLM 生成的随机性并行生成 N 个双臂轨迹候选方案，引入第三个 LLM 作为裁判（LLM-as-Judge），根据防碰撞、轨迹匹配度、夹爪逻辑等硬性物理规则进行打分，输出得分最高的轨迹。

```python
import torch.nn as nn

class UltrasoundVLA(nn.Module):
    def __init__(self, vision_backbone):
        super().__init__()
        self.backbone = vision_backbone
        # 参数高效微调模块，用于适配超声图像
        self.tracon_register = TraConRegister() 
        # 跨深度融合头，融合浅层位置与深层语义
        self.cdf_head = CrossDepthFusionHead()  
        # 不确定性感知控制策略
        self.policy_network = UncertaintyAwarePolicy()

    def forward(self, us_image, language_instruction, robot_state):
        # 1. 视觉特征提取与 TraCon 条件注入
        shallow_feats, deep_feats = self.backbone(us_image, condition=self.tracon_register)

        # 2. 针尖追踪：融合跨深度特征输出坐标与不确定性

        # 3. 动作生成：结合语言指令、机器人状态与追踪结果
        action = self.policy_network(
            needle_position,
            tracking_uncertainty,
            language_instruction,
            robot_state
        )

        return needle_position, action, tracking_uncertainty

# 异步 VLA 执行流水线 (概念代码)
def asynchronous_vla_pipeline(model, env):
    while not env.task_completed():

        # 模型前向传播

            env.step(action)
        else:
            env.trigger_safety_stop() # 触发安全悬停或请求人类介入
```

### 第二模块：核心架构解释

EUEA 框架的运行逻辑分为三个核心阶段：技能注入（SFT）、逻辑对齐（GRPO）与闭环执行（Recovery）。

首先，作者构建了针对四项核心技能的多任务数据集：物体感知（识别环境中的相关物体）、任务规划（将长指令拆解为子目标）、动作理解（评估提议动作在当前物理状态下的成功概率）和目标识别（判断最终任务是否达成）。基础 VLM 通过监督微调掌握这些独立技能。
其次，为了防止模型在复杂场景下出现技能间的逻辑冲突（例如：规划模块生成了某动作，但动作理解模块认为该动作不可行），引入 GRPO 算法。通过对同一环境提示采样多个输出，并基于技能间的一致性计算奖励，利用相对优势更新策略，强制模型在内部逻辑上自洽。
最后，在实际部署阶段，智能体在执行动作前会调用“动作理解”技能进行前向校验。若预测失败率高，或“目标识别”发现任务未完成但规划已终止，则触发 Recovery 机制，重新采样替代动作以纠正轨迹。

以下是 EUEA 核心逻辑的伪代码实现：

```python
class EUEA_Agent:
    def __init__(self, vlm_model):
        self.vlm = vlm_model # 预训练的视觉语言模型
        
    def sft_phase(self, skill_dataset):
        # 阶段一：针对四项核心技能进行监督微调
        self.vlm.train(skill_dataset, objective="cross_entropy")
        
    def grpo_phase(self, env_prompts):
        # 阶段二：使用 GRPO 进行技能逻辑一致性对齐
        for prompt in env_prompts:
            # 采样一组预测结果
            responses = self.vlm.sample_group(prompt, group_size=G)
            # 基于四项技能的逻辑一致性计算奖励
            rewards = compute_consistency_reward(responses)
            # 计算组内相对优势
            advantages = (rewards - mean(rewards)) / (std(rewards) + 1e-8)
            # 强化学习策略更新
            self.vlm.grpo_update(responses, advantages)

    def execute_task(self, instruction, env):
        # 阶段三：带恢复机制的闭环执行
        obs = env.get_observation()
        
        while True:
            # 技能 4: 目标识别 (判断是否完成)
            if self.vlm.recognize_goal_completion(obs, instruction):
                break
                
            # 技能 1 & 2: 物体感知与任务规划
            subgoal, target_obj = self.vlm.plan_and_perceive(obs, instruction)
            proposed_action = self.vlm.generate_action(subgoal, target_obj)
            
            # 技能 3: 动作理解 (预测动作成功率)
            success_prob = self.vlm.predict_action_success(obs, proposed_action)
            
            # 恢复机制 (Recovery Step)
            if success_prob < THRESHOLD:
                proposed_action = self.sample_alternative_action(obs, instruction)
                
            obs, reward, done = env.step(proposed_action)
            
            if done:
                break
```
