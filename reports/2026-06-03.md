### 第二模块：核心架构解释

PHASER 的运行流程分为任务边界处的“记忆写入”与新任务训练时的“记忆读取与路由”两个核心环节。

**1. 阶段划分与等额写入 (Phase Decomposition & Intra-Task Allocation)**
当 VLA 完成一个任务的训练后，系统会根据人类标注或 Auto-PC 自动流水线，将该任务的演示轨迹切割为多个语义阶段（如：靠近、抓取、移动）。为了打破长阶段对内存的垄断，PHASER 强制为每一个阶段分配完全相等的帧容量（$K$ 帧）。系统在阶段边界内进行时间下采样，并使用水库采样填满该容量。

**2. 多模态原型构建 (Multi-Modal Prototype Construction)**
在写入阶段数据的同时，系统会为每个阶段 $i$ 提取并缓存一个三模态原型 $P_i = (e^L_i, e^V_i, e^A_i)$，分别代表该阶段的语言指令嵌入、平均视觉特征和归一化的运动学特征。

**3. 干扰感知路由与采样 (Interference-Aware Routing & Inter-Task Sampling)**
在训练新任务的阶段 $k$ 时，系统需要从历史记忆中抽取数据。PHASER 不采用均匀抽取，而是计算历史阶段 $i$ 与当前阶段 $k$ 的干扰分数 $U_{i,k}$。计算逻辑是：如果两者感知上下文（语言+视觉）高度相似，但需要的物理动作（运动学）差异巨大，则说明当前任务的梯度极易覆盖历史任务的权重，该历史阶段获得高优先级。随后通过玻尔兹曼分布将分数转化为采样概率。

**底层逻辑伪代码实现：**

```python
import numpy as np

class PHASER_Buffer:
    def __init__(self, K_frames_per_phase, temperature=0.25):
        self.K = K_frames_per_phase
        self.tau = temperature
        self.memory = {}      # 存储阶段数据
        self.prototypes = {}  # 存储阶段原型 (L, V, A)
        
    def write_to_memory(self, task_id, trajectory, phase_boundaries):
        """任务结束时：阶段等额写入与原型缓存"""
        for phase_id, (start_idx, end_idx) in enumerate(phase_boundaries):
            phase_frames = trajectory[start_idx:end_idx]
            
            # 1. 阶段等额容量分配 (Phase-Centric Allocation)
            # 无论阶段长短，强制采样 K 帧
            sampled_frames = uniform_reservoir_sample(phase_frames, self.K)
            self.memory[(task_id, phase_id)] = sampled_frames
            
            # 2. 缓存多模态原型 (L: 语言, V: 视觉, A: 动作)
            self.prototypes[(task_id, phase_id)] = extract_prototype(sampled_frames)

    def compute_interference(self, hist_proto, curr_proto, alpha=0.5, gamma=0.5):
        """计算历史阶段与当前阶段的干扰分数"""
        # 感知上下文重叠度 (语言与视觉的余弦相似度加权)
        sim_L = cosine_similarity(hist_proto.L, curr_proto.L)
        sim_V = cosine_similarity(hist_proto.V, curr_proto.V)
        S_ctx = alpha * sim_L + (1 - alpha) * sim_V
        
        # 动作散度 (动作差异越大，散度越高)
        D_A = 0.5 * (1 - cosine_similarity(hist_proto.A, curr_proto.A))
        
        # 核心逻辑：上下文越相似且动作越冲突，遗忘风险越高
        U = S_ctx * (D_A - gamma * (1 - D_A))
        return U

    def sample_replay_batch(self, current_phase_proto, batch_size):
        """训练新任务时：基于玻尔兹曼分布的干扰路由采样"""
        hist_keys = list(self.prototypes.keys())
        scores = []
        
        # 零前向传播开销：仅使用缓存的原型进行向量计算
        for key in hist_keys:
            hist_proto = self.prototypes[key]
            u_score = self.compute_interference(hist_proto, current_phase_proto)
            scores.append(u_score)
            
        # 玻尔兹曼温度缩放
        scores = np.array(scores) / self.tau
        probs = np.exp(scores) / np.sum(np.exp(scores))
        
        # 根据计算出的概率分布抽取历史阶段
        selected_phases = np.random.choice(hist_keys, size=batch_size, p=probs)
        
        replay_batch = [sample_random_frame(self.memory[p]) for p in selected_phases]
        return replay_batch
```

### 第二模块：核心架构解释

当前论文提出的部分可观测对抗补丁攻击框架分为两个核心阶段：基于注意力的补丁定位，以及内容感知的补丁优化。

1. **前缀数据收集:** 机器人在无攻击状态下执行前 $K$ 帧，攻击者收集这 $K$ 帧的图像观测、文本指令以及对应的状态-动作轨迹。
2. **阶段一：基于注意力的补丁定位 (Attention-Based Patch Localization):** 攻击者利用 VLA 模型处理第 $K$ 帧图像。提取模型内部的交叉模态注意力矩阵，将文本指令 Token 的注意力权重在图像空间上进行最大值聚合，生成显著性图。通过滑动窗口寻找显著性得分最高的 $s \times s$ 连续区域，生成补丁掩码（Mask），确定补丁的物理放置位置。
3. **阶段二：内容感知补丁优化 (Content-Aware Patch Optimization):** 在确定的掩码区域内，利用前 $K$ 帧数据对补丁像素进行梯度更新。优化目标包含两部分：
    *   **语义破坏 (Semantic Grounding Disruption):** 计算施加补丁前后，指令目标名词在图像上的注意力中心坐标。通过损失函数最大化这两个坐标之间的欧氏距离，迫使模型丢失目标物体。
    *   **轨迹破坏 (Trajectory Smoothness Disruption):** 基于前 $K$ 帧的末端执行器位置拟合三维样条曲线。在空间中采样多个未来运动方向，计算并选出能使轨迹曲率增幅最大的方向。通过损失函数迫使 VLA 在前 $K$ 帧输出的动作向量逼近该高曲率方向。
4. **攻击执行:** 将优化收敛的补丁固定在环境中，干扰机器人从 $K+1$ 帧到任务结束的所有后续决策。

**核心伪代码实现:**

```python
import torch
import torch.nn.functional as F

def generate_adversarial_patch(vla_model, prefix_data, instruction, K, patch_size):
    # prefix_data: list of tuples (image_t, action_t, state_t) for t=1 to K
    image_K = prefix_data[-1][0]
    
    # Stage 1: Attention-Based Patch Localization
    # Extract cross-modal attention map for the last prefix frame
    attention_map = vla_model.get_attention_map(image_K, instruction) 
    saliency_map = aggregate_text_tokens(attention_map) # Shape: [H, W]
    
    # Find top-left coordinate (i, j) for the highest scoring s x s window
    i_star, j_star = find_max_saliency_window(saliency_map, patch_size)
    patch_mask = create_binary_mask(i_star, j_star, patch_size, image_K.shape)
    
    # Initialize patch parameters
    patch = torch.rand_like(image_K, requires_grad=True)
    optimizer = torch.optim.SGD([patch], lr=20.0)
    
    # Stage 2: Content-Aware Patch Optimization
    # Pre-calculate high-curvature target direction based on prefix trajectory
    prefix_states = [data[2] for data in prefix_data]
    target_direction = compute_max_curvature_direction(prefix_states)
    
    for iteration in range(50):
        optimizer.zero_grad()
        total_loss = 0
        
        for t in range(K):
            img_t, clean_action_t, _ = prefix_data[t]
            
            # Apply patch using mask
            patched_img_t = img_t * (1 - patch_mask) + patch * patch_mask
            
            # Forward pass with patched image
            adv_action_t, adv_attention = vla_model(patched_img_t, instruction)
            clean_attention = vla_model.get_attention_map(img_t, instruction)
            
            # 1. Semantic Grounding Disruption Loss
            clean_focus = soft_argmax(clean_attention)
            adv_focus = soft_argmax(adv_attention)
            L_sem = -torch.sum((adv_focus - clean_focus) ** 2)
            
            # 2. Trajectory Smoothness Disruption Loss
            # Cosine similarity between adversarial action and target high-curvature direction
            L_traj = -F.cosine_similarity(adv_action_t, target_direction, dim=0)
            
            # Combine losses
            loss = 1.0 * L_sem + 12.0 * L_traj
            total_loss += loss
            
        total_loss.backward()
        
        # Update patch only within the mask region
        patch.grad *= patch_mask
        optimizer.step()
        
    return patch.detach()
```

### 第二模块：核心架构解释

EvoMemNav 的系统架构围绕“建图-检索-决策-反思”的闭环展开，核心包含三个关键组件：

1.  **VSMGraph (视觉-语义记忆图)**:
    构建了一个“房间-视图-物体”的层级拓扑图。图的节点不是抽象的 3D 坐标，而是**锚点视图 (Anchor Views)**（包含丰富物体的已探索区域）和**前沿视图 (Frontier Views)**（可到达的探索边界）。每个视图节点保留原始 RGB 图像，并附加轻量级的 CLIP 房间标签和 YOLO/SAM 提供的物体可见性标签作为软提示。
2.  **Budgeted Coarse-to-Fine Policy (预算感知的由粗到细策略)**:
    为了避免对庞大记忆库进行昂贵的 VLM 全量推理，策略分为两步：
    *   *Coarse (Explore)*: 利用轻量级标签（房间类型、物体命中率）对候选视图进行分桶和排序，将搜索空间压缩到一个极小的候选集。
    *   *Fine (Search + Verify)*: 仅对压缩后的候选集调用 VLM 进行精准选择。当到达目标视图时，不立即停止，而是触发多视角 STOP 验证，防止过早停止（Premature Stop）。
3.  **RDCMA (反思驱动的持续记忆自适应)**:
    一个无需训练的经验回写机制。在每次子任务结束后，系统会根据 STOP 验证的结果（成功停止或重新选择），更新挂载在图节点上的先验概率（如死胡同风险、锚点可靠性）。这些先验分为短期的 Episode-STM 和长期的 Scene-LTM，直接影响下一次 Coarse 阶段的排序。

```python
            self.vsm_graph.add_node(rgb, current_pose, tags)
            
            # 2. Coarse Stage: 粗筛候选集 (结合图结构与历史先验)
            candidates = self.vsm_graph.get_all_frontiers_and_anchors()
            shortlist = self.coarse_explore(candidates, goal, self.priors)
            
            # 3. Fine Stage: VLM 精搜与决策
            selected_node, confidence = self.vlm.search(shortlist, goal)
            
            if confidence == 'LOW':
                selected_node = force_route_to_frontier(shortlist)
                
            # 4. 移动到目标节点
            current_pose = execute_path_to(selected_node)
            
            # 5. Verify Stage: 多视角验证
            if is_anchor(selected_node):
                verdict = self.vlm.verify_stop(current_pose, goal, self.priors)
                if verdict == 'STOP':
                    # 6. 反思与回写 (自我进化)
                    self.priors.update_success(selected_node, goal)
                    return SUCCESS
                else:
                    self.priors.update_failure(selected_node, goal) # 标记为不可靠
                    continue # 重新进入循环
                    
        return FAILURE
```

### 第二模块：核心架构解释

AgenticRL 的核心架构分为离线闭环训练与在线真机部署两个阶段。其本质是一个由大语言模型驱动的自动化强化学习流水线。

**核心流程解释**：
1.  **多模态任务理解与奖励生成**：系统接收自然语言指令、场景图像以及环境观察空间定义。GPT 识别场景中的关键实体（如门、障碍物），并生成初始的 Python 奖励函数代码。
2.  **策略训练**：将生成的奖励代码嵌入 UAV 仿真环境，使用 PPO（近端策略优化）算法训练无人机飞行策略。
3.  **策略诊断**：在仿真中测试训练好的策略。系统不依赖单一的回合奖励数值，而是记录具体的物理行为指标（如碰撞事件、降落精度、过门成功率），打包成“诊断数据包”。
4.  **奖励自我修正**：GPT 充当 Critic（批评家），分析诊断数据包，识别失败模式（例如“无人机频繁撞墙”），生成修正提示词，并输出更新后的奖励函数代码。重复步骤 2-4 直至满足成功率阈值。
5.  **真机部署**：在真实世界中，使用轻量级 VLM（如 GPT-4o-mini）观察无人机摄像头的实时画面，自动匹配场景库，并调用对应的最优策略执行飞行。

**核心逻辑伪代码**：
```python
def agentic_rl_pipeline(task_text, scene_image, obs_spec, max_iters, target_threshold):
    # 1. 初始奖励生成
    reward_code = vlm_agent.generate_reward(task_text, scene_image, obs_spec)
    best_policy = None
    best_success_rate = -float('inf')

    for k in range(max_iters):
        # 2. 策略训练 (使用 PPO 算法)
        policy = ppo_train(env, reward_code)
        
        # 3. 策略诊断 (收集物理行为指标)
        metrics, success_rate = evaluate_policy(env, policy)
        diagnosis_packet = aggregate_metrics(metrics) # 包含碰撞、偏离等具体失败原因
        
        # 保存最优策略
        if success_rate > best_success_rate:
            best_success_rate = success_rate
            best_policy = policy
            
        # 达到目标成功率则提前终止
        if success_rate >= target_threshold:
            break
            
        # 4. 奖励自我修正 (VLM 分析失败原因并重写代码)
        refinement_prompt = vlm_agent.analyze_failure(diagnosis_packet)
        reward_code = vlm_agent.update_reward(reward_code, refinement_prompt)

    return best_policy

def deploy_to_real_world(camera_feed, task_text, policy_registry):

    scenario_id = vlm_agent.identify_scenario(camera_feed, task_text)
    active_policy = policy_registry.get(scenario_id)
    execute_on_drone(active_policy)
```
