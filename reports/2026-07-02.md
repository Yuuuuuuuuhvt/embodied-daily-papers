### 第二模块：核心架构解释

DART 的核心架构分为四个客观执行阶段，完全在模型的权重参数空间（Weight Space）中进行，不改变 VLA 的前向推理架构。

1. 基础微调阶段：给定一个多任务基础模型，分别使用源域的单样本数据和目标域的单样本数据（两者必须是同一任务）进行行为克隆（BC）微调。将微调后的权重减去基础模型权重，得到源域更新向量和目标域更新向量。
2. 领域向量提取阶段：将目标域更新向量减去源域更新向量。这一步的数学逻辑是消除两个向量中重合的任务特定方向，保留目标域独有的环境偏移方向。
3. 子空间滤波与缩放阶段：对源域和目标域的更新向量进行奇异值分解（SVD）。计算源域左奇异基向量与目标域子空间的重叠能量（Overlap Energy），剔除能量低于动态阈值的源域基向量。随后，利用两个子空间的整体对齐分数对提取出的领域向量进行标量缩放，以抑制未对齐带来的噪声。
4. 模型合并阶段：将经过滤波和缩放的领域向量乘以一个超参数系数，直接加回原始基础模型的权重中，输出最终的适应模型。

```python
# DART 核心逻辑伪代码 (Python-style)
import numpy as np

def compute_update_vector(base_weights, fine_tuned_weights):
    return fine_tuned_weights - base_weights

def subspace_filtering_and_scaling(delta_src, delta_tgt, threshold_ratio):
    # 1. 奇异值分解
    U_tgt, S_tgt, V_tgt = np.linalg.svd(delta_tgt, full_matrices=False)
    U_src, S_src, V_src = np.linalg.svd(delta_src, full_matrices=False)
    
    # 2. 计算子空间对齐分数 (Alignment Score)
    alignment_score = np.linalg.norm(U_tgt @ U_tgt.T @ delta_src) / np.linalg.norm(delta_src)
    
    # 3. 计算源域基向量的重叠能量并进行贪婪过滤
    interaction_matrix = U_tgt.T @ U_src
    overlap_energies = np.linalg.norm(interaction_matrix, axis=0) ** 2
    
    # 筛选出高能量的基向量索引
    valid_indices = overlap_energies >= (threshold_ratio * np.sum(overlap_energies))
    U_src_filtered = U_src[:, valid_indices]
    
    # 4. 重构过滤后的源域更新向量
    delta_src_filtered = U_src_filtered @ U_src_filtered.T @ delta_src
    
    # 5. 提取并缩放领域向量
    domain_vector = delta_tgt - delta_src_filtered
    refined_domain_vector = alignment_score * domain_vector
    
    return refined_domain_vector

def dart_adaptation(base_model, src_data, tgt_data, alpha=0.8):
    # 分别在源域和目标域数据上微调基础模型
    model_src = finetune(base_model, src_data)
    model_tgt = finetune(base_model, tgt_data)
    
    # 获取更新向量
    delta_src = compute_update_vector(base_model.weights, model_src.weights)
    delta_tgt = compute_update_vector(base_model.weights, model_tgt.weights)
    
    adapted_weights = {}
    for layer in base_model.layers:
        # 对每一层执行子空间滤波与领域向量提取
        refined_domain_vec = subspace_filtering_and_scaling(delta_src[layer], delta_tgt[layer])
        
        # 将领域向量注入基础模型
        adapted_weights[layer] = base_model.weights[layer] + alpha * refined_domain_vec
        
    return adapted_weights
```

### 第二模块：核心架构解释

DeWorldSG 的系统架构主要分为四个连续的计算阶段，旨在将原始的 RGB-D 视频流转化为具有时空一致性的高维 3D 语义场景图。

**1. 统一表示空间**

```python
    # Encode multimodal inputs into a shared hidden context
    context = vlm_encoder(images, language, state, tactile_history)
    
    # 2. Tactile-Action Manifold-Preserving Gating (MPG)
    # Compute discrepancy between context and clean anchors using Sliced Wasserstein Distance
    discrepancy_act = compute_swd(context, clean_action_anchor)
    discrepancy_tac = compute_swd(context, clean_tactile_anchor)
    joint_discrepancy = 0.5 * (discrepancy_act + discrepancy_tac)
    
    # Generate reliability gate
    gate = exp(-joint_discrepancy / tau)
    
    # Modulate residual enhancement to stabilize predictions
    enhanced_context = context + lambda_weight * stop_gradient(gate) * residual_net(context)
    
    # 3. Dual-Expert Velocity Prediction (Flow Matching)
    # Action Expert predicts action velocity
    action_velocity = action_expert(noisy_action, flow_time, enhanced_context)
    
    # Tactile Expert predicts tactile velocity (World Model dynamics)
    tactile_velocity = tactile_expert(noisy_tactile, flow_time, enhanced_context)
    
    return action_velocity, tactile_velocity

def compute_loss(action_velocity, target_action_vel, tactile_velocity, target_tactile_vel):

    loss_tac = mse_loss(tactile_velocity, target_tactile_vel)
```

### 第二模块：核心架构解释

本文并非提出单一的神经网络架构，而是对整个 World Action Models (WAM) 赛道进行了架构级的解构与重组。其核心逻辑分为两个层级：

**层级一：世界模型（WM）的表征空间划分**
1. **观测空间模型（Observation-space WMs）**：直接在像素（Pixels）或点云（Point Clouds）级别进行未来预测。视觉保真度极高，但空间结构和物理可解释性较弱，控制可用性低（难以直接提取物理状态）。
2. **状态空间模型（State-space WMs）**：在隐变量（Latent vectors）或以物体为中心（Object-centric）的低维空间进行预测。物理可解释性和控制可用性强，但难以泛化到开放世界的复杂视觉场景。

**层级二：世界动作模型（WAM）的四大执行范式**
为了将上述 WM 的预测能力转化为机器人的 Action，作者总结了四种架构级融合方法：
1. **先想象后执行（Imagine-then-execute）**：利用 WM 在隐空间或视觉空间中展开多步未来预测，结合奖励函数或代价函数，通过模型预测控制（MPC）或树搜索寻找最优动作序列。
2. **视频特征条件动作预测（Video-feature-conditioned action prediction）**：WM 先生成未来视频/观测，随后将这些生成的未来表征作为额外输入（Condition），喂给一个独立的策略网络（Policy）来输出动作。
3. **联合视频-动作建模（Joint video-action modeling）**：将视觉观测和动作全部 Token 化，使用单一的 Transformer 进行自回归生成，同时预测未来的视频帧和对应的动作序列（类似 VLA 的扩展版）。
4. **辅助视频预测（Auxiliary video prediction for policy learning）**：不直接在推理阶段使用视频生成，而是在策略训练阶段，将未来视频预测作为辅助损失函数（Auxiliary Loss），迫使策略网络的表征学习到环境的动态变化。

**核心逻辑伪代码（Python 风格）：**

```python
class WorldActionModelTaxonomy:
    def __init__(self, world_model, policy_network):
        self.wm = world_model        # 预测未来状态/观测
        self.policy = policy_network # 输出物理动作

    def paradigm_1_imagine_then_execute(self, current_state, candidate_actions):
        """范式1：基于模型预测控制 (MPC) 的想象与执行"""
        best_action = None
        highest_reward = -float('inf')
        for action_seq in candidate_actions:
            # 在世界模型中展开未来
            predicted_states = self.wm.rollout(current_state, action_seq)
            reward = evaluate_trajectory(predicted_states)
            if reward > highest_reward:
                highest_reward = reward
                best_action = action_seq[0]
        return best_action

    def paradigm_2_feature_conditioned(self, current_obs):
        """范式2：基于未来视频特征的动作预测"""
        # WM 预测未来观测特征
        future_features = self.wm.predict_future_features(current_obs)
        # Policy 结合当前观测与未来特征输出动作
        action = self.policy(current_obs, condition=future_features)
        return action

    def paradigm_3_joint_modeling(self, context_tokens):
        """范式3：联合视频-动作自回归建模"""
        # 单一 Transformer 同时输出下一个观测 Token 和动作 Token
        next_obs_token, action_token = self.wm.autoregressive_generate(context_tokens)
        action = decode_to_continuous_action(action_token)
        return action

    def paradigm_4_auxiliary_learning(self, current_obs, action, next_obs_gt):
        """范式4：作为表征学习辅助任务（仅训练阶段）"""
        # 主任务：动作预测损失
        pred_action = self.policy(current_obs)
        action_loss = compute_loss(pred_action, action)
        
        # 辅助任务：未来观测预测损失
        pred_next_obs = self.wm(current_obs, action)
        aux_loss = compute_loss(pred_next_obs, next_obs_gt)
        
        total_loss = action_loss + lambda_weight * aux_loss
        total_loss.backward()
```

### 第二模块：核心架构解释

3DPWM 的架构分为三个主要阶段：点云获取与补全、动力学预测、基于模型的规划。

1. 点云获取与补全 (Point Cloud Completion)
系统首先构建当前环境的完整 3D 观测。对于机器人本体，通过读取关节角度并结合 URDF 模型，利用正向运动学直接采样得到末端执行器的完整点云。对于场景物体，系统接收单视角 RGB-D 图像，利用 SAM3 进行实例分割，反投影深度图得到物体的局部点云。随后，将局部点云输入至点云补全网络，输出物体的完整点云。最后将机器人点云与物体点云合并，形成当前时间步的完整场景点云。

2. 3D 点云动力学模型 (Point Dynamics Model)
动力学模型以 Point Transformer V3 (PTV3) 为骨干网络。输入特征包含每个点的空间坐标、当前速度和上一时间步速度。在特征提取的瓶颈层，系统将机器人动作向量通过 MLP 编码，并与一个可学习的寄存器 Token (Register Token) 拼接，作为交叉注意力机制的 Key 和 Value；点云特征作为 Query。这种设计强制与动作相关的点（如机器人本体）关注动作指令，而与动作无关的点（如静止的背景物体）关注寄存器 Token。随后通过自注意力层传播动作影响，最终由解码器预测每个点在下一时间步的速度，并据此更新点云位置。

3. 训练与规划 (Training & Planning)
训练阶段，模型在仿真环境中获取具有精确点对点对应关系的完整点云，直接使用 Huber 损失函数对多步自回归推演的逐点速度进行强监督。规划阶段，采用 MPPI (Model Predictive Path Integral) 算法，在补全的点云观测空间中直接定义代价函数，通过动力学模型进行大量轨迹采样和推演，输出最优动作序列。

```python
# 3DPWM 核心逻辑伪代码
def point_cloud_completion(rgbd_image, joint_angles, robot_urdf):
    # 1. 获取机器人本体完整点云
    robot_points = forward_kinematics(joint_angles, robot_urdf)
    
    # 2. 获取场景物体完整点云
    masks = SAM3_segmentation(rgbd_image.rgb)
    partial_object_points = backproject(rgbd_image.depth, masks)
    complete_object_points = point_completion_network(partial_object_points)
    
    # 3. 融合场景
    scene_points = merge(robot_points, complete_object_points)
    return scene_points

def dynamics_model_step(scene_points, point_features, action, register_token):
    # point_features 包含 [坐标, 当前速度, 上一步速度]
    
    # 1. PTV3 编码器提取特征
    z = PTV3_encoder(scene_points, point_features)
    
    # 2. 动作条件注入 (Cross-Attention)
    action_emb = MLP(action)
    keys_values = concat(action_emb, register_token)
    z_act = CrossAttention(query=z, key=keys_values, value=keys_values)
    
    # 3. 特征传播与解码
    z_out = SelfAttention(z_act)
    point_features_out = PTV3_decoder(z_out)
    
    # 4. 预测下一步速度并更新位置
    predicted_velocities = MLP_head(point_features_out)
    next_scene_points = scene_points + predicted_velocities
    
    return next_scene_points, predicted_velocities

def train_step(initial_points, initial_features, action_sequence, ground_truth_velocities, horizon=15):
    loss = 0
    current_points = initial_points
    current_features = initial_features
    
    # 多步自回归训练
    for h in range(horizon):
        action = action_sequence[h]
        current_points, pred_vel = dynamics_model_step(current_points, current_features, action)
        
        # 直接计算点对点速度的 Huber Loss，替代 Chamfer 距离
        loss += HuberLoss(pred_vel, ground_truth_velocities[h])
        
        # 更新特征用于下一步推演
        current_features = update_features(current_points, pred_vel)
        
    return loss / horizon
```

### 第一模块：一分钟核心速写

2. TL;DR: DART 提出了一种基于权重向量算术（Weight Vector Arithmetic）的单样本（One-Shot）适应框架，以解决 VLA 模型在环境偏移问题，在 LIBERO 仿真基准和真实机械臂任务上实现了显著的跨任务成功率提升。

- 存疑数据：在极端视角偏移（Large viewpoint shift）下，DART 的成功率从 Small 视角的 92.0% 骤降至 64.4%。这表明当源域和目标域的物理表征差异过大时，权重空间中“任务”与“领域”严格正交且可线性加法的假设会发生衰减，提取的领域向量不可避免地混入了无法对齐的噪声。

### 第二模块：核心架构解释

DART 的核心架构分为四个客观执行阶段，完全在模型的权重参数空间（Weight Space）中进行，不改变 VLA 的前向推理架构。

1. 基础微调阶段：给定一个多任务基础模型，分别使用源域的单样本数据和目标域的单样本数据（两者必须是同一任务）进行行为克隆（BC）微调。将微调后的权重减去基础模型权重，得到源域更新向量和目标域更新向量。
2. 领域向量提取阶段：将目标域更新向量减去源域更新向量。这一步的数学逻辑是消除两个向量中重合的任务特定方向，保留目标域独有的环境偏移方向。
3. 子空间滤波与缩放阶段：对源域和目标域的更新向量进行奇异值分解（SVD）。计算源域左奇异基向量与目标域子空间的重叠能量（Overlap Energy），剔除能量低于动态阈值的源域基向量。随后，利用两个子空间的整体对齐分数对提取出的领域向量进行标量缩放，以抑制未对齐带来的噪声。
4. 模型合并阶段：将经过滤波和缩放的领域向量乘以一个超参数系数，直接加回原始基础模型的权重中，输出最终的适应模型。

```python
# DART 核心逻辑伪代码 (Python-style)
import numpy as np

def compute_update_vector(base_weights, fine_tuned_weights):
    return fine_tuned_weights - base_weights

def subspace_filtering_and_scaling(delta_src, delta_tgt, threshold_ratio):
    # 1. 奇异值分解
    U_tgt, S_tgt, V_tgt = np.linalg.svd(delta_tgt, full_matrices=False)
    U_src, S_src, V_src = np.linalg.svd(delta_src, full_matrices=False)
    
    # 2. 计算子空间对齐分数 (Alignment Score)
    alignment_score = np.linalg.norm(U_tgt @ U_tgt.T @ delta_src) / np.linalg.norm(delta_src)
    
    # 3. 计算源域基向量的重叠能量并进行贪婪过滤
    interaction_matrix = U_tgt.T @ U_src
    overlap_energies = np.linalg.norm(interaction_matrix, axis=0) ** 2
    
    # 筛选出高能量的基向量索引
    valid_indices = overlap_energies >= (threshold_ratio * np.sum(overlap_energies))
    U_src_filtered = U_src[:, valid_indices]
    
    # 4. 重构过滤后的源域更新向量
    delta_src_filtered = U_src_filtered @ U_src_filtered.T @ delta_src
    
    # 5. 提取并缩放领域向量
    domain_vector = delta_tgt - delta_src_filtered
    refined_domain_vector = alignment_score * domain_vector
    
    return refined_domain_vector

def dart_adaptation(base_model, src_data, tgt_data, alpha=0.8):
    # 分别在源域和目标域数据上微调基础模型
    model_src = finetune(base_model, src_data)
    model_tgt = finetune(base_model, tgt_data)
    
    # 获取更新向量
    delta_src = compute_update_vector(base_model.weights, model_src.weights)
    delta_tgt = compute_update_vector(base_model.weights, model_tgt.weights)
    
    adapted_weights = {}
    for layer in base_model.layers:
        # 对每一层执行子空间滤波与领域向量提取
        refined_domain_vec = subspace_filtering_and_scaling(delta_src[layer], delta_tgt[layer])
        
        # 将领域向量注入基础模型
        adapted_weights[layer] = base_model.weights[layer] + alpha * refined_domain_vec
        
    return adapted_weights
```

### 第二模块：核心架构解释

DeWorldSG 的系统架构主要分为四个连续的计算阶段，旨在将原始的 RGB-D 视频流转化为具有时空一致性的高维 3D 语义场景图。

1.  **输入处理与深度引导滤波 (Depth-Guided Filtering)**：接收连续的 RGB-D 帧序列。利用深度图对 2D 实例分割结果进行滤波，剔除深度边缘的噪声像素，提取出纯净的实例级视觉与几何特征。
2.  **概率 3D 节点构建 (Probabilistic 3D Nodes)**：摒弃传统的单点投影（Centroid projection）。基于滤波后的深度和相机内参，计算每个实例在 3D 空间中的均值和协方差，将其建模为一个 3D 高斯分布（3D Gaussian）。这使得场景图的节点具备了体积感知和空间不确定性。
3.  **时空证据聚合 (Spatiotemporal Evidence Aggregation)**：在时间轴上追踪对象。对于任意两个对象（Object Pair），跨越多个视频帧收集它们之间的相对位置、视觉特征变化等交互证据，形成聚合的关系特征向量，缓解单帧视角受限导致的信息盲区。
4.  **世界模型先验注入与关系细化 (World-Model Priors Refinement)**：将聚合后的特征与原始视频序列输入到 V-JEPA 2 世界模型中。提取 V-JEPA 2 内部蕴含的物理规律和时空上下文先验（Contextual Priors），通过图神经网络或注意力机制对关系特征进行修正，最终输出包含对象类别（Nodes）和谓词关系（Edges）的 3D 语义场景图。

### 第二模块：核心架构解释

TTP 框架的核心逻辑在于“统一空间表示”与“双专家联合生成”。

**1. 统一表示空间**
为了消除人类手部与不同机器人末端执行器之间的形态鸿沟，模型在预训练和微调阶段强制使用统一的表示空间：动作空间被固定为 200 维（包含位姿、关节角等），触觉空间被固定为 351 维（将所有异构触觉传感器的读数投影到人类 MANO 手部网格的固定顶点上）。

**2. 多模态理解与上下文提取**
模型以 VQA（视觉问答）的形式组织输入。多模态理解专家（基于 InternVL-3.5 初始化）接收图像、语言指令、本体感受状态以及经过步幅采样的历史触觉序列，将其编码为统一的隐藏上下文特征。

**3. 流形保持门控（MPG）**
由于动作和触觉的语义分布存在差异，直接联合预测容易产生高方差。MPG 模块通过计算当前上下文特征与无噪声动作/触觉锚点之间的切片 Wasserstein 距离（SWD），生成一个可靠性门控信号。该信号用于动态调节残差增强的强度，确保在上下文发生偏移时预测依然稳定。

**4. 双专家流匹配（Flow Matching）**
在提取并增强上下文特征后，模型进入连续时间生成过程。动作专家负责预测未来动作块（Action Chunk）的去噪速度场；触觉专家负责预测未来触觉序列的去噪速度场。触觉专家本质上充当了一个前向动力学世界模型，强制网络理解物理交互的后果。

```python
    # 1. Multimodal Understanding Expert (VLM)
    # Encode multimodal inputs into a shared hidden context
    context = vlm_encoder(images, language, state, tactile_history)
    
    # 2. Tactile-Action Manifold-Preserving Gating (MPG)
    # Compute discrepancy between context and clean anchors using Sliced Wasserstein Distance
    discrepancy_act = compute_swd(context, clean_action_anchor)
    discrepancy_tac = compute_swd(context, clean_tactile_anchor)
    joint_discrepancy = 0.5 * (discrepancy_act + discrepancy_tac)
    
    # Generate reliability gate
    gate = exp(-joint_discrepancy / tau)
    
    # Modulate residual enhancement to stabilize predictions
    enhanced_context = context + lambda_weight * stop_gradient(gate) * residual_net(context)
    
    # 3. Dual-Expert Velocity Prediction (Flow Matching)
    # Action Expert predicts action velocity
    action_velocity = action_expert(noisy_action, flow_time, enhanced_context)
    
    # Tactile Expert predicts tactile velocity (World Model dynamics)
    tactile_velocity = tactile_expert(noisy_tactile, flow_time, enhanced_context)
    
    return action_velocity, tactile_velocity

def compute_loss(action_velocity, target_action_vel, tactile_velocity, target_tactile_vel):
    # Flow matching MSE loss for both modalities
    loss_act = mse_loss(action_velocity, target_action_vel)
    loss_tac = mse_loss(tactile_velocity, target_tactile_vel)
    return lambda_act * loss_act + lambda_tac * loss_tac
```

### 第二模块：核心架构解释

本文并非提出单一的神经网络架构，而是对整个 World Action Models (WAM) 赛道进行了架构级的解构与重组。其核心逻辑分为两个层级：

**层级一：世界模型（WM）的表征空间划分**
1. **观测空间模型（Observation-space WMs）**：直接在像素（Pixels）或点云（Point Clouds）级别进行未来预测。视觉保真度极高，但空间结构和物理可解释性较弱，控制可用性低（难以直接提取物理状态）。
2. **状态空间模型（State-space WMs）**：在隐变量（Latent vectors）或以物体为中心（Object-centric）的低维空间进行预测。物理可解释性和控制可用性强，但难以泛化到开放世界的复杂视觉场景。

**层级二：世界动作模型（WAM）的四大执行范式**
为了将上述 WM 的预测能力转化为机器人的 Action，作者总结了四种架构级融合方法：
1. **先想象后执行（Imagine-then-execute）**：利用 WM 在隐空间或视觉空间中展开多步未来预测，结合奖励函数或代价函数，通过模型预测控制（MPC）或树搜索寻找最优动作序列。
2. **视频特征条件动作预测（Video-feature-conditioned action prediction）**：WM 先生成未来视频/观测，随后将这些生成的未来表征作为额外输入（Condition），喂给一个独立的策略网络（Policy）来输出动作。
3. **联合视频-动作建模（Joint video-action modeling）**：将视觉观测和动作全部 Token 化，使用单一的 Transformer 进行自回归生成，同时预测未来的视频帧和对应的动作序列（类似 VLA 的扩展版）。
4. **辅助视频预测（Auxiliary video prediction for policy learning）**：不直接在推理阶段使用视频生成，而是在策略训练阶段，将未来视频预测作为辅助损失函数（Auxiliary Loss），迫使策略网络的表征学习到环境的动态变化。

**核心逻辑伪代码（Python 风格）：**

```python
class WorldActionModelTaxonomy:
    def __init__(self, world_model, policy_network):
        self.wm = world_model        # 预测未来状态/观测
        self.policy = policy_network # 输出物理动作

    def paradigm_1_imagine_then_execute(self, current_state, candidate_actions):
        """范式1：基于模型预测控制 (MPC) 的想象与执行"""
        best_action = None
        highest_reward = -float('inf')
        for action_seq in candidate_actions:
            # 在世界模型中展开未来
            predicted_states = self.wm.rollout(current_state, action_seq)
            reward = evaluate_trajectory(predicted_states)
            if reward > highest_reward:
                highest_reward = reward
                best_action = action_seq[0]
        return best_action

    def paradigm_2_feature_conditioned(self, current_obs):
        """范式2：基于未来视频特征的动作预测"""
        # WM 预测未来观测特征
        future_features = self.wm.predict_future_features(current_obs)
        # Policy 结合当前观测与未来特征输出动作
        action = self.policy(current_obs, condition=future_features)
        return action

    def paradigm_3_joint_modeling(self, context_tokens):
        """范式3：联合视频-动作自回归建模"""
        # 单一 Transformer 同时输出下一个观测 Token 和动作 Token
        next_obs_token, action_token = self.wm.autoregressive_generate(context_tokens)
        action = decode_to_continuous_action(action_token)
        return action

    def paradigm_4_auxiliary_learning(self, current_obs, action, next_obs_gt):
        """范式4：作为表征学习辅助任务（仅训练阶段）"""
        # 主任务：动作预测损失
        pred_action = self.policy(current_obs)
        action_loss = compute_loss(pred_action, action)
        
        # 辅助任务：未来观测预测损失
        pred_next_obs = self.wm(current_obs, action)
        aux_loss = compute_loss(pred_next_obs, next_obs_gt)
        
        total_loss = action_loss + lambda_weight * aux_loss
        total_loss.backward()
```

### 第二模块：核心架构解释

3DPWM 的架构分为三个主要阶段：点云获取与补全、动力学预测、基于模型的规划。

1. 点云获取与补全 (Point Cloud Completion)
系统首先构建当前环境的完整 3D 观测。对于机器人本体，通过读取关节角度并结合 URDF 模型，利用正向运动学直接采样得到末端执行器的完整点云。对于场景物体，系统接收单视角 RGB-D 图像，利用 SAM3 进行实例分割，反投影深度图得到物体的局部点云。随后，将局部点云输入至点云补全网络，输出物体的完整点云。最后将机器人点云与物体点云合并，形成当前时间步的完整场景点云。

2. 3D 点云动力学模型 (Point Dynamics Model)
动力学模型以 Point Transformer V3 (PTV3) 为骨干网络。输入特征包含每个点的空间坐标、当前速度和上一时间步速度。在特征提取的瓶颈层，系统将机器人动作向量通过 MLP 编码，并与一个可学习的寄存器 Token (Register Token) 拼接，作为交叉注意力机制的 Key 和 Value；点云特征作为 Query。这种设计强制与动作相关的点（如机器人本体）关注动作指令，而与动作无关的点（如静止的背景物体）关注寄存器 Token。随后通过自注意力层传播动作影响，最终由解码器预测每个点在下一时间步的速度，并据此更新点云位置。

3. 训练与规划 (Training & Planning)
训练阶段，模型在仿真环境中获取具有精确点对点对应关系的完整点云，直接使用 Huber 损失函数对多步自回归推演的逐点速度进行强监督。规划阶段，采用 MPPI (Model Predictive Path Integral) 算法，在补全的点云观测空间中直接定义代价函数，通过动力学模型进行大量轨迹采样和推演，输出最优动作序列。

```python
# 3DPWM 核心逻辑伪代码
def point_cloud_completion(rgbd_image, joint_angles, robot_urdf):
    # 1. 获取机器人本体完整点云
    robot_points = forward_kinematics(joint_angles, robot_urdf)
    
    # 2. 获取场景物体完整点云
    masks = SAM3_segmentation(rgbd_image.rgb)
    partial_object_points = backproject(rgbd_image.depth, masks)
    complete_object_points = point_completion_network(partial_object_points)
    
    # 3. 融合场景
    scene_points = merge(robot_points, complete_object_points)
    return scene_points

def dynamics_model_step(scene_points, point_features, action, register_token):
    # point_features 包含 [坐标, 当前速度, 上一步速度]
    
    # 1. PTV3 编码器提取特征
    z = PTV3_encoder(scene_points, point_features)
    
    # 2. 动作条件注入 (Cross-Attention)
    action_emb = MLP(action)
    keys_values = concat(action_emb, register_token)
    z_act = CrossAttention(query=z, key=keys_values, value=keys_values)
    
    # 3. 特征传播与解码
    z_out = SelfAttention(z_act)
    point_features_out = PTV3_decoder(z_out)
    
    # 4. 预测下一步速度并更新位置
    predicted_velocities = MLP_head(point_features_out)
    next_scene_points = scene_points + predicted_velocities
    
    return next_scene_points, predicted_velocities

def train_step(initial_points, initial_features, action_sequence, ground_truth_velocities, horizon=15):
    loss = 0
    current_points = initial_points
    current_features = initial_features
    
    # 多步自回归训练
    for h in range(horizon):
        action = action_sequence[h]
        current_points, pred_vel = dynamics_model_step(current_points, current_features, action)
        
        # 直接计算点对点速度的 Huber Loss，替代 Chamfer 距离
        loss += HuberLoss(pred_vel, ground_truth_velocities[h])
        
        # 更新特征用于下一步推演
        current_features = update_features(current_points, pred_vel)
        
    return loss / horizon
```

```python
    def __init__(self, base_vlm):
        super().__init__()
        self.vlm = base_vlm
        # 动作预测头：输出双臂的连续控制指令 (e.g., 关节角度/末端位姿)
        self.action_head = nn.Linear(self.vlm.hidden_size, action_dim)
        # 进度预测头：输出 0~1 的连续标量，表示当前子任务完成度
        self.progress_head = nn.Sequential(
            nn.Linear(self.vlm.hidden_size, 1),
            nn.Sigmoid()
        )

    def forward(self, image, language_instruction):

        features = self.vlm.extract_features(image, language_instruction)
        
        action = self.action_head(features)
        progress = self.progress_head(features)
        
        return action, progress

    """
    task_plan: 包含多个子任务语言指令的列表，例如:
    ["pick up the leg", "align the leg with the hole", "insert the leg"]

    current_subtask_idx = 0
    obs = env.reset()
```

### 第二模块：核心架构解释

ACT-VLA 框架将组合轨迹合成从一个“推理期的控制技巧”转变为一个“系统化的离线数据增强管道”。其核心流程分为三个阶段：

1.  **表征引导的轨迹合成 (Representation-Guided Trajectory Synthesis)**：提取两个基础任务（Task 1 和 Task 2）的文本潜变量 $T^1$ 和 $T^2$。在时间步 $i$ 推进时，计算一个线性缩放的过渡速度 $\alpha$。通过公式动态修改文本隐藏状态，抑制 Task 2 的初始上下文并逐渐注入，同时淡出 Task 1 的上下文，从而引导 VLA 模型输出物理上连续的组合轨迹。
2.  **数据记录与质量过滤 (Data Recording & Processing)**：记录多视角 RGB、本体感受状态、执行动作，并拼接生成新的组合语言指令。此阶段引入了关键的**双重过滤机制**：利用物理仿真器作为严格的裁判，仅保留成功完成组合任务且在预设步数预算内的轨迹，坚决丢弃失败样本，防止错误的状态-动作关联污染策略。
3.  **增强策略训练 (Augmented Policy Training)**：将合成的高质量数据集与原始数据集混合。为了防止分布偏移导致灾难性遗忘，严格保持合成数据与原始数据在任务套件级别的数量级对等。最后使用标准的行为克隆（Behavioral Cloning）对 VLA 模型进行重新训练，将组合能力内化到模型权重中。

### 第二模块：核心架构解释

Valdi 的核心架构建立在 TD-MPC 的潜在规划框架之上，但彻底重构了动态预测模块。其运行流程分为以下四个关键步骤：

1. **状态编码 (Representation)**：系统接收当前的视觉观测和本体感受数据，通过卷积神经网络（CNN）和多层感知机（MLP）将其压缩为一个低维的潜在状态向量。
2. **轨迹联合扩散 (Dynamics)**：这是核心创新点。模型不采用一步步自回归预测未来的方式，而是接收当前潜在状态、采样的未来动作序列以及一段纯噪声轨迹。通过一个双向 Transformer 模型，预测整条轨迹的去噪速度（Velocity），从而在单步内直接重构出未来 H 步的完整潜在轨迹。
3. **奖励与价值评估 (Reward & Value)**：在去噪生成的未来潜在轨迹上，模型使用独立的 MLP 网络预测每一步的即时奖励，以及轨迹末端状态的长期价值（Value）。这些预测用于计算时序差分（TD）损失以更新网络。
4. **在线规划 (Inference)**：在环境交互时，规划器使用交叉熵方法（CEM）在动作空间中采样大量候选动作序列。通过上述单步扩散模型快速生成对应的未来轨迹并计算累积回报，选出得分最高的动作序列，执行其第一个动作，随后在下一帧重新规划。

```python
def valdi_training_step(obs_seq, action_seq):
    # 1. 编码当前状态与目标轨迹
    z_t = encoder(obs_seq[0])
    target_z_seq = target_encoder(obs_seq[1:]) # 提取未来 H 步的真实潜在状态
    
    # 2. 前向加噪 (Diffusion Forward)
    noise = sample_normal_distribution()
    tau = sample_diffusion_timestep()
    noisy_z_seq, target_velocity = add_noise_with_velocity_parameterization(target_z_seq, noise, tau)
    
    # 3. 预测去噪速度 (Dynamics Model)
    # Transformer 联合处理整条轨迹，条件为当前状态、动作序列和时间步
    pred_velocity = transformer_dynamics(z_t, noisy_z_seq, action_seq, tau)
    
    # 4. 单步去噪重构轨迹
    denoised_z_seq = reconstruct_trajectory(noisy_z_seq, pred_velocity, tau)
    
    # 5. 计算损失
    loss_diff = mse_loss(pred_velocity, target_velocity)
    
    # 停止梯度，防止奖励和价值的误差干扰扩散模型的生成逻辑
    z_seq_sg = stop_gradient(denoised_z_seq)
    pred_rewards = reward_model(z_seq_sg, action_seq)
    pred_values = value_model(z_seq_sg)
    
    loss_rew = mse_loss(pred_rewards, target_rewards)
    loss_val = td_loss(pred_values, target_values)
    
    total_loss = loss_diff + loss_rew + loss_val
    return total_loss

    action_dist = initialize_cem_distribution()

        # 推理时强制使用单步扩散 (tau = 0)
        noisy_z_seq = sample_normal_distribution()
        pred_velocity = transformer_dynamics(z_0, noisy_z_seq, action_seqs, tau=0)
        denoised_z_seq = reconstruct_trajectory(noisy_z_seq, pred_velocity, tau=0)
        
        # 评估轨迹回报
        rewards = reward_model(denoised_z_seq, action_seqs)
        values = value_model(denoised_z_seq[:, -1])
        returns = compute_discounted_returns(rewards, values)
        
        # 更新 CEM 采样分布
        action_dist.update(action_seqs, returns)
        
    return action_dist.get_best_action()[0]
```

### 第二模块：核心架构解释

MuSix 框架的运行流程分为前向路由选择与测试时知识演化两个核心阶段：

**1. 双阶段尺度感知路由 (Two-stage Scale-based Routing)**
模型被划分为 $G$ 个尺度组（从低层物理模型到高层认知地图）。
第一阶段：提取当前观测的特征，计算其与历史经验分布的马氏距离（经验距离 $\delta$）。元路由器（Meta-router）将 $\delta$ 映射为连续尺度空间上的权重分布。熟悉的场景产生低 $\delta$，权重集中在低尺度；新颖场景产生高 $\delta$，权重集中在高尺度。
第二阶段：各尺度组内的基础路由器（Base router）计算具体世界模型的得分。最终的路由概率由元路由器的尺度权重与基础路由器的得分积分相乘得出，选出 Top-k 个世界模型进行前向预测。

**2. 知识演化与适应 (Knowledge Adaptation)**
在测试时（Test-time），智能体根据世界模型的预测误差生成知识增量。
尺度内适应（Intra-scale）：根据元路由器确定的当前尺度，将知识增量分配给对应的尺度组。应用尺度依赖的遗忘率：低尺度组遗忘率高（快速刷新瞬态细节），高尺度组遗忘率低（保留长期抽象规则）。
尺度间适应（Inter-scale）：通过预训练的门控矩阵，将更新后的知识状态在相邻尺度组（如 Group 1 与 Group 2）之间进行双向传递，确保跨层级知识的逻辑一致性。

**核心逻辑伪代码**：

```python
    # 1. 计算经验距离 (Experiential Distance)
    obs_emb = encoder(observation)
    mu_E, sigma_E = compute_history_distribution(history_experience)
    delta = mahalanobis_distance(obs_emb, mu_E, sigma_E)
    
    # 2. 双阶段路由 (Two-stage Routing)
    # Meta-router: 基于经验距离输出尺度空间的权重
    scale_weights = meta_router(delta) 
    
    # Base-router: 计算每个世界模型的局部得分
    model_scores = base_router(observation, action) 
    
    # 融合权重并选择 Top-k 世界模型
    final_routing_probs = compute_integral(scale_weights, model_scores)
    selected_models = top_k(world_models, final_routing_probs, k=4)
    
    # 3. 预测与误差计算
    prediction = sum([prob * model(observation, action) for model, prob in selected_models])
    next_obs_actual = environment.step(action)
    prediction_error = compute_error(prediction, next_obs_actual)
    
    # 4. 测试时知识演化 (Test-time Evolution)
    knowledge_increment = compute_increment(prediction_error)
    current_scale = argmax(scale_weights) # 确定当前主导尺度
    
    for group_idx in range(G):
        # 尺度内适应：分配增量 + 尺度依赖的遗忘率 (alpha)
        # 低 group_idx 对应大 alpha，高 group_idx 对应小 alpha
        alpha = compute_forgetting_rate(group_idx)
        group_increment = knowledge_increment * final_routing_probs[group_idx]
        knowledge_states[group_idx] = (1 - alpha) * knowledge_states[group_idx] + group_increment
        
        # 尺度间适应：相邻组的门控知识传递
        g_plus, g_minus = compute_gating_factors(obs_emb)
        transfer_in = g_plus * knowledge_states[group_idx - 1] + g_minus * knowledge_states[group_idx + 1]
        transfer_out = g_plus * knowledge_states[group_idx] + g_minus * knowledge_states[group_idx]
        
        knowledge_states[group_idx] = knowledge_states[group_idx] + transfer_in - transfer_out

    return action, knowledge_states
```

```python
import torch.nn as nn

def compute_importance_mask(model, calibration_dataloader, sparsity_ratio=0.6):
    """离线计算参数重要性并生成掩码"""
    importance_scores = {}
    
    # 1. 前向传播收集激活值
    for batch in calibration_dataloader:
        model.forward(batch) # 伪代码：需挂载hook记录每层输入激活的L2范数
        
    # 2. 计算重要性得分并生成掩码
    masks = {}
    for name, layer in model.named_modules():
        if isinstance(layer, nn.Linear) and is_intermediate_layer(name):
            weight_mag = torch.abs(layer.weight.data)
            activation_norm = layer.input_activation_l2_norm # 从hook获取
            
            # 核心公式：Score = |W| * ||X||_2
            score = weight_mag * activation_norm
            
            # 确定阈值
            threshold = torch.quantile(score.view(-1), sparsity_ratio)
            
            # 得分小于阈值的为休眠参数(1)，否则为关键参数(0)
            masks[name] = (score < threshold).float()
            
    return masks

def train_step(model, batch, masks, optimizer):
    """在线掩码隔离训练"""
    optimizer.zero_grad()
    
    # 前向传播计算自回归损失
    loss = model(vision_img=batch.v_img, tactile_img=batch.t_img, text=batch.text)
    loss.backward()
    
    # 核心机制：应用掩码阻断关键参数的梯度
    for name, param in model.named_parameters():
        if name in masks:
            # 仅允许休眠参数更新 (梯度乘以掩码)
            param.grad *= masks[name]
        elif is_critical_vision_param(name):
            # 视觉前端和关键层完全冻结
            param.grad = None 
            
    optimizer.step()
    return loss
```

```python
import torch
from planner import AutonomousDrivingPlanner
from vlm import ExpertVLM, TargetVLM

def calculate_pkl(planner, scene, hidden_agent):
    # 1. 计算未感知到隐藏智能体时的自车轨迹概率分布
    traj_dist_without_agent = planner.plan(scene.visible_state)

    scene_with_agent = scene.inject_ground_truth(hidden_agent)
    traj_dist_with_agent = planner.plan(scene_with_agent)
    
    # 3. 计算两个分布之间的 KL 散度
    pkl_value = torch.nn.functional.kl_div(
        traj_dist_without_agent.log(), 
        traj_dist_with_agent, 
        reduction='batchmean'
    )
    return pkl_value

def generate_training_data(dataset, planner, expert_vlm, pkl_threshold):
    training_data = []
    for scene in dataset:

                    "annotation": annotation,
                    "pkl_score": pkl
                })
    return training_data
```

*   **存疑的试验结果**：论文在 Table 4 中展示了其时序扩展版本 GaussianFusion-T 达到了 77.6 NDS。理由：该时序扩展仅通过简单的坐标系变换将历史帧高斯表示对齐到当前帧并进行融合，缺乏对动态物体运动学（如速度、加速度）的显式建模。在高度动态或遮挡场景下的长时序一致性表现现有信息不足以做出判断，其高分可能更多依赖于单帧表征的强大，而非时序建模的优越性。

### 第二模块：核心架构解释

GaussianFusion 的整体架构分为三个核心阶段：多模态高斯初始化、共享高斯编码器更新、以及任务无关的体素化感知。

1.  **多模态高斯初始化 (Multi-modal Gaussian Initialization)**：
    *   **相机分支**：利用 LSS (Lift-Splat-Shoot) 范式预测图像的深度分布，将深度点作为 3D 高斯的初始均值（位置 $\mu$），尺度 $s$ 和旋转 $r$ 随机初始化。
    *   **激光雷达分支**：将点云体素化为 BEV 网格，以体素中心作为高斯的初始均值 $\mu$，同样随机初始化尺度和旋转。
2.  **共享高斯编码器 (Shared Gaussian Encoder)**：
    *   **高斯先验形变注意力 (Deformable Attention with Gaussian)**：传统的形变注意力在均匀网格上初始化采样点。本文将 3D 高斯分布投影到 BEV 特征图上，利用高斯的协方差矩阵（包含尺度和旋转信息）生成采样偏移量。这使得采样点直接贴合目标物体的几何形状。
    *   **渐进式更新 (Gaussian Updating)**：不直接预测全新的高斯参数，而是通过 MLP 预测参数的偏移量（$\Delta\mu, \Delta s, \Delta r$），将其加到上一层的高斯参数上，实现跨模态特征的逐步对齐。
3.  **多传感器融合与体素化 (Multi-Sensor Fusion & Voxelization)**：
    *   将更新后的相机和激光雷达高斯集合合并。
    *   将连续的 3D 高斯空间划分为体素网格，利用 MeanVFE 对落入同一体素内的高斯进行池化降采样，生成统一的体素特征，随后接入标准的 3D 检测或占用预测头。

```python
# GaussianFusion 核心逻辑伪代码
def gaussian_fusion_forward(camera_features, lidar_features):
    # 1. 多模态高斯初始化
    # 相机：通过 LSS 获取深度分布作为初始均值
    depth_dist = LSS(camera_features) 
    cam_mu = get_3d_coordinates(depth_dist)
    cam_gaussians = initialize_gaussians(cam_mu) # [N, Dg]
    
    # 激光雷达：通过 BEV 体素中心作为初始均值
    lidar_bev = Voxelize(lidar_features)
    lidar_mu = get_voxel_centers(lidar_bev)
    lidar_gaussians = initialize_gaussians(lidar_mu) # [M, Dg]
    
    # 2. 共享高斯编码器 (迭代更新)
    for layer in range(num_encoder_layers):
        # 提取高斯属性作为位置编码 (PE)
        cam_query = MLP(cam_gaussians.properties) + cam_gaussians.features
        lidar_query = MLP(lidar_gaussians.properties) + lidar_gaussians.features
        
        # 带有高斯先验的形变注意力
        # 采样点分布由高斯的协方差矩阵 (covariance) 决定，而非均匀分布
        cam_features = DeformableAttn_with_Gaussian(cam_query, camera_features, cam_gaussians.covariance)
        lidar_features = DeformableAttn_with_Gaussian(lidar_query, lidar_bev, lidar_gaussians.covariance)
        
        # 预测偏移量并更新高斯属性
        cam_gaussians = update_gaussian_properties(cam_gaussians, delta=MLP(cam_features))
        lidar_gaussians = update_gaussian_properties(lidar_gaussians, delta=MLP(lidar_features))
        
    # 3. 多传感器融合与体素化
    # 合并跨模态高斯集合
    unified_gaussians = merge(cam_gaussians, lidar_gaussians)
    
    # 高斯到体素的池化 (Gaussian-to-Voxel Pooling)
    voxel_features = MeanVFE(unified_gaussians)
    
    # 4. 任务无关感知头
    detection_output = DetectionHead(voxel_features)
    occupancy_output = OccupancyHead(voxel_features)
    
    return detection_output, occupancy_output
```

Q2: 作者提出的核心解决方案（创新点）是什么？

A2: 提出基于 3DGS 的连续空间多模态融合范式。核心机制包括：基于前向投影的确定性高斯初始化、利用高斯协方差矩阵指导采样点分布的形变注意力机制，以及通过预测属性偏移量来渐进式对齐跨模态特征的共享编码器。

Q3: 实验设计的关键支撑（或巧妙之处/数据集特点）是什么？

A3: 实验设计的关键支撑在于其任务无关性（Task-agnostic）验证。作者没有局限于单一任务，而是将融合后的特征同时接入 3D 目标检测（稀疏目标）和 3D 语义占用预测（密集场景）两个截然不同的任务头。巧妙之处在于消融实验中对“初始化策略”的对比，直接证明了基于物理几何意义的前向投影初始化远优于随机初始化。

Q4: 这篇论文最显著的贡献点（Top 3）是什么？

A4:
1. 提出了首个基于 3D 高斯表示的统一多模态融合框架，打破了传统 BEV 离散网格在早期特征融合时的信息损耗局限。

3. 引入了共享的跨模态高斯编码器，利用高斯形状先验改进形变注意力机制，实现了更精准的跨模态空间对齐。

Q6: 客观评价：这篇论文的局限性、漏洞或"未讲明的故事"是什么？对后续科研有何启发？
