### 第二模块：核心架构解释

SA-WAM 的核心架构建立在预训练的视频扩散模型（Cosmos-Predict2）之上，其运行流程可拆解为以下三个关键步骤：

2. 统一分词与隐空间构建：使用冻结的 Wan2.1 时空 VAE 分词器，将 RGB 图像和归一化后的深度图分别编码为隐特征（Latent frames）。
3. 联合扩散去噪：构建一个统一的 DiT 序列，序列中包含：任务指令文本特征、当前本体感觉、当前 RGB 与深度隐特征，以及需要预测的动作块（Action chunk）、未来 RGB 隐特征和未来深度隐特征。模型通过 EDM 目标函数，在单一网络中联合预测未来状态与动作。

```python
import torch

def log_scale_normalize(depth, d_min, d_max):
    # 截断深度图至有效物理范围
    depth_clipped = torch.clamp(depth, d_min, d_max)
    # 对数尺度归一化至 [0, 1]，保留近场高分辨率
    norm_depth = torch.log(depth_clipped / d_min) / torch.log(d_max / d_min)
    # 缩放至 [-1, 1] 以匹配 VAE 输入域
    return 2 * norm_depth - 1

def sa_wam_training_step(rgb_obs, depth_obs, proprio, instruction, action_chunk, future_rgb, future_depth, frozen_vae, dit_backbone):
    # 1. 深度图归一化处理
    depth_norm = log_scale_normalize(depth_obs, d_min=0.1, d_max=3.0)
    future_depth_norm = log_scale_normalize(future_depth, d_min=0.1, d_max=3.0)
    
    # 2. 统一分词：复用冻结的 VAE (深度图复制为3通道)
    with torch.no_grad():
        rgb_latent = frozen_vae.encode(rgb_obs)
        depth_latent = frozen_vae.encode(depth_norm.repeat(1, 3, 1, 1))
        future_rgb_latent = frozen_vae.encode(future_rgb)
        future_depth_latent = frozen_vae.encode(future_depth_norm.repeat(1, 3, 1, 1))
        
    # 3. 构建 DiT 序列 (Condition + Target)
    condition = torch.cat([instruction, proprio, rgb_latent, depth_latent], dim=1)
    target = torch.cat([action_chunk, future_rgb_latent, future_depth_latent], dim=1)
    
    # 4. 扩散过程 (EDM 框架)
    noise = torch.randn_like(target)
    sigma = sample_sigma() # 采样噪声强度
    noisy_target = target + noise * sigma
    
    # 5. 联合去噪预测
    pred_target = dit_backbone(noisy_target, condition, sigma)
    
    # 6. 计算损失
    loss = torch.nn.functional.mse_loss(pred_target, target)
    return loss
```

### 第二模块：核心架构解释

WCD 框架将冻结的 WAM 转化为一个 Best-of-N 的测试时规划器，其运行流程分为三个阶段：

**1. 执行前评估 (Phase 1: Pre-execution)**
在每个决策步，冻结的 WAM 根据当前观测历史采样 $N$ 个“未来视觉-动作”候选对。系统利用模型内部的生成动力学特征对候选进行打分：
- **视频流惊奇度 (Flow-based Video Surprisal)**：通过累积流匹配（Flow-matching）去噪轨迹上的散度（Divergence）来衡量视觉合理性。散度越大，说明生成的未来状态在模型学到的先验分布中密度越低（越不合理）。
- **动作路径代价 (Action Path Effort)**：通过计算动作去噪轨迹中每一步的更新幅度来衡量动作的平滑度与稳定性。

**2. 延迟自验证 (Phase 2: After execution)**
系统选择综合得分最优的候选动作在物理世界中执行。执行后，环境返回真实的视觉观测。系统计算“选中的想象未来”与“真实观测”之间的均方误差（MSE），即后向误差（Backward Error）。这是一个完全自监督的可靠性信号。

**3. 在线校准与摊销 (Phase 3: Online calibration)**
由于计算视频流惊奇度需要重放去噪轨迹，计算成本极高。WCD 将执行后得到的后向误差存入经验回放池，在线训练一个轻量级预测器。当数据量达到阈值后，系统切换为使用该预测器，直接根据生成时的浅层特征预测未来的后向误差，从而摊销了高昂的计算成本。

**核心伪代码实现：**

```python
def world_coherent_decoding(wam, obs_history, N, predictor, replay_buffer, threshold):
    # Phase 1: Candidate Generation
    candidates = wam.sample_candidates(obs_history, num_samples=N)
    scores = []
    
    for c in candidates:
        # Action path effort is always computed (cheap)
        effort_score = compute_action_effort(c.action_denoising_trace)
        
        if len(replay_buffer) >= threshold:
            # Post-warm: Use lightweight online predictor to estimate mismatch
            video_score = predictor.predict_error(c.generation_features)
        else:
            # Pre-warm: Use expensive flow surprisal (divergence accumulation)
            video_score = compute_flow_surprisal(c.video_denoising_trace)
            
        # Normalize and fuse scores
        fused_score = lambda_weight * video_score + (1 - lambda_weight) * effort_score
        scores.append(fused_score)
        
    # Select the most reliable candidate
    best_idx = argmin(scores)
    best_candidate = candidates[best_idx]
    
    # Execute action in the physical world
    real_obs = execute_in_environment(best_candidate.action)
    
    # Phase 2: Delayed Self-Verification
    # Calculate imagination-reality mismatch (Backward Error)
    backward_error = MSE(best_candidate.imagined_future, real_obs)
    
    # Phase 3: Online Calibration
    # Store features and ground-truth error to train the predictor
    replay_buffer.add(best_candidate.generation_features, backward_error)
    if len(replay_buffer) >= threshold:
        predictor.train_online(replay_buffer)
        
    return real_obs
```

```python
def log_scale_normalize(depth, d_min, d_max):
    # 截断深度图至有效物理范围
    depth_clipped = torch.clamp(depth, d_min, d_max)
    # 对数尺度归一化至 [0, 1]，保留近场高分辨率
    norm_depth = torch.log(depth_clipped / d_min) / torch.log(d_max / d_min)
    # 缩放至 [-1, 1] 以匹配 VAE 输入域
    return 2 * norm_depth - 1

    # 1. 深度图归一化处理
    depth_norm = log_scale_normalize(depth_obs, d_min=0.1, d_max=3.0)
    future_depth_norm = log_scale_normalize(future_depth, d_min=0.1, d_max=3.0)
    
    # 2. 统一分词：复用冻结的 VAE (深度图复制为3通道)
    with torch.no_grad():
        rgb_latent = frozen_vae.encode(rgb_obs)
        depth_latent = frozen_vae.encode(depth_norm.repeat(1, 3, 1, 1))
        future_rgb_latent = frozen_vae.encode(future_rgb)
        future_depth_latent = frozen_vae.encode(future_depth_norm.repeat(1, 3, 1, 1))
        
    # 3. 构建 DiT 序列 (Condition + Target)
    condition = torch.cat([instruction, proprio, rgb_latent, depth_latent], dim=1)
    target = torch.cat([action_chunk, future_rgb_latent, future_depth_latent], dim=1)
    
    # 4. 扩散过程 (EDM 框架)
    noise = torch.randn_like(target)
    sigma = sample_sigma() # 采样噪声强度
    noisy_target = target + noise * sigma
    
    # 5. 联合去噪预测
    pred_target = dit_backbone(noisy_target, condition, sigma)
```

- **核心数据**：在 RoboTwin 2.0 的有限随机场景监督（Limited-randomization）Hard 难度下，WCD 将成功率从 55.80% 提升至 60.90%，其中长视野（Horizon-3）任务暴涨 +16.43 个百分点。理由：这直接证明了在基座模型对复杂场景泛化不足时，测试时搜索（Test-time scaling）能有效挽救因生成随机性导致的早期错误累积。
- **存疑数据**：论文在标准协议（Standard protocol）下，整体 Hard 成功率仅从 91.55% 提升至 92.28%（见 Table 1）。理由：基座模型（LingBot-VA）在充足数据下已接近性能饱和，导致 WCD 的测试时算力开销在简单或数据充足场景下的边际收益极低。其实际应用价值高度依赖于基座模型的“半生不熟”状态（即具备基础生成能力但不够稳定）。

### 第二模块：核心架构解释

WCD 框架将冻结的 WAM 转化为一个 Best-of-N 的测试时规划器，其运行流程分为三个阶段：

**1. 执行前评估 (Phase 1: Pre-execution)**
在每个决策步，冻结的 WAM 根据当前观测历史采样 $N$ 个“未来视觉-动作”候选对。系统利用模型内部的生成动力学特征对候选进行打分：
- **视频流惊奇度 (Flow-based Video Surprisal)**：通过累积流匹配（Flow-matching）去噪轨迹上的散度（Divergence）来衡量视觉合理性。散度越大，说明生成的未来状态在模型学到的先验分布中密度越低（越不合理）。
- **动作路径代价 (Action Path Effort)**：通过计算动作去噪轨迹中每一步的更新幅度来衡量动作的平滑度与稳定性。

**2. 延迟自验证 (Phase 2: After execution)**
系统选择综合得分最优的候选动作在物理世界中执行。执行后，环境返回真实的视觉观测。系统计算“选中的想象未来”与“真实观测”之间的均方误差（MSE），即后向误差（Backward Error）。这是一个完全自监督的可靠性信号。

**3. 在线校准与摊销 (Phase 3: Online calibration)**
由于计算视频流惊奇度需要重放去噪轨迹，计算成本极高。WCD 将执行后得到的后向误差存入经验回放池，在线训练一个轻量级预测器。当数据量达到阈值后，系统切换为使用该预测器，直接根据生成时的浅层特征预测未来的后向误差，从而摊销了高昂的计算成本。

**核心伪代码实现：**

```python
def world_coherent_decoding(wam, obs_history, N, predictor, replay_buffer, threshold):
    # Phase 1: Candidate Generation
    candidates = wam.sample_candidates(obs_history, num_samples=N)
    scores = []
    
    for c in candidates:
        # Action path effort is always computed (cheap)
        effort_score = compute_action_effort(c.action_denoising_trace)
        
        if len(replay_buffer) >= threshold:
            # Post-warm: Use lightweight online predictor to estimate mismatch
            video_score = predictor.predict_error(c.generation_features)
        else:
            # Pre-warm: Use expensive flow surprisal (divergence accumulation)
            video_score = compute_flow_surprisal(c.video_denoising_trace)
            
        # Normalize and fuse scores
        fused_score = lambda_weight * video_score + (1 - lambda_weight) * effort_score
        scores.append(fused_score)
        
    # Select the most reliable candidate
    best_idx = argmin(scores)
    best_candidate = candidates[best_idx]
    
    # Execute action in the physical world
    real_obs = execute_in_environment(best_candidate.action)
    
    # Phase 2: Delayed Self-Verification
    # Calculate imagination-reality mismatch (Backward Error)
    backward_error = MSE(best_candidate.imagined_future, real_obs)
    
    # Phase 3: Online Calibration
    # Store features and ground-truth error to train the predictor
    replay_buffer.add(best_candidate.generation_features, backward_error)
    if len(replay_buffer) >= threshold:
        predictor.train_online(replay_buffer)
        
    return real_obs
```

### 第二模块：核心架构解释

ZETA 并非提出一个新的网络架构，而是提出了一套严密的评估协议与数据处理流程。其核心流程分为数据构建、表征转换、两阶段训练与受控评估四个步骤。

1. **协议与数据构建**：严格区分两类零样本测试。
   - 严格零样本（Strict Zero-Shot）：目标机器人 $e_t$ 完全不出现在预训练集 $\mathcal{E}_{pre}$ 中。
   - 预训练曝光零样本（Pretrain-Exposed Zero-Shot）：目标机器人 $e_t$ 存在于预训练集中，但其下游特定任务数据被严格剔除。
2. **表征转换机制**：将传统的基于机器人基座（Base Frame）的绝对坐标，转换为基于当前末端执行器（EEF Frame）的相对坐标。这一转换剥离了不同机器人基座定义和运动学结构的差异，迫使模型学习纯粹的局部运动语义。
3. **两阶段训练**：使用统一的 Mixture-of-Transformers (MoT) 骨干网络，先在包含（或不包含）目标具身的混合数据集上进行预训练，随后仅使用源具身（Source Embodiment）的下游任务数据进行微调（Post-training）。
4. **受控评估**：在测试阶段，强制定义一个统一的“桌面任务坐标系”。所有机器人的第三人称相机和腕部相机均相对于该坐标系进行严格的外部参数校准，确保模型看到的视觉分布差异仅来源于机器人本体的外观和形态，而非相机视角的偏移。

```python
    # Enforce strict alignment of camera extrinsics, lighting, and object poses
```

### 第二模块：核心架构解释

WM-LOCO 摒弃了传统的“先训练特权专家，再蒸馏给视觉策略”的繁琐流程，采用单阶段、端到端的联合训练架构。其核心流程如下：

1. **多模态观测输入**: 在时间步 $t$，系统接收 5 帧本体感觉历史（关节位置、速度、IMU等）、单帧机载深度图以及速度指令。
2. **世界模型前向推断 (RSSM)**: 观测数据输入循环状态空间模型。模型结合上一时刻的确定性记忆 $h_{t-1}$ 和动作 $a_{t-1}$ 更新当前记忆 $h_t$。同时，后验网络结合当前观测推断潜变量 $z_t$，先验网络仅依赖 $h_t$ 预测 $z_t$。
3. **预测性特征提取**: 直接从确定性记忆 $h_t$ 中提取出包含未来地形与奖励预测信息的循环特征 $f_t^{WM}$。
4. **策略动作输出**: PPO 的 MoE（混合专家）Actor-Critic 网络接收本体感觉、深度图、速度指令以及 $f_t^{WM}$，输出当前的关节动作。
5. **联合损失优化**: 将 PPO 的 Surrogate Loss 与世界模型的重构损失（深度图 MSE、本体感觉 MSE、奖励预测 MSE）及正则化损失（先验与后验的 KL 散度）相加，进行端到端反向传播。

**核心逻辑伪代码 (Python 风格)**:

```python
def train_step(obs, actions, rewards, h_prev, z_prev):
    # obs 包含: proprio_history, depth_image, velocity_cmd
    
    # ================= 1. 世界模型 (RSSM) 前向传播 =================
    # 更新确定性记忆状态 h_t
    h_t = rnn_cell(h_prev, z_prev, actions)
    
    # 后验推断 (Posterior): 结合当前观测推断潜变量
    z_post, post_dist = posterior_net(h_t, obs['proprio_history'][-1], obs['depth_image'])
    
    # 先验预测 (Prior): 仅依赖记忆预测潜变量 (用于计算 KL 散度)
    z_prior, prior_dist = prior_net(h_t)
    
    # ================= 2. 提取预测性循环特征 =================
    f_wm = feature_extractor(h_t)
    
    # ================= 3. 策略网络 (PPO + MoE) 前向传播 =================
    policy_input = concatenate([obs['proprio_history'], obs['depth_image'], obs['velocity_cmd'], f_wm])
    action_dist, value = moe_actor_critic(policy_input)
    
    # ================= 4. 损失计算与联合优化 =================
    # 世界模型损失: 重构本体感觉、重构深度图、预测奖励、KL正则化
    loss_recon_proprio = MSE(decoder_proprio(h_t, z_post), obs['proprio_history'][-1])
    loss_recon_depth = MSE(decoder_depth(h_t, z_post), obs['depth_image'])
    loss_pred_reward = MSE(decoder_reward(h_t, z_post), rewards)
    loss_kl = KL_divergence(post_dist, prior_dist)
    
    loss_world_model = loss_recon_proprio + loss_recon_depth + loss_pred_reward + beta * loss_kl
    
    # PPO 策略损失
    loss_ppo = compute_ppo_surrogate_loss(action_dist, value, ...)
    
    # 端到端联合反向传播
    total_loss = loss_ppo + loss_world_model
    total_loss.backward()
    optimizer.step()
    
    return h_t, z_post
```

### 第二模块：核心架构解释

HINT 框架的运行流程本质上是一个异步的、事件驱动的感知与控制闭环。其核心架构分为三个阶段：

**阶段一：模式感知的感知调度 (Pattern-Aware Perception Scheduling)**
系统不逐帧调用 VLM。而是通过一个轻量级的多模态网络（Pattern Router），实时接收多视角图像、本体感受和关节力矩，预测当前处于哪种操作模式（自由移动、接触前、搬运接触、灵巧接触）以及模式进度。当检测到模式转换时，触发阶段二。

**阶段二：语义承诺与视觉追踪 (Semantic Commitment and Visual Tracking)**
一旦触发更新，Task Manager（基于 Qwen3-VL）根据全局指令和当前上下文，解析出当前子任务和目标实体。Semantic Grounder（基于 DINO）在对应视角的图像中生成目标边界框。在两次模式转换之间，系统使用 SAM2 进行连续的视觉追踪；若追踪置信度低于阈值，则重新触发 Grounder 定位。

**阶段三：视图路由的语义意图注入 (View-Routed Semantic Intent Injection)**
将追踪到的目标掩码（Mask）通过两种无参数接口注入到冻结的 VLA 模型中：
1. 像素级视觉高亮：在原图上叠加半透明的目标掩码轮廓。
2. Token 级注意力先验：将掩码下采样至 VLA 的 Patch 分辨率，在 VLA 的 Transformer 中间层修改注意力矩阵，强制 Action Token 关注目标相关的 Visual Token。

作为一篇综述文章，本文的核心架构并非单一的神经网络，而是一个高度抽象的**动作接地推理（Action-Grounded Reasoning）通用范式**。该范式将自动驾驶系统的决策过程标准化为三个阶段：多模态输入处理、中间状态推理（核心）、连续动作生成。

2.  **中间状态推理（Intermediate Reasoning）**：这是本文的分类核心，系统根据不同的表征形式进行推理：
    *   **Language-based**：将场景转化为文本描述，利用 LLM 进行逻辑推理。

    *   **Latent-dynamic**：利用世界模型（World Models）在隐空间中进行未来状态的自回归预测，捕捉物理动态。
    *   **Externalized**：依赖外部知识图谱、物理引擎或交通规则库进行符号化推理。
3.  **动作生成（Action Generation）**：将上述中间表征解码为底层的连续控制信号（转向、油门、刹车）或高维轨迹航点。

```python
class ActionGroundedReasoner:
    def __init__(self, reasoning_type: str):
        self.reasoning_type = reasoning_type
        # 初始化对应的中间表征模型
        self.language_model = LLM()
        self.spatial_model = BEVEncoder()
        self.world_model = LatentDynamicsModel()
        self.knowledge_base = ExternalRuleEngine()
        self.action_decoder = ContinuousActionDecoder()

    def generate_intermediate_representation(self, sensor_data, instruction):
        """根据不同的推理范式生成中间状态表征"""
        if self.reasoning_type == "language-based":
            # 文本思维链：输出语义逻辑步骤
            return self.language_model.generate_cot(sensor_data, instruction)
            
        elif self.reasoning_type == "visual-spatial":
            # 视觉空间推理：输出占据网格或代价地图
            return self.spatial_model.predict_occupancy(sensor_data)
            
        elif self.reasoning_type == "latent-dynamic":
            # 潜在动态推理：在隐空间中预测未来状态序列
            latent_state = self.world_model.encode(sensor_data)
            return self.world_model.rollout_future(latent_state)
            
        elif self.reasoning_type == "externalized":
            # 外部化推理：查询交通规则或物理引擎
            return self.knowledge_base.query_constraints(sensor_data)
            
        else:
            raise ValueError("Unsupported reasoning type")

    def step(self, sensor_data, instruction):
        """端到端推理与动作生成流程"""
        # 1. 生成中间表征 (Intermediate State)
        intermediate_rep = self.generate_intermediate_representation(sensor_data, instruction)
        
        # 2. 动作接地 (Action Grounding)
        continuous_action = self.action_decoder.decode(intermediate_rep)
        
        return continuous_action
```

### 第二模块：核心架构解释

本文的模型架构摒弃了将整个场景压缩为单一隐变量的传统做法，转而采用一种高度解耦的、基于对象的条件计算流程。其核心逻辑分为以下四个步骤：

1. **特征构建 (Feature Construction)**：针对场景中的每一个物体，提取其当前位姿、速度、相对目标位置、机械臂动作，并聚合其他物体的排列不变特征，拼接成该物体的独立特征向量。
2. **变化门控 (Change Gate)**：将特征向量输入一个共享权重的门控网络，输出一个离散的二元决策（0 或 1）。训练时使用 Gumbel Straight-Through 估计器保证梯度回传，推理时输出硬离散值，决定该物体在下一帧是否发生状态改变。
3. **残差预测 (Residual Delta Head)**：将特征向量输入另一个共享权重的残差网络，预测该物体在 $x, y, \theta$ 上的位姿增量（$\Delta$）。
4. **掩码更新 (Masked Update)**：将预测的残差增量与门控决策相乘。只有门控激活（值为 1）的物体才会加上残差增量更新位姿；门控未激活（值为 0）的物体，其残差被强制清零，直接原样复制当前位姿。

**核心伪代码实现：**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SparseResidualWorldModel(nn.Module):
    def __init__(self, feat_dim):
        super().__init__()
        # 变化门：预测物体是否移动
        self.gate_net = nn.Sequential(
            nn.Linear(feat_dim, 128), 
            nn.ReLU(), 
            nn.Linear(128, 1)
        )
        # 残差头：预测位姿增量 (x, y, theta)
        self.delta_head = nn.Sequential(
            nn.Linear(feat_dim, 128), 
            nn.ReLU(), 
            nn.Linear(128, 3)
        )

    def forward(self, current_poses, features):
        """
        features: [batch_size, num_objects, feat_dim]
        current_poses: [batch_size, num_objects, 3]
        """
        # 1. 预测变化门控 (使用 Gumbel-Softmax 实现离散采样且可导)
        gate_logits = self.gate_net(features)
        # 训练时保留梯度，推理时输出硬离散值 {0, 1}
        gate_decisions = F.gumbel_softmax(gate_logits, tau=1.0, hard=True)

        # 2. 预测位姿残差
        deltas = self.delta_head(features)

        # 3. 掩码残差更新：仅对 gate_decisions == 1 的物体应用 delta
        masked_deltas = gate_decisions * deltas
        
        # 4. 计算下一时刻位姿：静止物体直接复制 current_poses
        next_poses = current_poses + masked_deltas

        return next_poses, gate_decisions, deltas
```

### 第二模块：核心架构解释

LAVLA 框架的运行流程可解构为四个核心阶段：数据与嵌入收集、交叉注意力加权、降维与聚类、概念生成与评估。

1. **数据与嵌入收集 (Embedding Collection)**：将自然语言指令、当前视觉帧和机器人本体状态输入冻结的 GR00T N1.5 模型。在模型前向传播时，拦截并保存 VLM 主干的最后一层输出，以及 DiT 动作解码器中所有交叉注意力层在 4 个扩散时间步（Timesteps）下的嵌入向量。
2. **交叉注意力加权 (Cross-Attention-Based Weighting)**：这是最核心的创新。在 DiT 的交叉注意力机制中，Query 来自上一层自注意力编码的动作 Token，Key 和 Value 来自 VLM 注入的视觉-语言特征。算法直接提取注意力权重矩阵 $\alpha$，对所有目标动作 Token 的注意力求平均，得到每个源视觉-语言 Token 的重要性得分。经过 Softmax 归一化后，与原始 VLM 嵌入进行哈达玛乘积（Hadamard product），放大关键特征，抑制无关背景。
3. **降维与聚类 (Dimensionality Reduction & Clustering)**：对加权后的高维嵌入（可选使用 PCA 降维至 100 维）应用凝聚层次聚类（Agglomerative Clustering）。通过计算层间和时间步间的 Jaccard 指数和重叠系数（Overlap Coefficient），并使用匈牙利算法解决标签切换问题，追踪簇的演化。
4. **概念生成 (Concept Generation)**：选取每个簇距离质心最近的 Top-n 样本，将其视频帧序列和文本指令输入外部大模型（LLaVA-72B），生成人类可读的语义概念，最后使用 CLIP 计算文本与视频帧的相似度进行评估。

**核心逻辑伪代码**：

```python
import numpy as np
from sklearn.cluster import AgglomerativeClustering
from sklearn.decomposition import PCA

def lavla_weighting_and_clustering(action_queries, vlm_embeddings, attention_matrix, use_pca=True):
    """
    action_queries: 动作 Token 序列 (a x d)
    vlm_embeddings: 视觉-语言 Token 序列 (n x d)
    attention_matrix: 交叉注意力权重矩阵 (a x n)
    """
    a, n = attention_matrix.shape
    
    # 1. 计算每个 VLM Token 的平均影响力得分 (Eq. 2)
    impact_scores = np.mean(attention_matrix, axis=0) # shape: (n,)
    
    # 2. Softmax 归一化得到权重向量 (Eq. 3)
    exp_scores = np.exp(impact_scores - np.max(impact_scores)) # 减去max防止溢出
    weights = exp_scores / np.sum(exp_scores) # shape: (n,)
    
    # 3. 哈达玛乘积加权 VLM 嵌入
    # 将 weights 扩展维度以匹配 vlm_embeddings 的特征维度 d
    weighted_vlm_embeddings = vlm_embeddings * weights[:, np.newaxis] 
    
    # 4. 降维 (可选)
    if use_pca:
        pca = PCA(n_components=100)
        processed_embeddings = pca.fit_transform(weighted_vlm_embeddings)
    else:
        processed_embeddings = weighted_vlm_embeddings
        
    # 5. 凝聚层次聚类
    clustering_model = AgglomerativeClustering(
        n_clusters=None, 
        distance_threshold=50.0, # 依据层级动态调整的超参数
        linkage='average',
        metric='euclidean'
    )
    cluster_labels = clustering_model.fit_predict(processed_embeddings)
    
    return cluster_labels, processed_embeddings
```

### 第二模块：核心架构解释

本研究的核心在于对比三种架构在处理世界动态时的表现。普通的 Byte-Transformer 将地图和动作视为一维字符串；Auxiliary Latent-Memory 增加了一维的额外记忆槽；而核心创新的 Pseudo-Video Spatial-Memory Transformer 则构建了一个显式的二维空间记忆流。

其运行流程如下：
1. **空间初始化**：将输入的 ASCII 初始地图保留其行列几何结构，映射为二维的初始潜在帧（Latent Frame）。
2. **动作驱动更新**：接收离散的动作指令（如“向上”、“向左”），通过因果动作编码器生成上下文向量。该向量写入当前的二维潜在帧，并通过空间自注意力和时间自注意力生成下一帧。这一过程没有中间地图的监督，完全是模型内部的“空间想象”。
3. **跨模态读取与解码**：在预测最终位置或文本观察时，文本解码器通过交叉注意力（Cross-Attention）机制，读取最终的二维潜在帧，自回归地生成精确的字节输出。

以下是该核心机制的 Python 风格伪代码实现逻辑：

```python
import torch
import torch.nn as nn

class PseudoVideoSpatialMemoryTransformer(nn.Module):
    def __init__(self, text_vocab_size, spatial_dim, hidden_dim):
        super().__init__()
        # 文本流编码与解码
        self.text_embed = nn.Embedding(text_vocab_size, hidden_dim)
        self.text_decoder = CausalTransformerDecoder(hidden_dim)
        
        # 空间记忆流组件
        self.spatial_embed = nn.Linear(spatial_dim, hidden_dim)
        self.action_encoder = CausalTransformerEncoder(hidden_dim)
        self.spatial_attention = SpatialSelfAttention(hidden_dim)
        self.temporal_attention = TemporalSelfAttention(hidden_dim)
        
        # 跨模态读取
        self.cross_attention = CrossAttention(query_dim=hidden_dim, key_val_dim=hidden_dim)

    def forward(self, initial_map_2d, action_sequence, target_prefix):
        # 1. 空间初始化：保留二维几何结构
        # initial_map_2d shape: (batch, rows, cols, spatial_dim)
        latent_frame = self.spatial_embed(initial_map_2d) 
        
        # 2. 动作驱动的隐式更新 (伪视频生成)
        # action_sequence shape: (batch, num_actions, hidden_dim)
        action_contexts = self.action_encoder(action_sequence)
        
        for t in range(action_contexts.size(1)):
            current_action = action_contexts[:, t, :].unsqueeze(1).unsqueeze(2)
            # 将动作信息广播并写入当前二维帧
            latent_frame = latent_frame + current_action 
            # 空间与时间维度的自注意力更新
            latent_frame = self.spatial_attention(latent_frame)
            latent_frame = self.temporal_attention(latent_frame)
            
        # 3. 跨模态读取与解码
        # 将最终的二维潜在帧展平作为 Key 和 Value
        final_spatial_memory = latent_frame.view(latent_frame.size(0), -1, latent_frame.size(-1))
        
        text_queries = self.text_embed(target_prefix)
        # 文本解码器通过交叉注意力读取空间记忆
        fused_features = self.cross_attention(query=text_queries, key=final_spatial_memory, value=final_spatial_memory)
        
        # 自回归预测输出
        logits = self.text_decoder(fused_features)
        return logits
```

# 第二模块：核心架构解释

ShallowStream 的架构设计将连续的视频流处理拆分为高频的轻量级感知与低频的重度推理两个阶段。

阶段一：Query-Agnostic Shallow Index Construction (无查询的浅层索引构建)
视频帧连续到达时，模型不执行完整的 Transformer 前向传播。视觉编码器提取特征后，仅通过语言模型的前 P 层（如前 5 层）进行处理。系统将这些浅层的 KV Cache 截留并保存，形成一个轻量级的全历史视觉索引。当内存达到阈值时，触发可选的长时聚类模块，将旧的帧特征进行合并压缩。

阶段二：Query-Time Answering (查询时的解答)
当用户或系统发出 Query 时，触发解答流程：
1. 门控路由 (Retrieval Gate)：通过一个 Few-shot Prompt 让模型输出特定 Token，判断该问题是需要追溯历史，还是仅靠当前最新帧即可解答。
2. 证据检索 (Evidence Retrieval)：若需追溯历史，将 Query 送入浅层网络，计算其与历史浅层 KV Cache 的 Attention 分数。通过 Token Voting（词元投票）和 Max-Min 多样性策略，精准召回最相关的 Top-K 历史帧。
3. 选择性生成 (Selective Generation)：将召回的历史帧与当前帧拼接，送入完整的 MLLM（执行剩余的深层网络）生成最终答案。

```python
def shallow_stream_process(video_stream, query, shallow_layers, deep_layers, gate_threshold):
    shallow_kv_cache = []
    recent_context = []
    
    # Stage 1: Query-Agnostic Stream Processing (High Frequency)
    for frame in video_stream:
        # Only process through shallow layers (e.g., layers 0 to P-1)
        shallow_features, kv = shallow_layers.forward(frame)
        
        # Maintain lightweight index
        shallow_kv_cache.append({'frame': frame, 'kv': kv, 'features': shallow_features})
        recent_context.update(frame)
        
        # Optional: Compress old memory if budget exceeded
        if memory_exceeded():
            shallow_kv_cache = cluster_compress(shallow_kv_cache)
            
    # Stage 2: Query-Time Answering (Low Frequency)
    if query_arrives(query):
        # Gate: Decide if historical retrieval is needed via logit difference
        logit_diff = compute_gate_logits(query, recent_context)
        
        if logit_diff > gate_threshold:
            # Retrieve from history using shallow attention scores
            query_shallow_kv = shallow_layers.forward(query)
            attention_scores = compute_attention(query_shallow_kv, shallow_kv_cache)
            
            # Token voting + Max-Min diversity selection
            selected_indices = diversity_aware_select(attention_scores, top_k=8)
            retrieved_frames = [shallow_kv_cache[i]['frame'] for i in selected_indices]
        else:
            retrieved_frames = []
            
        # Assemble context and run full-depth MLLM (layers P to L-1)
        final_context = retrieved_frames + recent_context + query
        answer = deep_layers.forward(final_context)
        
        return answer
```

### 第二模块：核心架构解释

LookStep 的核心架构将传统的“观察-动作”映射重构为“观察-预演-记忆-动作”的自回归文本生成流水线。整个流程由两个核心模块构成，并在统一的 MLLM（Qwen3-VL 8B）中端到端执行。

**1. 语言中心化未来状态建模 (LFS)**
在执行动作前，模型首先输出当前导航进度（如 `start`, `near_goal`）。随后，模型针对动作空间中的每一个候选动作（前进、左转、右转、停止），显式生成对应的未来状态文本标签（如 `advance_to_goal`, `wrong_turn`）。这一步等价于一个轻量级的、基于语言的 World Model，用于在动作执行前评估后果。

**2. 事件驱动滚动记忆 (EDRM)**
模型在生成未来状态后，会输出一个记忆写入决策（`keep` 或 `drop`）以及当前帧的语义角色（如 `turn_end`, `stop_evidence`）。如果决策为 `keep`，当前 RGB 观测及其语义角色将被推入一个定长（长度为 8）的 FIFO 队列中。这使得模型能够自主过滤冗余帧，仅保留关键导航事件。

**3. 动作预测与训练**
在生成上述所有中间文本后，模型最终输出下一步动作。在训练阶段，所有中间标签（进度、未来状态、记忆决策、记忆角色）均通过确定性规则从专家轨迹中自动提取，无需人工标注。整个序列通过标准的 Next-token 负对数似然损失进行联合优化。

**核心逻辑伪代码：**

```python
class LookStepAgent:
    def __init__(self, mllm_model, memory_capacity=8):
        self.mllm = mllm_model
        self.memory_queue = [] # FIFO queue for EDRM
        self.memory_capacity = memory_capacity
        self.action_space = ['MOVE', 'TURN_LEFT', 'TURN_RIGHT', 'STOP']

    def step(self, instruction, current_observation):
        # Construct input context
        context = {
            "instruction": instruction,
            "history_memory": self.memory_queue,
            "current_obs": current_observation
        }
        
        # Autoregressive generation via MLLM
        # 1. Predict current progress
        progress = self.mllm.generate_progress(context)
        
        # 2. LFS: Predict future outcomes for ALL candidate actions
        outcomes = {}
        for action in self.action_space:
            outcomes[action] = self.mllm.generate_outcome(context, action)
            
        # 3. EDRM: Predict memory write decision and semantic role
        memory_write = self.mllm.generate_memory_decision(context)
        memory_role = self.mllm.generate_memory_role(context)
        
        # 4. Predict final action based on all generated intermediate reasoning
        final_action = self.mllm.generate_action(context, progress, outcomes, memory_write, memory_role)
        
        # Update Event Driven Rolling Memory
        if memory_write == 'keep':
            memory_event = {
                "observation": current_observation,
                "role": memory_role
            }
            self.memory_queue.append(memory_event)
            
            # Maintain bounded FIFO memory
            if len(self.memory_queue) > self.memory_capacity:
                self.memory_queue.pop(0)
                
        return final_action
```

### 第二模块：核心架构解释

DiffuSearch 采用两阶段架构，其核心思想是“System 1 快速直觉生成 + System 2 慢速逻辑验证”，并通过统一的目标函数将两者绑定。

**阶段一：基于引导扩散的联合预测 (Joint Prediction via Guided Diffusion)**
模型接收地图、静态障碍物和智能体历史状态，使用 Diffusion Transformer (DiT) 骨干网络预测自车和周围智能体的未来联合轨迹。在去噪过程中，引入无分类器引导（Classifier-Free Guidance），利用四个可微的驾驶目标函数（防碰撞、可行驶区域、进度、舒适度）计算梯度，隐式地将生成的轨迹推向安全区域。该阶段输出一个全局合理的场景级轨迹先验。

**阶段二：动作空间中的蒙特卡洛树搜索 (MCTS in Action Space)**
由于扩散模型无法提供绝对的安全硬约束，第二阶段在离散的动作空间（加速度和转向角）中运行 MCTS 进行显式局部细化。
1. **先验聚焦**：将阶段一生成的自车轨迹转化为动作序列，构建一个紧凑的高斯分布作为 MCTS 的先验概率，极大地缩小了搜索空间。
2. **环境模拟**：使用运动学自行车模型模拟自车动作，同时使用阶段一预测的其他智能体轨迹作为“世界模型”来推演未来场景。
3. **统一奖励**：MCTS 评估叶子节点时，使用与阶段一完全相同的四个驾驶目标函数计算奖励。这确保了搜索是对初始提案的“微调”而非“重写”。

```python
# DiffuSearch 核心逻辑伪代码
def diffusearch_planner(scene_context, num_mcts_steps=256):
    # 阶段一：引导扩散模型生成联合轨迹先验
    # 目标函数：碰撞、道路边界、进度、舒适度
    shared_objectives = [cost_collision, cost_drivable, cost_progress, cost_comfort]
    
    # 隐式引导去噪过程
    joint_trajectory_proposal = guided_diffusion_model(
        scene_context, 
        guidance_fns=shared_objectives
    )
    
    ego_proposal = joint_trajectory_proposal.ego
    other_agents_pred = joint_trajectory_proposal.others # 作为 MCTS 的世界模型
    
    # 阶段二：MCTS 动作空间搜索
    mcts = MCTS(action_space=DiscreteActionSpace())
    root_state = scene_context.current_ego_state
    
    for step in range(num_mcts_steps):
        # 1. 选择 (Selection): 利用扩散先验 P(s,a) 聚焦搜索
        node = mcts.select(root_state, prior_trajectory=ego_proposal)
        
        # 2. 扩展 (Expansion): 离散动作展开
        action = node.get_feasible_action()
        
        # 3. 模拟 (Simulation): 运动学模型 + 其他智能体预测
        next_state = kinematic_bicycle_model(node.state, action)
        simulated_scene = update_scene(next_state, other_agents_pred)
        
        # 4. 评估 (Evaluation): 使用与阶段一完全相同的目标函数计算 Reward
        reward = sum([-weight * obj(simulated_scene) for obj, weight in shared_objectives])
        
        # 5. 回溯 (Backpropagation)
        mcts.backpropagate(node, reward)
        
    # 提取最优动作序列并转换为最终轨迹
    best_action_sequence = mcts.get_best_path()
    final_trajectory = rollout_kinematic_model(root_state, best_action_sequence)
    
    return final_trajectory
```
