### 第二模块：核心架构解释

WVM 的核心架构设计旨在将视频世界模型的生成能力无缝转化为判别式的价值评估能力，同时避免破坏原有的视频表征。其工作流程可拆解为以下四个关键步骤：

1.  **视频特征编码 (Video Stream)**：利用预训练的 Wan2.2 VAE 将输入的视频片段（包含前缀帧、当前上下文帧、未来目标帧）压缩为时空潜在变量（Latents）。
2.  **双流 DiT 与非对称耦合 (Value Stream & MoT)**：构建一个轻量级的 Value DiT。在 Transformer 的每一层中，视频 Token 正常进行自注意力计算；而价值 Token 则通过混合 Transformer（MoT）机制，与视频 Token 拼接后进行注意力计算。**关键设计是采用非对称掩码**：价值 Token 可以“看到”视频特征，但视频 Token 严格屏蔽价值 Token，确保视频生成流不受干扰。
3.  **连续价值块预测 (Distributional Chunk via Flow Matching)**：不预测单一的标量进度，而是预测一个长度为 $h$ 的价值序列块（Value Chunk）。采用流匹配（Flow Matching）目标函数，联合优化视频潜在变量的去噪速度场和价值块的去噪速度场。
4.  **鲁棒性数据增强 (Augmentations)**：在训练时引入“前缀随机化（Prefix Randomization）”防止模型过度依赖历史帧走捷径；引入“视频倒放（Video Rewinding）”人为构造进度倒退和停滞的样本，弥补专家数据中缺乏次优行为的缺陷。

def wvm_forward_and_loss(video_clip, value_chunk_gt):
    """
    video_clip: [prefix_frame, current_frames, future_frames]
    value_chunk_gt: Ground truth progress values for the chunk, shape [h]
    """
    # 1. 视频 VAE 编码提取时空特征
    video_latents = video_vae.encode(video_clip)
    current_context = video_latents.current
    future_latents = video_latents.future
    
    # 2. 流匹配 (Flow Matching) 加噪过程
    noise_video = sample_normal_like(future_latents)
    noise_value = sample_normal_like(value_chunk_gt)
    t = sample_time_step() # t in (0, 1)
    
    noisy_future = t * future_latents + (1 - t) * noise_video
    noisy_value = t * value_chunk_gt + (1 - t) * noise_value
    
    # 3. 序列化 Token
    video_tokens = patchify(noisy_future, current_context)
    value_tokens = linear_proj(noisy_value)
    
    # 4. 双流 DiT 与 MoT 非对称耦合
    for layer in mot_transformer_layers:
        # 视频流：独立自注意力
        video_tokens = layer.video_attn(video_tokens)
        
        # 价值流：非对称注意力 (Value 关注 Value + Video)
        # 掩码保证 Video 不会关注到 Value
        joint_tokens = concat([value_tokens, video_tokens])
        value_tokens = layer.value_attn(value_tokens, context=joint_tokens)
        
    # 5. 速度场预测 (Velocity Field Prediction)
    pred_video_vel = video_head(video_tokens)
    pred_value_vel = value_head(value_tokens)
    
    # 6. 计算 Flow Matching 损失
    loss_video = mse_loss(pred_video_vel, future_latents - noise_video)
    loss_value = mse_loss(pred_value_vel, value_chunk_gt - noise_value)
    
    # 联合优化 (lambda_weight 控制视频协同训练的权重)
    total_loss = loss_value + lambda_weight * loss_video
    return total_loss

### 第二模块：核心架构解释

GRA 框架的核心逻辑在于**解耦监督**。它放弃了从合成视频中提取 3D 动作的幻想，转而利用视频中唯一可靠的 2D 几何信息来锚定视觉特征。

**流程详解**：
1.  **路点提取（Waypoint Extraction）**：不直接处理生成的模糊视频，而是回到源头（源人类视频）。依次通过人体姿态估计、动作重定向到机器人模型、在仿真环境中运行，最后经过相机标定投影，计算出精确的未来 2D 末端执行器路点。
2.  **视觉主干网络对齐（Vision Backbone Alignment）**：将合成的机器人视频输入 VLA 的视觉主干网络。网络不仅需要输出特征给动作头，还需要通过一个辅助的 2D 预测头（Auxiliary 2D Head）预测上述提取的 2D 路点。这一步产生的路点损失（Waypoint Loss）作为“空间表示锚点”，迫使视觉模型理解几何轨迹。
3.  **动作头训练（Action Head Training）**：彻底剥离合成数据对控制信号的干扰。VLA 的动作预测头严格且仅使用真实的机器人演示数据（包含精确的电机指令）进行训练。

class GRA_VLA(nn.Module):
    def __init__(self, vision_backbone, action_head):
        super().__init__()
        self.vision_backbone = vision_backbone
        self.action_head = action_head
        # 核心创新：辅助的2D路点预测头，用于几何对齐
        self.auxiliary_2d_head = nn.Linear(vision_backbone.output_dim, 2)

    def forward(self, image, text_instruction):
        # 提取视觉特征
        visual_features = self.vision_backbone(image, text_instruction)
        # 预测底层控制动作
        predicted_action = self.action_head(visual_features)
        # 预测2D几何路点
        predicted_waypoints = self.auxiliary_2d_head(visual_features)
        return predicted_action, predicted_waypoints

def train_step(model, batch, optimizer):

    images = batch['image']
    texts = batch['text']
    is_real = batch['is_real'] # 布尔掩码：区分真实演示与合成视频
    
    pred_actions, pred_waypoints = model(images, texts)
    
    # 1. 动作损失：严格仅在真实数据上计算 (Control is learned from real demos)
    real_indices = torch.where(is_real)[0]
    if len(real_indices) > 0:
        action_loss = compute_action_loss(
            pred_actions[real_indices], 
            batch['real_actions'][real_indices]
        )
    else:
        action_loss = 0.0
        
    # 2. 几何路点损失：在合成数据上计算，作为空间表示锚点 (Geometry survives generation)
    waypoint_loss = compute_mse_loss(
        pred_waypoints, 
        batch['target_2d_waypoints']
    )
    
    # 联合优化：视觉主干同时受到真实动作和合成几何的梯度更新
    total_loss = action_loss + lambda_weight * waypoint_loss
    total_loss.backward()
    optimizer.step()
    
    return total_loss

            bound_futures.append(future)
    consistency_score = evaluate_consistency(bound_futures)

    # 在分布偏移下验证鲁棒性，拒绝不安全分支

    ood_score = evaluate_robustness(verified_futures)
    
    # Stage 4: Distillation (Metric: Efficiency)
    # 将存活的轨迹压缩为紧凑的决策变量，避免决策过载
    decision_variables = distill_to_compact_representation(verified_futures, budget)
    efficiency_score = evaluate_efficiency(decision_variables)

    # 将蒸馏的知识反馈给生成器，更新生成先验
    generator.update_prior(decision_variables)

    controllability_score = (novelty_score ** w1) * (consistency_score ** w2) * \

    return decision_variables, controllability_score

### 第二模块：核心架构解释

WVM 的核心架构设计旨在将视频世界模型的生成能力无缝转化为判别式的价值评估能力，同时避免破坏原有的视频表征。其工作流程可拆解为以下四个关键步骤：

1.  **视频特征编码 (Video Stream)**：利用预训练的 Wan2.2 VAE 将输入的视频片段（包含前缀帧、当前上下文帧、未来目标帧）压缩为时空潜在变量（Latents）。
2.  **双流 DiT 与非对称耦合 (Value Stream & MoT)**：构建一个轻量级的 Value DiT。在 Transformer 的每一层中，视频 Token 正常进行自注意力计算；而价值 Token 则通过混合 Transformer（MoT）机制，与视频 Token 拼接后进行注意力计算。**关键设计是采用非对称掩码**：价值 Token 可以“看到”视频特征，但视频 Token 严格屏蔽价值 Token，确保视频生成流不受干扰。
3.  **连续价值块预测 (Distributional Chunk via Flow Matching)**：不预测单一的标量进度，而是预测一个长度为 $h$ 的价值序列块（Value Chunk）。采用流匹配（Flow Matching）目标函数，联合优化视频潜在变量的去噪速度场和价值块的去噪速度场。
4.  **鲁棒性数据增强 (Augmentations)**：在训练时引入“前缀随机化（Prefix Randomization）”防止模型过度依赖历史帧走捷径；引入“视频倒放（Video Rewinding）”人为构造进度倒退和停滞的样本，弥补专家数据中缺乏次优行为的缺陷。

**核心逻辑伪代码 (Python 风格)**：

```python
def wvm_forward_and_loss(video_clip, value_chunk_gt):
    """
    video_clip: [prefix_frame, current_frames, future_frames]
    value_chunk_gt: Ground truth progress values for the chunk, shape [h]
    """
    # 1. 视频 VAE 编码提取时空特征
    video_latents = video_vae.encode(video_clip)
    current_context = video_latents.current
    future_latents = video_latents.future
    
    # 2. 流匹配 (Flow Matching) 加噪过程
    noise_video = sample_normal_like(future_latents)
    noise_value = sample_normal_like(value_chunk_gt)
    t = sample_time_step() # t in (0, 1)
    
    noisy_future = t * future_latents + (1 - t) * noise_video
    noisy_value = t * value_chunk_gt + (1 - t) * noise_value
    
    # 3. 序列化 Token
    video_tokens = patchify(noisy_future, current_context)
    value_tokens = linear_proj(noisy_value)
    
    # 4. 双流 DiT 与 MoT 非对称耦合
    for layer in mot_transformer_layers:
        # 视频流：独立自注意力
        video_tokens = layer.video_attn(video_tokens)
        
        # 价值流：非对称注意力 (Value 关注 Value + Video)
        # 掩码保证 Video 不会关注到 Value
        joint_tokens = concat([value_tokens, video_tokens])
        value_tokens = layer.value_attn(value_tokens, context=joint_tokens)
        
    # 5. 速度场预测 (Velocity Field Prediction)
    pred_video_vel = video_head(video_tokens)
    pred_value_vel = value_head(value_tokens)
    
    # 6. 计算 Flow Matching 损失
    loss_video = mse_loss(pred_video_vel, future_latents - noise_video)
    loss_value = mse_loss(pred_value_vel, value_chunk_gt - noise_value)
    
    # 联合优化 (lambda_weight 控制视频协同训练的权重)
    total_loss = loss_value + lambda_weight * loss_video
    return total_loss
```

### 第二模块：核心架构解释

InSight 框架的运行流程分为两个完全独立的阶段：离线图元分割与在线自主技能获取。

**阶段一：构建图元级可控的 VLA（离线）**
系统接收人类遥操作的演示视频与运动学数据。VLM 结合夹爪开合状态、末端执行器的主导运动轴以及视觉帧，将长视频自动切分为带有语义标签的短片段（即动作图元，如“向下移动”、“闭合夹爪”）。随后，使用这些图元片段通过 LoRA 微调预训练的 VLA 模型，使其能够根据具体的图元语言指令输出动作。

**阶段二：VLM 引导的自主技能获取（在线）**
当输入一个全新的任务指令时，VLM 首先生成包含多个图元的执行计划，并将其与 VLA 已知的图元库进行对比，标记出 VLA 不会的“缺失图元”。对于这些缺失图元，VLM 会观察当前环境图像，输出一个底层的控制指令（指定一个平移或旋转轴，以及运动幅度）。机器人执行该指令后，VLM 充当裁判（Oracle）对比执行前后的图像以判断是否成功。如果成功，该轨迹被存入数据集，VLA 重新进行微调，从而永久掌握该新图元。

        primitives = vlm_auto_segmentation(demo.video, demo.kinematics)

    known_vocabulary = extract_labels(primitive_dataset)

# 阶段二：在线自主技能获取飞轮
def stage2_autonomous_skill_acquisition(novel_task, steerable_vla, known_vocabulary):
    # VLM 拆解任务，找出 VLA 不会的缺失图元

    successful_rollouts = []
    for gap in primitive_gaps:

        axis, magnitude = vlm_propose_kinematic_params(gap, current_image)

        trajectory = execute_low_level_control(axis, magnitude)
        
        # VLM 裁判对比前后图像，验证图元是否执行成功
        is_success = vlm_oracle_check(before_image, after_image, gap)
        
        if is_success:
            successful_rollouts.append((gap, trajectory))
            
    # 将成功的试错数据加入训练集，重训 VLA
    if successful_rollouts:
        steerable_vla = retrain_vla(steerable_vla, successful_rollouts)
        known_vocabulary.update(primitive_gaps)
        
    return steerable_vla

### 第二模块：核心架构解释

GRA 框架的核心逻辑在于**解耦监督**。它放弃了从合成视频中提取 3D 动作的幻想，转而利用视频中唯一可靠的 2D 几何信息来锚定视觉特征。

**流程详解**：
1.  **路点提取（Waypoint Extraction）**：不直接处理生成的模糊视频，而是回到源头（源人类视频）。依次通过人体姿态估计、动作重定向到机器人模型、在仿真环境中运行，最后经过相机标定投影，计算出精确的未来 2D 末端执行器路点。
2.  **视觉主干网络对齐（Vision Backbone Alignment）**：将合成的机器人视频输入 VLA 的视觉主干网络。网络不仅需要输出特征给动作头，还需要通过一个辅助的 2D 预测头（Auxiliary 2D Head）预测上述提取的 2D 路点。这一步产生的路点损失（Waypoint Loss）作为“空间表示锚点”，迫使视觉模型理解几何轨迹。
3.  **动作头训练（Action Head Training）**：彻底剥离合成数据对控制信号的干扰。VLA 的动作预测头严格且仅使用真实的机器人演示数据（包含精确的电机指令）进行训练。

### 第二模块：核心架构解释

### 第二模块：核心架构解释

$G^3VLA$ 的核心逻辑是构建一个“相机感知几何模块”（Camera-Aware Geometric Module），并采用两阶段训练法。整个数据流和实验流程如下：

1. **视觉特征提取**：多视角 RGB 图像输入冻结的预训练视觉编码器（如 SigLIP），输出 2D Patch Tokens。
2. **内参条件射线嵌入（Ray Embeddings）**：利用相机内参 $K$，将像素坐标反投影为归一化射线方向。通过一个可学习的线性层将其映射为与 Token 同维度的向量，并直接加到对应的 Patch Tokens 上。
3. **双向跨视角融合（Cross-View Fusion with PRoPE）**：将所有视角的 Tokens 展平。在计算自注意力时，不使用传统的相对位置编码，而是使用 PRoPE（Projective Positional Encoding）。PRoPE 利用相机的内参 $K$ 和外参 $T$，计算不同视角 Token 之间的极线/投影几何关系，作为 Attention 的 Bias。
4. **几何蒸馏（Geometry Distillation）**：在进入 VLA 动作解码器之前，引出一个轻量级的辅助预测头，将融合后的 Tokens 解码为密集的射线坐标图和对数深度图（log-z）。
5. **两阶段训练**：
   - Stage 1：冻结 VLA 骨干，仅训练几何模块和辅助头。监督信号来自真实深度（GT）或离线教师模型（$\pi^3X$）生成的点图，并使用教师模型的置信度进行 Hard Gating（过滤低置信度像素）。
   - Stage 2：解冻全模型，以动作预测的损失（如 Flow-matching loss）为主导，几何蒸馏损失作为正则化项进行联合微调。

**核心逻辑伪代码 (Python 风格)**：

```python
def forward_g3vla(images, intrinsics, extrinsics, action_targets, teacher_point_maps, confidences):
    # 1. 预训练视觉编码器 (Frozen in Stage 1)
    # images: [V, C, H, W] -> patch_tokens: [V, P, D]
    patch_tokens = vision_encoder(images) 
    
    # 2. 内参条件射线嵌入
    # 计算归一化射线: r = K^{-1} * [x, y, 1]^T
    ray_maps = compute_rays_from_intrinsics(intrinsics) # [V, P, 2]
    ray_embeddings = ray_proj_layer(ray_maps)           # [V, P, D]
    z_tokens = patch_tokens + ray_embeddings            # 注入局部视角方向
    
    # 3. 双向跨视角融合与 PRoPE
    # 计算基于物理相机的注意力偏置
    prope_bias = compute_prope_bias(intrinsics, extrinsics) 
    flattened_tokens = rearrange(z_tokens, 'V P D -> (V P) D')
    # 跨视角 Attention，注入全局投影几何
    fused_tokens = cross_view_attention(flattened_tokens, attn_bias=prope_bias) 
    fused_tokens = rearrange(fused_tokens, '(V P) D -> V P D')
    
    # 4. 辅助几何蒸馏头 (仅训练时)
    pred_rays, pred_log_depth = auxiliary_point_head(fused_tokens)
    
    # 计算蒸馏损失 (使用置信度进行 Hard Gating)
    valid_mask = confidences > 0.1
    loss_distill = compute_mse_loss(pred_rays, pred_log_depth, teacher_point_maps, mask=valid_mask)
    
    # 5. VLA 动作预测
    # 融合后的 tokens 直接输入预训练 VLA 骨干
    action_preds = vla_action_decoder(fused_tokens, language_instruction, proprioception)
    loss_action = compute_action_loss(action_preds, action_targets)
    
    # 总损失 (Stage 1: lambda_act 极小; Stage 2: lambda_act 主导)
    total_loss = lambda_act * loss_action + lambda_distill * loss_distill
    
    return total_loss
```

### 第二模块：核心架构解释

NavWM 的架构设计摒弃了传统的模块化级联，采用多任务联合学习的统一网络。其核心流程分为特征编码、潜在世界推理、多模态轨迹提案和视觉前瞻四个阶段。

**1. 特征编码**：将历史观测帧、当前观测帧和目标图像通过预训练的 VAE 编码为潜在特征，并与一组可学习的“潜在世界 Token”拼接，输入双向 Mamba 主干网络提取全局时空特征。
**2. 潜在世界推理（辅助任务）**：将 Mamba 输出的潜在世界 Token 通过 CNN 解码器，预测未来的深度图和语义分割图。该分支在训练时由视觉基础模型（Depth Anything V2, SAM）提供伪标签监督，迫使模型学习三维几何与语义先验。
**3. 多模态轨迹提案**：基于提取的场景特征，通过意图头（预测锚点概率）和控制头（回归空间偏移）生成多个候选目标点，随后直接回归出对应的多条未来轨迹序列。
**4. 视觉前瞻与世界建模**：将预测的多条轨迹转化为光流场，与场景特征一同作为条件输入到 CDiT（条件扩散 Transformer）中。采用连续时间流匹配（Flow Matching）技术，生成每条候选轨迹对应的未来视觉观测。
**5. 闭环规划（推理阶段）**：评估所有生成的未来视觉观测与目标图像的对齐程度，选择最优轨迹执行。

**核心逻辑伪代码**：

```python
import torch
import torch.nn as nn

class NavWM(nn.Module):
    def __init__(self):
        super().__init__()
        self.vae_encoder = VAEEncoder()
        self.latent_world_tokens = nn.Parameter(torch.randn(1, N, D))
        self.bi_mamba = BidirectionalMamba()
        
        # Task Heads
        self.reasoning_decoder = SceneAbstractionDecoder()
        self.trajectory_proposal = MultimodalTrajectoryHead()
        self.cdit_world_model = ConditionalDiffusionTransformer()
        self.vae_decoder = VAEDecoder()

    def forward(self, history_obs, current_obs, goal_img):
        # 1. 视觉特征编码
        obs_latents = self.vae_encoder(history_obs, current_obs, goal_img)
        
        # 2. 时空特征提取 (融合可学习的物理先验 Token)
        input_tokens = torch.cat([obs_latents, self.latent_world_tokens], dim=1)
        scene_features = self.bi_mamba(input_tokens)
        
        # 3. 潜在世界推理 (输出深度与语义预测，用于辅助损失)
        depth_pred, semantic_pred = self.reasoning_decoder(scene_features)
        
        # 4. 多模态轨迹提案 (输出 K 条候选轨迹)
        # anchor_probs: [Batch, K], candidate_trajs: [Batch, K, Horizon, 2]
        anchor_probs, candidate_trajs = self.trajectory_proposal(scene_features)
        
        # 5. 视觉前瞻 (世界模型生成未来状态)
        future_observations = []
        for k in range(candidate_trajs.size(1)):
            traj_k = candidate_trajs[:, k, :, :]
            # 将轨迹转化为光流条件并进行流匹配生成
            latent_future = self.cdit_world_model(scene_features, traj_k)
            pixel_future = self.vae_decoder(latent_future)
            future_observations.append(pixel_future)
            
        return candidate_trajs, future_observations, depth_pred, semantic_pred

    def closed_loop_planning(self, history_obs, current_obs, goal_img):
        # 推理阶段：生成多条轨迹及其未来画面，通过 Critic 选择最优动作
        candidate_trajs, future_obs, _, _ = self.forward(history_obs, current_obs, goal_img)
        optimal_traj = self.evaluate_and_select(future_obs, goal_img, candidate_trajs)
        return optimal_traj
```

### 第二模块：核心架构解释

本文的方法论分为三个核心阶段：目标构造、策略查询与边界更新、以及模型恢复。其本质是通过智能体在特定任务上的表现，反推并锁定其内部世界模型的精度。

1.  **探针目标构造 (Goal Construction)**：利用线性时序逻辑（LTL）构造两组相互竞争的组合目标。目标 A 要求智能体在初始状态执行动作 $a$ 并重复特定转移 $r$ 次；目标 B 要求执行替代动作 $b$ 并重复该转移 $r+1$ 次。
2.  **策略查询与边界更新 (Policy Query & Bound Update)**：将上述组合目标输入给智能体，观察其在初始状态的首选动作。智能体的选择暴露了其内部对转移概率的预期。通过遍历不同的重复次数 $r$（从 $0$ 到 $n-1$），算法不断收紧该转移概率的理论上限（$p_{max}$）和下限（$p_{min}$）。
3.  **认证与模型恢复 (Certification & Estimation)**：如果环境真实的转移概率落在这个被收紧的上下限区间内，则该转移被“认证（Certified）”。对于被认证的转移，算法直接通过智能体发生动作切换的临界点 $r^\star$ 计算出其内部世界模型的估计值 $\hat{P}_{ss'}(a)$。

**核心算法伪代码 (Python 风格):**

```python
def structural_certification(agent_policy, s, a, s_prime, alt_b, n, delta, true_P):
    """
    对特定状态转移 (s, a, s') 进行结构化认证并恢复内部世界模型估计
    :param agent_policy: 智能体的确定性策略
    :param n: 目标最大深度 (Horizon)
    :param delta: 容许的失败率 (Failure rate)
    :param true_P: 真实的转移概率 P(s' | s, a)
    """
    p_min = 0.0
    p_max = 1.0
    r_star = None

    # 遍历深度 n，寻找智能体策略的切换临界点
    for r in range(n):
        # 构造 LTL 探针目标
        # goal_a: 初始执行 a，并要求转移发生 r 次
        # goal_b: 初始执行 alt_b，并要求转移发生 r+1 次
        composite_goal = construct_competing_goals(s, a, s_prime, alt_b, r, n)
        
        # 查询智能体在面对组合目标时的首选动作
        chosen_action = agent_policy.get_action(state=s, goal=composite_goal)
        
        if chosen_action == a:
            # 智能体认为执行 a 达到 r 次转移的概率更高，更新上限
            current_upper_bound = (r + 1) / (n + 1 - delta * (n - r))
            p_max = min(p_max, current_upper_bound)
            if r_star is None:
                r_star = r
        else:
            # 智能体认为执行 alt_b 达到 r+1 次转移的概率更高，更新下限
            current_lower_bound = ((r + 1) * (1 - delta)) / (n + 1 - (r + 1) * delta)
            p_min = max(p_min, current_lower_bound)

    # 检查真实转移概率是否在智能体行为推导出的严格边界内
    is_certified = (p_min <= true_P <= p_max) and (r_star is not None)

    # 如果通过认证，恢复智能体内部的世界模型估计值
    if is_certified:
        estimated_P = (r_star + 0.5) / (n + 1)
    else:
        estimated_P = None

    return is_certified, estimated_P
```

    # 1. 收集轨迹数据 (包含特权观测 s_t 和本体历史 o_t)
    trajectories = collect_data(teacher_enc, student_enc, actor_critic)
    
    # 2. 更新世界模型与教师编码器 (强制动力学感知)
    for epoch in range(wm_epochs):
        z_t = teacher_enc(s_t)
        s_next_pred = world_model(z_t, s_t)
        loss_wm = mse_loss(s_next_pred, s_next_true)
        # 梯度回传至 world_model 和 teacher_enc
        optimizer_wm.zero_grad()
        loss_wm.backward()
        optimizer_wm.step()
        
    # 3. 使用 PPO 更新 Actor-Critic 和教师编码器
    update_ppo(actor_critic, teacher_enc, trajectories)
    
    # 4. 更新学生编码器 (动量蒸馏)
    for epoch in range(distill_epochs):
        z_s_online = student_enc(o_t)
        with torch.no_grad():
            z_s_target = student_target_enc(o_t)
        z_t_teacher = teacher_enc(s_t).detach()
        
        # BYOL 归一化预测损失 + 缓慢更新的教师对齐损失
        loss_moment = normalized_mse(project(z_s_online), z_s_target)
        loss_align = mse_loss(z_s_online, z_t_teacher)
        loss_student = loss_moment + lambda_mse * loss_align
        
        optimizer_student.zero_grad()
        loss_student.backward()
        optimizer_student.step()
        
        # 5. EMA 更新动量目标编码器
        for param_online, param_target in zip(student_enc.parameters(), student_target_enc.parameters()):
            param_target.data = tau * param_target.data + (1 - tau) * param_online.data
```

### 第二模块：核心架构解释

DriveStack-VLA 的整体架构与训练流程分为三个阶段：

**1. 模型架构 (Actor-Critic)**
*   **Actor (VLM Backbone):** 基于 Qwen3-VL-4B。包含透视图像编码器和额外的 BEV 编码器（基于 BEVFormer）。BEV 特征不只在输入层拼接，而是通过 DeepStack 机制逐层注入到 LLM 解码器中。解码器输出离散的动作 Token（Scale token 和 Trajectory code token），由冻结的 VQ 动作码本解码为连续轨迹。
*   **Critic (Self-Critic):** 复用 LLM 解码器最后一层的视觉隐藏状态，拼接候选轨迹后，通过 Scoring Head 输出标量评分进行排序；若最高分低于阈值，则通过 Refinement Head 预测有界残差进行轨迹修正。

**2. 三阶段训练流程**
*   **Stage 1 (SFT + Render-Teacher Alignment):** 监督微调。输入成对的真实图像与光栅化图像。光栅化图像分支作为 Teacher（停止梯度），真实图像分支作为 Student。计算 Masked Token 均方误差与 Action-to-Vision 注意力分布的 KL 散度，迫使模型关注真实图像中的关键几何与交通参与者。
*   **Stage 2 (RFT):** 强化微调。冻结视觉投影层，使用 GRPO 算法优化 Actor。奖励函数结合了驾驶奖励（防碰撞、安全缓冲、可行驶区域）与格式奖励（Token 长度、范围、Schema 合法性）。
*   **Stage 3 (Critic Training):** 冻结 Actor，利用 Stage 1 模型生成的候选轨迹及对应的 PDMS 真实得分，训练 Scoring Head（SmoothL1 + Ranking Loss）和 Refinement Head。

def stage1_forward(real_images, rasterized_images, text_prompt, target_actions):
    # 1. 视觉特征提取
    real_cam_tokens = vision_encoder(real_images)
    rast_cam_tokens = vision_encoder(rasterized_images).detach() # Teacher, stop gradient
    
    # BEV 特征提取 (仅真实图像)
    bev_features = bev_encoder(real_images)
    
    # 2. DeepStack 注入与 LLM 解码
    # 初始化 LLM 隐藏状态
    real_hidden = llm_embed(text_prompt)
    rast_hidden = llm_embed(text_prompt)
    
    real_attn_maps = []
    rast_attn_maps = []
    
    for layer in llm_layers:
        # DeepStack: 逐层拼接 Camera Token 与 BEV Token
        real_layer_visual = concat(real_cam_tokens[layer], bev_projector(bev_features, layer))
        rast_layer_visual = concat(rast_cam_tokens[layer], bev_projector(bev_features, layer).detach())
        
        # LLM 前向传播，记录 Action-to-Vision 的注意力矩阵
        real_hidden, real_attn = layer(real_hidden, real_layer_visual)
        rast_hidden, rast_attn = layer(rast_hidden, rast_layer_visual)
        
        real_attn_maps.append(real_attn)
        rast_attn_maps.append(rast_attn)
    
    # 3. 损失计算
    # 3.1 自回归交叉熵损失
    loss_ce_real = cross_entropy(real_hidden, target_actions)
    loss_ce_rast = cross_entropy(rast_hidden, target_actions)
    
    # 3.2 Render-Teacher Alignment: Masked Token Alignment
    mask = compute_foreground_mask(rasterized_images)
    loss_mask = mse_loss(real_cam_tokens * mask, rast_cam_tokens * mask)
    
    # 3.3 Render-Teacher Alignment: Attention Distillation
    loss_attn = kl_divergence(real_attn_maps, rast_attn_maps)
    
    total_loss = loss_ce_real + lambda_m * loss_ce_rast + lambda_mask * loss_mask + lambda_attn * loss_attn
    return total_loss

def inference_with_critic(images, text_prompt):
    # Actor 生成 K 个候选轨迹 Token
    candidate_tokens, last_hidden_states = actor.generate(images, text_prompt, num_candidates=K)
    
    # 解码为连续轨迹
    trajectories = [vq_codebook.decode(tokens) for tokens in candidate_tokens]
    
    # Critic 评分
    env_tokens = extract_env_tokens(last_hidden_states)
    scores = [scoring_head(traj, env_tokens) for traj in trajectories]
    
    best_idx = argmax(scores)
    best_traj = trajectories[best_idx]
    
    # 条件残差微调
    if scores[best_idx] < threshold:
        residual = refinement_head(best_traj, env_tokens)
        best_traj = best_traj + residual
        
    return best_traj

### 第二模块：核心架构解释

LaGO 框架分为两个解耦的阶段：离线先验学习与在线强化学习。

**阶段一：离线先验学习 (Offline Prior Learning)**
目标是从离线专家数据中提取 LLM 的行为先验。首先冻结预训练 LLM 的主干网络。将任务的文本描述、历史状态序列和历史动作序列通过可学习的投影层映射为 LLM 的输入特征向量。在 LLM 顶部添加一个动作预测头，使用负对数似然（NLL）损失进行监督微调。此阶段不追求最优控制，而是获取一个粗略的先验分布模型。

**阶段二：带有潜在动作引导的在线强化学习 (Online RL with Latent Action Guidance)**
冻结阶段一训练好的先验模型。初始化一个标准的在线 RL 策略（如 PPO）。在环境交互过程中，RL 策略不仅通过环境反馈的奖励信号进行梯度更新，同时计算当前 RL 策略输出分布与 LLM 先验分布之间的差异（离散空间使用负对数概率，连续空间使用交叉熵）。将该差异作为正则化惩罚项加入 RL 的总损失函数中，从而实现软引导。

**核心伪代码实现:**

# ==========================================
# Stage 1: Offline Prior Learning
# ==========================================
def train_prior_model(expert_dataset, llm_backbone):
    # llm_backbone is frozen, only projection layers and action_head are trainable
    for text_task, states, actions, next_action_target in expert_dataset:
        # 1. Project states and actions to latent embeddings
        state_emb = projection_s(states)
        action_emb = projection_a(actions)
        
        # 2. Construct sequence: [text, s_1, a_1, ..., s_t, a_t]
        seq_input = concatenate(text_task, state_emb, action_emb)
        
        # 3. Forward pass through LLM
        latent_z = llm_backbone(seq_input)
        
        # 4. Predict next action distribution
        prior_dist = action_head(latent_z)
        
        # 5. Supervised loss (Negative Log-Likelihood)
        loss_offline = -log_likelihood(prior_dist, next_action_target)
        update_weights(loss_offline)
        
    return frozen_prior_model

# ==========================================
# Stage 2: Online RL with Latent Guidance
# ==========================================
def train_online_rl(env, frozen_prior_model, rl_policy, beta=0.1):
    for step in range(max_steps):
        state, history = env.get_state_and_history()
        
        # 1. RL policy proposes action distribution
        action, rl_dist = rl_policy(state)
        next_state, reward = env.step(action)
        
        # 2. Compute standard RL loss (e.g., PPO objective)
        loss_pg = compute_ppo_loss(reward, rl_dist)
        
        # 3. Get prior distribution from frozen LLM
        prior_dist = frozen_prior_model(history)
        
        # 4. Compute prior guidance loss (Cross-Entropy / KL regularization)
        # For continuous space: - \int prior_dist * log(rl_dist)
        loss_prior = compute_cross_entropy(prior_dist, rl_dist)
        
        # 5. Total loss optimization
        loss_total = loss_pg + beta * loss_prior
        update_rl_policy(loss_total)
```

### 第二模块：核心架构解释

UniDrive 的核心逻辑在于“动态看趋势，单帧抓细节”，其架构与实验流程可拆解为以下四个阶段：

1. **多模态输入处理**：系统同时接收一段历史低分辨率视频序列（用于提取运动趋势）和当前时刻的单帧高分辨率图像（用于提取空间细节），以及用户的文本指令（Prompt）。
2. **双分支特征提取**：时序分支（Temporal Branch）通过视频编码器提取多帧时空特征；空间分支（Spatial Branch）通过高分辨率图像编码器提取当前帧的细粒度特征。
3. **门控交叉注意力融合（Gated Cross-Attention）**：以时序特征为 Query，高分辨率空间特征为 Key 和 Value。通过门控机制，模型能够动态决定在预测当前风险时，需要从高分辨率特征中提取多少精确的空间位置信息来补充时序特征。
4. **联合解码输出**：融合后的视觉特征与文本指令拼接，输入到大语言模型（LLM）中。LLM 自回归地生成包含风险描述的自然语言文本，并同步输出对应风险目标的 2D 边界框坐标。

**核心逻辑伪代码**：

```python
import torch
import torch.nn as nn

class UniDrive(nn.Module):
    def __init__(self, video_encoder, image_encoder, cross_attention, llm):
        super().__init__()
        self.video_encoder = video_encoder       # 处理低分辨率多帧视频
        self.image_encoder = image_encoder       # 处理高分辨率单帧图像
        self.cross_attention = cross_attention   # 门控交叉注意力模块
        self.llm = llm                           # 大语言模型

    def forward(self, video_frames, high_res_image, text_prompt):
        # 1. 时序分支：提取多帧动态特征 (捕捉运动趋势与上下文)
        # video_frames shape: [Batch, Frames, Channels, H_low, W_low]
        temporal_features = self.video_encoder(video_frames)
        
        # 2. 空间分支：提取最新帧高分辨率特征 (捕捉远小目标细节)
        # high_res_image shape: [Batch, Channels, H_high, W_high]
        spatial_features = self.image_encoder(high_res_image)
        
        # 3. 门控交叉注意力融合：将精确的空间证据对齐到动态上下文中
        # Query: 时序特征, Key/Value: 空间特征
        fused_visual_features = self.cross_attention(
            query=temporal_features,
            key=spatial_features,
            value=spatial_features
        )
        
        # 4. 多模态对齐与拼接
        multimodal_input = self.align_and_concat(fused_visual_features, text_prompt)
        
        # 5. LLM 联合解码：同步输出自然语言描述与 Grounding 边界框
        risk_description, bounding_boxes = self.llm.generate(multimodal_input)
        
        return risk_description, bounding_boxes
```

3. 结果：在nuScenes数据集上，该方法在未见类别上比闭集方法高出15.3 mIoU。在没有新类真实标签的情况下，其性能可媲美使用40%真实标注的自监督/半监督基线。此外，推理速度提升2.5倍，内存消耗仅为投影方法的22%。

### 第二模块：核心架构解释

OVBEVSeg 的核心架构通过非对称的“离线优化+在线蒸馏”范式，将复杂的几何约束计算转移到离线阶段，从而保证在线推理的极高效率。整个流程分为三个递进阶段：

**阶段一：2D到BEV伪标签生成 (2D-to-BEV Pseudo-labeling)**
利用现成的2D视觉语言模型（VLM）提取多视角图像的开放词汇语义特征。通过可靠的3D投影机制，将这些2D语义初步映射到BEV空间，生成用于后续优化的伪标签。

**阶段二：2D-BEV单场景联合优化 (Joint 2D-BEV Per-scene Optimization)**
这是解决几何不一致性的核心。引入高斯溅射（Gaussian Splatting）作为3D场景表征。在单个场景内，联合优化2D图像渲染损失和BEV伪标签渲染损失，并强制加入BEV结构约束（Structural constraints）。这一步通过物理几何规则，修正了阶段一中粗糙投影带来的语义漂移和深度模糊。

**阶段三：3D几何蒸馏 (3D Geometric Distillation)**
为了满足自动驾驶的实时性要求，将阶段二中经过严密几何优化的、笨重的高斯溅射表征（Teacher），蒸馏到一个轻量级的在线前馈网络（Student）中。在线网络仅需输入多视角图像，即可直接输出具备3D几何一致性的开放词汇BEV分割结果。

**核心逻辑伪代码**：

```python
# Stage 1: 2D-to-BEV Pseudo-labeling
def generate_pseudo_labels(multi_view_images, vlm_model, camera_params):
    # 提取2D开放词汇语义
    semantics_2d = vlm_model.extract_features(multi_view_images)
    # 初始3D投影生成伪标签
    pseudo_labels_bev = reliable_3d_projection(semantics_2d, camera_params)
    return pseudo_labels_bev

# Stage 2: Joint 2D-BEV Per-scene Optimization (Offline)
def optimize_scene_geometry(multi_view_images, pseudo_labels_bev, camera_params):
    # 初始化高斯溅射表征
    gaussians = initialize_gaussian_splatting()
    optimizer = Adam(gaussians.parameters)
    
    for step in range(MAX_OPTIMIZATION_STEPS):
        # 渲染2D视图与BEV视图
        rendered_2d = render_to_camera(gaussians, camera_params)
        rendered_bev = render_to_bev(gaussians)
        
        # 计算联合损失与几何结构约束
        loss_2d = compute_loss(rendered_2d, multi_view_images)
        loss_bev = compute_loss(rendered_bev, pseudo_labels_bev)
        loss_geometry = structural_constraint_loss(gaussians)
        
        total_loss = loss_2d + loss_bev + loss_geometry
        total_loss.backward()
        optimizer.step()
        
    return gaussians # 获得几何一致的优化后表征

# Stage 3: 3D Geometric Distillation (Online Training)
def train_online_student(dataset, optimized_gaussians_dict):
    student_model = EfficientBEVNet() # 轻量级在线网络
    
    for images, scene_id in dataset:
        # 获取Teacher的高质量BEV特征
        teacher_bev_features = render_to_bev(optimized_gaussians_dict[scene_id])
        # Student前向传播
        student_bev_preds = student_model(images)
        
        # 蒸馏损失
        loss = distillation_loss(student_bev_preds, teacher_bev_features)
        loss.backward()
        update_weights(student_model)
        
    return student_model
```
