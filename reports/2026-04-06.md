### 第二模块：核心架构解释

MV-VDP 的核心思想是**表征对齐**。它将传统的低维机器人动作（如机械臂末端位姿）投影到多个相机视角下，生成 2D 动作热力图序列。随后，模型将这些热力图序列与多视角 RGB 视频序列在通道维度拼接，统一交由一个视频扩散模型进行联合去噪生成。

**工作流程**：
1. **状态输入**：获取当前时刻的多视角 RGB 图像（以及可选的本体感觉或语言指令）。
2. **联合扩散生成**：以当前状态为条件，扩散模型从纯噪声中逐步去噪，输出未来时间窗口内的多视角 RGB 视频（预测环境变化）和多视角热力图视频（预测动作轨迹）。
3. **动作解码**：利用多视角几何（如三角测量或空间 Argmax），将生成的多视角 2D 热力图逆向重构为 3D 空间中的机器人末端执行器位姿，下发给底层控制器。

### 第二模块：核心架构解释

本文的核心架构是一个解耦的、模块化的分层规划系统，主要由**多尺度潜在世界模型**与**分层模型预测控制（Hierarchical MPC）**两部分构成。

**1. 多尺度潜在世界模型 (Multi-scale Latent World Models)**
系统不依赖特定的底层架构（如 JEPA 或 RSSM 均可），而是针对同一环境训练多个具有不同时间跳跃步长（temporal jump）的动态模型。
- **高层模型 (High-level Model)**：以较大的时间步长 $K$ 运行，输入当前潜在状态，预测未来第 $t+K$ 步的潜在状态。它忽略了高频的局部动态，专注于长程状态演化。
- **低层模型 (Low-level Model)**：以基础时间步长 $1$ 运行，输入当前潜在状态和具体动作，预测第 $t+1$ 步的潜在状态。

**2. 分层规划流程 (Hierarchical Planning Pipeline)**
- **高层规划**：接收当前状态和最终目标。高层 MPC 利用高层世界模型在潜在空间中进行长视野搜索，寻找一条能够最小化到最终目标距离的粗粒度状态轨迹。该轨迹的第一个节点被设定为低层规划的**子目标 (Sub-goal)**。
- **低层规划**：接收当前状态和高层下发的子目标。低层 MPC 利用低层世界模型在短视野内搜索具体的动作序列（Primitive Actions），以最小化当前状态与子目标之间的距离。
- **执行与重规划**：低层输出最优动作序列的第一个动作并在环境中执行，随后系统根据新的观测状态滚动执行上述规划过程（Receding Horizon Control）。

### 第二模块：核心架构解释

SV-VLA 的核心架构分为三个逻辑模块：低频宏观规划、高频轻量验证、基于偏差的重规划。

1.  **低频宏观规划 (Macro Planning):** 在规划边界（任务开始或触发重规划时），冻结的重型 VLA 模型接收当前视觉观测、语言指令和本体状态，输出一个长程的宏观动作块（Macro Action Chunk）以及一个从 Transformer 提取的规划上下文特征（Planning Context Feature）。
2.  **高频轻量验证 (Lightweight Verification):** 在动作块的执行过程中，重型 VLA 处于休眠状态。一个轻量级的视觉编码器（如 ViT-Tiny）以控制频率运行，提取当前最新观测的视觉特征，并将其与规划上下文特征拼接。轻量级验证头基于融合特征预测出一个“参考动作”。
3.  **基于偏差的重规划 (Deviation-based Replanning):** 系统计算当前预定执行的宏观动作与验证器生成的参考动作之间的 L1 距离。如果该距离小于设定的安全阈值 $\tau$，则继续执行预定动作；如果距离大于 $\tau$，说明物理环境已发生偏离，系统丢弃动作块的剩余部分，并唤醒重型 VLA 根据当前最新状态重新生成动作块。

**核心伪代码实现：**

```python
def sv_vla_inference(heavy_vla, lightweight_verifier, instruction, initial_state, max_chunk_size, threshold_tau):
    current_obs, current_state = initial_state
    task_completed = False
    
    while not task_completed:
        # 1. 低频宏观规划：调用重型 VLA 生成动作块和上下文特征
        macro_action_chunk, context_feature = heavy_vla.plan(current_obs, instruction, current_state)
        
        # 立即执行动作块的第一个动作
        execute_action(macro_action_chunk[0])
        current_obs, current_state = get_next_state()
        
        # 2. 高频闭环验证
        for t in range(1, max_chunk_size):
            planned_action = macro_action_chunk[t]
            
            # 轻量级验证器结合最新观测与上下文特征，预测参考动作
            visual_feature = lightweight_verifier.extract_visual(current_obs)
            fused_feature = concatenate(visual_feature, context_feature)
            reference_action = lightweight_verifier.predict_action(fused_feature)
            
            # 3. 基于偏差的重规划机制
            discrepancy = l1_distance(reference_action, planned_action)
            
            if discrepancy > threshold_tau:
                # 偏差过大，触发重规划，跳出当前动作块的执行循环
                break 
            else:
                # 偏差在安全范围内，继续执行预定动作
                execute_action(planned_action)
                current_obs, current_state = get_next_state()
                
        task_completed = check_task_completion()
```

- **Stage 1 (Imitation Learning):** 先进行图像生成的预训练，随后进行监督微调（SFT），联合优化轨迹预测的 MSE 损失和 RGB/深度图生成的掩码 Token 预测（MTP）交叉熵损失。
- **Stage 2 (Reinforcement Learning):** 冻结大部分参数，使用 LoRA 微调。采样多条候选轨迹，利用 Stage 1 训练好的世界模型预测这些轨迹对应的未来图像。计算图像 Token 的概率熵作为探索奖励（新颖性），结合 PDMS 评分（安全性）计算总奖励，通过 GRPO 算法更新策略。

**核心逻辑伪代码 (Python 风格):**

```python
import torch
import torch.nn.functional as F

def compute_exploration_bonus(image_logits):
    # image_logits shape: [batch_size, num_tokens, vocab_size]
    # 计算生成图像 Token 的概率分布
    probs = F.softmax(image_logits, dim=-1)
    # 计算信息熵作为不确定性（新颖性）度量
    entropy = -torch.sum(probs * torch.log(probs + 1e-8), dim=-1)
    # 对所有 Token 的熵求平均，并归一化到 [0, 1]
    mean_entropy = torch.mean(entropy, dim=-1)
    exploration_bonus = normalize(mean_entropy)
    return exploration_bonus

def compute_composite_reward(trajectory, pdms_score, exploration_bonus, safety_threshold=0.9, lambda_weight=0.5):
    # 安全门控机制：只有当 PDMS 评分高于安全阈值时，才给予探索奖励
    if pdms_score > safety_threshold:
        reward = pdms_score + lambda_weight * exploration_bonus
    else:
        # 不安全的轨迹仅使用 PDMS 评分作为惩罚性反馈
        reward = pdms_score
    return reward

def grpo_step(model, inputs, num_samples=8):
    # 1. 采样 G 条候选轨迹
    trajectories = model.sample_trajectories(inputs, num_samples)
    
    rewards = []
    for traj in trajectories:
        # 2. 外部环境/评估器给出任务奖励 (PDMS)
        pdms_score = evaluate_trajectory_safety(traj)
        
        # 3. 世界模型预测未来图像并计算内在探索奖励
        future_image_logits = model.predict_future_images(inputs, traj)
        bonus = compute_exploration_bonus(future_image_logits)
        
        # 4. 计算复合奖励
        reward = compute_composite_reward(traj, pdms_score, bonus)
        rewards.append(reward)
        
    rewards = torch.tensor(rewards)
    
    # 5. 组内相对优势归一化 (GRPO 核心)
    advantages = (rewards - rewards.mean()) / (rewards.std() + 1e-8)
    
    # 6. 策略梯度更新 (最大化优势)
    loss = compute_policy_loss(model, trajectories, advantages)
    loss.backward()
    optimizer.step()
```

### 第二模块：核心架构解释

MV-VDP 的核心思想是**表征对齐**。它将传统的低维机器人动作（如机械臂末端位姿）投影到多个相机视角下，生成 2D 动作热力图序列。随后，模型将这些热力图序列与多视角 RGB 视频序列在通道维度拼接，统一交由一个视频扩散模型进行联合去噪生成。

**工作流程**：
1. **状态输入**：获取当前时刻的多视角 RGB 图像（以及可选的本体感觉或语言指令）。
2. **联合扩散生成**：以当前状态为条件，扩散模型从纯噪声中逐步去噪，输出未来时间窗口内的多视角 RGB 视频（预测环境变化）和多视角热力图视频（预测动作轨迹）。
3. **动作解码**：利用多视角几何（如三角测量或空间 Argmax），将生成的多视角 2D 热力图逆向重构为 3D 空间中的机器人末端执行器位姿，下发给底层控制器。

**2. 分层规划流程 (Hierarchical Planning Pipeline)**
- **高层规划**：接收当前状态和最终目标。高层 MPC 利用高层世界模型在潜在空间中进行长视野搜索，寻找一条能够最小化到最终目标距离的粗粒度状态轨迹。该轨迹的第一个节点被设定为低层规划的**子目标 (Sub-goal)**。

### 第二模块：核心架构解释

SV-VLA 的核心架构分为三个逻辑模块：低频宏观规划、高频轻量验证、基于偏差的重规划。

1.  **低频宏观规划 (Macro Planning):** 在规划边界（任务开始或触发重规划时），冻结的重型 VLA 模型接收当前视觉观测、语言指令和本体状态，输出一个长程的宏观动作块（Macro Action Chunk）以及一个从 Transformer 提取的规划上下文特征（Planning Context Feature）。
2.  **高频轻量验证 (Lightweight Verification):** 在动作块的执行过程中，重型 VLA 处于休眠状态。一个轻量级的视觉编码器（如 ViT-Tiny）以控制频率运行，提取当前最新观测的视觉特征，并将其与规划上下文特征拼接。轻量级验证头基于融合特征预测出一个“参考动作”。
3.  **基于偏差的重规划 (Deviation-based Replanning):** 系统计算当前预定执行的宏观动作与验证器生成的参考动作之间的 L1 距离。如果该距离小于设定的安全阈值 $\tau$，则继续执行预定动作；如果距离大于 $\tau$，说明物理环境已发生偏离，系统丢弃动作块的剩余部分，并唤醒重型 VLA 根据当前最新状态重新生成动作块。

**核心伪代码实现：**

```python
def sv_vla_inference(heavy_vla, lightweight_verifier, instruction, initial_state, max_chunk_size, threshold_tau):
    current_obs, current_state = initial_state
    task_completed = False
    
    while not task_completed:
        # 1. 低频宏观规划：调用重型 VLA 生成动作块和上下文特征
        macro_action_chunk, context_feature = heavy_vla.plan(current_obs, instruction, current_state)
        
        # 立即执行动作块的第一个动作
        execute_action(macro_action_chunk[0])
        current_obs, current_state = get_next_state()
        
        # 2. 高频闭环验证
        for t in range(1, max_chunk_size):
            planned_action = macro_action_chunk[t]
            
            # 轻量级验证器结合最新观测与上下文特征，预测参考动作
            visual_feature = lightweight_verifier.extract_visual(current_obs)
            fused_feature = concatenate(visual_feature, context_feature)
            reference_action = lightweight_verifier.predict_action(fused_feature)
            
            # 3. 基于偏差的重规划机制
            discrepancy = l1_distance(reference_action, planned_action)
            
            if discrepancy > threshold_tau:
                # 偏差过大，触发重规划，跳出当前动作块的执行循环
                break 
            else:
                # 偏差在安全范围内，继续执行预定动作
                execute_action(planned_action)
                current_obs, current_state = get_next_state()
                
        task_completed = check_task_completion()
```

   - 深度生成头输出未来深度图的离散 Token。

**训练流程：**
- **Stage 1 (Imitation Learning):** 先进行图像生成的预训练，随后进行监督微调（SFT），联合优化轨迹预测的 MSE 损失和 RGB/深度图生成的掩码 Token 预测（MTP）交叉熵损失。
- **Stage 2 (Reinforcement Learning):** 冻结大部分参数，使用 LoRA 微调。采样多条候选轨迹，利用 Stage 1 训练好的世界模型预测这些轨迹对应的未来图像。计算图像 Token 的概率熵作为探索奖励（新颖性），结合 PDMS 评分（安全性）计算总奖励，通过 GRPO 算法更新策略。

**核心逻辑伪代码 (Python 风格):**

```python
import torch
import torch.nn.functional as F

def compute_exploration_bonus(image_logits):
    # image_logits shape: [batch_size, num_tokens, vocab_size]
    # 计算生成图像 Token 的概率分布
    probs = F.softmax(image_logits, dim=-1)
    # 计算信息熵作为不确定性（新颖性）度量
    entropy = -torch.sum(probs * torch.log(probs + 1e-8), dim=-1)
    # 对所有 Token 的熵求平均，并归一化到 [0, 1]
    mean_entropy = torch.mean(entropy, dim=-1)
    exploration_bonus = normalize(mean_entropy)
    return exploration_bonus

def compute_composite_reward(trajectory, pdms_score, exploration_bonus, safety_threshold=0.9, lambda_weight=0.5):
    # 安全门控机制：只有当 PDMS 评分高于安全阈值时，才给予探索奖励
    if pdms_score > safety_threshold:
        reward = pdms_score + lambda_weight * exploration_bonus
    else:
        # 不安全的轨迹仅使用 PDMS 评分作为惩罚性反馈
        reward = pdms_score
    return reward

def grpo_step(model, inputs, num_samples=8):
    # 1. 采样 G 条候选轨迹
    trajectories = model.sample_trajectories(inputs, num_samples)
    
    rewards = []
    for traj in trajectories:
        # 2. 外部环境/评估器给出任务奖励 (PDMS)
        pdms_score = evaluate_trajectory_safety(traj)
        
        # 3. 世界模型预测未来图像并计算内在探索奖励
        future_image_logits = model.predict_future_images(inputs, traj)
        bonus = compute_exploration_bonus(future_image_logits)
        
        # 4. 计算复合奖励
        reward = compute_composite_reward(traj, pdms_score, bonus)
        rewards.append(reward)
        
    rewards = torch.tensor(rewards)
    
    # 5. 组内相对优势归一化 (GRPO 核心)
    advantages = (rewards - rewards.mean()) / (rewards.std() + 1e-8)
    
    # 6. 策略梯度更新 (最大化优势)
    loss = compute_policy_loss(model, trajectories, advantages)
    loss.backward()
```

### 第二模块：核心架构解释

本文并非提出一个全新的网络架构，而是对现有连续（Diffusion Policy, DP）和离散（Ordered Action Tokenization, OAT）动作表示管线进行信息论视角的解构。

**1. 连续信息管线 (Continuous Pathway - DP)**
- **流程**：观测数据 $O$ 通过视觉编码器映射为连续特征 $Z$，随后直接输入到去噪网络 $\epsilon_\theta$ 中，在连续空间中预测动作 $A$。
- **信息流**：$O \xrightarrow{f_{enc}} Z \xrightarrow{\epsilon_\theta} A$。
- **瓶颈分析**：互信息 $I(O; A) \le I(O; Z)$。由于没有硬性的离散化截断，系统的瓶颈在于编码器提取特征的能力 $I(O; Z)$。

**2. 离散信息管线 (Discrete Pathway - OAT)**
- **流程**：观测数据 $O$ 映射为连续特征 $Z$ 后，动作块首先被编码为连续潜变量，然后通过有限标量量化（FSQ）强制离散化为有限词表 $\mathcal{V}$ 中的 Token 序列 $T$，最后由自回归策略生成动作 $A$。
- **信息流**：$O \xrightarrow{f_{enc}} Z \xrightarrow{Q} T \xrightarrow{T^{-1}} A$。
- **瓶颈分析**：互信息 $I(O; A) \le I(Z; T) \le \log_2|\mathcal{V}|^{H_l}$。码本容量设定了信息吞吐量的绝对上限（约 80 bits）。当上游编码器提供的信息超过此上限时，多余信息被丢弃。

**核心伪代码实现逻辑对比**：

```python
import torch
import torch.nn as nn

class VisuomotorPipeline(nn.Module):
    def __init__(self, encoder_type, action_repr, codebook_size=1000):
        super().__init__()
        # Vision Encoder (The variable being scaled: ResNet vs SigLIP)
        self.vision_encoder = self._load_encoder(encoder_type)
        self.action_repr = action_repr
        
        if self.action_repr == 'discrete':
            # Discrete Bottleneck (OAT with FSQ)
            self.quantizer = FiniteScalarQuantization(vocab_size=codebook_size)
            self.ar_policy = AutoregressiveTransformer()
            self.action_decoder = TokenToActionDecoder()
        elif self.action_repr == 'continuous':
            # Continuous Pathway (Diffusion Policy)
            self.noise_pred_net = ConditionalUNet1D()
            self.noise_scheduler = DDIMScheduler()

    def forward(self, observation, action_target=None):
        # Step 1: Extract continuous visual features Z
        # I(O; Z) increases when upgrading from ResNet to SigLIP
        Z = self.vision_encoder(observation) 
        
        if self.action_repr == 'discrete':
            # Step 2a: The Compression Gap occurs here.
            # Information is truncated: I(Z; T) <= log2(codebook_size)
            continuous_action_latent = self.action_decoder.encode(action_target)
            quantized_tokens = self.quantizer(continuous_action_latent) 
            
            # Step 3a: Autoregressive prediction based on truncated information
            loss = self.ar_policy(Z, quantized_tokens)
            return loss
            
        elif self.action_repr == 'continuous':
            # Step 2b: No hard bottleneck. Z flows directly into the denoising process.
            noisy_action, noise = self.noise_scheduler.add_noise(action_target)
            
            # Step 3b: Predict noise in continuous space
            noise_pred = self.noise_pred_net(noisy_action, Z)
            loss = nn.MSELoss()(noise_pred, noise)
            return loss
```

**阶段二：真实世界高效适应（物理环境）**
1. **构建参考模型**：将仿真中训练好的 DreamTIP 模型复制并完全冻结，作为参考模型（Teacher）。

### 第二模块：核心架构解释

ARM 框架的运行流程可解构为三个核心阶段：

**阶段一：轻量化三态标注与模型训练**
放弃连续标量打分，将相邻帧的进度变化定义为离散的三态分类：Progressing (+1), Regressive (-1), Stagnant (0)。通过少量人工标注冷启动后，训练 ARM 模型。ARM 采用 MIMO 架构，输入多模态序列（视觉、本体感觉、文本指令），输出两个分支：多帧优势分类（预测相对增益）和任务完成度预测（预测是否为终止成功状态）。

**阶段二：全局进度重建 (Global Progress Reconstruction)**
在推理阶段，ARM 对完整的长视频进行并行切片推理。将局部预测的相对状态转移 $\Delta \hat{y}$ 与绝对任务完成信号 $C_t$（作为锚点，如 $P_T = 1.0$）进行数学积分（反向累加），将离散的局部预测转化为全局一致的密集进度曲线 $P_t$。

**阶段三：优势加权行为克隆 (AW-BC)**
利用重建的密集进度信号，计算动作块（Action Chunk）的长度自适应增益 $\Delta G_t$。通过统计归一化和截断机制，将增益转化为重要性权重 $\tilde{w}_i$。在训练 VLA 策略时，赋予高优势（有效推进或纠错）样本高权重，压制或过滤倒退样本。

```python
class ARM_Model(nn.Module):
    def __init__(self):
        super().__init__()
        self.multimodal_encoder = CLIP_and_MLPs()
        self.temporal_transformer = TransformerEncoder(layers=8)
        self.advantage_head = nn.Linear(hidden_dim, 3) # Output: +1, 0, -1 logits
        self.completion_head = nn.Linear(hidden_dim, 1) # Output: Probability of success

    def forward(self, obs_sequence):
        # obs_sequence: [batch, window_size, obs_dim]
        features = self.multimodal_encoder(obs_sequence)
        hidden_states = self.temporal_transformer(features)
        
        # MIMO outputs
        adv_logits = self.advantage_head(hidden_states) 
        completion_prob = torch.sigmoid(self.completion_head(hidden_states))
        return adv_logits, completion_prob

def reconstruct_global_progress(adv_preds, completion_preds, sequence_length):
    """
    Integrate local advantages with the completion anchor to build dense progress.
    """
    progress_curve = torch.zeros(sequence_length)
    # Anchor the end of the sequence if completion is detected
    progress_curve[-1] = 1.0 if completion_preds[-1] > threshold else 0.0
    
    # Backwards accumulation (integration)
    for t in range(sequence_length - 2, -1, -1):
        progress_curve[t] = progress_curve[t+1] - adv_preds[t]
        
    # Normalize to [0, 1]
    return normalize(progress_curve)

def compute_awbc_loss(policy_model, states, actions, progress_curve, L_seq, L_avg, horizon=32):
    """
    Advantage-Weighted Behavior Cloning Loss
    """
    batch_size = states.shape[0]
    gains = torch.zeros(batch_size)
    
    # 1. Calculate Length-adaptive Gain (Eq. 4)
    for t in range(batch_size):
        delta_P = progress_curve[t + horizon] - progress_curve[t]
        gains[t] = delta_P * (L_seq / L_avg)
        
    # 2. Statistical Weighting (Eq. 5)
    mu, sigma = gains.mean(), gains.std()
    b_lower = mu - 2 * sigma
    b_upper = mu + 2 * sigma
    
    # Clamp and normalize weights to [0, 1]
    raw_weights = (gains - b_lower) / (b_upper - b_lower + 1e-8)
    weights = torch.clamp(raw_weights, min=0.0, max=1.0)
    
    # 3. Weighted NLL Loss (Eq. 6)
    action_log_probs = policy_model.get_log_prob(states, actions)
    loss = -torch.mean(weights * action_log_probs)
    return loss
```

### 第二模块：核心架构解释

V2X-MoE 的架构设计遵循“共享主干+显式特化”的极简原则。其核心流程如下：

1. **多模态预处理**：接收视觉证据（单车图像、路端图像或车路双图）和包含四个选项的MCQA文本提示，通过Qwen3-VL的处理器进行Token化。
2. **显式视角路由（Explicit View-Based Routing）**：不使用传统的Softmax门控网络，而是根据输入样本的视角标签 $v \in \{VS, IS, CO\}$，通过确定性的硬路由直接激活三个LoRA专家（车端专家、路端专家、协同专家）中的唯一一个。
3. **视角特化注意力调制**：在冻结的Transformer Block中，被激活的LoRA专家向自注意力机制的投影矩阵（$W_q, W_k, W_v, W_o$）注入低秩更新。这使得模型能够在不破坏通用多模态表征的前提下，针对特定视角提取特征（例如路端专家专注于全局拓扑，协同专家专注于跨视角对齐）。
4. **多阶段对齐训练**：首先使用标准的自回归负对数似然损失进行全量MCQA训练；随后冻结其他专家，仅使用协同数据对协同专家进行微调；最后仅使用路端数据对路端专家进行微调。

**底层逻辑伪代码实现**：

```python
import torch
import torch.nn as nn

class V2X_MoE_Layer(nn.Module):
    def __init__(self, frozen_attention, rank=16):
        super().__init__()
        # 冻结的基座注意力层 (Qwen3-VL)
        self.frozen_attn = frozen_attention
        
        # 定义三个特定视角的LoRA专家
        self.expert_VS = LoRA_Expert(frozen_attention.dim, rank)
        self.expert_IS = LoRA_Expert(frozen_attention.dim, rank)
        self.expert_CO = LoRA_Expert(frozen_attention.dim, rank)

    def forward(self, x, view_type):
        # 1. 显式硬路由：根据视角信号选择唯一专家
        if view_type == "VS":
            active_expert = self.expert_VS
        elif view_type == "IS":
            active_expert = self.expert_IS
        elif view_type == "CO":
            active_expert = self.expert_CO
        else:
            raise ValueError("Invalid view type")

        # 2. 获取冻结的注意力投影矩阵
        W_q, W_k, W_v, W_o = self.frozen_attn.get_weights()

        # 3. 计算当前专家的低秩更新 (ΔW = B @ A)
        delta_W_q, delta_W_k, delta_W_v, delta_W_o = active_expert.get_delta_weights()

        # 4. 视角特化的注意力计算
        Q = x @ (W_q + delta_W_q)
        K = x @ (W_k + delta_W_k)
        V = x @ (W_v + delta_W_v)

        # 标准自注意力机制
        attn_scores = torch.softmax(Q @ K.transpose(-2, -1) / math.sqrt(Q.size(-1)), dim=-1)
        attn_output = attn_scores @ V

        # 输出投影与残差返回
        output = attn_output @ (W_o + delta_W_o)
        return output

def v2x_moE_forward(images, prompt, view_type, model):
    # 预处理
    tokens = model.processor(images, prompt)
    
    # 逐层前向传播
    for layer in model.transformer_blocks:
        tokens = layer(tokens, view_type)
        
    # 生成MCQA选项
    logits = model.lm_head(tokens)
    return parse_option(logits)
```

### 第二模块：核心架构解释

FSUNav 的系统架构明确划分为负责高级认知的大脑（Cerebrum）和负责底层执行的小脑（Cerebellum）。

**1. 大脑模块 (Cerebrum Module - 高频转低频的语义引擎)**
大脑包含三个协同层，全部围绕单一 VLM（Qwen3-VL-32B）展开：
*   **语义层 (Semantic Layer):** 将文本、图像或类别输入转化为统一的结构化目标特征，并利用 VLM 输出归一化边界框，结合深度图投影到 3D 空间，实现免训练的开放词汇目标检测。
*   **空间层 (Spatial Layer):** 维护一个几何鸟瞰图（BEV）。当目标不可见时，利用 VLM 观察当前 RGB 图像，输出一个“语义上最可能通向目标”的航点，并与基于几何的边界（Frontier）探索算法结合，生成混合探索策略。
*   **规则层 (Rule Layer):** 状态机中枢。采用两阶段验证（全局场景确认 -> 局部实例匹配）来过滤 VLM 的假阳性。同时引入“自适应冷却（Cooldown）”机制，在未发现目标时降低 VLM 调用频率，节省算力。

**2. 小脑模块 (Cerebellum Module - 尺寸感知的局部规划器)**
*   采用 Soft Actor-Critic (SAC) 强化学习算法。
*   **核心创新:** 输入状态不仅包含目标点和当前速度，还将**机器人的物理尺寸（长、宽）和动力学极限（最大速度、加速度）**作为参数传入。通过 PointNet 提取包含机器人自身几何约束的障碍物特征，使得同一个策略网络能够直接控制不同大小、不同形态的机器人。

```python
                if self.cerebrum_vlm.local_match(rgb, goal_prompt):
                    return "STOP_ACTION" # 找到目标，任务成功
                else:
                    self.cooldown_counter = SHORT_COOLDOWN
            else:
                self.cooldown_counter = LONG_COOLDOWN
            
            # 2. 空间层：目标未找到，生成探索航点
            geometric_frontiers = extract_frontiers(depth)
            semantic_prior = self.cerebrum_vlm.get_semantic_waypoint(rgb)
            target_waypoint = calculate_hybrid_utility(geometric_frontiers, semantic_prior)
        else:
            self.cooldown_counter -= 1
            target_waypoint = self.last_waypoint # 冷却期内沿用旧航点

        # ================= 小脑逻辑 (高频实时控制) =================
        # 3. 将机器人尺寸参数化，与 LiDAR 点云融合
        dim_aware_obstacles = encode_geometry_with_robot_size(lidar, self.robot_dims)
        
        # 4. DRL 输出底层速度指令 (v, w)，确保绝对避障安全
        action = self.cerebellum_drl.act(
            state=dim_aware_obstacles, 
            goal=target_waypoint, 
            limits=self.robot_dims.velocity_limits
        )
        
        return action
```

### 第二模块：核心架构解释

当前论文的导航框架采用模块化设计，支持 LiDAR 和单目相机两种感知输入，其核心创新在于单目感知分支的处理流程。

**1. 感知与尺度恢复模块 (Perception & Metric Rescaling)**
- **相对深度提取**：输入单目 RGB 图像，通过预训练的 Depth Anything V2 模型进行零样本推理，输出高分辨率但无物理尺度的相对深度图。
- **稀疏尺度对齐**：并行运行 VINS-Mono（视觉惯性 SLAM），获取当前帧的稀疏 3D 特征点（包含真实物理尺度）。将这些稀疏点投影到相对深度图上，通过最小二乘法计算出一个全局缩放因子（Scale Factor）和一个偏移量（Shift），将相对深度图转换为度量深度图（Metric Depth）。

**2. 鲁棒性增强模块 (Robustness Enhancements)**
- **边缘掩码 (Edge-Masking)**：单目深度模型在物体边缘常产生“飞点”（Flying pixels/伪影）。系统通过计算深度图的图像梯度，生成掩码过滤掉高梯度区域（即物体边缘），防止导航系统将伪影误认为障碍物（Obstacle Hallucination）。
- **时间平滑 (Temporal Smoothing)**：由于 SLAM 提取的特征点数量在帧间波动，计算出的缩放因子会产生跳变。系统对缩放因子应用指数移动平均（EMA）进行时间平滑，确保连续帧之间深度图的尺度稳定性。

**3. 建图与规划模块 (Mapping & Planning)**
- 将处理后的度量深度图转换为 3D 点云。
- 将点云投影为以机器人为中心的 2.5D 高程图（Elevation Map）。
- 基于高程图生成代价地图（Costmap），并交由局部规划器（Local Planner）输出控制指令。

**核心逻辑伪代码 (Python 风格)**：

```python
def process_monocular_frame(image, slam_sparse_points):
    # 1. 零样本相对深度估计
    relative_depth = DepthAnythingV2.predict(image)
    
    # 2. 尺度对齐 (利用 SLAM 稀疏点)
    # 将 SLAM 3D 点投影到图像平面，获取对应的相对深度值
    projected_points = project_to_image_plane(slam_sparse_points)
    slam_depths = get_depths(slam_sparse_points)
    model_depths = sample_depths(relative_depth, projected_points)
    
    # 计算缩放因子 (scale) 和偏移量 (shift)
    scale, shift = compute_least_squares_fit(model_depths, slam_depths)
    
    # 3. 时间平滑 (EMA) 缓解 SLAM 抖动
    global current_scale, current_shift
    alpha = 0.2 # 平滑系数
    current_scale = alpha * scale + (1 - alpha) * current_scale
    current_shift = alpha * shift + (1 - alpha) * current_shift
    
    # 恢复度量深度
    metric_depth = relative_depth * current_scale + current_shift
    
    # 4. 边缘掩码过滤伪影
    depth_gradients = compute_gradients(metric_depth)
    edge_mask = depth_gradients < GRADIENT_THRESHOLD
    filtered_metric_depth = apply_mask(metric_depth, edge_mask)
    
    # 5. 生成点云
    point_cloud = depth_to_pointcloud(filtered_metric_depth, camera_intrinsics)
    
    return point_cloud

def navigation_step(point_cloud):
    elevation_map = build_2_5D_elevation_map(point_cloud)
    costmap = generate_costmap(elevation_map)
    control_command = local_planner.compute_velocity(costmap)
    return control_command
```
