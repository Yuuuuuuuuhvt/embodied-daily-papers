### 第二模块：核心架构解释

HiVLA 的架构分为高层规划器、底层动作专家以及异步执行流三个核心部分：

1. **高层 VLM 规划器 (High-Level VLM Planner)**
输入当前视觉观察、历史视觉帧和语言指令。VLM（基于 Qwen3-VL）不直接输出动作，而是进行任务分解，输出一个结构化的 JSON 计划，包含：下一步的子任务描述（如 "pick up the cup"）以及目标物体在原图中的归一化边界框（Bounding Box）。

2. **底层 DiT 动作专家 (Low-Level DiT Action Expert)**
基于条件流匹配（Conditional Flow Matching）的 Diffusion Transformer。其核心创新在于 Transformer Block 内部的**级联交叉注意力（Cascaded Cross-Attention）**。它不将所有条件简单拼接，而是按“从粗到细”的顺序依次注入：
- **全局视觉上下文**：让模型理解整体场景和物体关系。
- **位置感知局部特征**：利用 VLM 提供的 BBox 从 1080p 原图中裁剪出高分辨率目标，并**强行加上基于原图坐标的绝对正弦位置编码**，解决裁剪导致的空间位置丢失问题。
- **子任务语言引导**：注入具体的技能语义（如区分 pick 和 push）。

3. **异步推理流 (Asynchronous Inference)**
VLM 推理极慢（1.9s/步），DiT 推理极快（0.162s/16步动作块）。系统通过异步并行运行两者，DiT 在 VLM 计算下一步时继续执行当前子任务，从而实现 8Hz 的实际控制频率。

```python
    global_feat = vision_encoder(global_img)
    local_feat = vision_encoder(local_crop_img)
    lang_feat = text_encoder(subtask_lang)
    
    # 2. 注入绝对空间位置先验 (核心创新)
    # 根据 bbox 计算局部图像在全局 1080p 图像中的绝对中心坐标 p
    p = compute_absolute_center_coordinates(bbox) 
    absolute_pe = generate_sinusoidal_pe(p)
    local_feat_with_pos = local_feat + absolute_pe
    
    x = state_action_tokens

    # 第一层：关注全局上下文 (在哪、环境长什么样)
    x = cross_attention_layer_1(query=x, key=global_feat, value=global_feat)

    x = cross_attention_layer_2(query=x, key=local_feat_with_pos, value=local_feat_with_pos)

    output = ffn(x)
```

### 第二模块：核心架构解释

VLAJS 的核心逻辑是在标准的在线强化学习 (PPO) 框架中，注入一个随时间衰减的 VLA 动作正则化项。其运行流程如下：

1. **双速率控制架构**：系统维持两个控制频率。RL 智能体以高频 (如 20Hz) 接收低维状态或本体感觉输入并输出连续动作；VLA 模型以低频 (稀疏查询) 接收高维视觉和文本指令，输出高层动作建议。
2. **方向性动作一致性正则化**：在 RL 探索阶段，计算 RL 输出动作向量与 VLA 建议动作向量之间的方向一致性（通常为余弦相似度）。该一致性得分作为额外的内在奖励 (Intrinsic Reward) 附加到环境奖励中，引导 RL 智能体向 VLA 建议的方向探索。
3. **动态退火机制**：正则化项的权重系数随训练步数线性或指数衰减。早期依赖 VLA 跨越探索鸿沟，后期权重归零，RL 完全依靠环境真实奖励进行微调，从而克服 VLA 固有的精度缺陷。

**核心伪代码实现**：

```python
def train_vlajs(env, rl_agent, vla_model, total_timesteps, query_freq):
    for t in range(total_timesteps):
        obs = env.get_observation()
        
        # 1. 稀疏查询 VLA：降低计算开销，获取高层动作先验
        if t % query_freq == 0:
            vla_action = vla_model.get_action(obs.image, obs.text_instruction)
        
        # 2. RL 策略输出高频动作
        rl_action, log_prob, value = rl_agent.get_action(obs.state)
        
        # 3. 环境步进
        next_obs, env_reward, done = env.step(rl_action)
        
        # 4. 计算退火系数 (随时间 t 衰减至 0)
        alpha = compute_annealing_factor(t, total_timesteps)
        
        # 5. 方向性动作一致性正则化 (核心创新)
        if alpha > 0:
            # 计算 RL 动作与 VLA 动作的方向一致性 (如余弦相似度)
            consistency_bonus = compute_cosine_similarity(rl_action, vla_action)
            # 增强奖励 = 环境奖励 + 退火系数 * 一致性奖励
            augmented_reward = env_reward + alpha * consistency_bonus
        else:
            augmented_reward = env_reward
            
        # 6. 存储轨迹并更新 PPO
        rl_agent.buffer.add(obs, rl_action, augmented_reward, log_prob, value)
        if rl_agent.buffer.is_full():
            rl_agent.update_ppo()
```

### 第二模块：核心架构解释

Goal2Skill 框架由两个在不同时间尺度上运行的核心模块组成：高层规划器（High-Level Planner）和底层执行器（Low-Level Executor）。

**1. 高层规划器 (VLM-based)**
运行在较慢的时间尺度。接收全局目标和当前观测，维护包含情景历史、工作记忆和错误寄存器的结构化记忆状态。其核心流程为：

- **验证与反思**：底层执行结束后，通过 VLM 验证后置条件是否满足。若失败，触发反思引擎，结合错误寄存器生成诊断信息，并决定是修改参数重试（Retry/Adjust）还是全局重规划（Replan）。

**2. 底层执行器 (VLA-based)**
运行在较快的时间尺度。接收当前子任务和原始传感器数据流。

- **扩散动作生成**：调用预训练的扩散视觉运动策略（技能库），基于过滤后的图像、本体感受状态和指令嵌入，生成连续的动作块（Action Chunk）并执行。

```python
        self.executor = vla_executor
        self.memory = {"history": [], "working_memory": "", "error_register": []}

        plan = self.planner.generate_plan(goal, initial_obs, self.memory)
        task_idx = 0
        
        while task_idx < len(plan):

            self.memory["working_memory"] = self.planner.update_memory(self.memory, end_obs, sub_task, success_signal)

                task_idx += 1

                    sub_task.retry_count += 1
                    # 保持当前 task_idx，重新执行
                else:
                    # 触发全局重规划
```

### 第二模块：核心架构解释

本文的核心架构将世界模型的训练从“文本重建”转变为“行为保留”。具体流程如下：

1. **数据重构**：从离线交互轨迹中提取四元组：历史上下文、真实下一状态、预测下一状态、记录的专家动作。
2. **状态生成**：给定历史上下文和当前动作，世界模型（策略模型）生成多个候选的下一状态。
3. **行为一致性奖励 (BehR) 计算**：引入一个冻结的参考大语言模型（Reference Agent）。分别计算在“真实状态”和“预测状态”下，执行“记录的专家动作”的对数似然。计算两者的绝对差值，差值越小，说明预测状态越能诱导与真实状态相同的行为，奖励越高。
4. **GRPO 强化学习优化**：使用组相对策略优化（GRPO）算法，利用 BehR 奖励对世界模型进行微调，抛弃 Critic 网络，通过组内优势归一化稳定训练。

```python
import math

def compute_behr_reward(history, real_state, pred_state, expert_action, ref_agent):
    # 1. 构建参考智能体的 Prompt
    prompt_real = build_prompt(history, real_state)
    prompt_pred = build_prompt(history, pred_state)
    
    # 2. 计算真实状态下，专家动作的平均 Token 对数似然
    ll_real = ref_agent.get_log_prob(prompt_real, expert_action)
    
    # 3. 计算预测状态下，专家动作的平均 Token 对数似然
    ll_pred = ref_agent.get_log_prob(prompt_pred, expert_action)
    
    # 4. 计算行为一致性奖励 (采用指数衰减形式)
    delta = abs(ll_pred - ll_real)
    reward = math.exp(-1.0 * delta) 
    
    return reward

def train_step_grpo(world_model, batch_data, ref_agent):
    for history, real_state, expert_action in batch_data:
        # WM 生成 n 个候选状态 (例如 n=5)
        pred_states = world_model.generate(history, num_candidates=5, temperature=1.3)
        
        rewards = []
        for pred_state in pred_states:
            r = compute_behr_reward(history, real_state, pred_state, expert_action, ref_agent)
            rewards.append(r)
            
        # GRPO 组内优势归一化 (减去均值，除以标准差)
        advantages = normalize_rewards(rewards)
        
        # 依据优势值更新世界模型参数
        world_model.update_policy(pred_states, advantages)
```

# 第二模块：核心架构解释

EEAgent 的架构设计将感知与决策解耦，并通过记忆机制实现闭环进化。整个流程分为三个核心阶段：

1. **环境解释阶段 (Environment Interpreter)**：
利用大视觉语言模型（VLM，如 GPT-4o）和外部工具（如 SAM）对当前环境进行解析。SAM 负责提取环境中的所有物体实体（Bounding Boxes 和图像裁剪），VLM 则根据用户指令，通过调用 `image_match()` 或 `semantic_match()` 等预定义函数，将指令中的目标与环境中的实体进行精准对齐，输出结构化的环境信息。

2. **策略规划阶段 (Policy Planner)**：
大语言模型（LLM）接收用户指令、上一步解析出的环境信息，以及包含“长期记忆（原则）”和“短期记忆（建议）”的 Prompt。LLM 在预定义的动作库（如 `PickPlace`, `PickRotate`）中进行选择，输出可执行的 JSON 格式动作序列。

3. **长短期反思与优化阶段 (LSTRO)**：
动作执行后，系统根据环境反馈（成功或失败）触发反思：
- **成功时**：LLM 总结成功经验，提炼出具有全局适用性的原则，存入长期记忆（LM）。
- **失败时**：首先进行**错误定位**（通过图像-描述一致性检查感知错误，通过动作-指令一致性检查决策错误）。随后，LLM 针对错误提取具体的短期建议（存入 SM）和泛化原则（存入 LM）。
- **记忆优化**：为防止 Prompt 爆炸和幻觉，LLM 会定期对长期记忆进行审查，合并同类项、消除冲突，并限制记忆条目的总数。

**核心逻辑伪代码 (Python 风格)**：

```python
class EEAgent:
    def __init__(self, vlm, llm, sam):
        self.vlm = vlm
        self.llm = llm
        self.sam = sam
        self.long_term_memory = []  # 存储全局泛化原则
        self.short_term_memory = [] # 存储当前任务特定建议
        self.max_trials = 3

    def execute_task(self, instruction, environment):
        for trial in range(self.max_trials):
            # 1. 环境解释
            entities = self.sam.extract_entities(environment)
            env_info = self.vlm.match_entities(instruction, entities)
            
            # 2. 策略规划
            prompt = self.build_prompt(instruction, env_info, self.long_term_memory, self.short_term_memory)
            action_sequence = self.llm.generate_actions(prompt)
            
            # 3. 执行动作并获取反馈
            feedback = environment.step(action_sequence)
            
            # 4. 长短期反思与优化 (LSTRO)
            if feedback == "SUCCESS":
                principles = self.llm.reflect_success(action_sequence, env_info)
                self.optimize_and_update_memory(principles, memory_type="long_term")
                return True
            else:
                # 错误定位
                error_source = self.locate_error(instruction, env_info, action_sequence)
                # 提取教训
                principles, suggestions = self.llm.reflect_failure(error_source)
                self.optimize_and_update_memory(principles, memory_type="long_term")
                self.short_term_memory.append(suggestions)
                
        return False

    def optimize_and_update_memory(self, new_insights, memory_type):
        """记忆优化：去重、解决冲突、限制容量"""
        if memory_type == "long_term":
            merged_memory = self.llm.merge_and_resolve_conflicts(self.long_term_memory, new_insights)
            self.long_term_memory = merged_memory[:20] # 限制最大记忆数为20条
```

2. **认知核心 (VLM as Cerebrum)**：利用大型视觉语言模型（如 GPT-4V）作为慢速思考的“大脑”。通过思维链（CoT）将模糊的自然语言指令分解为可执行的子目标，并结合拓扑地图或 3D 场景图进行空间接地（Spatial Grounding）。
3. **感觉运动策略 (VLA as Cerebellum)**：利用视觉语言动作模型（如 OpenVLA, $\pi_0$）作为快速反应的“小脑”。将无人机的底层控制指令（如线速度、角速度）作为特殊的语言 Token 纳入词表，实现从多模态感知到连续控制的端到端映射。
4. **物理接地推理 (World Model Integration)**：引入生成式世界模型（如视频扩散模型）。在 VLA 执行动作前，世界模型预测未来的视觉观测和物理状态，赋予智能体“预见性”和物理常识，从而规避碰撞并优化长程路径。

以下是代表当前 UAV-VLN 最前沿架构（World Model + VLA）底层逻辑的 Python 风格伪代码：

```python
class UAVAgenticSystem:
    def __init__(self, vlm_planner, vla_policy, world_model):
        # 初始化三大核心基础模型
        self.vlm = vlm_planner       # 认知大脑：负责高维语义推理与任务分解
        self.vla = vla_policy        # 运动小脑：负责端到端多模态控制
        self.wm = world_model        # 世界模型：负责物理规律模拟与未来预测
        self.observation_history = [] # 历史观测序列 o_{<=t}

    def execute_mission(self, natural_language_instruction, environment):
        current_obs = environment.get_observation() # 包含 RGB, Depth, IMU
        
        # 1. 认知大脑进行任务分解 (Chain-of-Thought)
        sub_goals = self.vlm.decompose_task(natural_language_instruction, current_obs)
        
        for goal in sub_goals:
            while not self.is_goal_reached(goal, current_obs):
                self.observation_history.append(current_obs)
                
                # 2. 世界模型进行前向模拟与安全验证 (Foresight & Safety)
                # 预测采取潜在动作后的未来状态
                predicted_future = self.wm.simulate_future(self.observation_history, goal)
                
                if self.wm.detect_collision_risk(predicted_future):
                    # 如果世界模型预测有风险，触发 VLM 重新规划
                    goal = self.vlm.replan(current_obs, risk_info=predicted_future)
                    continue
                
                # 3. VLA 模型生成底层飞行控制指令 (Action Tokenization)
                # a_t ~ \pi_\theta ( \cdot | o_{\le t}, L )
                action_tokens = self.vla.generate_action(self.observation_history, goal)
                continuous_control_cmd = self.decode_to_velocity(action_tokens) # [v_x, v_y, v_z, \omega_z]
                
                # 4. 与环境交互
                current_obs, reward, done = environment.step(continuous_control_cmd)
                
                if done:
                    break
```

### 第二模块：核心架构解释

C$^2$T 框架的运行流程严格分为三个解耦的阶段：结构化文本生成、离线奖励模型训练、以及在线强化学习集成。

**阶段一：结构化文本生成与样本配对 (Stage 1)**
系统首先从交通模拟器中收集原始观测数据。为了消除 LLM 处理自由文本时产生的幻觉，C$^2$T 使用固定的模板，将交通状态（如相位、排队长度、路口压力、平均延迟、碰撞时间 TTC、急刹车次数等）转换为带有明确物理单位的确定性文本。随后，系统根据拥堵程度和安全指标的差异，采样出具有高对比度的文本对，构建偏好数据集。

**阶段二：离线常识奖励学习 (Stage 2)**
将阶段一生成的文本对输入给固定的 LLM（如 GPT 或 Llama）。LLM 根据提示词判断哪一个文本描述的交通状态更优（更安全、更高效）。保留 LLM 给出明确偏好的数据，使用 Bradley-Terry 损失函数训练一个轻量级的多层感知机（MLP）作为内在奖励模型。该模型输入文本特征和数值特征，输出一个标量分数。此阶段完全离线运行。

**阶段三：奖励重塑与强化学习集成 (Stage 3)**
在标准的多智能体强化学习（PPO）训练中，冻结阶段二训练好的内在奖励模型。在每一步控制中，系统计算环境给出的外部奖励（如路口压力）和模型给出的内在奖励。为了保证绝对安全，系统引入了一个“安全掩码”：当检测到极度危险状态（如 TTC 过低或闯红灯）时，直接屏蔽内在奖励，并施加安全惩罚。最后，对各项奖励进行独立的标准化处理，并按动态权重相加，用于更新交通信号灯控制器的策略网络。

**核心逻辑伪代码 (Python 风格):**

```python
def train_c2t_rl_agent(env, intrinsic_reward_model, ppo_agent, total_steps):
    # 初始化运行时的均值和方差记录器，用于奖励标准化
    norm_ext = RunningNormalizer()
    norm_int = RunningNormalizer()
    norm_safe = RunningNormalizer()
    
    for step in range(total_steps):
        # 1. 获取当前观测状态
        obs = env.get_observation()
        
        # 2. 智能体输出动作（交通信号灯相位切换）
        actions = ppo_agent.get_actions(obs)
        
        # 3. 环境执行动作，返回下一状态和外部奖励（如路口压力）
        next_obs, ext_reward = env.step(actions)
        
        # 4. 计算内在奖励与安全掩码
        int_reward = intrinsic_reward_model.predict(next_obs)
        is_safe = check_safety_thresholds(next_obs) # 检查 TTC, 急刹车等
        
        if is_safe:
            mask = 1.0
            safe_penalty = 0.0
        else:
            mask = 0.0
            safe_penalty = -1.0 * penalty_weight
            
        # 5. 奖励流独立标准化与软裁剪
        norm_ext_r = norm_ext.normalize_and_clip(ext_reward)
        norm_int_r = norm_int.normalize_and_clip(int_reward * mask)
        norm_safe_r = norm_safe.normalize_and_clip(safe_penalty)
        
        # 6. 动态权重调度（随着训练进行，逐渐增加内在奖励的比重）
        lambda_weight = get_schedule_weight(step, total_steps)
        
        # 7. 混合最终奖励
        mixed_reward = norm_ext_r + (lambda_weight * norm_int_r) + norm_safe_r
        
        # 8. 存储经验并更新 PPO 策略
        ppo_agent.store_transition(obs, actions, mixed_reward, next_obs)
        if step % update_interval == 0:
            ppo_agent.update_policy()
```
