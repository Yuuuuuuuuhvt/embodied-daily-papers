### 第二模块：核心架构解释

GARFIELD 的核心逻辑在于将输入图像和可选的稀疏约束映射到一个概率隐空间，并在该空间中直接解析运动学信息，而不是生成未来帧的图像。

**处理流程**：
1. **条件编码**：接收当前场景的单张图像，以及可选的时空稀疏约束（例如指定某个物体在未来某时刻必须到达的坐标）。
2. **隐空间分布建模**：编码器将输入映射为一个结构化的时空隐变量分布。这个分布代表了当前状态下所有符合物理规律的“可能未来”的集合（即薛定谔的猫处于叠加态）。
3. **双路解码**：
   - **轨迹采样器 (Trajectory Sampler)**：从隐分布中进行联合采样，生成具体的未来运动轨迹（Kinematics）。
   - **密度解码器 (Density Decoder)**：这是一个确定性网络，不依赖蒙特卡洛采样，直接计算并输出特定场景元素在特定时间步的运动概率密度。
4. **不确定性定位与细化**：通过密度解码器，模型可以精确定位场景中哪些部分的未来运动存在高不确定性。当引入新的稀疏约束时，隐分布会随之更新，不确定性被逐步收敛。

import torch
import torch.nn as nn

class GARFIELD(nn.Module):
    def __init__(self):
        super().__init__()
        # 编码器：处理图像和稀疏约束
        self.image_encoder = ImageEncoder()
        self.constraint_encoder = ConstraintEncoder()
        
        # 概率隐空间网络：输出分布参数 (如均值和方差)
        self.latent_distribution_net = LatentDistributionNetwork()
        
        # 双路解码器
        self.trajectory_sampler = TrajectoryDecoder()
        self.density_decoder = DeterministicDensityDecoder()

    def forward(self, image, sparse_constraints=None):
        # 1. 提取条件特征
        img_feat = self.image_encoder(image)
        cond_feat = img_feat
        
        if sparse_constraints is not None:
            const_feat = self.constraint_encoder(sparse_constraints)
            cond_feat = torch.cat([img_feat, const_feat], dim=-1)
            
        # 2. 预测时空隐分布参数 (mu, sigma)
        latent_mu, latent_sigma = self.latent_distribution_net(cond_feat)
        latent_dist = torch.distributions.Normal(latent_mu, latent_sigma)
        
        # 3a. 采样具体轨迹 (用于执行或模拟)
        sampled_latents = latent_dist.rsample(sample_shape=(num_trajectories,))
        trajectories = self.trajectory_sampler(sampled_latents)
        
        # 3b. 确定性密度估计 (用于不确定性感知规划)
        # 直接从分布参数解码概率密度，无需蒙特卡洛采样
        motion_density = self.density_decoder(latent_mu, latent_sigma)
        
        return trajectories, motion_density

### 第二模块：核心架构解释

CoTinyVLA 的架构是一个四阶段的流水线，核心逻辑是将多模态输入序列化，通过轻量级视觉-语言骨干网络，输出结构化的推理文本和连续的动作块。

**架构流程：**
1. **输入组装与标记化:** 模型在每个控制步接收 8 帧第三人称图像和 8 帧腕部图像。每帧图像前都强制插入显式的文本标记（如 `[Third frame 1]`），以此替代额外的时间位置编码。同时，8 维的本体感受向量通过 MLP 投影后作为软 token 拼接到自然语言指令前。
2. **分层思维链（CoT）生成:** 
   - **Episode 级别 (Plan):** 在任务开始时生成一次，将自然语言指令分解为有序的子目标。
   - **Chunk 级别 (Think):** 在每次预测动作块前生成，包含三个固定槽位：`Phase`（当前子动作阶段）、`Gripper`（夹爪开闭状态）和 `Next`（下一步动作简述）。
3. **动作预测:** 动作头读取推理文本之后的隐藏状态，输出一个 8 步的动作块（包含 6 自由度末端执行器位移和 1 自由度夹爪指令）。
4. **推理期优化:** 由于 `Plan` 在整个任务期间是稳定的，推理时只需生成一次并缓存，后续步骤仅生成 `Think` 和动作，这使得推理延迟减半，峰值显存仅需 2.25 GiB。

**核心伪代码实现逻辑：**

```python
class CoTinyVLA(nn.Module):
    def __init__(self, vlm_backbone_0_9B):
        super().__init__()
        self.vlm = vlm_backbone_0_9B
        self.proprio_proj = nn.Sequential(nn.Linear(8, hidden_dim), nn.ReLU(), nn.Linear(hidden_dim, hidden_dim))
        self.action_head = nn.Linear(hidden_dim, 8 * 7) # 8 steps, 7 DoF
        
    def forward(self, images_3rd, images_wrist, proprio, instruction, is_first_step=True, cached_plan=None):
        # 1. Process Proprioception
        proprio_token = self.proprio_proj(proprio)
        
        # 2. Assemble Visual History with Text Markers
        visual_tokens = []
        for i in range(8):
            visual_tokens.append(tokenize(f"[Third frame {i+1}]"))
            visual_tokens.append(self.vlm.encode_image(images_3rd[i]))
        for i in range(8):
            visual_tokens.append(tokenize(f"[Wrist frame {i+1}]"))
            visual_tokens.append(self.vlm.encode_image(images_wrist[i]))
            
        # 3. Hierarchical CoT Generation
        if is_first_step:
            # Generate Episode-level Plan
            prompt = concat(visual_tokens, proprio_token, instruction)
            plan_tokens = self.vlm.generate(prompt, start_token="<plan>", end_token="</plan>")
            cached_plan = plan_tokens
        
        # Generate Chunk-level Think
        prompt_with_plan = concat(visual_tokens, proprio_token, instruction, cached_plan)
        think_tokens = self.vlm.generate(prompt_with_plan, start_token="<think>", end_token="</think>")
        
        # 4. Action Prediction
        # Action head reads the hidden state at the end of the Think span
        final_hidden_state = self.vlm.get_hidden_state(concat(prompt_with_plan, think_tokens))
        action_chunk = self.action_head(final_hidden_state) # Shape: [8, 7]
        
        return action_chunk, cached_plan
```

### 第二模块：核心架构解释

GARFIELD 的核心逻辑在于将输入图像和可选的稀疏约束映射到一个概率隐空间，并在该空间中直接解析运动学信息，而不是生成未来帧的图像。

**处理流程**：
1. **条件编码**：接收当前场景的单张图像，以及可选的时空稀疏约束（例如指定某个物体在未来某时刻必须到达的坐标）。
2. **隐空间分布建模**：编码器将输入映射为一个结构化的时空隐变量分布。这个分布代表了当前状态下所有符合物理规律的“可能未来”的集合（即薛定谔的猫处于叠加态）。
3. **双路解码**：
   - **轨迹采样器 (Trajectory Sampler)**：从隐分布中进行联合采样，生成具体的未来运动轨迹（Kinematics）。
   - **密度解码器 (Density Decoder)**：这是一个确定性网络，不依赖蒙特卡洛采样，直接计算并输出特定场景元素在特定时间步的运动概率密度。
4. **不确定性定位与细化**：通过密度解码器，模型可以精确定位场景中哪些部分的未来运动存在高不确定性。当引入新的稀疏约束时，隐分布会随之更新，不确定性被逐步收敛。

**核心伪代码 (Python-style)**：

import torch
import torch.nn as nn

class GARFIELD(nn.Module):
    def __init__(self):
        super().__init__()
        # 编码器：处理图像和稀疏约束
        self.image_encoder = ImageEncoder()
        self.constraint_encoder = ConstraintEncoder()
        
        # 概率隐空间网络：输出分布参数 (如均值和方差)
        self.latent_distribution_net = LatentDistributionNetwork()
        
        # 双路解码器
        self.trajectory_sampler = TrajectoryDecoder()
        self.density_decoder = DeterministicDensityDecoder()

    def forward(self, image, sparse_constraints=None):
        # 1. 提取条件特征
        img_feat = self.image_encoder(image)
        cond_feat = img_feat
        
        if sparse_constraints is not None:
            const_feat = self.constraint_encoder(sparse_constraints)
            cond_feat = torch.cat([img_feat, const_feat], dim=-1)
            
        # 2. 预测时空隐分布参数 (mu, sigma)
        latent_mu, latent_sigma = self.latent_distribution_net(cond_feat)
        latent_dist = torch.distributions.Normal(latent_mu, latent_sigma)
        
        # 3a. 采样具体轨迹 (用于执行或模拟)
        sampled_latents = latent_dist.rsample(sample_shape=(num_trajectories,))
        trajectories = self.trajectory_sampler(sampled_latents)
        
        # 3b. 确定性密度估计 (用于不确定性感知规划)
        # 直接从分布参数解码概率密度，无需蒙特卡洛采样
        motion_density = self.density_decoder(latent_mu, latent_sigma)
        
        return trajectories, motion_density

# 细化预测：不确定性收敛

### 第二模块：核心架构解释

CoTinyVLA 的架构是一个四阶段的流水线，核心逻辑是将多模态输入序列化，通过轻量级视觉-语言骨干网络，输出结构化的推理文本和连续的动作块。

**架构流程：**
1. **输入组装与标记化:** 模型在每个控制步接收 8 帧第三人称图像和 8 帧腕部图像。每帧图像前都强制插入显式的文本标记（如 `[Third frame 1]`），以此替代额外的时间位置编码。同时，8 维的本体感受向量通过 MLP 投影后作为软 token 拼接到自然语言指令前。
2. **分层思维链（CoT）生成:** 
   - **Episode 级别 (Plan):** 在任务开始时生成一次，将自然语言指令分解为有序的子目标。
   - **Chunk 级别 (Think):** 在每次预测动作块前生成，包含三个固定槽位：`Phase`（当前子动作阶段）、`Gripper`（夹爪开闭状态）和 `Next`（下一步动作简述）。
3. **动作预测:** 动作头读取推理文本之后的隐藏状态，输出一个 8 步的动作块（包含 6 自由度末端执行器位移和 1 自由度夹爪指令）。
4. **推理期优化:** 由于 `Plan` 在整个任务期间是稳定的，推理时只需生成一次并缓存，后续步骤仅生成 `Think` 和动作，这使得推理延迟减半，峰值显存仅需 2.25 GiB。

**核心伪代码实现逻辑：**

```python
class CoTinyVLA(nn.Module):
    def __init__(self, vlm_backbone_0_9B):
        super().__init__()
        self.vlm = vlm_backbone_0_9B
        self.proprio_proj = nn.Sequential(nn.Linear(8, hidden_dim), nn.ReLU(), nn.Linear(hidden_dim, hidden_dim))
        self.action_head = nn.Linear(hidden_dim, 8 * 7) # 8 steps, 7 DoF
        
    def forward(self, images_3rd, images_wrist, proprio, instruction, is_first_step=True, cached_plan=None):
        # 1. Process Proprioception
        proprio_token = self.proprio_proj(proprio)
        
        # 2. Assemble Visual History with Text Markers
        visual_tokens = []
        for i in range(8):
            visual_tokens.append(tokenize(f"[Third frame {i+1}]"))
            visual_tokens.append(self.vlm.encode_image(images_3rd[i]))
        for i in range(8):
            visual_tokens.append(tokenize(f"[Wrist frame {i+1}]"))
            visual_tokens.append(self.vlm.encode_image(images_wrist[i]))
            
        # 3. Hierarchical CoT Generation
        if is_first_step:
            # Generate Episode-level Plan
            prompt = concat(visual_tokens, proprio_token, instruction)
            plan_tokens = self.vlm.generate(prompt, start_token="<plan>", end_token="</plan>")
            cached_plan = plan_tokens
        
        # Generate Chunk-level Think
        prompt_with_plan = concat(visual_tokens, proprio_token, instruction, cached_plan)
        think_tokens = self.vlm.generate(prompt_with_plan, start_token="<think>", end_token="</think>")
        
        # 4. Action Prediction
        # Action head reads the hidden state at the end of the Think span
        final_hidden_state = self.vlm.get_hidden_state(concat(prompt_with_plan, think_tokens))
        action_chunk = self.action_head(final_hidden_state) # Shape: [8, 7]
        
        return action_chunk, cached_plan
```

### 第二模块：核心架构解释

Wonder 的系统级架构由三个核心模块协同构成，旨在实现实时、长程且高度可控的视频生成：

**1. 密集坐标场条件注入 (Dense Coordinate Field Conditioning)**
模型不直接摄入抽象的相机外参矩阵（Extrinsics），而是将相机运动与朝向预渲染为一个密集的空间坐标场。该坐标场与视觉特征在空间维度上严格对齐，使得模型能够将相机运动直接作为视觉线索进行处理，大幅降低了模型理解复杂 3D 变换的难度，提高了控制精度。

**2. 稀疏注意力记忆机制 (Sparse Attention-based Memory)**
为了支持分钟级的长程生成，模型维护一个持续增长的上下文记忆库。在推理阶段，模型不执行全局自注意力（这会导致 $O(N^2)$ 的计算复杂度爆炸），而是通过查询（Query）机制，从记忆库中稀疏检索出与当前帧最相关的少量上下文 Tokens。这使得模型在任意长度的生成过程中，单步推理的计算量保持恒定。

**3. 修正的自强制蒸馏 (Rectified Self-Forcing Distillation)**
为了达到 16 FPS 的实时生成速度，作者采用了一种教师-学生（Teacher-Student）蒸馏管道。通过引入特定的修正技术，强制学生模型在减少去噪步数的同时，严格遵守相机控制信号，并继承教师模型的多样性生成模式与长程记忆能力。

**核心逻辑伪代码 (Python 风格)**：

class WonderWorldModel(nn.Module):
    def __init__(self, student_unet, memory_bank_size, top_k_tokens):
        super().__init__()
        self.unet = student_unet
        self.memory_bank = MemoryBank(max_size=memory_bank_size)
        self.top_k = top_k_tokens

    def render_coordinate_field(self, camera_pose, image_resolution):
        # 将相机姿态矩阵转换为与图像分辨率对齐的密集坐标场
        # 返回 shape: [B, C, H, W] 的坐标特征
        coord_field = compute_dense_flow_and_orientation(camera_pose, image_resolution)
        return coord_field

    def sparse_memory_retrieval(self, current_query_tokens):
        # 从全局记忆库中检索最相关的 top_k 个 tokens
        # 确保计算复杂度独立于已生成的总帧数
        keys, values = self.memory_bank.get_all()
        attention_scores = compute_similarity(current_query_tokens, keys)
        top_k_indices = get_top_k_indices(attention_scores, k=self.top_k)
        retrieved_k, retrieved_v = gather_tokens(keys, values, top_k_indices)
        return retrieved_k, retrieved_v

    def forward_step(self, current_latent, camera_pose, condition_image_or_video):
        # 1. 生成相机控制信号
        coord_field = self.render_coordinate_field(camera_pose, current_latent.shape[-2:])
        
        # 2. 拼接当前潜变量与坐标场
        model_input = torch.cat([current_latent, coord_field], dim=1)
        
        # 3. 提取当前输入的 Query tokens
        query_tokens = self.unet.get_query(model_input)
        
        # 4. 稀疏检索历史记忆
        context_k, context_v = self.sparse_memory_retrieval(query_tokens)
        
        # 5. 执行单步/少步去噪预测 (基于蒸馏后的学生模型)
        next_latent = self.unet.predict_noise(model_input, context_k, context_v, condition_image_or_video)
        
        # 6. 更新记忆库
        new_k, new_v = self.unet.extract_kv(next_latent)
        self.memory_bank.update(new_k, new_v)
        
        return next_latent

    def explore_world(self, initial_condition, camera_trajectory):
        # 实时长程漫游循环
        current_latent = encode(initial_condition)
        generated_frames = []
        
        for pose in camera_trajectory:
            current_latent = self.forward_step(current_latent, pose, initial_condition)

### 第二模块：核心架构解释

IDR（Infer-Diagnose-Refine）框架的核心逻辑在于将测试时的动作预测过程拆解为三个独立的阶段，通过因果干预来动态调整视觉模态的权重。

1. **Infer（推断阶段）**：模型首先接收完整的视觉观察、语言指令和本体感觉状态，进行一次标准的前向传播，得到“事实动作”（Factual Action）。随后，对视觉输入施加干预（如零填充 Zero-padding），屏蔽视觉信息，进行第二次前向传播，得到“反事实动作”（Counterfactual Action）。
2. **Diagnose（诊断阶段）**：计算事实动作与反事实动作之间的差异。差异越大，说明当前阶段的动作决策越依赖视觉信息。通过基于范数的量化方法（Norm-based quantification），将这种差异转化为视觉模态的因果效应得分（即动态重要性权重）。
3. **Refine（修正阶段）**：利用诊断阶段得到的动态重要性权重，通过门控残差融合机制（Gated residual fusion），对原始的动作预测进行加权修正，输出最终的执行动作。

    alpha = normalize_to_weight(causal_effect)

    # 这里假设模型内部有一个基础动作预测 base_action 和一个视觉残差 visual_residual

### 第二模块：核心架构解释

SAM3D-VLA 的核心架构建立在 $\pi_0$ 模型之上，采用双分支（Teacher-Student）的特征对齐训练策略。整个流程分为数据预处理、特征提取与对齐、以及动作生成三个阶段。

**1. 子任务感知的掩码生成（数据预处理）**
对于长程任务，首先利用 LLM 将高层指令分解为子任务。在训练数据的每一帧，使用 Grounding DINO 和 YOLO 定位当前子任务的目标物体，并利用 SAM2 生成二进制掩码（Mask）。

**4. 动作预测与联合优化**
VLA 最后一层的特征输入动作专家模块（Action Expert），通过条件流匹配（Conditional Flow Matching）预测连续动作块。最终的损失函数是动作流匹配损失与 3D 特征对齐损失的加权和。

**核心伪代码实现：**

```python
import torch
import torch.nn.functional as F

def train_step(images, instructions, actions, object_masks, pi_zero, sam3d, projector, alpha=0.1):
    """
    images: [B, V, 3, H, W]
    object_masks: [B, V, H, W]
    """
    B, V = images.shape[:2]
    
    # 1. Teacher Pathway: Extract SAM3D features (Frozen)
    with torch.no_grad():
        # Flatten batch and views for SAM3D
        flat_images = images.view(B*V, 3, H, W)
        flat_masks = object_masks.view(B*V, H, W)
        
        # Extract features: [B*V, L_T, D_T]
        teacher_features = sam3d.extract_features(flat_images, flat_masks)
        
        # Reshape and interpolate to match student token resolution (H_S, W_S)
        teacher_2d = reshape_to_2d_grid(teacher_features) 
        teacher_resized = F.interpolate(teacher_2d, size=(H_S, W_S), mode='bilinear')
        teacher_target = flatten_and_reassemble(teacher_resized) # [B, V*L_S, D_T]

    # 2. Student Pathway: VLA Forward
    # hidden_states contains features from all Gemma layers
    hidden_states, action_pred = pi_zero(images, instructions)
    
    # Extract intermediate layer features: [B, V*L_S, D_S]
    student_features = hidden_states[selected_layer_index]
    
    # Project to teacher dimension: [B, V*L_S, D_T]
    student_projected = projector(student_features)

    # 3. Masked Normalized Alignment Loss
    # Expand mask to token level: [B, V*L_S, 1]
    token_mask = pool_mask_to_tokens(object_masks, size=(H_S, W_S)).unsqueeze(-1)
    
    # L2 Normalize features
    student_norm = F.normalize(student_projected, p=2, dim=-1)
    teacher_norm = F.normalize(teacher_target, p=2, dim=-1)
    
    # Compute MSE only on masked regions
    diff = (student_norm - teacher_norm) ** 2
    loss_align = (diff * token_mask).sum() / (token_mask.sum() + 1e-8)

    # 4. Action Loss (Flow Matching)
    loss_action = compute_flow_matching_loss(action_pred, actions)

    # 5. Total Loss
    total_loss = loss_action + alpha * loss_align
    total_loss.backward()
    
    return total_loss
```

### 第二模块：核心架构解释

Reinformed Dreamer 的核心架构建立在循环状态空间模型（RSSM）之上，其运行流程分为训练、想象（Imagination）和执行（Execution）三个阶段。

**1. 架构方法与流程**
*   **双编码器机制**：模型内部包含一个特权编码器（接收历史状态和下一时刻的特权信息）和一个普通编码器（仅接收历史状态和当前观测）。
*   **训练阶段（收紧下界）**：为了最大化对数似然，模型使用特权编码器生成高质量的后验隐变量。由于特权编码器包含了更多信息，它有效消除了“信息鸿沟（Information Gap）”，从而提供了一个更紧致的 ELBO 下界来优化奖励解码器和信息解码器。
*   **隐变量引导（Latent Guidance）**：由于特权编码器在部署时不可用，必须训练普通编码器。作者通过在损失函数中引入额外的 KL 散度项，强制普通编码器的输出分布与先验分布对齐，而先验分布又被特权编码器对齐。普通编码器借此在隐空间中“间接”学习到了特权信息。
*   **想象与执行阶段**：策略的训练完全在隐空间中进行（Latent Imagination），无需解码观测图像。在实际部署时，直接丢弃特权编码器，仅使用普通编码器提取当前观测的隐状态并输入给策略网络输出动作。

**2. 核心伪代码实现**

```python
# 伪代码：Reinformed Dreamer 核心前向传播与损失计算逻辑
def compute_reinformed_loss(obs, priv_info, actions, rewards, prev_state):
    """
    obs: 当前时刻的普通观测 (o_t)
    priv_info: 下一时刻的特权信息 (i_{t+1})
    """
    # 1. 动力学先验 (Prior)
    # 基于上一时刻状态和动作预测当前隐状态分布
    prior_dist = dynamics_model(prev_state, actions)
    
    # 2. 特权编码器 (Privileged Encoder) - 仅训练时可用
    # 接收特权信息，输出更紧致的后验分布
    priv_post_dist = privileged_encoder(prior_dist, priv_info)
    
    # 3. 普通编码器 (Unprivileged Encoder) - 部署时使用
    # 仅接收普通观测，输出普通后验分布
    unpriv_post_dist = unprivileged_encoder(prior_dist, obs)
    
    # 4. 重构损失 (Reconstruction Loss)
    # 使用特权后验进行解码，确保动力学模型学到特权特征
    pred_reward = reward_decoder(priv_post_dist)
    pred_priv_info = info_decoder(priv_post_dist)
    recon_loss = calc_log_prob(pred_reward, rewards) + calc_log_prob(pred_priv_info, priv_info)
    
    # 5. 隐变量引导 (Latent Guidance)
    # 特权后验指导先验网络
    kl_priv_prior = KL_divergence(priv_post_dist, prior_dist)
    # 普通后验对齐先验网络 (间接吸收特权信息)
    kl_unpriv_prior = KL_divergence(unpriv_post_dist, prior_dist)
    
    # 6. 总体 ELBO 目标 (最大化下界等价于最小化以下 Loss)
    # 对应论文公式 (21)
    loss = -recon_loss + kl_priv_prior + kl_unpriv_prior
    
    return loss
```

### 第一模块：一分钟核心速写

**1. 论文领域：** World Model 增强 VLA (基于可查询语义地图的具身导航)

**2. TL;DR:** IMPRINT 提出了一种基于网络图像检索增强的零样本即插即用框架，以解决长尾/细粒度目标导航中纯文本查询语义不足的痛点问题，在 OVON 和新提出的 HSSD-rare 基准上实现了目标定位与端到端导航成功率的显著提升。

**3. 研究动机:** 现存开放词汇导航方案最大的痛点是，当面对细粒度或长尾物体（如特定品牌或款式的家具）时，纯文本查询提供的视觉线索极其匮乏，导致定位严重失效。本文的切入点极具仿生学意味且巧妙：模仿人类遇到未知物体时“上网搜图”的行为，直接利用网络搜索引擎获取目标物体的丰富视觉示例，作为补充查询条件。
**核心机制:** 剥离复杂的数学公式，其本质就是将传统的“用文本特征搜地图”升级为“用文本+网络检索图片的联合特征搜地图”，无需重新训练任何底层导航策略即可直接插入现有系统。

**4. 关键数据:**
- **最能证明其有效性的核心数据:** 在 OVON-syn 数据集的静态目标定位测试中，图像条件查询相比纯文本查询，平均提升了 +10.54% 的成功率（SR）。这直接证明了引入外部视觉上下文能有效弥补文本在长尾目标上的语义缺失。
- **存疑/值得深思的试验结果:** 在 HSSD-rare 数据集的端到端导航测试中，尽管静态定位有明显提升，但基于 OneMap 基准的导航成功率仅从 6.58% 微弱提升至 7.05%。作者坦诚地通过消融实验指出，这是因为下游的“目标检测模块”成为了系统瓶颈——如果检测器认不出长尾物体，地图定位再准也无法触发最终的导航停止动作。

### 第二模块：核心架构解释

IMPRINT 框架的运行流程分为建图、查询增强、特征匹配与导航四个核心步骤。其不改变原有的探索策略，仅在语义匹配层进行干预。

1. **语义建图 (Mapping):** 机器人在环境中移动，通过 RGB-D 相机获取观测数据。利用预训练的视觉语言模型 (VLM) 提取图像特征，并结合深度信息将其投影到 3D 空间，最终离散化为 2D 的全局可查询语义地图。
2. **查询增强 (Query-Retrieval):** 接收到长尾文本查询（如“Jason Maple chest”）后，系统自动在网络上检索 Top-N 张相关图像，并进行元数据过滤去重。
3. **特征匹配与定位 (Aggregate and Localize):** 将检索到的网络图像通过 VLM 编码为视觉特征，分别与语义地图计算余弦相似度，生成 N 个相似度地图。通过算术平均将这些地图（可选地融合文本特征地图）聚合成最终的得分图，得分最高的网格即为目标候选位置。
4. **导航执行 (Navigation):** 导航策略引导机器人前往高分区域，配合目标检测模块确认目标，最终执行 PointGoal 策略到达终点。

**底层逻辑伪代码实现：**

```python
def imprint_localization(text_query, rgb_obs, depth_obs, poses, vlm_encoder, map_resolution):
    # 1. 构建全局可查询语义地图
    semantic_map = initialize_map(map_resolution)
    for rgb, depth, pose in zip(rgb_obs, depth_obs, poses):
        # 提取视觉特征并投影到空间网格
        feature = vlm_encoder.encode_image(rgb)
        point_cloud = project_to_3d(depth, pose)
        semantic_map.update(point_cloud, feature)
    
    # 2. 网络图像检索 (获取视觉上下文)
    web_images = web_search(text_query, top_n=10)
    
    # 3. 图像条件查询与相似度计算
    similarity_maps = []
    for img in web_images:
        img_feature = vlm_encoder.encode_image(img)
        # 计算图像特征与地图网格特征的余弦相似度
        sim_map = cosine_similarity(img_feature, semantic_map)
        similarity_maps.append(sim_map)
        
    # 4. 聚合与定位 (采用算术平均聚合)
    final_sim_map = mean(similarity_maps, axis=0) 
    
    # 可选：联合文本特征进行混合推理
    # text_feature = vlm_encoder.encode_text(text_query)
    # text_sim_map = cosine_similarity(text_feature, semantic_map)
    # final_sim_map = mean([final_sim_map, text_sim_map], axis=0)
    
    # 选取相似度得分最高的区域作为导航目标点
    target_location = argmax(final_sim_map)
    
    return target_location
```

Q2: 作者提出的核心解决方案（创新点）是什么？
