**方法与实验流程详解**

1.  **离线训练阶段 (Offline Training)**

2.  **在线部署阶段 (Deployment-time Intervention)**
    *   **实时监控**：标称策略输出动作并控制机器人。监控器实时计算当前状态的平滑活跃度价值。
    *   **触发干预**：当活跃度价值超过动态衰减的阈值（表明策略正在偏离目标）时，暂停标称策略，触发规划器。
    *   **动作搜索与执行**：规划器以标称策略的当前动作为基准，利用交叉熵方法（CEM）在数据驱动的主成分空间中采样候选动作块。世界模型并行推演这些动作块的未来状态，并用活跃度价值网络进行打分。系统执行得分最优的动作块的前几步，随后将控制权交还给标称策略。

### 第二模块：核心架构解释

Robota-Embed 的核心架构设计围绕“异构数据统一”与“预测性对齐”展开。其工作流可拆解为编码器架构、训练目标以及下游应用接口三个部分。

**1. 编码器架构 (VLA Encoder)**
模型基于 Cosmos3-Edge 4B 构建。为了处理不同机器人平台（如单臂、双臂、人类灵巧手）维度和频率各异的原生动作，作者为每个数据源设计了专属的动作投影器（Source-specific projectors）。
*   **Query 端：** 输入为指令（Language）、当前交互区域的 SAM3 裁剪图像（Vision）、以及同步的当前原生动作（Action）。
*   **Target 端：** 输入为指令（Language）、未来 4 秒的视频片段（Video）、以及未来 4 秒的原生动作序列（Action）。
两者共享 Transformer 主干网络，但通过不同的残差适配器（Residual Adapters）输出归一化的 Query 向量和 Target 向量。

**2. 训练目标 (Training Objectives)**
训练过程不依赖人工标注，而是通过结构化解析构建弱标签，核心损失函数包含三部分：
*   **预测性检索对齐 (Predictive Retrieval Alignment):** 双向 InfoNCE 损失，拉近 Query 与其真实的未来 Target。
*   **多模态接地与判别 (Multimodal Grounding and Discrimination):** 引入硬负样本（Hard Negatives）。通过规则挖掘出“任务相同但动作阶段不同”或“动作相同但操作对象不同”的样本作为强干扰项；同时引入模态替换（Modality Swaps）惩罚，防止模型退化为仅依赖单一模态（如只看文本）。
*   **表征正则化 (Representation Regularization):** 约束 Embedding 空间的各向同性，防止特征坍缩。

**3. 下游应用接口 (Downstream Interfaces)**
*   **Embed2ICL:** 静态检索。将检索到的未来片段直接作为视频输入（用于 DreamZero）或转化为 Context Tokens（用于 Fast-WAM），实现免训练或基于训练的策略条件化。
*   **Embed2Evolve:** 动态进化。在冻结的 GPT-6 Astra 策略下，机器人不断尝试任务，将成功或失败的轨迹存入本地记忆库。Robota-Embed 负责在每次决策时检索最相关的历史经验，作为 Prompt 喂给大模型。

**核心逻辑伪代码实现：**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class RobotaEmbed(nn.Module):
    def __init__(self, base_model, source_action_dims):
        super().__init__()
        self.transformer = base_model.transformer
        self.shared_head = base_model.projection_head
        
        # 异构动作投影器
        self.action_projectors = nn.ModuleDict({
            source: nn.Linear(dim, hidden_dim) 
            for source, dim in source_action_dims.items()
        })
        
        # Query 和 Target 的专属残差适配器
        self.query_adapter = nn.Linear(hidden_dim, hidden_dim, bias=False)
        self.target_adapter = nn.Linear(hidden_dim, hidden_dim, bias=False)
        self.temperature = nn.Parameter(torch.tensor(0.07))

    def encode_query(self, text, image, action, source):
        # 融合当前状态
        action_feat = self.action_projectors[source](action)
        fused_tokens = self.transformer(text, image, action_feat)
        
        # 时序池化与适配
        pooled = fused_tokens.mean(dim=1)
        base_embed = self.shared_head(pooled)
        query_embed = base_embed + self.query_adapter(base_embed)
        return F.normalize(query_embed, p=2, dim=-1)

    def encode_target(self, text, future_video, future_action, source):
        # 融合未来状态
        action_feat = self.action_projectors[source](future_action)
        fused_tokens = self.transformer(text, future_video, action_feat)
        
        pooled = fused_tokens.mean(dim=1)
        base_embed = self.shared_head(pooled)
        target_embed = base_embed + self.target_adapter(base_embed)
        return F.normalize(target_embed, p=2, dim=-1)

    def compute_loss(self, q, k, hard_negatives):
        # 预测性检索对齐 (InfoNCE with Hard Negatives)
        sim_matrix = torch.matmul(q, k.T) / self.temperature
        
        # 掩码逻辑：过滤掉语义兼容但非配对的样本，保留硬负样本
        valid_mask = self.build_valid_mask(hard_negatives) 
        sim_matrix = sim_matrix.masked_fill(~valid_mask, float('-inf'))
        
        labels = torch.arange(q.size(0)).to(q.device)
        loss_q2k = F.cross_entropy(sim_matrix, labels)
        loss_k2q = F.cross_entropy(sim_matrix.T, labels)
        
        return (loss_q2k + loss_k2q) / 2.0
```

MetaGenSim 的运行流程分为三个独立且连续的阶段：

1. 探测与打分器元学习 (Rater Network Learning)
系统首先在预定义的仿真参数空间中均匀采样，生成少量的探测数据集。随后进入双层优化循环：内层循环使用探测数据和真实训练数据更新一个代理策略网络；外层循环在真实验证集上计算该策略的验证损失，并通过元梯度（Meta-gradients）反向传播更新打分器网络。打分器的目标是为每一个仿真状态-动作对输出一个标量效用分数。

2. 参数效用分布构建 (Parameter Utility Landscape)
打分器训练完成后，对探测数据集中的所有轨迹进行打分。系统使用条件风险价值（CVaR）聚合单条轨迹的得分，将其映射回生成该轨迹的底层仿真参数。随后，利用核密度估计（KDE）和温度缩放的 Softmax 函数，在连续参数空间上构建出一个平滑的概率密度函数，高分参数区域被赋予更高的采样概率。

### 第二模块：核心架构解释

**方法与实验流程详解**

本研究的架构分为离线训练与在线部署两个阶段。

1.  **离线训练阶段 (Offline Training)**
    *   **数据收集**：在目标任务上运行标称策略（Nominal Policy），收集带有稀疏回合级别结果标签（成功/失败）的轨迹数据。
    *   **活跃度价值网络 (Liveness Value Function) 训练**：利用收集的轨迹，通过贝尔曼更新（使用 min 算子反向传播目标达成状态）训练一个策略条件价值网络。该网络输出 $[-1, 1]$ 的值，越接近 $-1$ 代表越接近成功。
    *   **潜在世界模型 (Latent World Model) 训练**：结合策略轨迹数据和辅助的无标签探索数据（Play Data），训练一个紧凑的 4 层 ViT 模型。该模型在 SigLIP 图像编码器提取的潜在特征空间中进行自回归前向预测。

2.  **在线部署阶段 (Deployment-time Intervention)**
    *   **实时监控**：标称策略输出动作并控制机器人。监控器实时计算当前状态的平滑活跃度价值。
    *   **触发干预**：当活跃度价值超过动态衰减的阈值（表明策略正在偏离目标）时，暂停标称策略，触发规划器。
    *   **动作搜索与执行**：规划器以标称策略的当前动作为基准，利用交叉熵方法（CEM）在数据驱动的主成分空间中采样候选动作块。世界模型并行推演这些动作块的未来状态，并用活跃度价值网络进行打分。系统执行得分最优的动作块的前几步，随后将控制权交还给标称策略。

**核心逻辑伪代码 (Python 风格)**

```python
def deployment_loop(nominal_policy, monitor_ensemble, world_model, env, max_steps):
    state = env.reset()
    
    for t in range(max_steps):
        # 1. 监控器计算当前状态的平滑活跃度价值
        liveness_value = compute_smoothed_value(monitor_ensemble, state, window_size=3)
        threshold = get_decaying_threshold(t)
        
        # 2. 判断是否需要干预
        if liveness_value > threshold:
            # 触发干预：获取标称策略的基准动作
            base_action_chunk = nominal_policy.get_action(state)
            
            # 使用 CEM 和世界模型搜索最优纠正动作
            best_action_chunk = plan_correction(
                base_action_chunk, state, world_model, monitor_ensemble
            )
            
            # 执行纠正动作块的前 h 步
            for i in range(h):
                state = env.step(best_action_chunk[i])
                t += 1
        else:
            # 3. 标称策略正常执行
            action = nominal_policy.get_action(state)
            state = env.step(action)
```

**2. TL;DR:**

### 第二模块：核心架构解释

Robota-Embed 的核心架构设计围绕“异构数据统一”与“预测性对齐”展开。其工作流可拆解为编码器架构、训练目标以及下游应用接口三个部分。

**1. 编码器架构 (VLA Encoder)**
模型基于 Cosmos3-Edge 4B 构建。为了处理不同机器人平台（如单臂、双臂、人类灵巧手）维度和频率各异的原生动作，作者为每个数据源设计了专属的动作投影器（Source-specific projectors）。
*   **Query 端：** 输入为指令（Language）、当前交互区域的 SAM3 裁剪图像（Vision）、以及同步的当前原生动作（Action）。
*   **Target 端：** 输入为指令（Language）、未来 4 秒的视频片段（Video）、以及未来 4 秒的原生动作序列（Action）。
两者共享 Transformer 主干网络，但通过不同的残差适配器（Residual Adapters）输出归一化的 Query 向量和 Target 向量。

**2. 训练目标 (Training Objectives)**
训练过程不依赖人工标注，而是通过结构化解析构建弱标签，核心损失函数包含三部分：
*   **预测性检索对齐 (Predictive Retrieval Alignment):** 双向 InfoNCE 损失，拉近 Query 与其真实的未来 Target。
*   **多模态接地与判别 (Multimodal Grounding and Discrimination):** 引入硬负样本（Hard Negatives）。通过规则挖掘出“任务相同但动作阶段不同”或“动作相同但操作对象不同”的样本作为强干扰项；同时引入模态替换（Modality Swaps）惩罚，防止模型退化为仅依赖单一模态（如只看文本）。
*   **表征正则化 (Representation Regularization):** 约束 Embedding 空间的各向同性，防止特征坍缩。

**3. 下游应用接口 (Downstream Interfaces)**
*   **Embed2ICL:** 静态检索。将检索到的未来片段直接作为视频输入（用于 DreamZero）或转化为 Context Tokens（用于 Fast-WAM），实现免训练或基于训练的策略条件化。
*   **Embed2Evolve:** 动态进化。在冻结的 GPT-6 Astra 策略下，机器人不断尝试任务，将成功或失败的轨迹存入本地记忆库。Robota-Embed 负责在每次决策时检索最相关的历史经验，作为 Prompt 喂给大模型。

**核心逻辑伪代码实现：**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class RobotaEmbed(nn.Module):
    def __init__(self, base_model, source_action_dims):
        super().__init__()
        self.transformer = base_model.transformer
        self.shared_head = base_model.projection_head
        
        # 异构动作投影器
        self.action_projectors = nn.ModuleDict({
            source: nn.Linear(dim, hidden_dim) 
            for source, dim in source_action_dims.items()
        })
        
        # Query 和 Target 的专属残差适配器
        self.query_adapter = nn.Linear(hidden_dim, hidden_dim, bias=False)
        self.target_adapter = nn.Linear(hidden_dim, hidden_dim, bias=False)
        self.temperature = nn.Parameter(torch.tensor(0.07))

    def encode_query(self, text, image, action, source):
        # 融合当前状态
        action_feat = self.action_projectors[source](action)
        fused_tokens = self.transformer(text, image, action_feat)
        
        # 时序池化与适配
        pooled = fused_tokens.mean(dim=1)
        base_embed = self.shared_head(pooled)
        query_embed = base_embed + self.query_adapter(base_embed)
        return F.normalize(query_embed, p=2, dim=-1)

    def encode_target(self, text, future_video, future_action, source):
        # 融合未来状态
        action_feat = self.action_projectors[source](future_action)
        fused_tokens = self.transformer(text, future_video, action_feat)
        
        pooled = fused_tokens.mean(dim=1)
        base_embed = self.shared_head(pooled)
        target_embed = base_embed + self.target_adapter(base_embed)
        return F.normalize(target_embed, p=2, dim=-1)

    def compute_loss(self, q, k, hard_negatives):
        # 预测性检索对齐 (InfoNCE with Hard Negatives)
        sim_matrix = torch.matmul(q, k.T) / self.temperature
        
        # 掩码逻辑：过滤掉语义兼容但非配对的样本，保留硬负样本
        valid_mask = self.build_valid_mask(hard_negatives) 
        sim_matrix = sim_matrix.masked_fill(~valid_mask, float('-inf'))
        
        labels = torch.arange(q.size(0)).to(q.device)
        loss_q2k = F.cross_entropy(sim_matrix, labels)
        loss_k2q = F.cross_entropy(sim_matrix.T, labels)
        
        return (loss_q2k + loss_k2q) / 2.0
```

### 第二模块：核心架构解释

MetaGenSim 的运行流程分为三个独立且连续的阶段：

1. 探测与打分器元学习 (Rater Network Learning)
系统首先在预定义的仿真参数空间中均匀采样，生成少量的探测数据集。随后进入双层优化循环：内层循环使用探测数据和真实训练数据更新一个代理策略网络；外层循环在真实验证集上计算该策略的验证损失，并通过元梯度（Meta-gradients）反向传播更新打分器网络。打分器的目标是为每一个仿真状态-动作对输出一个标量效用分数。

2. 参数效用分布构建 (Parameter Utility Landscape)
打分器训练完成后，对探测数据集中的所有轨迹进行打分。系统使用条件风险价值（CVaR）聚合单条轨迹的得分，将其映射回生成该轨迹的底层仿真参数。随后，利用核密度估计（KDE）和温度缩放的 Softmax 函数，在连续参数空间上构建出一个平滑的概率密度函数，高分参数区域被赋予更高的采样概率。

3. 定向生成与协同训练 (Targeted Synthesis and Co-training)
系统根据构建的概率密度函数，从高价值参数区域进行采样，调用生成式仿真器合成大规模的目标仿真数据集。最后，将这些高质量的仿真数据与少量的真实数据混合，训练最终的控制策略（如 Diffusion Policy 或 VLA）。

# 第二模块：核心架构解释

VLRLA 的核心思想是将强化学习算法蒸馏到序列模型中。其架构与实验流程分为以下四个关键步骤：

1. **视觉与语言预处理**
模型复用预训练 VLA（如 $\pi_{0.5}$）的视觉-语言编码器。输入当前的图像观察和文本指令，提取出前缀嵌入（Prefix embeddings）或键值缓存（KV Cache），作为当前时间步的环境表征。

2. **循环记忆模块（Recurrent Memory）**
为了处理跨越多个回合（Episode）的长序列交互，模型采用类似 Transformer-XL 的循环记忆机制。该模块缓存历史时间步的特征（包含状态、动作、奖励、回合终止信号），为当前决策提供历史上下文，避免了全局注意力机制带来的巨大计算开销。

3. **策略实例化（Policy Instantiations）**
框架提供两种变体以适配不同场景：
- **VLRLA-simp**：针对简单任务。冻结视觉编码器，训练一个全新的 Transformer 接收视觉特征和记忆，直接输出确定性动作。
- **VLRLA-bridge**：针对复杂任务。冻结视觉编码器和动作专家（Action Expert）。引入一个可训练的残差适配器（Residual Adapter），根据循环记忆生成残差，修改视觉编码器的 KV Cache，随后将修改后的 KV Cache 喂给冻结的动作专家（如基于流匹配的策略）生成随机动作。

4. **学习历史构建与训练**
为了让模型学会“如何进步”，必须用包含“从差到好”演变过程的数据进行训练。作者设计了三种数据收集策略：
- **仿真 RL**：保存 PPO 等强化学习算法在训练过程中的完整迭代轨迹。
- **人在回路课程（HITL）**：在真机上，逐步增加人类接管的比例（从纯模型控制到 1/3、2/3 直至完全人类控制），构建行为逐步改善的序列。
- **事后重标记（HER）**：利用成功的单次回合数据，通过修改指令和奖励标签，人工拼接出带有探索和纠错过程的跨回合序列。
训练时，使用行为克隆（MSE）或流匹配（Flow Matching）损失函数优化外挂模块的参数。

```python
        # 冻结预训练 VLA 的视觉语言编码器和动作专家
        self.vlm_encoder = pretrained_vla.encoder.eval()
        self.action_expert = pretrained_vla.action_expert.eval()
        
        # 可训练的循环记忆与残差适配器模块
        self.memory_module = RecurrentTransformer()
        self.residual_adapter = LowRankAdapter()
        
    def step(self, obs, instruction, proprioception, memory_state, last_action, last_reward, last_done):
        """
        部署时的单步执行逻辑
        """
        # 1. 提取当前时间步的 KV Cache (无梯度)
        with torch.no_grad():
            kv_cache = self.vlm_encoder.extract_kv_cache(obs, instruction)
            
        # 2. 更新循环记忆，融合历史交互信息
        # memory_state 包含跨 episode 的历史上下文
        updated_memory, memory_features = self.memory_module(
            proprioception, kv_cache, last_action, last_reward, last_done, memory_state
        )
        
        # 3. 生成残差并修改 KV Cache
        delta_kv = self.residual_adapter(memory_features)
        adapted_kv_cache = kv_cache + delta_kv
        
        # 4. 冻结的动作专家基于修改后的上下文生成动作 (如 Flow Matching 采样)
        with torch.no_grad():
            action_chunk = self.action_expert.sample_actions(proprioception, adapted_kv_cache)
            
        return action_chunk, updated_memory
```

### 第二模块：核心架构解释

本论文的核心不在于提出一个极其复杂的全新网络架构，而在于对**测试时干预（Test-time Consensus）**的证伪，以及对**训练时干预（Training-time Augmentation）**的标准化验证。

**流程一：测试时改写共识（Paraphrase Consensus / LCC）—— 被证伪的路径**
1. **指令生成**：对于原始指令 $\ell_1$，使用 LLM 生成 $K-1$ 个语义等价但句法/词汇不同的改写指令。
2. **动作查询**：冻结 VLA 模型权重，分别输入这 $K$ 个指令，获取 $K$ 个动作块（Action Chunks）。
3. **计算 Medoid（中心点）**：计算这 $K$ 个动作块两两之间的归一化距离，选择距离其他所有动作总和最小的那个动作块执行。
*结论：由于 VLA 只拟合了 $\ell_1$，其他改写指令会将模型引向错误的条件分布（引入 Bias），导致 Medoid 往往选择了一个次优动作。*

**流程二：训练时指令增强（Instruction Augmentation）—— 被验证的路径**
1. **数据重构**：保持原有专家演示（Demonstrations）的视觉和动作数据不变。
2. **指令替换**：将原始训练指令以一定概率替换为 LLM 生成的改写指令（包含词汇替换、句法重构等）。
3. **LoRA 微调**：在重构的数据集上对 VLA 模型的线性层进行低秩微调（Rank 32, LR $10^{-4}$），强制模型学习不同文本表述与同一动作轨迹的映射关系。

**核心逻辑伪代码（Python 风格）：**

```python
import numpy as np

def compute_normalized_distance(action_a, action_b, scale_stats):
    """计算两个动作块之间的归一化 L2 距离"""
    diff = (action_a - action_b) / scale_stats
    return np.linalg.norm(diff, ord=2)

def paraphrase_consensus_step(vla_policy, obs, instructions, scale_stats):
    """
    测试时改写共识（本文证明该方法无效/有害）
    instructions: 包含 1 个原始指令和 K-1 个改写指令的列表
    """
    K = len(instructions)
    action_chunks = []
    
    # 1. 获取所有指令对应的动作预测
    for instr in instructions:
        action = vla_policy.predict(obs, instr)
        action_chunks.append(action)
        
    # 2. 计算距离矩阵
    dist_matrix = np.zeros((K, K))
    for i in range(K):
        for j in range(K):
            if i != j:
                dist_matrix[i, j] = compute_normalized_distance(
                    action_chunks[i], action_chunks[j], scale_stats
                )
                
    # 3. 寻找 Medoid (距离其他动作总和最小的动作)
    total_distances = np.sum(dist_matrix, axis=1)
    medoid_idx = np.argmin(total_distances)
    
    # 论文发现：如果模型对改写指令极度不适应，这里的 medoid_idx 往往会选错
    return action_chunks[medoid_idx]

def instruction_augmentation_training(batch, llm_paraphraser, p_aug=1.0):
    """
    训练时指令增强（本文证明的有效解法）
    """
    obs, original_instr, target_action = batch
    
    # 以概率 p_aug 替换为改写指令
    if np.random.rand() < p_aug:
        train_instr = llm_paraphraser.sample_paraphrase(original_instr)
    else:
        train_instr = original_instr
        
    # 计算行为克隆损失 (BC Loss)
    predicted_action = vla_policy.forward(obs, train_instr)
    loss = mse_loss(predicted_action, target_action)
    
    return loss
```

现存端到端全身控制方案最大的痛点在于，底盘（宏观移动）、机械臂（位姿调整）与灵巧手（精细操作）在运动特性上存在极大的异构性，强行映射到一个统一的动作空间会导致策略学习困难；同时，长程任务极易产生级联误差，且现有遥操作平台缺乏集成的触觉传感来支持全身决策。本文的切入点极为巧妙：放弃暴力的全自由度端到端输出，采用“分而治之再耦合”的策略，将动作空间物理降维，再通过注意力机制在特征层重建协同。

**4. 核心机制:** 
上层利用视觉语言模型（VLM）将长程任务分解为短视距子任务以阻断时间误差传播；下层通过 COMET 网络将 29 维动作空间硬解耦为手、臂、底盘三个独立分支，并利用模块间的交叉注意力机制（Cross-Attention）实现局部动作特征的全局信息同步与协调。

**5. 关键数据:**
- **核心数据:** 在长程全身任务中，任务成功率比主流基准（Baselines）高出 20% 以上。理由：直接证明了“动作解耦+交叉注意力协调”机制在处理 29-DoF 这种超高自由度系统时的有效性，显著降低了策略崩溃的概率。
- **存疑数据:** 摘要中强调了“全掌 2D 触觉表征”实现了跨模块触觉赋能（cross-module tactile empowerment）。触觉对灵巧手（Hand）的增益是显而易见的，但其对底盘（Base）和机械臂（Arm）的独立贡献度存疑。若无严格的消融实验证明触觉信号直接改善了底盘或手臂的轨迹规划，则存在堆砌多模态传感器的嫌疑。

### 第二模块：核心架构解释

RoboSpan 的核心架构分为高层任务分解与底层模块化动作生成两个层级，具体流程如下：

1. **高层任务分解 (Hierarchical Task Decomposition):** 接收人类自然语言指令与当前视觉观测，通过 VLM 生成当前阶段的子任务目标（Sub-task Goal）。这一步将长程任务切断，限制了误差在时间维度上的累积。
2. **多模态状态编码 (Multimodal State Encoding):** 提取当前环境的视觉特征、机器人的本体感觉（Proprioception，如关节角度），以及全掌 2D 触觉表征（将分布式接触信号编码为 2D 矩阵）。
3. **动作空间解耦 (Action Space Decoupling):** 将 29-DoF 的动作空间在网络结构上强制拆分为三个独立的分支：底盘空间配置（Base）、手臂位姿调整（Arm）、手部精细操作（Hand）。
4. **COMET 策略网络 (Coordinated Modular Embodied Transformer):** 每个动作分支拥有独立的 Transformer 编码器处理自身特征。在输出动作前，通过 Inter-modular Cross-Attention 机制，让每个分支查询（Query）其他分支的特征（Key/Value），实现动态信息交换。例如，手臂分支会根据底盘的运动趋势调整自身的输出。

**核心伪代码实现逻辑：**

```python
class COMETPolicy(nn.Module):
    def __init__(self):
        super().__init__()
        # 独立特征提取器
        self.vision_encoder = VisionEncoder()
        self.tactile_encoder = TactileEncoder()
        self.proprio_encoder = ProprioEncoder()
        
        # 模块化 Transformer 分支
        self.base_branch = TransformerBlock()
        self.arm_branch = TransformerBlock()
        self.hand_branch = TransformerBlock()
        
        # 模块间交叉注意力机制
        self.cross_attn_base = CrossAttention()
        self.cross_attn_arm = CrossAttention()
        self.cross_attn_hand = CrossAttention()
        
        # 动作预测头
        self.base_head = ActionHead(d_out=2)  # 假设底盘为线速度和角速度
        self.arm_head = ActionHead(d_out=6)   # 假设手臂为6自由度
        self.hand_head = ActionHead(d_out=21) # 假设灵巧手为21自由度

    def forward(self, image, tactile, proprio, sub_task_embedding):
        # 1. 多模态特征融合
        v_feat = self.vision_encoder(image)
        t_feat = self.tactile_encoder(tactile)
        p_feat = self.proprio_encoder(proprio)
        
        # 拼接全局上下文特征
        context = concat([v_feat, t_feat, p_feat, sub_task_embedding])
        
        # 2. 独立分支特征处理
        base_feat = self.base_branch(context)
        arm_feat = self.arm_branch(context)
        hand_feat = self.hand_branch(context)
        
        # 3. 跨模块信息协调 (Inter-modular Cross-Attention)
        # 将其他模块的特征作为 Key 和 Value，当前模块特征作为 Query
        other_for_base = concat([arm_feat, hand_feat])
        coord_base = self.cross_attn_base(query=base_feat, key=other_for_base, value=other_for_base)
        
        other_for_arm = concat([base_feat, hand_feat])
        coord_arm = self.cross_attn_arm(query=arm_feat, key=other_for_arm, value=other_for_arm)
        
        other_for_hand = concat([base_feat, arm_feat])
        coord_hand = self.cross_attn_hand(query=hand_feat, key=other_for_hand, value=other_for_hand)
        
        # 4. 动作输出
        action_base = self.base_head(coord_base)
        action_arm = self.arm_head(coord_arm)
        action_hand = self.hand_head(coord_hand)
        
        return action_base, action_arm, action_hand

# 高层控制循环
def execution_loop(vlm, comet_policy, env, instruction):
    obs = env.reset()
    while not task_done:
        # VLM 阻断长程误差，生成当前子任务
        sub_task = vlm.decompose(instruction, obs.image)
        
        # COMET 生成协调的全身动作
        a_base, a_arm, a_hand = comet_policy(
            obs.image, obs.tactile, obs.proprio, sub_task
        )
        
        # 拼接为 29-DoF 动作执行
        full_action = concat([a_base, a_arm, a_hand])
        obs = env.step(full_action)
```

A2: 提出分层模块化框架（HMF）。高层使用 VLM 进行任务分解以抑制时间维度的误差传播；底层设计了 COMET 架构，将 29 维动作空间物理降维解耦为手、臂、底盘三个分支，并通过模块间的交叉注意力机制（Cross-Attention）在特征层面上实现动态信息交换与动作协调。

**Q3: 实验设计的关键支撑（或巧妙之处/数据集特点）是什么？**

**Q4: 这篇论文最显著的贡献点（Top 3）是什么？**

A4:
1. 开发了 RoboSpan 高自由度全身遥操作平台，并创新性地集成了全掌 2D 触觉表征系统。

3. 验证了 VLM 驱动的分层任务分解在抑制长程全身操作误差累积中的有效性，在物理机器人上实现了 20% 的成功率突破。

A6:
