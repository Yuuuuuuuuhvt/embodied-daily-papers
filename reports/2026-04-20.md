# 第二模块：核心架构解释

AEGIS 框架的运行流程完全集中在反向传播阶段，前向传播与模型架构保持不变。其核心流程分为三个阶段：

**阶段一：静态 Wasserstein 锚点预计算 (Static Anchor Pre-computation)**
在微调开始前，将 VQA 数据输入预训练 VLM，利用前向 Hook 提取所有 26 个 Transformer 层的隐藏状态。计算并保存每一层激活值的均值（$\mu^0$）和方差（$\sigma^0$）。这些统计量构成了代表预训练语义流形的静态几何参考点。

**阶段二：双重反向传播 (Sequential Dual-Backward)**
在训练的每一步，模型仅接收机器人动作数据。
1. 计算 Flow-Matching 动作任务的 MSE 损失，进行第一次反向传播（保留计算图），提取并缓存每个参数的**任务梯度 (Task Gradient)**。
2. 计算当前网络激活统计量（$\mu^t$, $\sigma^t$）与静态锚点之间的 Wasserstein-2 距离（通过 Bures 度量分解为均值偏移和方差失配）。将此距离作为惩罚项进行第二次反向传播，提取并缓存**最优传输梯度 (OT Gradient / Anchor Restoration Gradient)**。

**阶段三：层级 Gram-Schmidt 正交投影 (Layer-Wise Orthogonal Projection)**
以 Transformer 层为粒度（包含该层内所有注意力矩阵和 MLP 权重），计算该层任务梯度与 OT 梯度的点积。
*   如果点积 $\ge 0$，说明任务梯度不破坏锚点，直接放行。
*   如果点积 $< 0$，说明任务梯度存在将激活状态推离预训练分布的破坏性分量。此时计算投影系数，并从任务梯度中减去该破坏性分量，使最终梯度与 OT 梯度严格正交。

**核心伪代码实现**：

```python
# 预计算阶段：获取静态锚点
anchor_stats = precompute_vqa_statistics(pretrained_vlm, vqa_dataloader)

for batch in action_dataloader:
    # 1. 前向传播
    hidden_states = vlm(batch.images, batch.text)
    task_loss = flow_matching_loss(hidden_states, batch.actions)
    
    # 2. 第一次反向传播：提取任务梯度
    task_loss.backward(retain_graph=True)
    task_grads = {p: p.grad.clone() for p in vlm.parameters()}
    vlm.zero_grad()
    
    # 3. 计算 Wasserstein-2 惩罚项并进行第二次反向传播
    current_stats = compute_statistics(hidden_states)
    ot_penalty = compute_wasserstein2_bures(current_stats, anchor_stats)
    ot_penalty.backward()
    ot_grads = {p: p.grad.clone() for p in vlm.parameters()}
    vlm.zero_grad()
    
    # 4. 层级正交投影 (Layer-wise Gram-Schmidt)
    for layer in vlm.transformer_layers:
        # 展平并拼接该层所有参数的梯度
        layer_task_grad = flatten_concat([task_grads[p] for p in layer.parameters()])
        layer_ot_grad = flatten_concat([ot_grads[p] for p in layer.parameters()])
        
        # 计算点积以检测破坏性干涉
        dot_product = torch.dot(layer_task_grad, layer_ot_grad)
        
        if dot_product < 0:
            # 存在冲突，计算投影系数并执行正交相减
            ot_grad_sq_norm = torch.dot(layer_ot_grad, layer_ot_grad) + 1e-6
            alpha = dot_product / ot_grad_sq_norm
            
            for p in layer.parameters():
                # 弯曲任务梯度，使其与破坏性方向正交
                p.grad = task_grads[p] - alpha * ot_grads[p]
        else:
            # 无冲突，直接使用任务梯度
            for p in layer.parameters():
                p.grad = task_grads[p]
                
    optimizer.step()
```

        prompts = self.llm.generate_edit_prompts(context="room variation", count=num_cousins)

            # 基于 Prompt 编辑场景，生成变体
            gs_var, mesh_var = self.world_model.edit(panorama_image, prompt)
            cousins.append((gs_var, mesh_var))
        return cousins

    def build_interactive_env(self, gs_data, collision_mesh, task_type):
        # 转换为物理引擎支持的 USD 格式
        usd_scene = convert_to_usd(gs_data, collision_mesh)
        
        # LLM 决定交互资产的合理放置位置
        placement_pose = self.llm.get_placement_prior(usd_scene, task_type)
        
        # 从资产库加载具备物理属性的物体（刚体/柔性体/流体）
        interactive_asset = self.asset_library.sample(task_type)
        
        # 在物理引擎中实例化
        env = self.physics_engine.load(usd_scene)
        env.add_asset(interactive_asset, pose=placement_pose)
        return env

    def pipeline(self, real_panorama, task):
        # 1. 生成孪生与表亲场景
        twin_data = self.generate_digital_twin(real_panorama)
        cousin_data_list = self.generate_digital_cousins(real_panorama, num_cousins=10)
        
        # 2. 构建可交互仿真环境
        training_envs = []
        for gs, mesh in [twin_data] + cousin_data_list:
            env = self.build_interactive_env(gs, mesh, task)
            training_envs.append(env)
            
        return training_envs

### 第二模块：核心架构解释

VADF 框架由两个完全解耦的模块组成，分别作用于扩散策略的训练阶段和推理阶段，且不需要修改原有的扩散模型网络结构。

**训练阶段：Adaptive Loss Network (ALN)**
标准扩散模型训练采用均匀采样时间步 $k$ 和均匀采样轨迹数据。ALN 引入了重要性采样机制：
1. 维护一个可学习的时间步采样器 $\pi_\phi(k)$，通过一个 3 层 MLP 将时间步映射为采样概率。
2. 维护一个轨迹权重向量 $\mathbf{w}$。在每次迭代中，计算当前样本的 MSE 损失，将高损失（难负样本）转化为奖励信号，更新时间步采样器的参数，并增加该轨迹在后续训练中的被采样概率。

**推理阶段：Hierarchical Vision Task Segmenter (HVTS)**
标准扩散模型推理采用固定的降噪步数 $N_d$ 和动作执行视野 $N_a$。HVTS 引入了基于 VLM 的动态调度机制：
1. **离线分解**：将专家演示视频输入 VLM（Qwen2-VL），VLM 将任务分解为多个语义阶段，并为每个阶段分配特定的 $(N_a, N_d)$ 参数对。复杂阶段分配大 $N_d$ 小 $N_a$，简单阶段分配小 $N_d$ 大 $N_a$。
2. **在线调度**：在物理执行过程中，系统维护一个近期 RGB 观测的缓存。定期将观测帧输入 VLM，VLM 输出当前所处阶段的概率分布。控制器根据预测的阶段查表获取对应的 $(N_a, N_d)$，并以此参数执行当前的扩散降噪与动作输出。

        predicted_stage = self.vlm.predict_current_stage(obs_buffer)

        action_sequence = self.model.generate_actions(obs_buffer, denoising_steps=Nd)

本文虽为综述，但其梳理的具身智能基础模型（FM）应用范式可抽象为一个通用的**感知-推理-动作（Perception-Reasoning-Action）**架构。该架构展示了不同类型的基础模型如何在机器人控制闭环中协同工作。

**核心流程解析：**

2. **高层语义规划 (LLM/VLM)**：大型语言模型（LLM）接收人类自然语言指令和感知特征，利用其常识推理能力，将长程任务（Long-horizon task）分解为一系列可执行的子任务步骤（Sub-goals）。
3. **底层动作生成 (VLA/Policy)**：视觉-语言-动作模型（VLA）或特定领域的控制策略，将子任务指令与实时视觉观察对齐，直接输出低级控制动作（如关节角度、末端执行器位姿或速度指令）。
4. **知识注入与对齐**：通过预训练（海量互联网数据）、微调（机器人领域数据）或上下文学习（Prompting），实现模型能力向物理世界的迁移。

```python
class EmbodiedFoundationAgent:
    def __init__(self, vlm_model, llm_planner, vla_controller):
        # 初始化各类基础模型
        self.vlm = vlm_model           # 负责场景理解与视觉问答
        self.llm = llm_planner         # 负责长程任务拆解与逻辑推理
        self.vla = vla_controller      # 负责端到端动作输出
        self.memory = []               # 历史状态与动作记忆

    def perceive_environment(self, sensor_data):
        # VLM 提取多模态特征并生成场景描述
        scene_context = self.vlm.encode_and_describe(sensor_data.images, sensor_data.depth)
        return scene_context

    def plan_task(self, user_instruction, scene_context):
        # LLM 根据指令和场景上下文生成子任务序列
        prompt = self._build_prompt(user_instruction, scene_context, self.memory)
        sub_goals = self.llm.generate_plan(prompt)
        return sub_goals

    def execute_action(self, current_sub_goal, real_time_obs):
        # VLA 模型直接将当前目标和实时观测映射为底层控制指令
        action = self.vla.predict_action(current_sub_goal, real_time_obs)
        return action

    def step(self, user_instruction, env):
        # 完整的控制闭环
        sensor_data = env.get_observation()
        scene_context = self.perceive_environment(sensor_data)
        
        sub_goals = self.plan_task(user_instruction, scene_context)
        
        for goal in sub_goals:
            while not env.is_goal_reached(goal):
                real_time_obs = env.get_observation()
                action = self.execute_action(goal, real_time_obs)
                env.step(action)
                self.memory.append((real_time_obs, action))
```

### 第二模块：核心架构解释

ChemBot 的核心架构是一个双层闭环系统，分为高层 Agent 规划与底层 VLA 执行，并通过 MCP（Model Context Protocol）进行工具调用和状态同步。

**1. 高层 Agent 规划层 (Agent-as-Planner)**
- **场景描述器 (Scene Describer)**: 利用 Set-of-Mark (SoM) 提示词技术解析实验台图像，提取物体边界框、状态（如盖子是否打开）和物理关系。
- **双层记忆机制 (Dual-Layer Memory)**: 
  - *短期工作记忆 (Dashboard)*: 压缩当前上下文，记录实验阶段、当前试剂和待办目标，随时覆写更新。
  - *长期情景记忆 (Episodic Memory)*: 存储历史成功轨迹和实验日志，供新任务检索（RAG 机制）。
- **子任务生成器 (Subtask Generator)**: 包含 Reasoner（生成子任务）和 Reflector（验证子任务），通过链式回溯生成原子级的操作指令。

**2. 底层 VLA 执行层 (Skill-VLA)**
- **基础架构**: 采用 GR00T（基于 Diffusion Transformer, DiT）作为策略主干，输入视觉观察、语言指令和机器人本体状态，输出动作块（Action Chunk）。
- **进度预测头 (Progress Head)**: 核心创新。在 VLA 内部增加一个轻量级交叉注意力网络，将机器人状态作为 Query，VLM 提取的特征作为 Key/Value，输出一个 $[0, 1]$ 的连续标量 $p_t$，表示当前子任务的完成进度。
- **异步连续推理 (Asynchronous Inference)**: 为了防止推理延迟导致机械臂卡顿，模型预测未来状态 $s_{t+d}$ 作为边界约束，将推理与控制循环解耦，保证物理执行的平滑性。

**核心逻辑伪代码 (Python 风格)**:

```python
class ChemBot:
    def __init__(self, agent, memory, skill_vla):
        self.agent = agent
        self.memory = memory
        self.vla = skill_vla
        self.progress_threshold = 0.95 # 任务完成阈值

    def execute_experiment(self, user_instruction, env):
        # 1. 场景解析与记忆检索
        scene_graph = self.agent.scene_describer(env.get_image())
        past_experience = self.memory.retrieve_long_term(user_instruction)
        
        # 2. 任务分解 (Reasoner + Reflector)
        subtasks = self.agent.generate_subtasks(user_instruction, scene_graph, past_experience)
        
        for subtask in subtasks:
            self.memory.update_short_term_dashboard(subtask)
            
            while True:
                # 获取当前状态
                obs_img = env.get_image()
                robot_state = env.get_robot_state()
                
                # 3. Skill-VLA 推理 (包含异步未来状态预测)
                # action_chunk: 动作序列; progress: [0, 1] 的标量
                action_chunk, progress = self.vla.infer(obs_img, subtask.text, robot_state)
                
                # 4. 异步执行动作
                env.step_asynchronous(action_chunk)
                
                # 5. 闭环反馈：通过进度头判断是否切换子任务
                if progress >= self.progress_threshold:
                    self.memory.log_success(subtask)
                    break # 退出当前子任务循环，进入下一个
                    
                # 异常处理与回溯逻辑 (简化)
                if env.detect_collision() or progress_stagnant():
                    self.agent.replan(self.memory)
                    break
```
