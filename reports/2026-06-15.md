本文提出WAM4D，一种快速的4D世界动作模型。该方法在训练阶段引入轻量级的“空间寄存器标记（Spatial Register Tokens）”作为未来深度的读出机制，将预训练的几何先验知识转移到因果视频-动作Transformer中。在推理阶段，该寄存器分支被直接移除，从而实现轻量级的动作推理。此外，为防止非因果捷径，作者为混合Transformer（MoT）骨干网络设计了因果混合注意力机制，明确了视频、动作和几何标记之间的模态特定可见性。

### 2. $μ_0$: A Scalable 3D Interaction-Trace World Model

No Code Academic 🔴 No Code 🔥 Hot | Score: 4.05/5.0

> 基于3D交互轨迹的世界模型μ_0实现跨具身机器人学习。

**Affiliation**: University of Maryland, Seoul National University (Tier 3)
**Links**: [arXiv](http://arxiv.org/abs/2606.13769v1) | [PDF](https://arxiv.org/pdf/2606.13769v1) | [中文翻译](https://hjfy.top/arxiv/2606.13769)

问题：在机器人学习领域，现有的世界模型面临可扩展性挑战。像素级视频模型虽然能提供广泛的视觉先验，但消耗大量模型容量用于密集的视觉外观重建；而直接预测动作的模型则严重依赖特定具身（embodiment-specific）的动作标签，这极大地限制了模型在不同机器人形态间的大规模扩展。

方法：作者提出了$μ_0$，一个基于3D轨迹的可扩展世界模型。与预测密集像素或直接建模动作不同，$μ_0$预测显著交互点（如物体、工具、手和接触区域）的平滑3D轨迹，从而提供了一个紧凑且与具身无关的运动接口。为了从多样化的无动作视频源中进行训练，研究团队开发了TraceExtract系统，通过选择关键点、构建全局对齐的轨迹并将其与层级语言描述相关联，自动提取3D监督信号。$μ_0$的预训练结合了预训练的视觉-语言模型（VLM）骨干和模块化的轨迹专家，后者通过B样条控制点表示查询并预测未来轨迹。

结果：实验表明，$μ_0$在2D和3D轨迹预测任务上均优于现有的基线模型（包括专门的轨迹预测模型和基于Token的VLM方法）。更重要的是，由于$μ_0$是冻结且可复用的，它可以与下游特定机器人的动作专家结合。尽管预训练阶段完全没有动作监督，这种基于轨迹条件的策略在性能上足以媲美使用动作监督预训练的先进VLA模型（如$π_0$）。

意义：该研究确立了3D轨迹作为一种高度可扩展且可迁移的中间表示，为跨具身操作任务提供了一种全新的范式。它有效解耦了对特定动作数据的依赖，使得利用海量互联网视频预训练强大的物理世界模型成为可能，对具身智能的发展具有重要推动作用。

**Links**: [arXiv](http://arxiv.org/abs/2606.14574v1) | [PDF](https://arxiv.org/pdf/2606.14574v1) | [中文翻译](https://hjfy.top/arxiv/2606.14574)

1. 解决问题：现有的大语言模型（LLM）具身规划基准通常只关注计划是否能成功执行，而忽略了“潜在失败”（latent failures）。这类失败不会在执行时立即触发错误反馈，但会悄无声息地阻碍目标达成，甚至在严重情况下造成不可逆的物理损害。

2. 技术方法：作者提出了SIMMER基准，通过一个人工构建的厨房领域符号世界模型来评估LLM规划中的潜在失败。该世界模型包含77种动作、262种物体和约46800种基于真实烹饪脚本的交互。研究团队利用状态机执行器在世界模型中验证计划，检测即时前提违规、潜在危险和不可逆失败。

3. 实验结果：在6个主流LLM上的实验表明，即使是最先进的前沿模型也最多只能生成17%的无错误计划。高达56%的计划包含潜在失败，其中大部分会导致不可逆的后果。

4. 意义与价值：该研究揭示了LLM在具身智能规划中存在的隐蔽风险，并证明了通过反事实前瞻模拟（利用世界模型）进行显式状态推理可以大幅减少高达72%的潜在失败。这为构建更安全、鲁棒的基于世界模型的LLM规划器指明了方向。

2. 方法：本文提出COMET（Causal Object-centric Model for Efficient Tree search）算法，将蒙特卡洛树搜索（MCTS）引入基于槽（slot-structured）的潜在空间中。该方法结合了冻结的无监督对象中心编码器和基于Transformer的世界模型，通过新颖的动作-槽融合机制预测状态转移。此外，策略和价值头采用对象因果注意力机制，通过学习每个槽的相关性得分来调节Token交互，使决策过程能够自动聚焦于与任务相关的实体。

4. 意义：该研究为MuZero风格的潜在规划引入了显式的对象级归纳偏置，证明了结构化、对象中心的世界模型在复杂机器人操作和具身智能任务中的巨大潜力，为基于世界模型的具身决策和高效规划提供了新的范式。

### When and How Severely: Scenario-Specific Safety Envelopes for Driving VLAs

No Code 🔴 No Code | Score: 3.15/5.0 | Autonomous Driving

> 自动驾驶VLA模型需要二维场景化安全包络。

**Authors**: Abhinaw Priyadershi, Jelena Frtunikj
**Links**: [arXiv](http://arxiv.org/abs/2606.14238v1) | [PDF](https://arxiv.org/pdf/2606.14238v1) | [中文翻译](https://hjfy.top/arxiv/2606.14238)

<details>
<summary>详细分析</summary>

现有的自动驾驶视觉-语言-动作（VLA）模型在ISO 21448（SOTIF）安全认证下，通常依赖单一的聚合安全阈值，这掩盖了不同具体场景下模型失效的起始点和严重程度的差异。

作者在15,968个（视频片段，攻击）对上评估了100亿参数的开源驾驶VLA模型Alpamayo R1。通过高斯混合模型（GMM）对解释发生变化的子集进行聚类，识别出6个离散的严重程度频段，从而在同一语料库上联合分析“何时失效”和“失效严重度”。

研究发现，聚合的安全阈值（如在15% ADE预算下σ≤50）过于保守，掩盖了某些能容忍更高噪声的场景。更重要的是，噪声容忍度高的场景并不意味着严重失效（C4/C5）率低，例如STOP_SIGNAL场景的严重失效比例是LANE_KEEPING的4倍，尽管前者能容忍更大的扰动。

该研究表明，为驾驶VLA制定可部署的SOTIF运行设计域（ODD）规范不能仅依赖单一的聚合危险值，而必须采用包含“何时失效”与“失效严重度”的二维安全包络，这为大模型在自动驾驶中的安全落地提供了重要评估范式。

### CADET: Physics-Grounded Causal Auditing and Training-Free Deconfounding of End-to-End Driving Planners

No Code Academic 🔴 No Code | Score: 2.6/5.0 | Autonomous Driving

> 免训练的端到端自动驾驶规划器因果审计与去交织框架。

**Authors**: Zikun Guo
**Links**: [arXiv](http://arxiv.org/abs/2606.14438v1) | [PDF](https://arxiv.org/pdf/2606.14438v1) | [中文翻译](https://hjfy.top/arxiv/2606.14438)

<details>
<summary>详细分析</summary>

1. 问题：端到端（E2E）自动驾驶规划器通常通过模仿学习进行训练，容易产生统计捷径（因果混淆），即将与专家动作偶然共现的场景元素（如路边物体、建筑立面）与驾驶决策相关联，而非依赖真正的因果变量。这种混淆在长尾场景中会严重损害系统的可靠性，且现有的开环评估指标（如L2位移和碰撞率）难以检测出规划器是否依赖于虚假线索。

2. 方法：现有的基于因果干预训练的修复方法需要重新训练大型模型，且无法对已部署的规划器进行审计。为此，作者提出了CADET，这是一个免训练（training-free）的框架，旨在对预训练的E2E规划器进行因果审计、基准测试和修复。该方法基于物理基础，无需任何参数更新即可消除模型对虚假特征的依赖。

3. 结果：该框架成功实现了对预训练模型的直接审计与修复，能够在不重新训练的情况下，有效减少模型对非因果（虚假）线索的依赖，从而提升规划器在复杂场景下的鲁棒性与决策准确性。

4. 意义：该研究为自动驾驶系统的安全性和可解释性提供了重要工具。免训练的特性使其能够直接应用于现有的已部署模型，极大地降低了修复因果混淆的计算成本，对提升端到端自动驾驶在长尾场景中的可靠性具有重要实际意义。

**Key Terms**: End-to-End Driving, Causal Confusion, Deconfounding, Imitation Learning, Training-Free
**Scores**: Novelty 4/5 | Impact 3/5 | Reproducibility 2/5



</details>
