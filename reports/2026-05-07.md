### 第二模块：核心架构解释

InfoCoordiBridge 的整体架构分为三个解耦的层级：多智能体感知层、信息协调与抽象层（ICA）、以及场景摘要驱动的推理引擎（SSRE）。

1. **多智能体感知层 (Multi-Agent Perception)**
各传感器（BEVFusion、Camera、LiDAR、Radar）作为独立的 Agent，分别输出统一格式的结构化事实（JSON，包含 3D 框、类别、置信度等）以及一段简短的模态专属自然语言摘要。

2. **信息协调与抽象模块 (ICA)**
这是构建单一事实来源（Single Source of Truth）的核心。
- **坐标归一化与实体对齐**：将所有几何检测投影到统一的自车 BEV 坐标系中。通过计算马氏距离或欧氏距离，结合类别兼容性，使用匈牙利算法进行跨传感器的实体匹配。
- **冲突检查与属性融合**：对于匹配到同一物理实体的多个观测，连续属性（如位置、速度）采用基于置信度和不确定性的信息加权最小二乘法融合；离散属性（如类别）采用加权投票机制。
- **输出**：生成一个全局一致、带有数据溯源标签的 `SceneSummary`。

3. **场景摘要驱动的推理引擎 (SSRE)**
基于 `SceneSummary` 进行四阶段的受限 Prompt 推理：
- **SSP (结构化场景解析)**：将 JSON 转化为 LLM 更易处理的标准中间表示。
- **SRA (系统性风险评估)**：强制 LLM 优先输出按严重程度排序的风险列表。
- **VRCG (可验证推理链生成)**：生成决策和理由，强制要求所有事实声明必须引用 `SceneSummary` 中的实体 ID。
- **IVL (内省验证循环)**：将生成的草稿与 `SceneSummary` 进行比对，若发现幻觉或冲突，则触发修正循环。

**核心逻辑伪代码 (Python 风格)**:

```python
def InfoCoordiBridge_Pipeline(sensor_data, user_query):
    # 1. Multi-Agent Perception
    agent_outputs = []
    for sensor in [BEV, Camera, LiDAR, Radar]:
        facts_json, synopsis = sensor.process(sensor_data)
        agent_outputs.append((facts_json, synopsis))
    
    # 2. Information Coordination and Abstraction (ICA)
    # 坐标归一化与实体对齐
    aligned_entities = Hungarian_Match_in_BEV(agent_outputs)
    
    scene_summary = []
    for entity_group in aligned_entities:
        # 属性级冲突解决与融合
        fused_position = Information_Weighted_Fusion([e.position for e in entity_group])
        fused_class = Weighted_Voting([e.class_label for e in entity_group])
        
        scene_summary.append({
            "id": generate_global_id(),
            "position": fused_position,
            "class": fused_class,
            "provenance": [e.source for e in entity_group]
        })
        
    # 3. SceneSummary-Driven Reasoning Engine (SSRE)
    # SSP & SRA
    parsed_scene = LLM_Parse(scene_summary)
    risk_list = LLM_Assess_Risk(parsed_scene)
    
    # VRCG: Draft generation with entity anchoring
    draft_decision, draft_justification = LLM_Generate_Draft(
        user_query, parsed_scene, risk_list, require_entity_ids=True
    )
    
    # IVL: Introspective Verification Loop
    for _ in range(MAX_ITER):
        verification_result = LLM_Verify_Against_Summary(
            draft_decision, draft_justification, scene_summary
        )
        if verification_result.is_consistent:
            break
        else:
            draft_decision, draft_justification = LLM_Revise(
                draft_decision, draft_justification, verification_result.errors
            )
            
    return draft_decision, draft_justification
```
