### 第二模块：核心架构解释

GEM-4D 的核心架构分为训练阶段的**几何增强速度对齐（Geometry-Enhanced Velocity Alignment）**和推理阶段的**自适应逆动力学系统（AIDS）**。

**1. 训练阶段：双流匹配蒸馏架构**
模型采用流匹配（Flow Matching）框架。主干是一个 Video DiT，负责将噪声视频潜变量去噪为清晰视频。创新点在于引入了一个冻结的几何基础模型（Teacher）和一个辅助的 Geometry DiT。
*   **外观传输（视频分支）：** Video DiT 提取中间特征 $\mathbf{m}_t$，并预测视频潜变量的速度场。
*   **对应关系蒸馏（几何分支）：** 冻结的几何模型提取真实视频的密集几何特征 $\mathbf{g}_0$。Geometry DiT 负责预测几何特征的速度场，但**它没有任何直接的视觉输入，唯一的场景条件输入是 Video DiT 的中间特征 $\mathbf{m}_t$**。
*   **梯度回传：** 为了让 Geometry DiT 降低损失，$\mathbf{m}_t$ 必须被迫编码深度、相机位姿和物体运动信息。联合优化时，几何分支的梯度会回传给 Video DiT 的参数，实现零推理成本的特征级正则化。

**2. 推理与动作提取阶段：自适应逆动力学系统 (AIDS)**
推理时丢弃几何分支，仅用 Video DiT 生成视频。随后通过 AIDS 提取 6-DoF 动作：
*   **3D 场景接地：** 用 VLM (Qwen3.5-VL) 和 SAM-2 提取目标和末端执行器 (EE) 的掩码，结合深度图恢复初始 3D 位姿。
*   **双标准置信度门控跟踪：** 用 CoTracker3 跟踪 EE 像素。区分“渐进式漂移”（重新锚定关键点）和“灾难性崩溃”（调用 VLM 重新生成掩码）。
*   **几何-运动学姿态回退：** 当 FoundationPose 预测的 6D 姿态不可靠时，解耦平移（通过深度图质心恢复）和旋转（通过 SE(3) 球面线性插值平滑）。
*   **抓取合成：** 使用 GraspGen 预测抓取位姿，结合逆运动学 (IK) 生成最终的机器人关节轨迹。

```python
import torch.nn.functional as F

def gem_4d_training_step(video_frames, text_instruction, video_dit, geometry_dit, frozen_geo_model, alpha=1.0):
    """
    video_frames: [B, T, C, H, W]
    """
    # 1. 准备视频流匹配变量
    z0 = encode_to_latent(video_frames)
    z1 = torch.randn_like(z0)
    t = torch.rand(z0.shape[0])
    zt = t * z0 + (1 - t) * z1
    v_target_vid = z0 - z1

    # 2. 提取教师模型的几何特征 (Frozen)
    with torch.no_grad():
        g0 = frozen_geo_model(video_frames) 
    g1 = torch.randn_like(g0)
    gt = t * g0 + (1 - t) * g1
    v_target_geo = g0 - g1

    # 3. 视频分支前向传播 (Appearance)
    # m_t 是 Video DiT 的中间层特征
    m_t, v_pred_vid = video_dit(zt, t, text_instruction)
    loss_vid = F.mse_loss(v_pred_vid, v_target_vid)

    # 4. 几何分支前向传播 (Geometry Distillation)
    # 核心创新：Geometry DiT 仅以 m_t 为条件
    v_pred_geo = geometry_dit(gt, t, condition=m_t)
    loss_geo = F.mse_loss(v_pred_geo, v_target_geo)

    # 5. 联合优化
    # loss_geo 的梯度会通过 m_t 流向 video_dit 的参数
    total_loss = loss_vid + alpha * loss_geo
    
    total_loss.backward()
    return total_loss
```

### 第二模块：核心架构解释

CRONOS 并非提出一个新的生成模型，而是构建了一个严密的评估框架与数据生成流水线。其核心流程分为数据生成、反事实干预与模型评估三个阶段：

1.  **物理轨迹固定（Physics Simulation）**：在虚幻引擎中定义特定的物理事件（如碰撞、遮挡、掉落）。运行物理引擎并记录所有物体的 3D 坐标、速度、旋转等底层动力学状态轨迹。
2.  **反事实视觉渲染（Counterfactual Rendering）**：保持上述物理状态轨迹绝对不变，通过渲染引擎独立修改四个视觉变量之一：视角（相机位置）、场景（背景环境）、物体类别（3D网格模型）、物体外观（材质纹理）。由此生成一组底层物理相同但表层视觉不同的视频对。
3.  **一致性评估（Consistency Evaluation）**：将生成的反事实视频对的初始帧输入给待测的视频生成模型，获取其对未来帧的预测。通过对比模型在基准条件和干预条件下的预测误差，量化模型对视觉变化的敏感度及物理一致性。

```python
        base_video_gt = self.renderer.render(physics_trajectory, base_visual_config)

            intervened_video_gt = self.renderer.render(physics_trajectory, intervened_config)
            pairs.append((base_video_gt, intervened_video_gt, factor))

        return pairs

            base_cond = base_gt[0]
            intervened_cond = intervened_gt[0]

            # 待测模型预测未来帧
            base_pred = self.video_model.predict(base_cond)
            intervened_pred = self.video_model.predict(intervened_cond)

            # 计算预测视频与真实物理渲染视频的误差
            base_error = self.calculate_error(base_pred, base_gt)
            intervened_error = self.calculate_error(intervened_pred, intervened_gt)

            # 记录因视觉干预导致的物理预测性能衰减（一致性指标）
            results[factor] = abs(intervened_error - base_error)

        return results
```

### 第二模块：核心架构解释

JOPAT 的核心思想是将“未来状态”具象化为视觉潜变量与物理点轨迹的结合体。其模型架构与训练流程可以拆解为以下几个关键步骤：

1.  **观测条件编码 (Conditioning):** 接收过去两帧的 RGB 图像作为上下文，通过 ResNet 提取全局特征，作为后续扩散模型的条件注入（通过 AdaLN）。
2.  **多模态 Token 化 (Tokenization):**
    *   **动作 (Action):** 转化为一维 Token。
    *   **视觉潜变量 (Visual Latents):** 使用冻结的 SDXL VAE 将未来观测图像编码为潜变量 Token。
    *   **点轨迹 (Point Tracks):** 利用现成的追踪器（如 CoTracker）在当前帧撒下 25x25 的网格点，提取未来的 2D 坐标轨迹。将这些轨迹视为“时空视频”，通过 3D 卷积块化（Patchify）为轨迹 Token。
3.  **统一联合去噪 (Unified Denoising):** 将加噪后的动作 Token、视觉 Token 和轨迹 Token 拼接成一个长序列，送入共享的 DiT 网络中进行双向注意力交互，预测各自的噪声。
4.  **可见性解耦预测 (Visibility Prediction):** 轨迹点是否被遮挡或移出视野（Visibility）不参与去噪输入，而是由独立的预测头输出并计算 BCE 损失。这防止了模型在去噪时“作弊”提前知道哪些点不可见。
5.  **推理执行 (Inference):** 纯噪声输入，联合去噪采样出未来的动作、图像和轨迹。但物理执行时，**只截取动作 Token 解码输出**，图像和轨迹仅作为隐式的“未来状态约束”在自注意力中指导动作生成。

```python
import torch
import torch.nn as nn

class JOPAT(nn.Module):
    def __init__(self):
        super().__init__()
        self.obs_encoder = ResNet18() # 提取历史观测条件
        self.vae = Frozen_SDXL_VAE()  # 视觉潜变量编码
        self.track_patchifier = Conv3D_Patchifier() # 轨迹 3D 卷积块化
        self.dit_blocks = DiT_Transformer() # 核心联合去噪网络
        
        # 独立预测头
        self.action_head = nn.Linear(hidden_dim, action_dim)
        self.visual_head = nn.Linear(hidden_dim, visual_dim)
        self.track_head = nn.Linear(hidden_dim, track_dim)
        self.visibility_head = nn.Linear(hidden_dim, 1) # 预测点是否可见

    def forward(self, obs_history, noisy_actions, noisy_visuals, noisy_tracks, timesteps):
        # 1. 提取全局观测条件
        condition_feat = self.obs_encoder(obs_history)
        
        # 2. 统一 Token 序列拼接 (动作 + 视觉 + 轨迹 + 寄存器Token)
        # 此时输入的 visual 和 tracks 已经是加噪状态
        tokens = torch.cat([noisy_actions, noisy_visuals, noisy_tracks, self.register_tokens], dim=1)
        
        # 3. 联合去噪 (条件注入通过 AdaLN 实现)
        denoised_features = self.dit_blocks(tokens, condition_feat, timesteps)
        
        # 4. 拆解特征并预测噪声/可见性
        action_noise_pred = self.action_head(denoised_features[:, :action_len])
        visual_noise_pred = self.visual_head(denoised_features[:, action_len:action_len+visual_len])
        track_noise_pred = self.track_head(denoised_features[:, -track_len:])
        
        # 可见性预测（仅作为输出监督，不作为输入）
        visibility_logits = self.visibility_head(denoised_features[:, -track_len:])
        
        return action_noise_pred, visual_noise_pred, track_noise_pred, visibility_logits

# 训练损失计算逻辑
def compute_loss(model, batch):
    # 独立采样各模态的时间步和噪声
    noisy_a, noise_a, t_a = add_noise(batch.actions)
    noisy_v, noise_v, t_v = add_noise(batch.visual_latents)
    noisy_p, noise_p, t_p = add_noise(batch.tracks)
    
    # 前向传播
    pred_noise_a, pred_noise_v, pred_noise_p, pred_vis = model(
        batch.obs, noisy_a, noisy_v, noisy_p, (t_a, t_v, t_p)
    )
    
    # 联合损失：动作扩散 + 视觉扩散 + 轨迹扩散 + 可见性BCE
    loss_action = MSE(pred_noise_a, noise_a)
    loss_visual = MSE(pred_noise_v, noise_v)
    loss_track = MSE(pred_noise_p, noise_p)
    loss_visibility = BCE(pred_vis, batch.visibility_labels)
    
    return loss_action + lambda_v * loss_visual + lambda_p * loss_track + lambda_vis * loss_visibility
```

### 第二模块：核心架构解释

ChainFlow-VLA 的核心逻辑是将复杂的轨迹分布建模拆解为两个阶段：离散的因果模式生成（Chain）与连续的残差语义修正（Flow）。

1.  **感知与语义编码**：系统接收多视角图像和自车状态。一方面提取 BEV 驱动特征；另一方面，通过微调后的 VLM 处理图像和文本提示，提取高维隐藏状态（Hidden States）作为全局语义先验。
2.  **Chain（自回归轨迹生成）**：利用 BEV 特征和可学习的轨迹查询，通过自回归解码器结合自行车运动学模型（Bicycle Model），逐步推出 $K$ 个符合物理规律和时序因果的轨迹提案（Proposals）。
3.  **Flow（VLM 引导的残差扩散）**：不直接生成绝对轨迹，而是计算真实轨迹与 AR 提案之间的残差。使用 DiT（Diffusion Transformer）架构，将 VLM 的隐藏状态通过交叉注意力机制注入，指导模型在残差空间中进行去噪，从而实现带有高级语义理解的轨迹微调。
4.  **Scorer（轨迹打分）**：最后通过一个打分头对所有微调后的候选轨迹进行效用评估，输出得分最高的轨迹作为最终决策。

**核心伪代码（Python 风格）**：

```python
import torch
import torch.nn as nn

class ChainFlowVLA(nn.Module):
    def __init__(self, bev_encoder, vlm, ar_decoder, dit_refiner, scorer):
        super().__init__()
        self.bev_encoder = bev_encoder
        self.vlm = vlm
        self.ar_decoder = ar_decoder  # Chain
        self.dit_refiner = dit_refiner # Flow
        self.scorer = scorer
        
    def forward(self, images, ego_status, prompt, timesteps=4):
        # 1. Perception & Semantic Encoding
        bev_features = self.bev_encoder(images)
        vlm_hidden_states = self.vlm.extract_hidden_states(images, prompt)
        
        # 2. Chain: Autoregressive Proposal Generation
        # proposals shape: [Batch, K, Horizon, State_Dim]
        ar_proposals = self.ar_decoder(bev_features, ego_status) 
        
        # 3. Flow: VLM-Guided Residual Diffusion (Inference/Sampling)
        # Initialize pure noise in residual space
        residual_noise = torch.randn_like(ar_proposals) 
        
        for t in reversed(range(timesteps)):
            # DiT predicts noise conditioned on VLM semantics and AR proposals
            predicted_noise = self.dit_refiner(
                residual_noise, 
                t, 
                ego_status, 
                vlm_hidden_states, 
                ar_proposals
            )
            # DDIM step to denoise
            residual_noise = self.ddim_step(residual_noise, predicted_noise, t)
            
        # Reconstruct final trajectories: Proposal + Refined Residual
        refined_trajectories = ar_proposals + residual_noise
        
        # 4. Scorer: Select the best trajectory
        scores = self.scorer(refined_trajectories, bev_features)
        best_idx = torch.argmax(scores, dim=1)
        final_trajectory = refined_trajectories[torch.arange(len(best_idx)), best_idx]
        
        return final_trajectory
```

### 第二模块：核心架构解释

GEM-4D 的核心架构分为训练阶段的**几何增强速度对齐（Geometry-Enhanced Velocity Alignment）**和推理阶段的**自适应逆动力学系统（AIDS）**。

**1. 训练阶段：双流匹配蒸馏架构**
模型采用流匹配（Flow Matching）框架。主干是一个 Video DiT，负责将噪声视频潜变量去噪为清晰视频。创新点在于引入了一个冻结的几何基础模型（Teacher）和一个辅助的 Geometry DiT。
*   **外观传输（视频分支）：** Video DiT 提取中间特征 $\mathbf{m}_t$，并预测视频潜变量的速度场。
*   **对应关系蒸馏（几何分支）：** 冻结的几何模型提取真实视频的密集几何特征 $\mathbf{g}_0$。Geometry DiT 负责预测几何特征的速度场，但**它没有任何直接的视觉输入，唯一的场景条件输入是 Video DiT 的中间特征 $\mathbf{m}_t$**。
*   **梯度回传：** 为了让 Geometry DiT 降低损失，$\mathbf{m}_t$ 必须被迫编码深度、相机位姿和物体运动信息。联合优化时，几何分支的梯度会回传给 Video DiT 的参数，实现零推理成本的特征级正则化。

**2. 推理与动作提取阶段：自适应逆动力学系统 (AIDS)**
推理时丢弃几何分支，仅用 Video DiT 生成视频。随后通过 AIDS 提取 6-DoF 动作：
*   **3D 场景接地：** 用 VLM (Qwen3.5-VL) 和 SAM-2 提取目标和末端执行器 (EE) 的掩码，结合深度图恢复初始 3D 位姿。
*   **双标准置信度门控跟踪：** 用 CoTracker3 跟踪 EE 像素。区分“渐进式漂移”（重新锚定关键点）和“灾难性崩溃”（调用 VLM 重新生成掩码）。
*   **几何-运动学姿态回退：** 当 FoundationPose 预测的 6D 姿态不可靠时，解耦平移（通过深度图质心恢复）和旋转（通过 SE(3) 球面线性插值平滑）。
*   **抓取合成：** 使用 GraspGen 预测抓取位姿，结合逆运动学 (IK) 生成最终的机器人关节轨迹。

**核心逻辑伪代码 (Python 风格):**

```python
import torch
import torch.nn.functional as F

def gem_4d_training_step(video_frames, text_instruction, video_dit, geometry_dit, frozen_geo_model, alpha=1.0):
    """
    video_frames: [B, T, C, H, W]
    """
    # 1. 准备视频流匹配变量
    z0 = encode_to_latent(video_frames)
    z1 = torch.randn_like(z0)
    t = torch.rand(z0.shape[0])
    zt = t * z0 + (1 - t) * z1
    v_target_vid = z0 - z1

    # 2. 提取教师模型的几何特征 (Frozen)
    with torch.no_grad():
        g0 = frozen_geo_model(video_frames) 
    g1 = torch.randn_like(g0)
    gt = t * g0 + (1 - t) * g1
    v_target_geo = g0 - g1

    # 3. 视频分支前向传播 (Appearance)
    # m_t 是 Video DiT 的中间层特征
    m_t, v_pred_vid = video_dit(zt, t, text_instruction)
    loss_vid = F.mse_loss(v_pred_vid, v_target_vid)

    # 4. 几何分支前向传播 (Geometry Distillation)
    # 核心创新：Geometry DiT 仅以 m_t 为条件
    v_pred_geo = geometry_dit(gt, t, condition=m_t)
    loss_geo = F.mse_loss(v_pred_geo, v_target_geo)

    # 5. 联合优化
    # loss_geo 的梯度会通过 m_t 流向 video_dit 的参数
    total_loss = loss_vid + alpha * loss_geo
    
    total_loss.backward()
    return total_loss
```

### 第二模块：核心架构解释

CRONOS 并非提出一个新的生成模型，而是构建了一个严密的评估框架与数据生成流水线。其核心流程分为数据生成、反事实干预与模型评估三个阶段：

1.  **物理轨迹固定（Physics Simulation）**：在虚幻引擎中定义特定的物理事件（如碰撞、遮挡、掉落）。运行物理引擎并记录所有物体的 3D 坐标、速度、旋转等底层动力学状态轨迹。
2.  **反事实视觉渲染（Counterfactual Rendering）**：保持上述物理状态轨迹绝对不变，通过渲染引擎独立修改四个视觉变量之一：视角（相机位置）、场景（背景环境）、物体类别（3D网格模型）、物体外观（材质纹理）。由此生成一组底层物理相同但表层视觉不同的视频对。
3.  **一致性评估（Consistency Evaluation）**：将生成的反事实视频对的初始帧输入给待测的视频生成模型，获取其对未来帧的预测。通过对比模型在基准条件和干预条件下的预测误差，量化模型对视觉变化的敏感度及物理一致性。

```python
class CRONOS_Benchmark:
    def __init__(self, physics_engine, renderer, video_model):
        self.physics_engine = physics_engine
        self.renderer = renderer
        self.video_model = video_model
        # 定义四个独立干预的视觉变量
        self.factors = ['viewpoint', 'scene', 'object_category', 'object_appearance']

    def generate_counterfactual_pairs(self, event_type):
        # 1. 运行并固定底层物理动力学轨迹（确保物理规律绝对一致）
        physics_trajectory = self.physics_engine.simulate(event_type)

        # 2. 渲染基准视频
        base_visual_config = self.get_default_config()
        base_video_gt = self.renderer.render(physics_trajectory, base_visual_config)

        pairs = []
        # 3. 遍历干预因素，生成反事实视频
        for factor in self.factors:
            intervened_config = self.apply_intervention(base_visual_config, factor)
            intervened_video_gt = self.renderer.render(physics_trajectory, intervened_config)
            pairs.append((base_video_gt, intervened_video_gt, factor))

        return pairs

    def evaluate_model(self, event_type):
        pairs = self.generate_counterfactual_pairs(event_type)
        results = {}

        for base_gt, intervened_gt, factor in pairs:
            # 提取初始条件（如视频第一帧）
            base_cond = base_gt[0]
            intervened_cond = intervened_gt[0]

            # 待测模型预测未来帧
            base_pred = self.video_model.predict(base_cond)
            intervened_pred = self.video_model.predict(intervened_cond)

            # 计算预测视频与真实物理渲染视频的误差
            base_error = self.calculate_error(base_pred, base_gt)
            intervened_error = self.calculate_error(intervened_pred, intervened_gt)

            # 记录因视觉干预导致的物理预测性能衰减（一致性指标）
            results[factor] = abs(intervened_error - base_error)

        return results
```

### 第二模块：核心架构解释

JOPAT 的核心思想是将“未来状态”具象化为视觉潜变量与物理点轨迹的结合体。其模型架构与训练流程可以拆解为以下几个关键步骤：

1.  **观测条件编码 (Conditioning):** 接收过去两帧的 RGB 图像作为上下文，通过 ResNet 提取全局特征，作为后续扩散模型的条件注入（通过 AdaLN）。
2.  **多模态 Token 化 (Tokenization):**
    *   **动作 (Action):** 转化为一维 Token。
    *   **视觉潜变量 (Visual Latents):** 使用冻结的 SDXL VAE 将未来观测图像编码为潜变量 Token。
    *   **点轨迹 (Point Tracks):** 利用现成的追踪器（如 CoTracker）在当前帧撒下 25x25 的网格点，提取未来的 2D 坐标轨迹。将这些轨迹视为“时空视频”，通过 3D 卷积块化（Patchify）为轨迹 Token。
3.  **统一联合去噪 (Unified Denoising):** 将加噪后的动作 Token、视觉 Token 和轨迹 Token 拼接成一个长序列，送入共享的 DiT 网络中进行双向注意力交互，预测各自的噪声。
4.  **可见性解耦预测 (Visibility Prediction):** 轨迹点是否被遮挡或移出视野（Visibility）不参与去噪输入，而是由独立的预测头输出并计算 BCE 损失。这防止了模型在去噪时“作弊”提前知道哪些点不可见。
5.  **推理执行 (Inference):** 纯噪声输入，联合去噪采样出未来的动作、图像和轨迹。但物理执行时，**只截取动作 Token 解码输出**，图像和轨迹仅作为隐式的“未来状态约束”在自注意力中指导动作生成。

```python
        self.track_head = nn.Linear(hidden_dim, track_dim)
        self.visibility_head = nn.Linear(hidden_dim, 1) # 预测点是否可见

    def forward(self, obs_history, noisy_actions, noisy_visuals, noisy_tracks, timesteps):
        # 1. 提取全局观测条件
        condition_feat = self.obs_encoder(obs_history)
        
        # 2. 统一 Token 序列拼接 (动作 + 视觉 + 轨迹 + 寄存器Token)
        # 此时输入的 visual 和 tracks 已经是加噪状态
        tokens = torch.cat([noisy_actions, noisy_visuals, noisy_tracks, self.register_tokens], dim=1)
        
        # 3. 联合去噪 (条件注入通过 AdaLN 实现)
        denoised_features = self.dit_blocks(tokens, condition_feat, timesteps)
        
        # 4. 拆解特征并预测噪声/可见性
        action_noise_pred = self.action_head(denoised_features[:, :action_len])
        visual_noise_pred = self.visual_head(denoised_features[:, action_len:action_len+visual_len])
        track_noise_pred = self.track_head(denoised_features[:, -track_len:])
        
        # 可见性预测（仅作为输出监督，不作为输入）
        visibility_logits = self.visibility_head(denoised_features[:, -track_len:])
        
        return action_noise_pred, visual_noise_pred, track_noise_pred, visibility_logits

# 训练损失计算逻辑
def compute_loss(model, batch):
    # 独立采样各模态的时间步和噪声
    noisy_a, noise_a, t_a = add_noise(batch.actions)
    noisy_v, noise_v, t_v = add_noise(batch.visual_latents)
    noisy_p, noise_p, t_p = add_noise(batch.tracks)
    
    # 前向传播
    pred_noise_a, pred_noise_v, pred_noise_p, pred_vis = model(
        batch.obs, noisy_a, noisy_v, noisy_p, (t_a, t_v, t_p)
    )
    
    # 联合损失：动作扩散 + 视觉扩散 + 轨迹扩散 + 可见性BCE
    loss_action = MSE(pred_noise_a, noise_a)
    loss_visual = MSE(pred_noise_v, noise_v)
    loss_track = MSE(pred_noise_p, noise_p)
    loss_visibility = BCE(pred_vis, batch.visibility_labels)
    
    return loss_action + lambda_v * loss_visual + lambda_p * loss_track + lambda_vis * loss_visibility
```

### 第二模块：核心架构解释

ChainFlow-VLA 的核心逻辑是将复杂的轨迹分布建模拆解为两个阶段：离散的因果模式生成（Chain）与连续的残差语义修正（Flow）。

1.  **感知与语义编码**：系统接收多视角图像和自车状态。一方面提取 BEV 驱动特征；另一方面，通过微调后的 VLM 处理图像和文本提示，提取高维隐藏状态（Hidden States）作为全局语义先验。
2.  **Chain（自回归轨迹生成）**：利用 BEV 特征和可学习的轨迹查询，通过自回归解码器结合自行车运动学模型（Bicycle Model），逐步推出 $K$ 个符合物理规律和时序因果的轨迹提案（Proposals）。
3.  **Flow（VLM 引导的残差扩散）**：不直接生成绝对轨迹，而是计算真实轨迹与 AR 提案之间的残差。使用 DiT（Diffusion Transformer）架构，将 VLM 的隐藏状态通过交叉注意力机制注入，指导模型在残差空间中进行去噪，从而实现带有高级语义理解的轨迹微调。
4.  **Scorer（轨迹打分）**：最后通过一个打分头对所有微调后的候选轨迹进行效用评估，输出得分最高的轨迹作为最终决策。

**核心伪代码（Python 风格）**：

```python
import torch
import torch.nn as nn

class ChainFlowVLA(nn.Module):
    def __init__(self, bev_encoder, vlm, ar_decoder, dit_refiner, scorer):
        super().__init__()
        self.bev_encoder = bev_encoder
        self.vlm = vlm
        self.ar_decoder = ar_decoder  # Chain
        self.dit_refiner = dit_refiner # Flow
        self.scorer = scorer
        
    def forward(self, images, ego_status, prompt, timesteps=4):
        # 1. Perception & Semantic Encoding
        bev_features = self.bev_encoder(images)
        vlm_hidden_states = self.vlm.extract_hidden_states(images, prompt)
        
        # 2. Chain: Autoregressive Proposal Generation
        # proposals shape: [Batch, K, Horizon, State_Dim]
        ar_proposals = self.ar_decoder(bev_features, ego_status) 
        
        # 3. Flow: VLM-Guided Residual Diffusion (Inference/Sampling)
        # Initialize pure noise in residual space
        residual_noise = torch.randn_like(ar_proposals) 
        
        for t in reversed(range(timesteps)):
            # DiT predicts noise conditioned on VLM semantics and AR proposals
            predicted_noise = self.dit_refiner(
                residual_noise, 
                t, 
                ego_status, 
                vlm_hidden_states, 
                ar_proposals
            )
            # DDIM step to denoise
            residual_noise = self.ddim_step(residual_noise, predicted_noise, t)
            
        # Reconstruct final trajectories: Proposal + Refined Residual
        refined_trajectories = ar_proposals + residual_noise
        
        # 4. Scorer: Select the best trajectory
        scores = self.scorer(refined_trajectories, bev_features)
        best_idx = torch.argmax(scores, dim=1)
        final_trajectory = refined_trajectories[torch.arange(len(best_idx)), best_idx]
        
        return final_trajectory
```

# 第二模块：核心架构解释

**模型架构与实验流程详细解释**：

1.  **数据预处理与高斯初始化**：首先从多视角视频中提取 2D 分割掩码。利用 2D 点追踪和 ICP（迭代最近点）算法生成带有噪声的 3D 伪标签轨迹。对单帧图像进行 3DGS 优化，生成静态的 3D 高斯球集合，作为动力学模型的初始输入。
2.  **特征构建与对象 ID 分配 (Gaussian Integration)**：将每个高斯球的历史速度和高度拼接为输入特征。由于原始高斯球缺乏物理实体概念，模型计算每个高斯球对各个 2D 分割掩码的渲染贡献度（Rendering Contribution），并通过多视角多数投票机制（Majority Voting）为每个高斯球分配离散的 Object ID。
3.  **动力学预测 (Convolution-based Interaction Modeling)**：将带有特征和 ID 的高斯球输入基于 U-Net 架构的网络。网络内部交替执行两种卷积：`Object PointConv`（仅在同一物体内部的相邻高斯球间传递信息，模拟刚体内部力传导）和 `Relational PointConv`（在不同物体的相邻高斯球间传递信息，模拟碰撞交互）。
4.  **状态更新与联合监督**：网络输出下一帧高斯球的速度和旋转变化，更新高斯球状态。将更新后的高斯球送入可微渲染器生成预测图像，计算与真实图像的渲染损失（L1 Loss），同时结合预处理得到的伪标签计算位置回归损失（Huber Loss），完成端到端自回归训练。

### 第二模块：核心架构解释

SCOPE 的核心逻辑是将动作注入从“空间广播”转变为“局部自适应提取”。模型基于预训练的视频 DiT（Wan2.2-TI2V-5B），在每个 Transformer Block 的交叉注意力层和 FFN 之间插入零初始化的 SCOPE 模块。

处理流程如下：
1. **空间重塑 (Spatial Reshape)**：将标准的时空 Token 序列 $(B, f \times h \times w, D)$ 重塑为逐像素的独立时间序列 $(B \cdot h \cdot w, f, D)$。这意味着每个空间位置现在拥有自己独立的时间演变特征。
2. **离散动作通路 (Discrete Pathway)**：处理开火、换弹等瞬时动作。将离散动作编码后作为 Key 和 Value，将逐像素视觉特征作为 Query 进行交叉注意力计算。由于 Query 来自局部视觉内容，武器区域的像素会强烈关注动作信号，而背景像素的注意力权重趋近于零，从而隐式实现了 In-scope 隔离。
3. **连续动作通路 (Continuous Pathway)**：处理视角旋转、移动等平滑运动。提取当前帧前后的连续动作窗口，将其与逐像素特征拼接，通过 MLP 融合后，进行带有旋转位置编码（RoPE）的时间自注意力计算，专门负责 Out-of-scope 的背景光流与视差生成。
4. **残差融合 (Residual Fusion)**：将两路输出相加并作为残差注入原特征，重塑回标准 Token 形状后进入 FFN。

核心逻辑伪代码（Python 风格）：

```python
import torch
import torch.nn as nn

class SCOPEModule(nn.Module):
    def __init__(self, hidden_dim, action_dim_cont, action_dim_disc):
        super().__init__()
        # 连续动作通路
        self.mlp_fuse = nn.Linear(hidden_dim + action_dim_cont, hidden_dim)
        self.temporal_self_attn = TemporalSelfAttention(hidden_dim)
        
        # 离散动作通路
        self.mlp_embed = nn.Linear(action_dim_disc, hidden_dim)
        self.discrete_cross_attn = CrossAttention(hidden_dim)
        
        # 零初始化输出投影，确保初始状态等价于原版 DiT
        self.zero_proj_cont = nn.Linear(hidden_dim, hidden_dim)
        self.zero_proj_disc = nn.Linear(hidden_dim, hidden_dim)
        nn.init.zeros_(self.zero_proj_cont.weight)
        nn.init.zeros_(self.zero_proj_disc.weight)

    def forward(self, x, a_cont, a_disc, B, f, h, w):
        """
        x: 视觉特征 [B, f*h*w, D]
        a_cont: 连续动作窗口特征 [B, f, action_dim_cont]
        a_disc: 离散动作特征 [B, f, action_dim_disc]
        """
        D = x.shape[-1]
        
        # 1. 空间重塑: [B, f*h*w, D] -> [B*h*w, f, D]
        # 将空间维度合并到 Batch 维度，暴露时间维度 f
        x_reshaped = x.view(B, f, h*w, D).permute(0, 2, 1, 3).reshape(B*h*w, f, D)
        
        # 扩展动作特征以匹配空间像素数量
        a_cont_expanded = a_cont.unsqueeze(1).expand(B, h*w, f, -1).reshape(B*h*w, f, -1)
        a_disc_expanded = a_disc.unsqueeze(1).expand(B, h*w, f, -1).reshape(B*h*w, f, -1)

        # 2. 连续动作通路 (Out-of-scope)
        # 拼接视觉特征与连续动作，通过 MLP 和时间自注意力
        x_cont = torch.cat([x_reshaped, a_cont_expanded], dim=-1)
        x_cont = self.mlp_fuse(x_cont)
        delta_x_cont = self.temporal_self_attn(x_cont)
        delta_x_cont = self.zero_proj_cont(delta_x_cont)

        # 3. 离散动作通路 (In-scope)
        # 视觉特征作为 Query，离散动作作为 Key/Value
        k_v_disc = self.mlp_embed(a_disc_expanded)
        delta_x_disc = self.discrete_cross_attn(query=x_reshaped, key=k_v_disc, value=k_v_disc)
        delta_x_disc = self.zero_proj_disc(delta_x_disc)

        # 4. 残差融合与形状还原
        x_out = x_reshaped + delta_x_cont + delta_x_disc
        
        # [B*h*w, f, D] -> [B, f*h*w, D]
        x_out = x_out.view(B, h*w, f, D).permute(0, 2, 1, 3).reshape(B, f*h*w, D)
        
        return x_out
```

### 第二模块：核心架构解释

Agentic-VLA 的核心架构是一个闭环的在线强化学习微调系统，主要由三个模块构成，并采用 GRPO 算法进行策略优化：

1. **经验记忆（Experience Memory, EM）**：在遇到新任务时，系统首先通过冻结的文本编码器计算任务指令的嵌入向量，从记忆库中检索 Top-k 个最相似的历史任务。通过对这些历史任务的策略权重进行带温度系数的软插值，为当前 VLA 模型提供热启动初始化，避免从头学习。
2. **语言引导探索（Language-Guided Exploration, LGE）**：在环境交互的探索阶段，系统调用预训练的 VLM（如 Qwen3-VL）作为评论家。VLM 观察当前图像和任务指令，输出具体的动作修正建议（如“从左侧靠近”）。该建议与原指令拼接后输入 VLA，引导模型在有希望的区域采样，且建议的触发频率会随着奖励的提升而指数衰减。
3. **自适应奖励合成（Adaptive Reward Synthesis, ARS）**：利用 LLM 将长指令分解为多个子目标。系统维护每个子目标的指数移动平均（EMA）成功率。成功率越低的子目标，其分配到的奖励权重越高。结合视觉-语言-动作评论家模型（VLAC）输出的密集进度分数，系统动态计算出当前轨迹的最终奖励，形成自动课程学习。

**核心逻辑伪代码**：

```python
def train_agentic_vla(task_instruction, base_vla, memory_bank, llm, vlm, vlac):
    # 1. 经验记忆：权重热启动
    task_emb = text_encoder(task_instruction)
    top_k_tasks = memory_bank.retrieve_top_k(task_emb, k=3)
    interpolated_weights = compute_soft_weight_interpolation(top_k_tasks, temperature=0.1)
    base_vla.load_weights(interpolated_weights)
    
    # 2. 自适应奖励合成：任务分解与能力追踪初始化
    sub_goals = llm.decompose_task(task_instruction)
    capability_scores = {goal: 0.0 for goal in sub_goals} # 追踪每个子目标的成功率
    
    for iteration in range(MAX_ITERS):
        trajectories = []
        
        # 3. 语言引导探索：数据收集
        for _ in range(BATCH_SIZE):
            if should_trigger_exploration(current_reward_ema):
                vlm_suggestion = vlm.generate_hint(current_image, task_instruction)
                prompt = task_instruction + " " + vlm_suggestion
            else:
                prompt = task_instruction
                
            trajectory = base_vla.rollout(prompt)
            trajectories.append(trajectory)
            
        # 计算自适应奖励
        rewards = []
        for traj in trajectories:
            total_reward = 0
            for goal in sub_goals:
                # 核心：能力越弱（score越低），该子目标的奖励权重越高
                weight = 1.0 - capability_scores[goal] 
                dense_progress = vlac.estimate_progress(traj, goal)
                total_reward += weight * dense_progress
            rewards.append(total_reward)
            
        # 策略优化 (GRPO)
        base_vla.update_policy_grpo(trajectories, rewards)
        
        # 更新能力追踪器 (EMA)
        for goal in sub_goals:
            success_flag = check_subgoal_success(trajectories, goal)
            capability_scores[goal] = 0.9 * capability_scores[goal] + 0.1 * success_flag
            
    # 训练结束，将新任务权重写入记忆库
    memory_bank.add(task_emb, base_vla.get_weights())
    return base_vla
```

先在离线状态下使用大语言模型将长任务视频切分为“动词-名词”的短技能片段并打上标签；在训练时，训练一个小型的技能预测网络，根据当前的图像和指令预测当前处于哪个技能阶段；最后，通过对比学习强制系统将语义上相似的技能分配给同一批固定的专家网络去处理，且在同一个动作块（Action Chunk）内保持路由分配的一致性。

### 第二模块：核心架构解释

SMoDP 的架构分为离线数据处理和在线策略训练两个主要阶段。

**1. 离线语义技能抽象 (Offline Semantic Skill Abstraction)**
使用现成的 VLM（如 Qwen3-VL）处理原始演示视频。输入视频和任务指令，VLM 输出时间边界和对应的开放词汇技能描述（严格限制为“动词-名词”格式，如 `pick up, red cup`）。这一步将无结构的轨迹转化为带有语义标签的数据集，仅用于训练阶段提供监督信号。

**2. 轻量级技能预测器 (Lightweight Skill Predictor)**
在策略网络内部，使用一个单层交叉注意力机制。它接收当前的视觉特征和语言指令特征作为上下文，通过一个可学习的查询向量（Query）提取出当前的技能嵌入向量（Skill Embedding）。这个向量被映射到与 VLM 文本编码器相同的特征空间中。

**3. 双重语义对比对齐 (Dual Semantic Contrastive Alignment)**
为了让路由分配具有语义意义，设计了两个损失函数：
*   **跨模态对比学习 (InterCL):** 将技能预测器输出的向量与 VLM 生成的真实文本标签向量进行对齐，确保预测器学到正确的语义。
*   **模态内对比学习 (IntraCL):** 计算不同技能文本之间的相似度，并强制 MoE 路由器在面对相似的技能时，输出相似的专家分配概率分布。

**4. 块一致性技能路由 (Chunk-Consistent Skill-Based Routing)**
在扩散模型的 Transformer 架构中，将预测出的技能嵌入向量输入到 MoE 路由器中。为了保证动作的连贯性，同一个动作块（Action Chunk）内的所有时间步强制使用同一个技能向量进行路由，从而选择相同的专家网络进行去噪计算。

**核心逻辑伪代码 (Python 风格):**

```python
def forward_smodp(obs_tokens, goal_tokens, noisy_action_chunk, text_labels):
    # 1. 拼接上下文
    context = concat(obs_tokens, goal_tokens)
    
    # 2. 轻量级技能预测器
    # 使用可学习的 query 从上下文中提取技能特征
    skill_feature = cross_attention(query=learnable_skill_query, key=context, value=context)
    pred_skill_emb = feed_forward(skill_feature) # 映射到文本特征空间
    
    # 3. 跨模态对比学习 (InterCL)
    # text_labels 是离线 VLM 生成的 "动词-名词" 标签
    target_text_emb = frozen_text_encoder(text_labels)
    loss_intercl = contrastive_loss(pred_skill_emb, target_text_emb)
    
    # 4. 准备扩散 Transformer 的输入
    transformer_input = concat(context, noisy_action_chunk)
    
    # 5. 块一致性 MoE 路由
    # 将预测的技能嵌入作为路由器的输入，并广播到整个动作块
    router_logits = moe_router(pred_skill_emb) 
    expert_weights = top_k_softmax(router_logits, k=2)
    
    # 6. 模态内对比学习 (IntraCL)
    # 强制语义相似的技能产生相似的 router_logits
    semantic_similarity_matrix = compute_similarity(target_text_emb)
    loss_intracl = routing_consistency_loss(router_logits, semantic_similarity_matrix)
    
    # 7. 混合专家计算
    expert_outputs = sum([weight * expert(transformer_input) for weight, expert in zip(expert_weights, experts)])
    
    # 8. 预测扩散噪声
    predicted_noise = final_projection(expert_outputs)
    
    # 9. 总损失
    loss_diff = mse_loss(predicted_noise, true_noise)
    total_loss = loss_diff + lambda_1 * loss_intercl + lambda_2 * loss_intracl + load_balance_loss
    
    return total_loss
```

### 第二模块：核心架构解释

GPLD 的核心逻辑是不改变 DreamerV3 的主体架构，而是在其损失函数中加入一个针对后验概率映射的局部平滑正则项。完整流程如下：

1. **后验概率提取**：在世界模型训练阶段，给定当前步的确定性隐状态 $h_t$ 和编码后的观测特征 $e_t$，拼接得到后验输入 $u_t = [h_t, e_t]$。模型输出后验分布 $q_\phi(z_t | h_t, e_t)$，该分布在 DreamerV3 中被表示为 $K$ 个分类变量（每个变量 $C$ 个类别）的概率表。
2. **Hutchinson 雅可比估计**：直接计算概率表对输入 $u_t$ 的完整雅可比矩阵开销极大。GPLD 采用 Hutchinson 迹估计器，通过向输出空间注入 Rademacher 噪声（随机的 +1 或 -1），将雅可比矩阵的 Frobenius 范数计算转化为高效的向量-雅可比乘积（Vector-Jacobian Product, VJP）。
3. **时间衰减惩罚**：计算出的梯度惩罚项被加入到总损失中。由于训练初期模型极度不准确，强平滑约束有助于稳定学习；而后期模型拟合度提高，过强的平滑会限制表达能力。因此，GPLD 采用随优化步数平方根衰减的动态惩罚系数。

**核心伪代码实现 (Python 风格)**:

```python
import torch

def compute_gpld_loss(posterior_input, posterior_model, K, C):
    """
    计算 GPLD 梯度惩罚损失
    posterior_input: 拼接后的隐状态与观测特征 [batch_size, hidden_dim]
    posterior_model: 输出后验概率分布的网络
    K: 离散潜变量的数量
    C: 每个潜变量的类别数
    """
    # 允许对输入求导
    posterior_input.requires_grad_(True)
    
    # 获取逐行概率分布: [batch_size, K, C]
    q_probs = posterior_model(posterior_input)
    
    gpld_loss = 0.0
    
    # 遍历 K 个分类变量
    for i in range(K):
        q_i = q_probs[:, i, :] # 取出第 i 个变量的概率分布 [batch_size, C]
        
        # 采样 Rademacher 噪声 epsilon ~ {-1, 1}^C
        epsilon = torch.randint(0, 2, size=q_i.shape, device=q_i.device).float() * 2 - 1
        
        # 计算噪声与概率分布的内积 <epsilon, q_i>
        dot_product = torch.sum(epsilon * q_i, dim=-1)
        
        # 计算内积对输入的梯度 (Vector-Jacobian Product)
        gradients = torch.autograd.grad(
            outputs=dot_product,
            inputs=posterior_input,
            grad_outputs=torch.ones_like(dot_product),
            create_graph=True,
            retain_graph=True
        )[0]
        
        # 累加梯度的 L2 范数平方
        gpld_loss += torch.sum(gradients ** 2, dim=-1).mean()
        
    # 返回平均雅可比惩罚
    return gpld_loss / K

# 在主训练循环中集成
# total_loss = dreamer_loss + lambda_t * compute_gpld_loss(...)
```

### 第二模块：核心架构解释

$\pi_0$-EqM 的核心在于保持 $\pi_0$ 的上游视觉-语言表征栈（VLM）完全不变，仅将其动作解码器替换为 EqM 解码器。其运行流程可拆解为以下三个阶段：

1.  **无时间向量场训练**：给定专家演示动作块 $A$ 和结构化噪声 $\epsilon$，模型学习一个无时间依赖的条件向量场 $f_\theta(A; c_t)$。训练目标是让该向量场拟合指向目标动作的残差向量，使得真实数据流形成为该向量场的稳定平衡点集合。
2.  **结构化热启动（Structural Warm-Start）**：在闭环控制的推理阶段，当前时间步 $t$ 的初始动作猜测 $A_t^{(0)}$ 不再是纯随机噪声。模型截取上一时间步 $t-1$ 输出动作块的后半段，作为当前初始化的前半段，仅对后半段填充随机噪声。这利用了控制周期的时序一致性，缩短了收敛距离。
3.  **自适应深度推理（Adaptive Inference Depth）**：使用 Nesterov 加速求解器迭代更新动作。在每次迭代中，计算当前前瞻点（lookahead point）的归一化残差。当残差低于设定的阈值 $\tau$，或达到最大迭代次数时，提前终止迭代并输出动作。

**核心伪代码（Python 风格）**：

```python
import numpy as np

def generate_action_chunk(c_t, A_prev_out, f_theta, H, d, max_steps, tau, mu, eta):
    """
    c_t: 多模态条件 (视觉, 语言, 状态)
    A_prev_out: 上一控制周期输出的动作块 (shape: H x d)
    f_theta: 训练好的 EqM 条件向量场网络
    tau: 提前停止的残差阈值
    mu: 动量因子
    eta: 步长
    """
    
    # 1. 结构化热启动 (Structural Warm-Start)
    if A_prev_out is not None:
        A_copy = A_prev_out[H//2:]          # 复用上一帧动作的后半段
        noise = np.random.randn(H//2, d)    # 剩余部分采样新噪声
        A_k = np.concatenate([A_copy, noise], axis=0)
    else:
        A_k = np.random.randn(H, d)
        
    A_k_minus_1 = A_k.copy()
    
    # 2. 迭代求解平衡点 (Equilibrium Solving via Nesterov)
    for k in range(max_steps):
        # 计算前瞻点 (Lookahead point)
        A_tilde = A_k + mu * (A_k - A_k_minus_1)
        
        # 评估向量场
        vector_field = f_theta(A_tilde, c_t)
        
        # 3. 自适应停止 (Adaptive Stopping)
        # 计算归一化残差
        residual = np.linalg.norm(vector_field) / np.sqrt(H * d)
        if residual <= tau:
            break  # 达到残差阈值，提前停止
            
        # 梯度下降更新
        A_k_minus_1 = A_k.copy()
        A_k = A_tilde - eta * vector_field
        
    return A_k # 返回可执行的动作块
```

### 第二模块：核心架构解释

WMAttack 的核心架构是一个双阶段的有限预算搜索优化流程，旨在平衡探索（Exploration）与利用（Exploitation）。

**阶段一：表征引导攻击检索 (RGAR - Representation-Guided Attack Retrieval)**
面对全新的任务-智能体组合，系统首先提取其在干净环境下的轨迹数据，构建一个紧凑的潜在行为摘要（Latent Behavioral Summary）。随后，在历史攻击记忆库中计算表征相似度，检索出在相似任务中表现优异的攻击配置（如扰动预算、优化步数、攻击族类），以此构建初始的提议分布，解决冷启动问题。

**阶段二：自校正攻击搜索 (SCAS - Self-Correcting Attack Search)**
在获得热启动后，系统进入迭代搜索。每一轮采样一批攻击配置，并在闭环环境中进行评估。评估采用 Scout-Confirm（侦察-确认）协议：先用极少量的 rollout 快速估算效用，仅对高潜力配置追加完整评估。评估产生的多维反馈（奖励下降、动作不稳定性、运行时间、方差）被聚合为标量化效用得分，系统据此动态更新提议分布，将搜索概率质量向高破坏力区域转移。

```python
def WMAttack_Search(task_env, victim_model, memory_bank, budget):
    # Stage 1: RGAR (Representation-Guided Attack Retrieval)
    # 提取当前任务的潜在行为表征
    task_repr = extract_latent_behavior(task_env, victim_model)
    
    # 检索 Top-K 相似历史任务并初始化提议分布 (Warm Start)
    similar_tasks = memory_bank.retrieve_top_k(task_repr)
    proposal_dist = initialize_distribution(similar_tasks)
    
    search_history = []
    
    # Stage 2: SCAS (Self-Correcting Attack Search)
    for step in range(budget):
        # 从当前提议分布中采样候选攻击配置
        candidates = proposal_dist.sample_batch()
        
        round_feedback = []
        for config in candidates:
            # Scout-Confirm 协议：闭环 Rollout 评估
            # 包含：奖励下降(D), 动作翻转(F), 耗时(T), 方差(V)
            utility, feedback_signals = evaluate_closed_loop(task_env, victim_model, config)
            round_feedback.append({
                'config': config, 
                'utility': utility, 
                'signals': feedback_signals
            })
            
        search_history.extend(round_feedback)
        
        # 利用多维反馈更新提议分布，将概率质量推向高收益区域
        proposal_dist.update_distribution(round_feedback)
        
    # 返回预算耗尽后效用最高的攻击配置
    best_attack = max(search_history, key=lambda x: x['utility'])
    return best_attack
```

### 第二模块：核心架构解释

ComPose 的整体架构分为三个并行且相互交织的阶段：独立线索提取、自适应权重预测、以及位姿融合与修正。

1.  **独立线索提取 (Feature & Cue Extraction)**
    *   **物体几何线索:** 利用 SAM3 提取目标物体的掩码，结合 3D 基础模型（如 Flow3R）生成稠密点云。对相邻两帧的可见点云执行迭代最近点（ICP）算法，计算出基于物体的相对旋转 $R_{obj}$。
    *   **手部运动线索:** 利用手部姿态估计器（如 WiLoR）提取 3D 手部关节坐标。
2.  **自适应权重预测 (Adaptive Weight Prediction)**
    *   将 DINOv2 提取的图像特征与手部关节 Token 输入到时空 Transformer 网络中。
    *   网络输出两个关键参数：一是关节权重 $w$（赋予稳定接触的关节高权重，抑制无关的手指滑动）；二是融合系数 $\alpha$（评估当前帧手和物体线索的相对可靠性）。
3.  **位姿融合与修正 (Pose Fusion & Refinement)**
    *   **旋转融合:** 利用预测的权重 $w$ 对手部关节执行加权 Procrustes 对齐，得到基于手的相对旋转 $R_{hand}$。随后利用 $\alpha$ 在 $R_{obj}$ 和 $R_{hand}$ 之间进行球面线性插值（SLERP）。
    *   **平移修正:** 以可见点云的质心作为初始平移量，网络额外预测一个残差 $\delta$ 来补偿因遮挡导致的质心偏移。

**核心逻辑伪代码 (Python-style):**

```python
import numpy as np
from scipy.spatial.transform import Rotation as R
from scipy.spatial.transform import Slerp

def compose_tracking_step(frame_i, frame_j, model):
    # 1. 提取基础特征
    # P: 物体掩码点云, J: 3D手部关节, img_feat: DINOv2图像特征
    P_i, P_j = extract_masked_pointcloud(frame_i, frame_j)
    J_i, J_j = extract_hand_joints(frame_i, frame_j)
    img_feat = extract_image_features(frame_i, frame_j)
    
    # 2. 计算物体线索 (ICP)
    R_obj = compute_icp_rotation(P_i, P_j)
    
    # 3. 网络预测自适应参数
    # alpha: 融合系数 [0, 1], w: 关节权重 (21,), delta: 平移残差 (3,)
    alpha, w, delta = model.predict_parameters(img_feat, J_i, J_j)
    
    # 4. 计算手部线索 (加权 Procrustes 对齐)
    # 仅高度信任与物体稳定接触的关节
    R_hand = weighted_procrustes_alignment(J_i, J_j, weights=w)
    
    # 5. 旋转融合 (球面线性插值 SLERP)
    # 将旋转矩阵转为四元数进行插值
    q_obj = R.from_matrix(R_obj)
    q_hand = R.from_matrix(R_hand)
    
    # 根据 alpha 决定信任手还是信任物体
    key_rots = R.from_quat([q_obj.as_quat(), q_hand.as_quat()])
    slerp = Slerp([0, 1], key_rots)
    R_fused = slerp([alpha])[0].as_matrix()
    
    # 6. 平移修正
    # 初始平移基于可见点云质心，加上网络预测的残差补偿遮挡偏差
    centroid_i = np.mean(P_i, axis=0)
    t_fused = centroid_i + delta
    
    return R_fused, t_fused
```

### 第二模块：核心架构解释

FM-CGM（Foundation Model Powered Causal Generative Model）框架将反事实图像生成过程拆解为三个由独立基础模型驱动的模块：

1.  **概念提取器 (Concept Extractor)**：输入原始图像和基础提示词，调用推理型 VLM（如 Qwen3-VL）。VLM 识别图像中的核心语义概念（如：性别、年龄、胡须），并输出一个描述这些概念因果关系的有向无环图（DAG）。
2.  **概念操纵器 (Concept Manipulator)**：在提取的因果图上执行数学上的 `do()` 干预操作。再次调用 VLM，计算当某个概念被强制改变时（例如：性别从男变女），哪些子代概念（如：胡须）必须随之改变，哪些非子代概念（如：背景天气）必须保持不变。输出更新后的反事实概念集。
3.  **反事实生成器 (Counterfactual Generator)**：使用文本到图像扩散模型（如 SDXL）。首先通过反演（Inversion）获取原图的潜在噪声。随后在去噪生成过程中，应用作者提出的**因果语义引导 (Causal Semantic Guidance, CSG)**。CSG 通过提取扩散模型 U-Net 的交叉注意力掩码，精准定位受干预影响的像素区域，仅在这些区域施加编辑梯度，从而实现满足“反事实最小化”原则的图像生成。

**核心逻辑伪代码 (Python-style)**：

```python
def FM_CGM_pipeline(image, base_prompt, intervention_target, new_value):
    # 1. 概念提取器：利用 VLM 提取图像概念与因果图
    concepts, causal_graph = VLM.extract_concepts_and_graph(image, base_prompt)
    
    # 2. 概念操纵器：执行 do-calculus 干预，计算因果图上的连锁反应
    # 返回包含目标节点及其子代节点新状态的集合
    counterfactual_concepts = VLM.propagate_intervention(
        concepts, causal_graph, intervention_target, new_value
    )
    
    # 3. 反事实生成器：图像反演获取初始噪声
    latent_noise = Diffusion.invert(image)
    
    # 扩散模型去噪循环 (应用 CSG 因果语义引导)
    for step in diffusion_steps:
        # 获取无条件和基础条件的分数预估
        score_uncond = Diffusion.predict_noise(latent_noise, step, "")
        score_base = Diffusion.predict_noise(latent_noise, step, base_prompt)
        
        guidance_update = 0
        # 遍历所有受因果干预影响的节点（目标节点 + 子代节点）
        for concept in counterfactual_concepts.descendants:
            score_concept = Diffusion.predict_noise(latent_noise, step, concept.prompt)
            
            # 核心机制：提取交叉注意力掩码，定位需要修改的像素区域
            mask_attention = Diffusion.get_cross_attention_mask(concept)
            mask_preserve = Diffusion.get_unconditioned_mask()
            final_mask = mask_attention * mask_preserve
            
            # 仅在受因果影响的区域施加引导，隔离非子代节点（不变区域）
            guidance_update += final_mask * (score_concept - score_uncond)
            
        # 更新潜变量
        latent_noise = step_scheduler(latent_noise, score_base + guidance_update)
        
    return Diffusion.decode(latent_noise)
```
