X-WAM 的架构建立在预训练的视频扩散模型（Wan2.2-5B）之上，其核心流程分为多模态输入对齐、共享主干去噪、轻量级深度解耦以及异步推理四个阶段：

1. **多模态 Token 化**：将多视角 RGB 图像通过 VAE 编码为潜变量，将本体感受状态（State）和动作（Action）通过 MLP 投影到同一潜空间，并拼接成统一的去噪序列。
2. **共享 DiT 主干（Shared Trunk）**：序列首先通过前 $N-M$ 个标准的 DiT 块进行联合注意力计算，此时视频、状态和动作特征相互交织。
3. **轻量级深度适应（Unilateral Attention）**：在最后 $M$ 个 Block，模型分叉为主分支和深度分支。深度分支由主分支的 Block 复制而来。关键设计是**单向注意力**：深度分支可以 Cross-Attend 到主分支的特征来回归深度图，但主分支完全不受深度分支影响。这严格保护了预训练的视觉先验。
4. **异步推理（Asynchronous Inference）**：动作 Token 仅需 $T_a$ 步去噪即可收敛并输出给机器人执行；而视频 Token 则继续去噪至 $T_O$ 步（$T_O > T_a$）。

```python
def x_wam_forward_step(Z_noisy, t_video, t_action, N, M, shared_blocks, main_blocks, depth_blocks):
    """
    Z_noisy: 拼接后的多模态潜变量 [Video, State, Action]
    N: 总 DiT Block 数量
    M: 复制用于深度预测的 Block 数量
    """
    # 1. 共享主干处理 (前 N-M 个 Blocks)
    Z = Z_noisy
    for i in range(N - M):
        Z = shared_blocks[i](Z)
        
    # 2. 分支初始化
    Z_main = Z
    Z_depth = Z
    
    # 3. 轻量级深度适应 (后 M 个 Blocks，单向注意力)
    for j in range(M):
        # 深度分支：以 Z_main 为 Context 进行 Cross-Attention
        Z_depth = depth_blocks[j](Z_depth, context=Z_main)
        # 主分支：正常 Self-Attention，不受 Depth 干扰
        Z_main = main_blocks[j](Z_main)
        
    # 4. 预测输出
    v_video, v_state, v_action = head_main(Z_main)
    inverse_depth = head_depth(Z_depth)
    
    return v_video, v_state, v_action, inverse_depth
```

本文提出的“提升世界模型（Lifted World Model）”框架主要由三个核心组件和一套规划流程构成：

1.  **底层世界模型 (Base World Model)**：一个标准的、预训练且参数冻结的视觉世界模型。它接收当前观测图像和高维底层动作（如全身关节指令），预测下一帧的观测图像。
2.  **轻量级策略网络 (Lightweight Policy)**：一个被单独训练的神经网络。它接收当前观测图像和一个低维的高层动作（在本文中定义为图像平面上几个关键叶节点关节——如骨盆、头部、双手的 2D 目标坐标），输出一段固定长度的底层动作序列。
3.  **提升世界模型 (Lifted World Model)**：上述两者的组合。输入当前观测和低维高层动作，策略网络先生成底层动作序列，随后底层世界模型利用该序列进行自回归展开，直接输出多步之后的未来观测图像。
4.  **基于 CEM 的规划 (Planning with CEM)**：在推理阶段，交叉熵方法（CEM）不再于高维的底层关节空间中盲目采样，而是直接在低维的 2D 图像坐标空间中采样高层动作。通过提升世界模型评估这些高层动作带来的未来观测结果，选出最优的 2D 航点，进而转化为底层控制指令执行。

### 第二模块：核心架构解释

X-WAM 的架构建立在预训练的视频扩散模型（Wan2.2-5B）之上，其核心流程分为多模态输入对齐、共享主干去噪、轻量级深度解耦以及异步推理四个阶段：

1. **多模态 Token 化**：将多视角 RGB 图像通过 VAE 编码为潜变量，将本体感受状态（State）和动作（Action）通过 MLP 投影到同一潜空间，并拼接成统一的去噪序列。
2. **共享 DiT 主干（Shared Trunk）**：序列首先通过前 $N-M$ 个标准的 DiT 块进行联合注意力计算，此时视频、状态和动作特征相互交织。
3. **轻量级深度适应（Unilateral Attention）**：在最后 $M$ 个 Block，模型分叉为主分支和深度分支。深度分支由主分支的 Block 复制而来。关键设计是**单向注意力**：深度分支可以 Cross-Attend 到主分支的特征来回归深度图，但主分支完全不受深度分支影响。这严格保护了预训练的视觉先验。
4. **异步推理（Asynchronous Inference）**：动作 Token 仅需 $T_a$ 步去噪即可收敛并输出给机器人执行；而视频 Token 则继续去噪至 $T_O$ 步（$T_O > T_a$）。

**核心逻辑伪代码 (Python 风格)**:

```python
def x_wam_forward_step(Z_noisy, t_video, t_action, N, M, shared_blocks, main_blocks, depth_blocks):
    """
    Z_noisy: 拼接后的多模态潜变量 [Video, State, Action]
    N: 总 DiT Block 数量
    M: 复制用于深度预测的 Block 数量
    """
    # 1. 共享主干处理 (前 N-M 个 Blocks)
    Z = Z_noisy
    for i in range(N - M):
        Z = shared_blocks[i](Z)
        
    # 2. 分支初始化
    Z_main = Z
    Z_depth = Z
    
    # 3. 轻量级深度适应 (后 M 个 Blocks，单向注意力)
    for j in range(M):
        # 深度分支：以 Z_main 为 Context 进行 Cross-Attention
        Z_depth = depth_blocks[j](Z_depth, context=Z_main)
        # 主分支：正常 Self-Attention，不受 Depth 干扰
        Z_main = main_blocks[j](Z_main)
        
    # 4. 预测输出
    v_video, v_state, v_action = head_main(Z_main)
    inverse_depth = head_depth(Z_depth)
    
    return v_video, v_state, v_action, inverse_depth

    """

            Z_video = scheduler_O.step(Z_video, v_v)
            Z_action = scheduler_a.step(Z_action, v_a)

                # 动作解码完成，立即下发给物理机器人执行
                dispatch_to_robot(Z_action)
        else:

            v_v, _, _, depth = x_wam_forward_step([Z_video, Z_state, Z_action_clean], t_O[k], t_a=0)
```

方法：作者提出了一种“提升（Lifting）”框架。首先训练一个轻量级策略，将高层动作映射为底层关节动作序列。然后将该策略与冻结的世界模型组合，形成“提升的世界模型（Lifted World Model）”。对于仿人智能体，高层动作被定义为当前观测帧上的少量2D路点（waypoints），分别指定骨盆、头部、手部等末端关节的近期目标位置。这些路点维度低、具有视觉可解释性，且易于手动指定或进行搜索优化。

### 第二模块：核心架构解释

本文提出的“提升世界模型（Lifted World Model）”框架主要由三个核心组件和一套规划流程构成：

1.  **底层世界模型 (Base World Model)**：一个标准的、预训练且参数冻结的视觉世界模型。它接收当前观测图像和高维底层动作（如全身关节指令），预测下一帧的观测图像。
2.  **轻量级策略网络 (Lightweight Policy)**：一个被单独训练的神经网络。它接收当前观测图像和一个低维的高层动作（在本文中定义为图像平面上几个关键叶节点关节——如骨盆、头部、双手的 2D 目标坐标），输出一段固定长度的底层动作序列。
3.  **提升世界模型 (Lifted World Model)**：上述两者的组合。输入当前观测和低维高层动作，策略网络先生成底层动作序列，随后底层世界模型利用该序列进行自回归展开，直接输出多步之后的未来观测图像。
4.  **基于 CEM 的规划 (Planning with CEM)**：在推理阶段，交叉熵方法（CEM）不再于高维的底层关节空间中盲目采样，而是直接在低维的 2D 图像坐标空间中采样高层动作。通过提升世界模型评估这些高层动作带来的未来观测结果，选出最优的 2D 航点，进而转化为底层控制指令执行。

### 第二模块：核心架构解释

STARRY 的系统架构由四个核心专家模块构成，采用三阶段训练策略（时空预训练、动作与几何学习、端到端联合微调）。其前向推理流程如下：

1. **输入构建**：将多视角 RGB 图像、深度图以及投影到相机平面的 3D 末端执行器轨迹在空间上拼接，构建统一的 RGB-D 格式时空输入，并编码为视频 token。
2. **语义理解 (Understanding Expert)**：基于 Qwen-VL 架构，处理视觉与语言指令，提供全局语义 grounding token。
3. **联合去噪 (ST World Model & Action Expert)**：在扩散模型的框架下，使用特定分支的时间步长，联合预测未来的时空潜变量（包含外观、运动、几何的结构化信息）和未来的动作序列。
4. **几何调制 (Geometry Expert & GASAM)**：Geometry Expert 预测未来的深度序列和末端执行器 3D 位置。GASAM 利用相机参数将深度反投影为 3D 点云，计算每个场景点与预测末端位置的 L2 距离。该距离被映射为单调递减的权重，并与动作查询（Action Queries）到视觉键（Video Keys）的注意力矩阵相加，强制动作分支聚焦于距离末端较近的几何关键区域。

```python
    st_input = compose_spatial_temporal(obs_rgb, obs_depth, end_effector_traj)

    semantic_tokens = understanding_expert(obs_rgb, language_cmd)

    pred_depth, pred_end_pose = geometry_expert(video_tokens, past_actions, t_v, t_a)

    # Unproject depth to 3D points
    points_3d = unproject(pred_depth, camera_intrinsics)
    # Compute L2 distance between scene points and predicted end-effector pose
    distances = compute_l2_distance(points_3d, pred_end_pose)
    # Convert distances to attention weights (closer = higher weight)
    geo_weights = distance_to_weights(distances)
    
    # 5. Modulated Action Attention (Inside Action Expert)
    def modulated_attention(action_query, video_key, video_value, geo_weights, lambda_val):
        standard_attn_logits = dot_product(action_query, video_key) / sqrt(d)
        # Inject geometric bias directly into logits
        modulated_logits = standard_attn_logits + lambda_val * log(geo_weights + epsilon)
        attn_probs = softmax(modulated_logits)
        return matmul(attn_probs, video_value)
    
    # 6. Joint Denoising
    pred_st_latents = st_world_model(video_tokens, semantic_tokens, noise_v, t_v)
    pred_actions = action_expert(video_tokens, semantic_tokens, noise_a, t_a, geo_weights)
    
    return pred_st_latents, pred_actions
```

```python
    def __init__(self, generative_model, physics_simulator, vlm_agent):
        self.gen_model = generative_model
        self.simulator = physics_simulator
        self.vlm = vlm_agent

    def generate_sim_ready_asset(self, prompt):
        # 1. 生成基础几何与外观
        raw_geometry, texture = self.gen_model.generate_shape(prompt)
        
        # 2. 运动学与物理属性推断 (Data Generator 核心)
        kinematic_tree = self.vlm.infer_articulation(raw_geometry)
        physical_params = self.vlm.estimate_physics(raw_geometry, material_type="auto")
        
        # 3. 格式化与物理验证
        asset_urdf = self._serialize_to_urdf(raw_geometry, kinematic_tree, physical_params)
        if not self.simulator.check_stability(asset_urdf):
            asset_urdf = self._post_hoc_physics_refinement(asset_urdf)
            
        return asset_urdf

    def construct_interactive_scene(self, task_instruction, asset_library):
        # 1. 智能体驱动的场景布局规划 (Simulation Environments 核心)
        layout_spec = self.vlm.plan_layout(task_instruction)
        
        # 2. 实例化与碰撞检测
        scene = self._instantiate_assets(layout_spec, asset_library)
        while self.simulator.detect_interpenetration(scene):
            scene = self.vlm.propose_layout_correction(scene)
            
        return scene

    def sim_to_real_transfer(self, real_world_observation):
        # 1. 生成式数字孪生构建 (Sim2Real Bridge 核心)
        digital_twin = self._reconstruct_from_vision(real_world_observation)
        
        # 2. 物理参数对齐与数据增强
        aligned_twin = self._align_dynamics_with_real_world(digital_twin)
        augmented_demos = self.gen_model.synthesize_trajectories(aligned_twin)
        
        return augmented_demos
```

首先，系统接收人类的自然语言指令（如“我想去散步”）。高层VLM结合当前的GPS坐标，向公共地图API发起检索，获取附近的兴趣点（POIs）。VLM根据指令语义选择最匹配的目的地，并调用地图API生成粗略的步行路线，将其转化为一系列带有地理坐标的局部航点（Waypoints）。

进入导航循环后，系统在每个控制步构建包含当前RGB图像、位姿、历史轨迹和下一个航点的环境观测。此时触发核心的“观测感知路由机制”：高层VLM对当前场景进行联合评估，判断前方是常规路段还是复杂场景（如十字路口、密集人群），并输出安全决策（继续前进或停下等待）。

如果VLM判定安全并允许前进，底层VLA模型将接管控制权，基于自我中心视角的观测数据生成一条短程的、符合社交规范的局部轨迹，交由底盘执行；如果VLM判定存在安全隐患，机器人将直接执行零位移的“停下等待”动作，并在短暂延迟后重新请求VLM进行评估，直至场景安全。

```python
# Walk with Me 核心逻辑伪代码
class WalkWithMeSystem:
    def __init__(self, vlm, vla, map_api, robot_controller):
        self.vlm = vlm
        self.vla = vla
        self.map_api = map_api
        self.robot = robot_controller
        
    def high_level_semantic_planning(self, instruction, current_gps):
        # 1. 目的地接地与航点生成
        poi_candidates = self.map_api.search_pois(current_gps, category=instruction)
        destination = self.vlm.select_destination(instruction, poi_candidates)
        route = self.map_api.get_walking_route(current_gps, destination)
        waypoints = self.extract_waypoints(route)
        return waypoints

    def navigate(self, instruction):
        current_gps = self.robot.get_gps()
        waypoints = self.high_level_semantic_planning(instruction, current_gps)
        
        # 2. 闭环执行与自适应双策略导航
        while not self.robot.reached_destination(waypoints[-1]):
            observation = self.robot.get_observation() # 包含 RGB, Pose, History, Next_Waypoint
            route_context = self.get_current_route_step(waypoints)
            
            # 3. 联合路由与安全决策 (高层 VLM)
            routing_type, safety_decision, conf = self.vlm.assess_scene(observation, route_context)
            
            if safety_decision == "proceed" and conf >= THRESHOLD:
                # 4. 常规路段：底层 VLA 生成局部轨迹
                trajectory = self.vla.predict_trajectory(observation)
                self.robot.execute_trajectory(trajectory)
            elif safety_decision == "stop-and-wait":
                # 5. 复杂场景：触发安全机制
                self.robot.stop_and_wait()
                self.robot.sleep(WAIT_INTERVAL)
            else:
                self.robot.stop_and_wait()
                
            self.robot.update_state()
```

### 第二模块：核心架构解释

MCM-VG 的核心逻辑是将 3D 视觉定位从“依赖 3D 提议的盲盒”转变为“2D 先验引导的 3D 修正与降维推理”过程。其架构包含三个关键阶段：

1. **语义对齐 (Semantic Alignment)**：首先利用 LLM 解析用户输入的自然语言 Query，提取核心目标类别。随后，将原始且充满噪声的 3D 提议与提取的类别进行粗到细的 2D-3D 匹配，剔除明显的类别不匹配项。
2. **实例校正 (Instance Rectification)**：针对 3D 提议器漏检或几何极度不准的目标，调用 VLM 在 2D 多视角图像上进行精准的 2D 实例分割。结合相机的深度图（Depth Maps），将这些高质量的 2D 掩码反投影（Back-project）到 3D 空间，生成补充的、高精度的 3D 边界框。
3. **视角蒸馏与推理 (Viewpoint Distillation & Reasoning)**：为了消除多视角冗余，对观察候选目标的 3D 相机方向进行聚类，筛选出无遮挡、视角最佳的 RGB 帧。将这些最优帧与场景的鸟瞰图（BEV）拼接，构建紧凑的视觉提示集。最终，将定位任务转化为 VLM 擅长的多项选择题（Multiple-choice reasoning）输出最终结果。

```python
def MCM_VG_pipeline(scene_3d, multi_view_images, depth_maps, text_query):
    # 阶段一：语义对齐 (Semantic Alignment)
    target_category = LLM_parse_query(text_query)
    noisy_3d_proposals = generate_initial_3d_proposals(scene_3d)
    aligned_proposals = coarse_to_fine_matching(noisy_3d_proposals, target_category)
    
    # 阶段二：实例校正 (Instance Rectification)
    # 如果现有提议质量差或缺失，利用 2D 先验反向重建 3D
    if evaluate_proposal_quality(aligned_proposals) < THRESHOLD:
        masks_2d = VLM_guided_2D_segmentation(multi_view_images, text_query)
        rectified_3d_boxes = back_project_to_3d(masks_2d, depth_maps)
        aligned_proposals.merge(rectified_3d_boxes)
        
    # 阶段三：视角蒸馏与 VLM 推理 (Viewpoint Distillation & Reasoning)
    # 聚类相机视角，提取观察候选框的最优 2D 帧
    optimal_views = cluster_and_extract_best_views(aligned_proposals, multi_view_images)
    # 生成鸟瞰图以保留全局空间拓扑
    bev_map = generate_bev_map(scene_3d, aligned_proposals)
    
    # 构建视觉与文本提示，转化为多选题
    visual_prompts = construct_visual_prompts(optimal_views, bev_map)
    text_prompt = format_as_multiple_choice(text_query, aligned_proposals)
    
    # VLM 执行最终的消歧与定位
    final_grounded_target = VLM_reasoning(visual_prompts, text_prompt)
    
    return final_grounded_target
```
