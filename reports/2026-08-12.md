### 第二模块：核心架构解释

FACT 的核心逻辑是将“动作生成”与“后果预测”解耦，使得模型可以从失败中学习物理规律，而不被失败的动作污染策略。

**1. 共享扩散主干 (Shared Diffusion Backbone)**
模型接收当前的视觉观察图像和语言指令作为前缀条件。使用单一的因果扩散 Transformer 同时处理三种目标：动作序列、任务进度价值、未来视频帧。

**2. 教师强制掩码机制 (Teacher-Forced Masking)**
在训练阶段，模型内部存在两组动作数据：模型自己预测的噪声动作，以及真实的动作（无论成功还是失败）。通过注意力掩码，强制要求“价值”和“未来视频”的预测只能依赖真实的动作，而不能依赖模型预测的噪声动作。这确立了“动作决定未来”的因果关系。

**3. 失败感知协同训练 (Failure-Aware Co-training)**
对数据进行分类处理：
- 遇到成功的演示数据：计算动作生成损失、价值预测损失、未来视频预测损失。
- 遇到失败的演示数据：将动作生成损失屏蔽（权重设为0），仅计算价值预测损失（目标值设低）和未来视频预测损失（真实的失败画面）。

**4. 两阶段推理 (Two-Stage Inference)**
- 阶段一：仅去噪生成动作序列。如果对延迟要求极高，可以直接输出该动作执行。
- 阶段二（可选）：并行生成多个候选动作，将这些动作填入条件位置，预测对应的任务进度价值。选择预测价值最高的动作执行。

```python
        # 3. 未来感知推理 (基于世界模型)
        for action_seq in candidate_actions:
            # 预测未来状态轨迹及边界违规情况
            predicted_states, boundary_violations = self.world_model.predict(current_state, action_seq)
            
            # 评估轨迹：奖励贴近物理极限的行为，惩罚越界行为
            reward = self.evaluate_trajectory(predicted_states, boundary_violations)
            
            if reward > max_reward:
                max_reward = reward
                best_action = action_seq[0]
                
        return best_action

    def closed_loop_refinement(self, replay_buffer):
        # 4. 闭环优化：利用极限边缘的成功与失败数据更新模型
        near_limit_data = replay_buffer.sample_near_limit_transitions()
        
        # 联合优化世界模型与策略
        self.world_model.train(near_limit_data)
        self.policy.train(near_limit_data, self.world_model)
```

### 第二模块：核心架构解释

SALT 的核心思想是**干预动作分词器的训练阶段**，而不改变下游 VLA 的架构与推理流程。其整体流程分为两个阶段：

**1. 分词器训练阶段（Tokenizer Training - 核心创新）**
*   **连续动作编码：** 将连续的机器人动作轨迹切分为固定长度的块（如 8 步，7-DoF），通过残差 VQ-VAE 编码器映射为离散的 Codebook 索引，并聚合为量化隐变量。
*   **双重梯度监督：**
    *   **物理重建分支：** 解码器将隐变量还原为连续动作，计算 L1 重建损失，保证动作的可执行性。
    *   **语义对齐分支：** 将隐变量通过线性映射加上位置编码，转化为软前缀（Soft Prefix）。将其与文本提示（如 "Describe the robot's action:"）拼接，输入到一个**冻结的预训练 VLM** 中。计算 VLM 生成真实自然语言指令的交叉熵损失。
*   **反向传播：** 语言模型的梯度回传，通过直通估计器（Straight-Through Estimator）更新 VQ-VAE 的编码器和 Codebook，使得具有相同语义（如“翻转”）的动作轨迹被强制分配到相同的离散 Token 中。

**2. VLA 策略训练阶段（VLA Training）**
*   分词器训练完成后，冻结其编码器和 Codebook。
*   下游 VLA 骨干网络接收视觉图像和语言指令，通过标准的自回归交叉熵损失，学习预测 SALT 生成的离散动作 Token ID。

**核心伪代码实现逻辑：**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SALT_Tokenizer(nn.Module):
    def __init__(self, vq_vae, frozen_vlm, latent_dim, vlm_embed_dim):
        super().__init__()
        self.vq_vae = vq_vae # 包含 encoder, codebook, decoder
        self.frozen_vlm = frozen_vlm # 冻结的语言模型
        self.frozen_vlm.eval()
        
        # 语义对齐投影层：将动作隐变量对齐到 VLM 的 embedding 空间
        self.gain = nn.Parameter(torch.tensor(1.0))
        self.pos_encoding = nn.Parameter(torch.randn(1, MAX_CHUNKS, vlm_embed_dim))
        self.proj = nn.Linear(latent_dim, vlm_embed_dim)

    def forward(self, action_chunks, text_instructions, text_prompts):
        # 1. 物理重建路径
        # z_q: 量化后的隐变量; vq_loss: codebook commitment loss
        z_q, vq_loss, token_ids = self.vq_vae.encode(action_chunks) 
        reconstructed_actions = self.vq_vae.decode(z_q)
        recon_loss = F.l1_loss(reconstructed_actions, action_chunks)
        
        # 2. 语义对齐路径 (核心创新)
        # 将动作隐变量转换为 VLM 的 Soft Prefix
        action_prefix = self.gain * self.proj(z_q) + self.pos_encoding[:, :z_q.size(1), :]
        
        # 拼接 Prompt Embeddings 和 Action Prefix Embeddings
        prompt_embeds = self.frozen_vlm.get_input_embeddings()(text_prompts)
        input_embeds = torch.cat([prompt_embeds, action_prefix], dim=1)
        
        # 冻结的 VLM 预测真实的语言指令
        with torch.no_grad():
            # 获取 target 指令的 token ids 用于计算 loss
            target_ids = self.frozen_vlm.tokenize(text_instructions)
            
        # 计算语言生成交叉熵损失 (梯度回传至 self.proj 和 self.vq_vae)
        vlm_outputs = self.frozen_vlm(inputs_embeds=input_embeds, labels=target_ids)
        align_loss = vlm_outputs.loss
        
        # 3. 总损失
        lambda_align = 0.1 # 权重超参
        total_loss = recon_loss + vq_loss + lambda_align * align_loss
        
        return total_loss
```

2. **结构化检索模型 (Structurally Grounded Retrieve Model)**：在推理时，将当前场景的静态和动态特征解耦，在记忆库中进行相似度匹配，召回最相关的历史失败案例。
3. **解耦 LoRA 测试时训练 (Decoupled LoRA-based TTT)**：在推理阶段，利用召回的失败案例及其专家标签，对模型中附加的轻量级 LoRA 模块进行快速反向传播更新（TTT）。更新完成后，用该模型对当前场景进行最终的轨迹预测。

```python
class DriveVLAM0:
    def __init__(self, backbone, lora_module, memory_pool, retriever):
        self.backbone = backbone       # 冻结的VLA主干网络
        self.lora = lora_module        # 解耦的轻量级LoRA，专用于TTT
        self.memory_pool = memory_pool # 失败案例记忆库
        self.retriever = retriever     # 结构化特征检索器

    def forward_inference(self, current_scene):
        # 1. 提取当前场景的解耦特征 (静态道路结构 + 动态智能体交互)
        scene_features = self.retriever.extract_features(current_scene)
        
        # 2. 从记忆库中检索最相似的失败案例 (包含场景特征和专家轨迹)
        retrieved_cases = self.retriever.search(scene_features, self.memory_pool, top_k=1)
        
        # 3. 测试时训练 (Test-Time Training)
        # 每次推理前重置 LoRA 权重，避免跨场景的知识污染
        self.lora.reset_weights() 
        
        for case in retrieved_cases:
            # 使用检索到的失败案例和专家标签进行前向传播
            pred_trajectory = self.forward_with_lora(case.scene)
            loss = compute_loss(pred_trajectory, case.expert_trajectory)
            
            # 仅对 LoRA 模块进行反向传播更新 (耗时极低，约26ms)
            loss.backward()
            self.lora.update_weights()
        
        # 4. 使用经过当前场景特异性纠偏后的模型进行最终预测
        final_trajectory = self.forward_with_lora(current_scene)
        
        return final_trajectory
        
    def forward_with_lora(self, scene):
        # 结合冻结的主干网络和动态更新的 LoRA 进行推理
        return self.backbone(scene) + self.lora(scene)
```

#### Deep Research 深度解读

### 第一模块：一分钟核心速写

1. **论文领域**：World Model 增强 VLA
2. **TL;DR**：FACT 提出了一种基于**失败感知因果训练（Failure-Aware Causal Training）**的**世界-动作模型（World-Action Model）**，以解决**现有模型在遇到错误动作时会产生成功偏见幻觉**的问题，在**仿真和真实双臂操作基准**上实现了**策略成功率的显著提升和推理延迟的降低**。

**核心机制**：改变传统的“先预测未来再解码动作”的顺序，采用“先生成动作，再基于该动作预测未来视频和任务进度”的因果架构。在训练失败数据时，强制将动作模仿的损失函数设为零（不学习执行错误动作），但保留未来预测和价值评估的损失函数（学习错误动作导致的客观物理后果）。
4. **关键数据**：
- **最能证明有效性的核心数据**：在真实世界未见过的任务（Unseen tasks）中，加入失败数据训练后，成功率从 67% 提升至 77%；结合可选的候选打分机制后达到 82%，逼近使用了大规模预训练的 $\pi_{0.5}$ (85%)。这直接证明了学习失败后果能显著提升策略的泛化与鲁棒性，且预测的价值得分具有极高的动作筛选参考价值。
- **存疑的试验结果**：在 RoboTwin 仿真基准中，FACT 的平均成功率（87.5%）略低于基线模型 Motus（87.8%）。虽然作者强调 FACT 推理速度快 3 倍，但这表明在纯粹的动作生成上限方面，单向因果架构（先动作后未来）在某些复杂仿真任务上并未绝对超越基于视频优先（先未来后动作）的逆动力学模型。

### 第二模块：核心架构解释

FACT 的核心逻辑是将“动作生成”与“后果预测”解耦，使得模型可以从失败中学习物理规律，而不被失败的动作污染策略。

**1. 共享扩散主干 (Shared Diffusion Backbone)**
模型接收当前的视觉观察图像和语言指令作为前缀条件。使用单一的因果扩散 Transformer 同时处理三种目标：动作序列、任务进度价值、未来视频帧。

**2. 教师强制掩码机制 (Teacher-Forced Masking)**
在训练阶段，模型内部存在两组动作数据：模型自己预测的噪声动作，以及真实的动作（无论成功还是失败）。通过注意力掩码，强制要求“价值”和“未来视频”的预测只能依赖真实的动作，而不能依赖模型预测的噪声动作。这确立了“动作决定未来”的因果关系。

**3. 失败感知协同训练 (Failure-Aware Co-training)**
对数据进行分类处理：
- 遇到成功的演示数据：计算动作生成损失、价值预测损失、未来视频预测损失。
- 遇到失败的演示数据：将动作生成损失屏蔽（权重设为0），仅计算价值预测损失（目标值设低）和未来视频预测损失（真实的失败画面）。

**4. 两阶段推理 (Two-Stage Inference)**
- 阶段一：仅去噪生成动作序列。如果对延迟要求极高，可以直接输出该动作执行。
- 阶段二（可选）：并行生成多个候选动作，将这些动作填入条件位置，预测对应的任务进度价值。选择预测价值最高的动作执行。

```python
    # 1. 初始化损失权重
    weight_action = 20.0
    weight_value = 1.0
    weight_video = 1.0

    if is_failure:
        weight_action = 0.0  # 核心创新：屏蔽动作模仿损失

    noisy_value = add_noise(value_gt)
    noisy_video = add_noise(video_gt)

    # 规则: 价值和视频只能关注 action_gt，不能关注 noisy_action
    attention_mask = build_causal_mask() 
    
    # 6. 模型前向传播预测去噪速度 (Velocity)
    pred_action_v, pred_value_v, pred_video_v = model(tokens, attention_mask)
    
    # 7. 计算损失并反向传播
    loss_action = mse_loss(pred_action_v, target_action_v) * weight_action
    loss_value = mse_loss(pred_value_v, target_value_v) * weight_value
    loss_video = mse_loss(pred_video_v, target_video_v) * weight_video
    
    total_loss = loss_action + loss_value + loss_video
    total_loss.backward()
    update_weights()
```

```python
    def __init__(self, world_model, policy):
        # world_model: 预测未来状态、动力学响应与物理边界
        # policy: 生成候选动作序列
        self.world_model = world_model
        self.policy = policy

    def act(self, current_observation):
        # 1. 状态构建
        current_state = self.construct_state(current_observation)
        
        # 2. 生成候选动作序列
        candidate_actions = self.policy.generate_candidates(current_state)
        
        best_action = None
        max_reward = -float('inf')
        
        # 3. 未来感知推理 (基于世界模型)
        for action_seq in candidate_actions:
            # 预测未来状态轨迹及边界违规情况
            predicted_states, boundary_violations = self.world_model.predict(current_state, action_seq)
            
            # 评估轨迹：奖励贴近物理极限的行为，惩罚越界行为
            reward = self.evaluate_trajectory(predicted_states, boundary_violations)
            
            if reward > max_reward:
                max_reward = reward
                best_action = action_seq[0]
                
        return best_action

    def closed_loop_refinement(self, replay_buffer):
        # 4. 闭环优化：利用极限边缘的成功与失败数据更新模型
        near_limit_data = replay_buffer.sample_near_limit_transitions()
        
        # 联合优化世界模型与策略
        self.world_model.train(near_limit_data)
        self.policy.train(near_limit_data, self.world_model)
```

### 第二模块：核心架构解释

SALT 的核心思想是**干预动作分词器的训练阶段**，而不改变下游 VLA 的架构与推理流程。其整体流程分为两个阶段：

**1. 分词器训练阶段（Tokenizer Training - 核心创新）**
*   **连续动作编码：** 将连续的机器人动作轨迹切分为固定长度的块（如 8 步，7-DoF），通过残差 VQ-VAE 编码器映射为离散的 Codebook 索引，并聚合为量化隐变量。
*   **双重梯度监督：**
    *   **物理重建分支：** 解码器将隐变量还原为连续动作，计算 L1 重建损失，保证动作的可执行性。
    *   **语义对齐分支：** 将隐变量通过线性映射加上位置编码，转化为软前缀（Soft Prefix）。将其与文本提示（如 "Describe the robot's action:"）拼接，输入到一个**冻结的预训练 VLM** 中。计算 VLM 生成真实自然语言指令的交叉熵损失。
*   **反向传播：** 语言模型的梯度回传，通过直通估计器（Straight-Through Estimator）更新 VQ-VAE 的编码器和 Codebook，使得具有相同语义（如“翻转”）的动作轨迹被强制分配到相同的离散 Token 中。

**2. VLA 策略训练阶段（VLA Training）**
*   分词器训练完成后，冻结其编码器和 Codebook。
*   下游 VLA 骨干网络接收视觉图像和语言指令，通过标准的自回归交叉熵损失，学习预测 SALT 生成的离散动作 Token ID。

**核心伪代码实现逻辑：**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SALT_Tokenizer(nn.Module):
    def __init__(self, vq_vae, frozen_vlm, latent_dim, vlm_embed_dim):
        super().__init__()
        self.vq_vae = vq_vae # 包含 encoder, codebook, decoder
        self.frozen_vlm = frozen_vlm # 冻结的语言模型
        self.frozen_vlm.eval()
        
        # 语义对齐投影层：将动作隐变量对齐到 VLM 的 embedding 空间
        self.gain = nn.Parameter(torch.tensor(1.0))
        self.pos_encoding = nn.Parameter(torch.randn(1, MAX_CHUNKS, vlm_embed_dim))
        self.proj = nn.Linear(latent_dim, vlm_embed_dim)

    def forward(self, action_chunks, text_instructions, text_prompts):
        # 1. 物理重建路径
        # z_q: 量化后的隐变量; vq_loss: codebook commitment loss
        z_q, vq_loss, token_ids = self.vq_vae.encode(action_chunks) 
        reconstructed_actions = self.vq_vae.decode(z_q)
        recon_loss = F.l1_loss(reconstructed_actions, action_chunks)
        
        # 2. 语义对齐路径 (核心创新)
        # 将动作隐变量转换为 VLM 的 Soft Prefix
        action_prefix = self.gain * self.proj(z_q) + self.pos_encoding[:, :z_q.size(1), :]
        
        # 拼接 Prompt Embeddings 和 Action Prefix Embeddings
        prompt_embeds = self.frozen_vlm.get_input_embeddings()(text_prompts)
        input_embeds = torch.cat([prompt_embeds, action_prefix], dim=1)
        
        # 冻结的 VLM 预测真实的语言指令
        with torch.no_grad():
            # 获取 target 指令的 token ids 用于计算 loss
            target_ids = self.frozen_vlm.tokenize(text_instructions)
            
        # 计算语言生成交叉熵损失 (梯度回传至 self.proj 和 self.vq_vae)
        vlm_outputs = self.frozen_vlm(inputs_embeds=input_embeds, labels=target_ids)
        align_loss = vlm_outputs.loss
        
        # 3. 总损失
        lambda_align = 0.1 # 权重超参
        total_loss = recon_loss + vq_loss + lambda_align * align_loss
        
        return total_loss
```

```python
class DriveVLAM0:
    def __init__(self, backbone, lora_module, memory_pool, retriever):
        self.backbone = backbone       # 冻结的VLA主干网络
        self.lora = lora_module        # 解耦的轻量级LoRA，专用于TTT
        self.memory_pool = memory_pool # 失败案例记忆库
        self.retriever = retriever     # 结构化特征检索器

    def forward_inference(self, current_scene):
        # 1. 提取当前场景的解耦特征 (静态道路结构 + 动态智能体交互)
        scene_features = self.retriever.extract_features(current_scene)
        
        # 2. 从记忆库中检索最相似的失败案例 (包含场景特征和专家轨迹)
        retrieved_cases = self.retriever.search(scene_features, self.memory_pool, top_k=1)
        
        # 3. 测试时训练 (Test-Time Training)
        # 每次推理前重置 LoRA 权重，避免跨场景的知识污染
        self.lora.reset_weights() 
        
        for case in retrieved_cases:
            # 使用检索到的失败案例和专家标签进行前向传播
            pred_trajectory = self.forward_with_lora(case.scene)
            loss = compute_loss(pred_trajectory, case.expert_trajectory)
            
            # 仅对 LoRA 模块进行反向传播更新 (耗时极低，约26ms)
            loss.backward()
            self.lora.update_weights()
        
        # 4. 使用经过当前场景特异性纠偏后的模型进行最终预测
        final_trajectory = self.forward_with_lora(current_scene)
        
        return final_trajectory
        
    def forward_with_lora(self, scene):
        # 结合冻结的主干网络和动态更新的 LoRA 进行推理
        return self.backbone(scene) + self.lora(scene)
```

4. **零开销推理**：推理阶段直接剥离几何基础模型，仅使用训练好的 WAM 根据历史输入生成未来帧和轨迹。

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class FourDWAM(nn.Module):
    def __init__(self, base_wam, geometric_foundation_model):
        super().__init__()
        self.wam = base_wam # 基于扩散架构的世界-动作模型
        self.geom_model = geometric_foundation_model
        self.geom_model.eval() # 训练期间冻结几何模型

    def decision_oriented_timestep_sampling(self, batch_size):
        # 核心创新：向早期、高噪声阶段（大 t）倾斜的采样策略
        # 因为驾驶决策主要在这些阶段形成
        weights = self.get_high_noise_biased_weights()
        t = torch.multinomial(weights, batch_size, replacement=True)
        return t

    def compute_4d_consistency_loss(self, pred_frames, gt_frames):
        # 提取真实帧的几何特征
        with torch.no_grad():
            gt_geom_features = self.geom_model(gt_frames)
        
        # 提取预测帧的几何特征，梯度回传至 WAM
        pred_geom_features = self.geom_model(pred_frames)
        
        # 强制预测帧在 4D 几何结构上与真实世界一致
        loss_4d = F.mse_loss(pred_geom_features, gt_geom_features)
        return loss_4d

    def forward_train(self, history_frames, gt_future_frames, gt_trajectory):
        batch_size = history_frames.size(0)
        
        # 1. 决策导向的时间步采样
        t = self.decision_oriented_timestep_sampling(batch_size)
        
        # 2. 前向加噪 (Diffusion process)
        noisy_future, noise = self.wam.add_noise(gt_future_frames, t)
        
        # 3. WAM 预测去噪帧与规划轨迹
        pred_frames, pred_trajectory = self.wam(history_frames, noisy_future, t)
        
        # 4. 基础任务损失
        loss_recon = F.mse_loss(pred_frames, gt_future_frames)
        loss_plan = F.mse_loss(pred_trajectory, gt_trajectory)
        
        # 5. 4D 一致性损失
        loss_4d = self.compute_4d_consistency_loss(pred_frames, gt_future_frames)
        
        total_loss = loss_recon + loss_plan + self.lambda_4d * loss_4d
        return total_loss

    def forward_inference(self, history_frames):
        # 推理阶段：无需几何模型，零额外计算开销
        pred_frames, pred_trajectory = self.wam.generate(history_frames)
        return pred_frames, pred_trajectory
```

```python
        vlm_features = self.vlm(current_rgb, instruction)
        action_chunk = self.late_block_diffusion_forward(vlm_features, z_sem)
        
        return action_chunk

                h = h + injected_features
            
            h = block(h) # Frozen transformer block
```

### 第二模块：核心架构解释

XCoT-VLA 的系统架构分为离线数据构造、监督微调（SFT）与策略优化（XCPO）三个核心环节。其底层逻辑是通过共享的注意力机制理解全局上下文，再通过物理隔离的前馈神经网络（FFN）分别处理“逻辑推理”与“轨迹生成”。

**1. 离线数据构造（Offline Data Construction）**
模型不依赖人工标注大量文本。系统首先从真实记录的驾驶轨迹中提取几何运动特征（如速度、加速度、横向偏移），随后利用视觉语言模型（VLM）结合当前场景图像，推断出导致该运动的语义原因（如红灯、导航左转）。最后，通过规则映射，将这些原因压缩为标准化的 XCoT Token 序列（如 `RED_LIGHT_HOLD`）。

**2. 第一阶段：解耦的监督微调（Stage I: SFT）**
模型接收多模态输入（图像、文本提示、自车状态）。所有的输入 Token 与 24 个用于预测未来轨迹的固定 Query Token 共同进入 Transformer。
在自注意力层（Self-Attention），所有 Token 互相交换信息。
在 FFN 层，执行**确定性 Token 函数路由**：
*   所有的上下文 Token 和 XCoT Token 被强制送入 **Reason FFN**，用于自回归预测下一步的 XCoT Token。
*   24 个轨迹 Query Token 被强制送入 **Control FFN**，输出连续的特征向量，随后交由条件流匹配（Conditional Flow Matching）解码器生成具体的物理轨迹（加速度和横摆角变化）。

**3. 第二阶段：XCoT 策略优化（Stage II: XCPO）**
在强化学习微调阶段，冻结视觉编码器、自注意力层、Control FFN 和轨迹解码器（即冻结执行栈）。仅开放 Reason FFN 的参数更新。模型通过采样不同的 XCoT 序列生成多条轨迹，利用轨迹级别的奖励（如安全性、舒适度）来计算优势函数，从而优化离散的推理策略。

**核心逻辑伪代码（Python 风格）**：

```python
def xcot_vla_forward(multimodal_context, traj_queries):
    # multimodal_context: 包含图像、状态、指令及已生成的 XCoT tokens
    # traj_queries: 24个固定的可学习向量，代表未来24个时间步的轨迹
    
    # 1. 拼接所有输入
    all_tokens = concatenate([multimodal_context, traj_queries])
    
    # 2. 共享多模态自注意力 (信息融合)
    attended_tokens = Shared_SelfAttention(all_tokens)
    
    # 3. 确定性 Token 路由 (分离推理与控制)
    num_context = len(multimodal_context)
    context_features = attended_tokens[:num_context]
    traj_features = attended_tokens[num_context:]
    
    # 4. 独立的前馈网络处理
    # Reason FFN 仅处理上下文与离散推理
    reason_output = Reason_FFN(context_features)
    # Control FFN 仅处理连续轨迹查询
    control_output = Control_FFN(traj_features)
    
    # 5. 预测输出
    # 自回归预测下一个 XCoT Token
    next_xcot_logits = XCoT_Prediction_Head(reason_output)
    
    # 基于流匹配生成连续物理轨迹 (加速度, 横摆角)
    continuous_trajectory = Flow_Matching_Decoder(control_output)
    
    return next_xcot_logits, continuous_trajectory
```

### 第二模块：核心架构解释

Surgical WAM 的核心架构基于 Cosmos Policy，采用两阶段训练范式，并在推理时使用后退视界（Receding-horizon）控制策略。

**1. 输入与表征**
模型在每个控制步接收当前内窥镜 RGB 图像、dVRK 机器人的本体感受状态（Proprioception）以及任务嵌入（Task Embedding）。这些输入被编码为 token 序列。

**2. 两阶段训练流程**
*   **阶段一（无动作视频预训练）**：模型仅作为世界模型运行。输入无动作标签的手术视频片段，掩码（Mask）掉动作和状态槽位，仅通过扩散去噪目标优化未来画面的预测。此阶段让模型学习手术器械移动、组织形变等视觉动态规律。
*   **阶段二（动作标签联合微调）**：引入固定预算的带动作标签演示数据。将视觉、状态、未来预测和动作 token 拼接在同一个序列中，注入噪声后，通过同一个 Transformer 网络联合去噪。动作预测流与视频预测流共享注意力机制，从而将阶段一学到的动态先验迁移到动作生成上。

**3. 闭环执行流程**
在部署阶段，模型联合采样未来画面和动作块（Action Chunk）。生成的未来画面被直接丢弃（仅作为计算过程中的条件约束），机器人仅执行动作块的前 $H_e$ 步，随后获取新观察并重新规划。

**核心伪代码实现**：

```python
import torch
import torch.nn as nn

class SurgicalWAM(nn.Module):
    def __init__(self, diffusion_backbone):
        super().__init__()
        # 共享的扩散 Transformer 骨干网络
        self.transformer = diffusion_backbone
        
    def stage1_video_pretraining(self, video_history, future_video_target):
        """
        阶段一：仅使用无标签视频学习视觉动态
        """
        # 动作与状态槽位置空
        action_tokens = None 
        state_tokens = None
        
        # 仅计算视频预测的去噪损失
        loss = self.transformer.compute_loss(
            context=(video_history, state_tokens),
            targets={'video': future_video_target, 'action': action_tokens}
        )
        return loss

    def stage2_joint_finetuning(self, obs, state, task, action_chunk, future_obs):
        """
        阶段二：使用带标签数据联合微调
        """
        # 联合去噪未来画面与动作块，共享注意力权重
        loss = self.transformer.compute_loss(
            context=(obs, state, task),
            targets={'video': future_obs, 'action': action_chunk}
        )
        return loss

    def closed_loop_step(self, current_obs, current_state, task, H_e):
        """
        部署阶段：后退视界闭环控制
        """
        # 联合采样未来画面与动作块 (联合生成，保留耦合关系)
        predicted_future_obs, predicted_action_chunk = self.transformer.sample(
            current_obs, current_state, task
        )
        
        # 丢弃画面预测，仅截取动作块的前 H_e 步执行
        executable_actions = predicted_action_chunk[:H_e]
        
        return executable_actions
```

### 第二模块：核心架构解释

JEPA-WAM 的核心架构分为两个训练阶段和一个闭环推理流程。其本质是将高维的任务阶段预测与低维的局部动作/视频生成进行解耦与条件融合。

1.  **阶段对构建 (Stage-pair Construction)**：无需人工标注。利用冻结的 V-JEPA2 提取密集演示轨迹的特征，计算局部窗口内的特征欧氏距离变化率。通过时间非极大值抑制（NMS）自动提取特征变化剧烈的帧作为关键阶段边界，构建“当前观测-下一阶段目标”的训练数据对。
2.  **Stage I - 训练 JEPA 预测器**：冻结 V-JEPA2 编码器。输入当前观测切片和语言指令，训练一个目标条件预测器（Stage-JEPA）。该预测器输出下一阶段目标的隐层 Token 表示，通过余弦相似度损失与真实的下一阶段隐层特征进行对齐。
3.  **Stage II - 训练阶段条件 WAM**：冻结 Stage-JEPA 分支。将预测的下一阶段隐层特征进行均值池化和线性映射，通过一个全局有界标量门控（Gated Interface）残差注入到 WAM（基于 Motus 架构）的视频 Token 中。WAM 结合当前观测、机器人状态和指令，联合预测短视距的未来视频流和动作块。
4.  **闭环推理 (Closed-Loop Inference)**：部署时，模型维护一个因果观测缓冲区。Stage-JEPA 根据历史观测预测下一阶段的隐层条件，WAM 接收该条件并生成动作块。环境执行动作，更新观测缓冲区，循环往复。

**核心逻辑伪代码**：

```python
import torch
import torch.nn as nn

class JEPA_WAM(nn.Module):
    def __init__(self, v_jepa_encoder, stage_predictor, wam_model):
        super().__init__()
        # Stage I components (Frozen during Stage II)
        self.v_jepa_encoder = v_jepa_encoder.eval() 
        self.stage_predictor = stage_predictor
        
        # Stage II components
        self.wam = wam_model
        self.gate_beta = nn.Parameter(torch.tensor(0.0)) # Learnable scalar
        self.mlp_proj = nn.Linear(1024, wam_model.video_dim)
        
    def get_stage_guidance(self, current_obs, instruction):
        # Extract current state representation using frozen V-JEPA2
        with torch.no_grad():
            z_current = self.v_jepa_encoder(current_obs)
            
        # Predict next stage latent tokens
        z_target_pred = self.stage_predictor(z_current, instruction)
        return z_target_pred

    def gated_injection(self, video_tokens, z_target_pred):
        # Mean pool the predicted target tokens
        h_t = self.mlp_proj(z_target_pred.mean(dim=1)) 
        
        # Calculate global bounded scalar gate: alpha = 0.2 * sigmoid(beta)
        alpha = 0.2 * torch.sigmoid(self.gate_beta)
        
        # Additive injection into WAM video tokens
        # h_t is broadcasted to all video tokens
        conditioned_video_tokens = video_tokens + alpha * h_t.unsqueeze(1)
        return conditioned_video_tokens, alpha, h_t

    def forward(self, current_obs, robot_state, instruction, action_chunk, target_video):
        # 1. Predict stage-level semantic future
        z_target_pred = self.get_stage_guidance(current_obs, instruction)
        
        # 2. Extract initial video tokens in WAM
        video_tokens = self.wam.extract_video_tokens(current_obs, target_video)
        
        # 3. Inject stage guidance into WAM
        conditioned_video_tokens, alpha, h_t = self.gated_injection(video_tokens, z_target_pred)
        
        # 4. Predict short-term physical future (video & actions)
        pred_video, pred_actions = self.wam.predict(
            conditioned_video_tokens, robot_state, instruction, action_chunk
        )
        
        return pred_video, pred_actions, alpha, h_t
```

意义：该研究为VLA模型的端侧实时部署提供了一种高效且可靠的加速方案。通过结合视觉相似度与模型内部置信度，在不牺牲控制精度的前提下显著降低了计算延迟，对具身智能的实际应用具有重要价值。

**3. 研究动机:** 
现存的 VLA 加速方案（如 VLA-Cache）最大的痛点在于**“盲目自信”**：它们仅依赖观测空间（Observation-space）的启发式规则（如相邻帧图像的视觉相似度）来决定是否复用 KV-Cache，完全忽略了模型在当前状态下输出动作的置信度。本文的切入点极其巧妙，直接利用自回归解码过程中免费的副产品——Top-2 动作 Token 的 Logit 差值（Margin），作为模型内部不确定性的衡量指标，将“视觉启发式”与“神经网络内省”结合。
**核心机制:** 剥离复杂的数学公式，其本质就是：**在模型输出动作时，如果最想做的动作和第二想做的动作概率非常接近（犹豫不决），就强制作废当前的视觉缓存，让模型重新看一眼完整的环境（Full Recompute）。**

**4. 关键数据:**

    *   *理由:* 恢复超过 100% 意味着 Gated VLA-Cache 的表现**超越了不使用任何缓存、每帧都完全重计算的 Baseline**。这在逻辑上暗示了：完全重计算可能会因为高频视觉噪声导致动作抖动（Overfitting to slight visual changes），而适度的缓存复用反而起到了时序平滑（Temporal Smoothing）的正则化作用。作者如果仅仅将其归功于“内省机制”，而没有深入探讨缓存带来的平滑效应，这个数据的解释就是不完整的。

### 第二模块：核心架构解释

Gated VLA-Cache 的核心架构是对标准 VLA 推理流程的轻量级拦截与控制。其运行流程可以拆解为以下几个关键步骤：

1.  **视觉相似度评估（前置过滤）：** 接收到新一帧图像后，首先计算当前帧与缓存帧在特征空间或像素空间的差异。如果差异过大，直接触发重计算；如果差异小，则进入缓存复用候选池。
2.  **动作解码与内省（核心创新）：** 在复用视觉 KV-Cache 进行自回归动作解码时，提取模型输出的动作 Token 的 Logit 分布。
3.  **置信度计算（Logit Margin）：** 计算 Top-1 动作 Token 与 Top-2 动作 Token 的 Logit 差值。这个差值代表了模型的“笃定程度”。
4.  **门控触发（Gating）：** 将计算出的 Margin 与预设的阈值（Threshold）进行比较。
    *   如果 `Margin >= Threshold`：模型很自信，继续使用当前的 KV-Cache 输出动作。
    *   如果 `Margin < Threshold`：模型犹豫不决（可能遇到了视觉上相似但物理语义发生关键变化的微小状态，如即将接触物体的瞬间），立即作废当前 Cache，强制对当前帧进行完整的视觉 Token 编码和 KV-Cache 计算。

**核心逻辑伪代码 (Python-style):**

```python
def generate_action_with_gated_cache(current_image, instruction, cache, threshold):
    # 1. 视觉启发式检查 (继承自 VLA-Cache)
    if not is_visually_similar(current_image, cache.reference_image):
        cache = full_recompute(current_image, instruction)
        return decode_action(cache), cache
    
    # 2. 尝试使用现有的 KV-Cache 进行前向传播
    logits = model_forward(cache.kv_states, instruction)
    
    # 3. 神经网络内省：计算 Top-2 Logit Margin
    # 对 logits 进行降序排序
    sorted_logits = sort_descending(logits)
    top1_logit = sorted_logits[0]
    top2_logit = sorted_logits[1]
    
    logit_margin = top1_logit - top2_logit
    
    # 4. 门控机制：判断模型是否自信
    if logit_margin < threshold:
        # 模型不自信 (Uncertainty high) -> 缓存失效，强制重计算
        cache = full_recompute(current_image, instruction)
        # 重新获取高置信度的 logits
        logits = model_forward(cache.kv_states, instruction)
    
    # 5. 最终动作解码
    action = sample_or_argmax(logits)
    
    return action, cache
```

### 第二模块：核心架构解释

本文的核心架构摒弃了传统的“图像+3D点云双流输入”模式，转而采用“隐式空间表征注入”的单流模式。其工作流程分为训练期的空间信息蒸馏与联合微调，以及推理期的空间思维链生成。

为了保证 Space Tokens 没有退化为无意义的噪声，架构中保留了一个轻量级的空间解码器。在训练时，强制要求生成的 Space Tokens 能够被解码还原为原始的 3D 几何属性，以此提供额外的监督信号。

```python
        super().__init__()
        self.vlm = base_vlm
        # 仅在训练阶段用于提取真实空间特征
        self.spatial_encoder = spatial_encoder 
        # 用于验证 Token 是否包含真实几何信息
        self.spatial_decoder = spatial_decoder 
        self.projector = nn.Linear(spatial_dim, vlm_hidden_dim)

    def forward_train(self, image, text_prompt, ground_truth_3d, text_answer):
        # 1. 提取并投影真实的 3D 空间特征为连续 Token
        raw_spatial_feat = self.spatial_encoder(ground_truth_3d)
        target_space_tokens = self.projector(raw_spatial_feat)
        
        # 2. 构建空间思维链目标序列: [Space Tokens] + [Text Answer]
        cot_target_sequence = concatenate(target_space_tokens, text_answer)
        
        # 3. VLM 前向传播，计算自回归生成损失
        vlm_loss = self.vlm.compute_loss(
            input_images=image, 
            input_text=text_prompt, 
            target_sequence=cot_target_sequence
        )
        
        # 4. 显式解码验证：确保生成的隐向量包含几何信息
        reconstructed_3d = self.spatial_decoder(target_space_tokens)
        recon_loss = mse_loss(reconstructed_3d, ground_truth_3d)
        
        return vlm_loss + lambda_weight * recon_loss

    def generate_inference(self, image, text_prompt):
        # 推理阶段：无需 spatial_encoder 和 ground_truth_3d
        # VLM 自回归生成完整的思维链序列
        generated_sequence = self.vlm.generate(image, text_prompt)
        
        # 解析序列，分离出空间 Token 和最终文本答案
        space_tokens, final_text_answer = self.parse_sequence(generated_sequence)
        
        return final_text_answer
```

### 第二模块：核心架构解释

Latent-to-4D 的核心逻辑在于“解耦与直通”。它将视频生成先验与 4D 几何解码器解耦，同时在数据流上直通隐空间，避免像素级渲染的损耗。

1. **隐变量提取 (Latent Extraction)**：冻结预训练的视频扩散 Transformer 模型，获取其最后一步去噪完成的视频隐变量（Latent），直接丢弃 VAE 的 RGB 解码步骤。
2. **网格对齐 (Grid Alignment)**：将提取到的高维时空隐变量在空间和时间维度上进行重采样或线性投影，使其维度与后置预训练 4D 解码器（如动态 3D 高斯表征）的输入 Token 网格严格对齐。
3. **时空细化 (Spatiotemporal Refinement)**：对齐后的特征输入细化模块。首先通过逐帧空间注意力（Frame-wise Spatial Attention）提取单帧内的几何结构；随后通过全局时空注意力（Global Spatiotemporal Attention）在时间轴上进行信息交互，确保动态几何的时序连贯性。
4. **4D 解码 (4D Decoding)**：将细化后的时空特征输入到预训练的 4D 解码器中，直接回归出显式的 4D 场景参数（如 3D 高斯的坐标、旋转、缩放、颜色及随时间的形变场）。

**核心伪代码实现**：

```python
import torch
import torch.nn as nn

class LatentTo4D(nn.Module):
    def __init__(self, pretrained_4d_decoder):
        super().__init__()
        # 线性投影层，用于对齐隐变量与 4D 解码器的特征维度
        self.alignment_proj = nn.Linear(latent_dim, decoder_token_dim)
        
        # 逐帧空间注意力与全局时空注意力
        self.spatial_attention = SpatialAttention(decoder_token_dim)
        self.temporal_attention = SpatiotemporalAttention(decoder_token_dim)
        
        # 冻结或微调的 4D 解码器
        self.decoder = pretrained_4d_decoder

    def forward(self, denoised_video_latent):
        # denoised_video_latent: [Batch, Channels, Time, Height, Width] 
        # 来自视频扩散模型去噪后的隐变量，未经 VAE 解码为 RGB
        
        B, C, T, H, W = denoised_video_latent.shape
        
        # 1. 维度重排与网格对齐
        # 转换为 [B, T, H*W, C]
        latent_tokens = rearrange(denoised_video_latent, 'b c t h w -> b t (h w) c')
        aligned_tokens = self.alignment_proj(latent_tokens) # [B, T, N, D]
        
        # 2. 时空细化 (Spatiotemporal Refinement)
        refined_tokens = []
        for t in range(T):
            # 逐帧处理空间几何特征
            frame_tokens = aligned_tokens[:, t, :, :] # [B, N, D]
            spatial_feat = self.spatial_attention(frame_tokens)
            refined_tokens.append(spatial_feat)
            
        # 堆叠回时空张量
        refined_tokens = torch.stack(refined_tokens, dim=1) # [B, T, N, D]
        
        # 全局时空注意力，确保时间轴上的物理与几何一致性
        global_feat = self.temporal_attention(refined_tokens) # [B, T, N, D]
        
        # 3. 4D 预测
        # 直接输出显式 4D 表征（如动态 3D 高斯参数）
        dynamic_4d_geometry = self.decoder(global_feat)
        
        return dynamic_4d_geometry
```

### 第二模块：核心架构解释

DURA 的核心逻辑是将对抗补丁的生成转化为一个“攻击引导的去噪问题”。其运行流程分为四个客观步骤：

1.  **初始化阶段:** 将一张视觉自然的干净种子补丁通过 VAE 编码器映射到潜在空间，并向其添加前向高斯噪声至中间时间步 $t_{start}$。此步骤保留了原图的宏观结构，同时为对抗优化提供空间。
2.  **锚点轨迹预计算:** 对加噪后的潜在变量执行标准的 DDIM 去噪，记录每一步的潜在状态作为“干净锚点（Clean Anchor）”。这些锚点用于在后续优化中约束补丁，防止其偏离自然图像流形。
3.  **对抗去噪优化:** 从 $t_{start}$ 开始逐步去噪。在每一个时间步 $t$：
    *   将当前的对抗潜在变量与对应的干净锚点进行线性加权混合。
    *   执行一步标准的 DDIM 去噪。
    *   **方向估计:** 
        *   白盒模式：将当前潜在变量解码并渲染到图像中，输入 VLA 模型，直接反向传播计算目标动作损失的梯度。
        *   黑盒模式：在当前潜在变量周围采样多个高斯扰动，解码并输入 VLA 模型获取动作输出，利用得分函数估计器（Score-function Estimator）近似计算梯度方向。
    *   沿着估计的梯度方向对潜在变量进行对抗更新。
4.  **解码输出:** 经过所有去噪步后，通过 VAE 解码器将最终的潜在变量还原为像素空间的对抗补丁。

**核心伪代码实现 (Python 风格):**

```python
    z_clean_0 = diffusion_model.vae_encode(p_clean)
    z_adv_tstart = diffusion_model.add_noise(z_clean_0, t_start)
    
    # 2. 预计算干净锚点轨迹
    z_anc_trajectory = compute_clean_ddim_trajectory(z_adv_tstart, diffusion_model, t_start)
    
    z_adv_t = z_adv_tstart
    
    # 3. 对抗去噪优化
    for t in range(t_start, 0, -1):
        # 软绑定：与干净锚点混合
        z_mix_t = (1 - alpha) * z_adv_t + alpha * z_anc_trajectory[t]
        
        # DDIM 去噪一步
        u_t_minus_1 = diffusion_model.ddim_step(z_mix_t, t)
        
        # 方向估计
        if mode == "white-box":
            # 白盒：直接计算梯度
            g_t = compute_gradient_via_backprop(u_t_minus_1, vla_model, target_action)
        elif mode == "black-box":
            # 黑盒：得分函数估计 (Score-function estimation)
            g_t = estimate_gradient_via_queries(u_t_minus_1, vla_model, target_action, num_queries=K)
            
        # 对抗更新
        z_adv_t_minus_1 = u_t_minus_1 - step_size * g_t
        z_adv_t = z_adv_t_minus_1
        
    # 4. 解码输出
    p_adv = diffusion_model.vae_decode(z_adv_t)
    return p_adv
```

### 第二模块：核心架构解释

Dreamer-SAC 的核心架构分为四个阶段：多模态编码、隐动力学建模、混合轨迹生成与离策略优化。

1.  **多模态编码 (Multi-modal Encoding)**：将前视摄像头图像通过 CNN 降维，将 LiDAR 与自车状态向量通过 MLP 降维，两者拼接后形成统一的观测表征。
2.  **隐动力学建模 (Latent Dynamics Modeling)**：使用 RSSM 学习环境的确定性与随机性隐状态。模型不仅重构观测，还通过三个独立的预测头输出多目标奖励（连续的驾驶效率、连续的居中保持、离散的终止状态）。
3.  **混合轨迹生成 (Hybrid Trajectory Generation)**：从真实经验回放池中采样真实轨迹，利用其后验隐状态作为起点。在不与真实环境交互的情况下，使用当前 SAC 策略在 RSSM 中向前“想象”固定步长（H=5）的短程轨迹。
4.  **离策略优化 (Off-policy Learning)**：将真实轨迹与想象轨迹合并。真实数据使用标准的 1-step TD 目标进行 Critic 更新；想象数据由于包含立即可用的未来奖励，使用 n-step TD 目标进行 Critic 更新。Actor 则基于混合数据最大化预期回报与策略熵。

**核心伪代码实现**：

```python
def train_dreamer_sac(env, world_model, actor, critic, real_buffer, rollout_horizon=5):
    while training:
        # 1. 收集真实环境数据
        real_transition = env.step(actor.get_action())
        real_buffer.add(real_transition)
        
        # 2. 采样真实数据并更新世界模型 (RSSM)
        real_batch = real_buffer.sample(batch_size)
        world_model.update(real_batch) # 最小化重构、奖励、终止预测损失及 KL 散度
        
        # 3. 生成短程想象轨迹 (Latent Rollouts)
        imagined_buffer = Buffer()
        # 以真实数据的后验隐状态为起点
        for state in real_batch.posterior_states:
            s = stop_gradient(state)
            for k in range(rollout_horizon):
                action = actor.sample_action(s)
                next_s, reward, cont = world_model.predict(s, action)
                imagined_buffer.add(s, action, reward, cont, next_s)
                s = next_s
                
        # 4. 离策略联合优化 SAC
        # 真实数据使用 1-step TD 目标
        critic_loss_real = compute_1_step_td_loss(critic, real_batch)
        # 想象数据使用 n-step TD 目标
        critic_loss_imagined = compute_n_step_td_loss(critic, imagined_buffer)
        
        critic.update(critic_loss_real + critic_loss_imagined)
        actor.update(actor_loss(actor, critic, real_batch + imagined_buffer))
        
        # 清空想象数据，避免使用过时的预测
        imagined_buffer.clear()
```

### 第二模块：核心架构解释

Stream Forcing 的核心在于将离散的训练策略转化为一个连续可导的参数化空间，并在此空间内执行三阶段的课程学习（Curriculum Learning）。

**1. 随机过程重构**
作者使用 Logit-Normal 分布来对每一帧的噪声水平进行采样。该分布由三个核心参数控制：
- 位置参数 $\mu$ 和 尺度参数 $\sigma$：控制单帧噪声分布的均值和方差。
- 时间相关系数 $\rho$：控制相邻帧之间噪声水平的依赖关系。

**2. 三大轨迹约束**
为了让模型从“独立采样”平滑过渡到“渐进采样”，作者设定了三个严格的数学约束：
- **平滑过渡 (Smooth trajectory transition)**：概率密度函数 (PDF) 的峰值位置（Mode）必须匀速移动，防止训练难度突变。
- **一致的单帧覆盖 (Consistent per-frame coverage)**：同一训练步内，所有帧的峰值概率密度必须对齐，防止某些帧被过度训练而另一些帧欠拟合。
- **帧间相关性 (Inter-frame correlation)**：随着训练推进，帧与帧之间的噪声采样必须从完全独立（$\rho=0$）逐渐变为强相关（$\rho \to 1$）。

**3. 训练流程**
- **阶段一：独立训练**。$\rho=0$，各帧独立采样，提供最广泛的噪声覆盖。
- **阶段二：轨迹过渡**。使用联合校准算法（Joint Calibration）计算满足约束的 $\mu$ 和 $\sigma$，并使用高斯 Copula 算法注入 $\rho$，实现平滑过渡。
- **阶段三：推理对齐训练**。$\rho \to 1$，完全对齐推理时的流式渐进噪声调度。

**核心伪代码实现**：

```python
import numpy as np
from scipy.stats import norm

def logit(x):
    return np.log(x / (1 - x))

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def get_mode_location(zeta, sigma):
    # 根据目标峰值位置 zeta 和尺度 sigma 计算位置参数 mu
    return logit(zeta) + (sigma**2) * (1 - 2*zeta)

def joint_calibration(target_modes, init_mu, init_sigma):
    """
    联合校准算法：确保平滑过渡和一致的单帧覆盖
    """
    T = len(target_modes)
    calibrated_params = []
    
    # 1. 计算全局参考峰值密度 H
    densities = [compute_pdf(init_mu, init_sigma, zeta) for zeta in target_modes]
    H = np.median(densities)
    
    # 2. 为每一帧网格搜索最佳的 sigma 和 mu
    for t in range(T):
        zeta_t = target_modes[t]
        best_sigma, best_mu = init_sigma, init_mu
        min_diff = float('inf')
        
        for sigma_cand in np.arange(0.05, 2.0, 0.05):
            mu_cand = get_mode_location(zeta_t, sigma_cand)
            density_cand = compute_pdf(mu_cand, sigma_cand, zeta_t)
            
            if abs(density_cand - H) < min_diff:
                min_diff = abs(density_cand - H)
                best_sigma = sigma_cand
                best_mu = mu_cand
                
        calibrated_params.append((best_mu, best_sigma))
        
    return calibrated_params

def temporal_correlated_sampling(calibrated_params, rho, T):
    """
    时间相关采样算法：使用高斯 Copula 注入帧间相关性
    """
    # 1. 生成具有自回归相关性的标准正态潜变量 z
    z = np.zeros(T)
    epsilon = np.random.normal(0, 1, T)
    z[0] = epsilon[0]
    for t in range(1, T):
        z[t] = rho * z[t-1] + np.sqrt(1 - rho**2) * epsilon[t]
        
    # 2. 通过逆 CDF 映射到目标 Logit-Normal 分布
    noise_levels = np.zeros(T)
    for t in range(T):
        mu_t, sigma_t = calibrated_params[t]
        # z_t 已经是标准正态分布，直接进行线性变换
        y_t = mu_t + sigma_t * z[t] 
        # 映射回 (0, 1) 的噪声水平
        noise_levels[t] = sigmoid(y_t)
        
    return noise_levels
```

```python
    def __init__(self, vla_backbone):
        self.policy = vla_backbone
        self.trajectory_memory = []
        
    def train_policy(self, dataset):
        # 混合数据集训练，使用 prompt 区分数据来源
        for batch in dataset:
            images, proprioception, prompt, target_action_chunks = batch
            predictions = self.policy(images, proprioception, prompt)
            loss = compute_chunking_loss(predictions, target_action_chunks)
            self.policy.update_weights(loss)
            
    def deploy_and_execute(self, env):
        # 真实环境部署
        obs = env.reset()
        trajectory = []
        
        while not env.is_done():
            # 获取多视角图像 (上鱼眼 + 下RGB) 和本体感受
            images = obs.get_four_wrist_camera_views()
            proprioception = obs.get_robot_state()
            prompt = "four-view real-robot deployment"

            action_chunk = self.policy(images, proprioception, prompt)
            
            # 执行动作块
            for action in action_chunk:
                next_obs, reward, done, info = env.step(action)
                trajectory.append((obs, action, next_obs, info))
                obs = next_obs
                if done: break
                
        return trajectory, env.get_outcome()

    def causal_analysis_and_recollect(self, trajectory, outcome):
        # 半自动因果分析闭环
        if outcome == "failure":
            # 人类审查员介入，标记失败的物理原因
            causal_tag = human_reviewer_tag_failure(trajectory)
            self.trajectory_memory.append({"traj": trajectory, "tag": causal_tag})
            
            # 针对性收集新数据
            new_data = collect_targeted_demonstrations(causal_tag)
            return new_data
        return None
```

### 第二模块：核心架构解释

本文的模型架构与实验流程可解耦为三个明确的阶段：数据收集、抓取生成、抓取执行。

**阶段一：多模态数据集收集 (Data Collection)**
作者使用 Apple Vision Pro 对 Unitree H1-2 双臂机器人（配备 Inspire 灵巧手）进行遥操作。记录 15Hz 的多模态数据，包括 RGB-D 图像、双臂及灵巧手的关节角度、手指关节力矩以及触觉传感器信号。通过 SAM (Segment Anything Model) 提取目标物体的 Mask，构建真实世界的数据底座。

**阶段二：抓取姿态生成 (Grasp Generation)**
这是一个基于条件扩散模型的生成过程。
1. 视觉预处理：输入单视角 RGB-D，用 SAM 提取目标 Mask，反投影生成局部 3D 点云。
2. 特征提取：将局部点云输入 PointNet++，提取 1024 维的全局几何特征向量。
3. 扩散生成：以该几何特征为条件，DDPM 从高斯噪声中迭代去噪，输出一个 26 维的向量（包含 2 个 7-DoF 机械臂和 2 个 6-DoF 灵巧手的目标关节角度），最后进行物理限位裁剪。

**阶段三：抓取执行与力觉微调 (Grasp Execution)**
将生成的 26 维静态姿态转化为物理世界的可执行动作。
1. 运动规划：为避免碰撞，规划一条包含“侧向抬起 -> 沿手掌法线后退（预抓取） -> 插入目标位置”的轨迹。
2. 力觉引导微调：到达目标位置后，执行两步闭环控制。首先双臂向内挤压直到被物体物理阻挡；然后各手指独立向内弯曲，直到关节力矩或指尖触觉传感器达到预设阈值，确保稳定接触。

### 第二模块：核心架构解释

TPSP 框架本质上是一个双层优化（Bi-level Optimization）的闭环系统：内层是驾驶策略（Ego Policy）的 PPO 强化学习，外层是场景扰动网络（Scene Perturbation Network）的威胁最大化学习。其核心流程如下：

1. **策略感知场景编码 (Policy-aware Scene Encoder)**：提取自车状态、周围物体状态、道路信息、风险特征，**并拼接当前冻结策略网络的隐藏层特征**。通过注意力机制聚合后，输出融合了物理环境与策略意图的综合表征。
2. **目标场景扰动 (Targeted Scene Perturbation)**：基于上述表征，网络对场景内的所有物体进行危险度打分，筛选出 Top-K 个最关键的物体。随后通过高斯分布采样，生成针对这 K 个物体的速度调整、生成时间偏移，以及自车初始状态的微调。
3. **威胁引导优化 (Threat-guided Optimization)**：使用相同的初始状态和相同的驾驶策略，分别在“原始场景”和“扰动场景”下进行 Rollout（轨迹推演）。计算两者在碰撞、偏离道路、TTC 等维度的“威胁分数差值（$\Delta \xi$）”。
4. **闭环更新**：将 $\Delta \xi$ 作为奖励信号，通过类似 REINFORCE 的策略梯度算法更新场景扰动网络；同时，将收集到的高威胁扰动场景放入经验池，使用 PPO 算法更新驾驶策略。

**核心逻辑伪代码 (Python 风格)**：

```python
def train_tpsp(env, policy, perturbation_net, original_dataset, iterations):
    scene_buffer = []
    
    for i in range(iterations):
        # 1. 采样场景并冻结当前策略
        scenes = sample_scenes(original_dataset, scene_buffer)
        frozen_policy = policy.clone().detach()
        
        # 2. 策略感知与扰动生成
        policy_features = frozen_policy.extract_hidden_states(scenes)
        scene_representations = encode_scene(scenes, policy_features)
        
        # 筛选 Top-K 关键物体并生成扰动参数 (速度, 生成时间, 自车初始状态)
        top_k_objects = get_top_k_objects(scene_representations)
        perturbations, log_probs = perturbation_net.sample(scene_representations, top_k_objects)
        perturbed_scenes = apply_perturbations(scenes, perturbations)
        
        # 3. 收集 Rollout 并更新驾驶策略 (PPO)
        perturbed_rollouts = env.simulate(perturbed_scenes, policy)
        policy.update_ppo(perturbed_rollouts)
        
        # 4. 威胁引导的扰动网络更新
        if should_update_perturbation_net():
            # 在原始场景上做对照组 Rollout
            original_rollouts = env.simulate(scenes, frozen_policy)
            
            # 计算威胁分数差值 (核心创新)
            threat_perturbed = calculate_threat_score(perturbed_rollouts)
            threat_original = calculate_threat_score(original_rollouts)
            delta_threat = threat_perturbed - threat_original
            
            # 优势归一化
            normalized_advantage = normalize(delta_threat)
            
            # 优化扰动网络 (最大化威胁差值)
            loss_pert = - (normalized_advantage * log_probs).mean() - entropy_bonus
            perturbation_net.optimize(loss_pert)
            
            # 5. 维护高威胁场景库
            scene_buffer.update(get_high_threat_scenes(perturbed_scenes, delta_threat))
```
